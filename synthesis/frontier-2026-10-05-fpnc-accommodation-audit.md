# Frontier 2026-10-05 — FPNC Re-audit and Neutral Accommodation

> 状态：supersedes the claim that singularity is conditionally solved without further premise audit.
>
> Core result: two methodological corrections change the current frontier. First, exact-one remains a valid conditional consequence only after an independently owed first-person non-compossibility premise. Second, a candidate completion witness must survive Neutral Accommodation, not merely fail to be entailed by Neutral Actuality.

## 0. Why this frontier reopened

The previous terminal picture was:

\[
NeutralActuality\;|\;CenteredActuality
\]

with centered horn continuing:

\[
ALO+OneWorld+NF+FPNC\Rightarrow ExactlyOneOpening.
\]

That conditional formula remains valid. What was overstated was its interpretation: `FPNC` had not been independently audited, while older project results already showed that perspectival/subjective actuality can pluralize.

At the same time, old CC1 treated:

\[
N\not\models X
\]

as part of a sufficient witness criterion, without explicitly asking whether a still-neutral extension can cheaply explain `X`.

Both issues are now corrected.

---

## 1. Singularity result after audit

List-style first-person facts support a substantive compossibility principle:

\[
Compossible_{FP}(F,G)
\Rightarrow
\exists p\;[ObtainsFrom(F,p)\land ObtainsFrom(G,p)].
\]

For mutually exclusive complete first-person states, this yields non-compossibility.

But moving from this result to the project-wide principle:

\[
DistinctIrreducibleCenters\Rightarrow NonCompossibility
\]

requires accepting that single-perspective co-obtaining is the right compossibility condition for all irreducible openings.

That is exactly where plural standpoint / constitutional perspectival models resist.

Therefore:

\[
\boxed{
USL\ remains\ valid\ conditionally;
FPNC/LFPC\ is\ now\ an\ explicit\ independent\ burden.
}
\]

The project no longer classifies singularity as solved.

---

## 2. Internal consistency check

This downgrade restores consistency with older project results:

\[
Unity\not\Rightarrow SingularityOfSubject,
\]

\[
SubjectiveArity\not\Rightarrow Singularity,
\]

\[
ConstitutionalPerspectivality\not\Rightarrow PerspectiveSingleton.
\]

USL adds a new premise to these older gaps; it does not erase them.

So the proper dependency is:

\[
Arity/Opening
\xrightarrow{+FPNC+NF}
AtMostOne.
\]

The research question has moved from `why exactly one?` to a sharper one:

> Why should irreducible first-person openings obey a single-perspective non-compossibility condition in complete actuality?

## 3. Role-First exact-one bookkeeping

The strongest Role-First model already specifies a unique occupant of the global opening role.

Thus exact-one is primitive inside that model.

USL can only count as a derivational saving if the positive model is first weakened so that the global opening role does not already carry uniqueness.

Otherwise USL is a reconstruction / compatibility result, not an independent parsimony gain.

---

## 4. Old CC1 was too weak

Old witness criterion:

\[
Independent(X)
\land N\not\models X
\land C\models X.
\]

Problem:

\[
N\not\models X
\not\Rightarrow
N\text{ cannot explain }X.
\]

The correct comparison is not bare entailment. It is:

\[
BestCenteredExplanation(X)
\quad vs\quad
BestStillNeutralExplanation(X).
\]

---

## 5. Neutral Accommodation Test

Define `CheapNeutralAccommodation(N,X)` when there is an extension `N+\Delta_N` such that:

1. it explains / predicts `X`;
2. it remains genuinely neutral with respect to global first-person arity;
3. the extension is independently motivated or not strongly ad hoc;
4. its theoretical cost is not clearly worse than the centered distinctive commitment;
5. it does not reintroduce centeredness under another name.

New CC1+:

\[
\boxed{
Independent(X)
\land NaturalFit(C,X)
\land \neg CheapNeutralAccommodation(N,X).
}
\]

The strongest discriminator occurs when Neutral can accommodate `X` only by migrating into centered-equivalent structure.

## 6. Reclassification of old witnesses

Most old candidate families fail even more clearly under CC1+:

- ordinary mineness / immediacy: local-FP neutral absorption;
- presence: relational / B-compatible / stage-based absorption;
- bare actuality: instantiation / uncentered primitive actuality;
- one-world unity: already part of Neutral packages;
- de se / epistemic directness: representation and self-location resources;
- generic causality: can be absorbed unless a centered-specific law is independently forced.

No current candidate reaches the strong accommodation-collapse level.

Thus Completion Underdetermination survives the stricter test.

## 8. New live research questions

### Q1 — FPNC independence

Can first-person non-compossibility be established without defining `absolute` or `nonfragmented` so that plurality is already excluded?

### Q2 — One reality with plural irreducible openings

Can a coherent model contain multiple irreducible perspective modes inside one complete actuality without reducing them to third-person meta-facts?

### Q3 — Accommodation-resistant witness

Is there any independently recognizable `X` that Centered Actuality naturally explains and Neutral Actuality cannot cheaply explain while staying neutral?

### Q4 — Collapse theorem

Can it be shown that any neutral explanation of some `X` necessarily introduces a global first-person role in disguise?

These are now higher priority than accumulating more phenomenology/presence literature.
