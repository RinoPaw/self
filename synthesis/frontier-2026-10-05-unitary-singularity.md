# Frontier — Unitary Singularity

> 日期：2026-10-05
>
> 状态：List quadrilemma + fragmentalism-cost audit 之后的新 endgame。

## 1. 一句话更新

此前：

\[
\boxed{LNP:\ FirstPersonActuality\Rightarrow ExactlyOneLocalRealization}
\]

整体未证明。

现在 singularity 可以拆成：

\[
\boxed{
AtLeastOneIrreducibleOpening
+
OneWorld
+
NonFragmentation
+
FPNonCompossibility
\Rightarrow
ExactlyOneIrreducibleOpening.
}
\]

所以：

\[
\boxed{\text{exact-one need not be independently primitive}.}
\]

---

## 2. List gives the at-most-one machinery

List 2025：

\[
FPR+NonSolipsism+NonFragmentation+OneWorld
\]

mutually inconsistent。

真正驱动结果的是：distinct irreducible first-person facts for distinct centers are non-compossible。

本项目反向使用：

\[
OneWorld+NonFragmentation
\Rightarrow
AtMostOneIrreducibleFPOpening.
\]

---

## 3. Two-Tier escape preserves other minds

本项目不接受 universal List-FPR：

\[
\forall S\,[Conscious(S)\to IrreducibleFPFact(S)].
\]

而保留：

\[
\forall S\;Conscious(S),
\]

\[
\forall S\;LocalFirstPersonOrganization(S),
\]

只对 absolute layer要求：

\[
\exists\sigma^*\;IrreducibleAbsoluteFPFact(\sigma^*).
\]

因此：

\[
\boxed{
GenuineOtherMinds
\neq
PluralIrreducibleSimpliciterCenters.
}
\]

这使 `ordinary FP != absolute FP` 获得一个新的逻辑用途：它允许 Non-Solipsism + One World + Non-Fragmentation 与 singular absolute opening 同时存在。

---

## 4. Fragmentalism remains live, but pays for plurality

plural irreducible centers 若仍放在 one world 内，就必须放弃 standard compossibility / NF。

已审成本：

- List：fragmented world 要显著修改标准 metaphysics / logic / scientific-model world concept；
- Merlo：unstructured fragmentalism 的 Tensed Belief Explosion；
- Lipman 2026：成熟修复需要 internal/external logic、new connectives、standpoint-switching inference、immersive thought、target semantics；
- Ewing 2026：fragmentalism 对 mind-independent passage 并无自动优势；
- relativity audit：invariant structure 表明 fragmentation并非物理学强制结论。

所以：

\[
\boxed{PluralIrreducibleCenters\to FragmentationMachinery\;or\;ManyWorlds.}
\]

这不是 refutation，而是 real architecture cost。

---

## 5. Presence bridge now has a better role

Hare / Conitzer 已给：

\[
PresenceSimpliciter
\to
I\text{-}NOW\ person\text{-}stage\ pressure.
\]

旧问题：presence simpliciter 不推出 unique present。

现在可改成：

\[
PresenceSimpliciter
\to
AtLeastOneIrreducibleOpening,
\]

再用 USL：

\[
AtLeastOne
+
UnitaryReality
\to
ExactlyOne.
\]

因此 Effingham-style multiple presents不再直接击中第一箭头；它成为拒绝 NF / unitism 的竞争 ontology。

---

## 6. Strongest remaining rival inside unitary reality: Universal-I

USL 排除的是：

\[
ManyDistinctIrreducibleCenters
\]

在 one coherent world 中同时 obtain。

它不排除：

\[
\exists!I_U\;\forall e\;ExperienceOf(e,I_U).
\]

所以在 `OneWorld + NonFragmentation + some first-person actuality` 条件下，strongest remaining split 是：

\[
\boxed{
SelectiveOpening
\quad|\quad
UniversalI.
}
\]

### SelectiveOpening

one current stage/path bears absolute opening；other subjects genuinely conscious but not separately simpliciter-centered facts。

### Universal-I

all experiences ultimately belong to one first-person center；local organism boundaries are access/organization boundaries。

因此最新核心不再首先是 “why exactly one?”，而是：

\[
\boxed{\text{why is the one center local/selective rather than universal?}}
\]

---

## 7. Stage-first path burden remains separate

USL 只给 current / mutually exclusive opening singularity。

它不决定：

\[
\sigma_t\to\sigma_{t+1}.
\]

因此：

- Stage-First Opening 仍是 preferred local formulation；
- Path Selection Problem 仍独立；
- Bader/Moorfoot stochastic grounding仍是 current best path schema。

---

## 8. Updated endgame

现在可以把整个 endgame 压成：

### Gate A — At-Least-One

\[
CompleteActuality\stackrel{?}{\Rightarrow}\exists\sigma\;IrreducibleOpening(\sigma).
\]

候选资源：Presence simpliciter / Nagai Opening / NOM / actuality-arity routes。

### Gate B — Unitary Reality

\[
OneWorld+NonFragmentation\ ?
\]

对手：fragmentalism / many-centred worlds。

### Gate C — Singularity

若 A+B + FP non-compossibility：

\[
\boxed{ExactlyOne}
\]

已条件导出。

### Gate D — Locality

\[
OneCenter\stackrel{?}{\Rightarrow}OneLocalStage/Path
\]

对手：Universal-I。

### Gate E — Diachronic path

\[
Open(\sigma_t)\to Succ_O(\sigma_t,\sigma_{t+1}).
\]

候选：stochastic grounding。

所以当前真正未解决的关键已从五个缩成三个 substantive gates：

\[
\boxed{AtLeastOne\quad|\quad UnitaryReality\quad|\quad Locality.}
\]

Singularity本身已有 conditional derivation；path是后续 dynamics。

---

## 9. Current judgement

本轮是正方的真实进展：

\[
\boxed{
\text{Opening singularity no longer needs to be primitive if unitary reality is independently accepted}.}
\]

但这不是 absolute-first-person thesis 的证明。

neutral M3 可拒绝 AtLeastOne；fragmentalist M2 可拒绝 NF；Universal-I 可接受 one center却拒绝 local selectivity。

因此 strongest current comparison：

\[
\boxed{
NeutralRelationalism
\;|\;
FragmentedPluralism
\;|\;
UniversalI
\;|\;
SelectiveOpening.
}
\]

SelectiveOpening 的新优势：在承认 one irreducible first-person actuality 的前提下，它可以与 ordinary one-world compossibility 共存，而无需 plural-fragment machinery。
