# Frontier — Subject Bearer Funnel

> Date: 2026-10-05
>
> Status: post-LUP / PFIP / BDP / CUSP locality frontier.

## 1. One-line update

The old locality premise

\[
SameSubject\Rightarrow OnePhenomenalField
\]

was too strong.

After the subject-ontology and causal-bearer audits, the locality problem is now better represented as a funnel over **what individuates a subject**.

## 2. Current positive decomposition

The project still has:

### ALO

\[
FirstPersonActuality\Rightarrow AtLeastOneOpening.
\]

Still unresolved.

### USL

\[
OneWorld+NonFragmentation+FPNonCompossibility
\Rightarrow
AtMostOneIrreducibleOpening.
\]

Conditionally established.

### Locality

Old LUP is replaced by a layered burden:

#### PFIP

\[
PhenomenalIndividuation
+ MaximalFieldDisconnection
\Rightarrow
NoSinglePhenomenallyConstitutedUniversalSubject.
\]

#### BDP

\[
DisconnectedFields+OneSubjectClaim
\Rightarrow
IndependentBearerDiscriminator.
\]

#### CUSP

\[
CausalUnity
\not\Rightarrow
ExperientialSubjecthood.
\]

Thus a Universal-I spanning disconnected local fields must supply more than global causal or mereological unity.

## 3. Subject ontology comparison

### Phenomenal-field / bundle

Subject identity follows maximal phenomenal organization.

Strength:

- ownership is constitutively explained;
- split-brain / partial-unity structure directly affects subject structure.

Cost:

- boundaries may be vague, overlapping, or non-integer under partial unity.

### Organismic / causal bearer

Subject identity can outrun phenomenal unity.

Strength:

- clear persistence criterion;
- Snowdon-style animalism can coherently retain one subject through split-brain disunity.

Cost:

- experiential ownership becomes derivative from bearer identity;
- organism/system unity does not by itself explain why that system is one experiential subject.

### Primitive bearer

Subject identity is fundamental.

Strength:

- maximally flexible;
- can span disconnected fields without contradiction by stipulation.

Cost:

- requires an assignment principle to distinguish one-bearer from many-bearer models;
- otherwise risks explanatory idleness / relabelling.

## 4. Cosmopsychism does not close the bridge

Priority monism may provide:

\[
OneFundamentalConcreteWhole,
\]

but not automatically:

\[
OneCosmicSubject.
\]

Constitutive cosmopsychism additionally faces the de-combination problem:

\[
CosmicSubject\stackrel{?}{\Rightarrow}LocalSubjects.
\]

So cosmopsychism is a live Universal-I model, not an independent derivation of Universal-I from global causal/mereological unity.

## 5. IIT gives the strongest non-brute discriminator found so far

IIT's exclusion/maximality architecture maps phenomenal axioms to a maximal irreducible physical substrate.

Schematically:

\[
PhenomenalDefiniteness
+ Integration
+ Exclusion
\Rightarrow
MaximalComplex.
\]

This is important because it demonstrates what a serious bearer discriminator can look like: a rule that selects one intrinsic whole and rejects overlapping causally connected supersets/subsets.

But IIT does not support:

\[
UniverseCausallyConnected\Rightarrow UniverseOneSubject.
\]

Its recursive exclusion procedure can instead yield multiple disjoint maximal complexes. A cosmic subject requires the universe itself to satisfy the relevant maximal irreducibility condition.

## 6. Updated Universal-I funnel

A substantive Universal-I now has four routes:

\[
\boxed{
UniversalI
\Rightarrow
\begin{cases}
U_1:& GlobalPhenomenalUnity\\
U_2:& GlobalMaximalIntrinsicIntegration+IdentityBridge\\
U_3:& IndependentGlobalBearerCriterion\\
U_4:& PrimitiveCosmicBearer+AssignmentPrinciple
\end{cases}
}
\]

### U1 — global phenomenal unity

Directly pressured by PFIP if local fields are maximally disconnected.

### U2 — global maximal intrinsic integration

The strongest non-primitive route. IIT provides the clearest model class, but no current result shows that the cosmos wins the maximality competition.

### U3 — independent global bearer

Animalism demonstrates coherence of extra-phenomenal bearer identity locally, but organismic identity does not automatically scale to the universe. Generic causal connectedness is blocked by CUSP.

### U4 — primitive cosmic bearer

Logically hardest to exclude. But BDP demands some assignment principle if the claim is to do explanatory work rather than simply label all experiences “mine”.

## 7. What has actually been gained

The project still has no theorem excluding Universal-I.

However, the rival has lost two cheap moves:

\[
DifferentOrganisms\Rightarrow DifferentUltimateSubjects
\]

was already invalidated by Roelofs / composite-subject possibilities, while now:

\[
OneCausalUniverse\Rightarrow OneUltimateSubject
\]

is also blocked.

The Universal-I must now pay for a **subject-sensitive bridge**.

That is a meaningful locality advance.

## 8. New highest-value question

The live non-primitive horn is:

\[
\boxed{
Can\ any\ plausible\ global\ subject\!\text{-}\!sensitive\ maximality\ criterion\ make\ the\ cosmos\ the\ winning\ subject?
}
\]

Priority order:

1. IIT / intrinsic causal power: conditions for a universal complex; whether exclusion structurally disfavors cosmic overlap.
2. cosmopsychist physical models: whether any actually derive cosmic subject boundaries rather than assume them.
3. holistic / field theories of consciousness: whether global field unity supplies a genuine subject discriminator.
4. if all fail, return to `PrimitiveCosmicBearer + AssignmentPrinciple` and test explanatory equivalence with arbitrary many-bearer assignments.

## 9. Current judgement

\[
\boxed{
Locality\ remains\ unproved,
\ but\ UniversalI\ now\ requires\ a\ nontrivial\ subject\!\text{-}\!individuation\ bridge.
}
\]

The best current positive chain is therefore:

\[
ALO
+ USL
+ PFIP/BDP/CUSP
\Rightarrow
OneLocalOpening
\]

only if the remaining global maximality / primitive-bearer horns can be independently defeated.
