# 当前研究立场

> 状态：工作假说，不视为已证明结论。
>
> 最后更新：2026-10-05。本文件优先于旧 frontier；最新正方前沿见 [`frontier-2026-10-05-self-manifesting-actuality.md`](frontier-2026-10-05-self-manifesting-actuality.md)。

## 1. 核心问题

项目研究比 ordinary first-personhood 更强的可能性：完整现实本身是否具有一个不可继续相对化的、全局唯一的 first-person orientation。

工作表达：

\[
\exists!E^*\;AbsoluteOrientation(E^*).
\]

同时坚持：

\[
\exists S_i\neq S_j\;[Conscious(S_i)\land Conscious(S_j)].
\]

即其他主体必须 genuinely conscious。

当前最重要的纪律是严格区分：

\[
\boxed{
\text{consciousness}
\neq
\text{local first-person organization}
\neq
\text{phenomenal mineness}
\neq
\text{strong FP fact}
\neq
\text{subject-bearing actuality}
\neq
\text{singular absolute orientation}.}
\]

这些层级之间没有哪条桥可以靠术语直接获得。

---

## 2. ordinary first-person axis 与 absolute axis 已彻底分离

ordinary subjectivity 一侧仍有独立问题：

\[
Consciousness
\to
SubjectInvolvement
\to
PhenomenalForMeNess
\to
Me/MineStructure
\to
StrongFPFact
\to
Irreducibility.
\]

其中尤其重要：

\[
\boxed{
IrreducibleFirstPersonRepresentation
\not\Rightarrow
IrreducibleFirstPersonFact.}
\]

Perry-style essential-indexical theory允许 first-person representation 不可消去，同时 truthmaker 仍是 ordinary impersonal fact。List / Lipman 一类理论则把 perspective 推进到 facts / obtaining 本身。

即使 strong FP facts 成立，也还没有得到：

\[
\exists!E^*\;AbsoluteOrientation(E^*).
\]

现在还必须额外区分：即使 actuality 本身带有某种 subjective arity，也未必只有一个 global subject-pole。

所以 ordinary first-person axis、actuality-arity axis、absolute-singularity axis 继续分开研究。

---

## 3. 当前 actuality 理论空间已经三分

此前把 endgame 写成：

\[
\text{Neutral Actuality}
\quad vs\quad
\text{Centered Actuality}.
\]

Whitehead `vacuous actuality` audit 以后，至少要保留三个 distinct packages。

### C0 — Subject-neutral actuality

\[
\boxed{
Complete(R)\land\neg SubjectiveArity(R).
}
\]

成熟邻近 package 包括：

\[
\text{N1 indexical}
\;|\;
\text{N2 instantiation}
\;|\;
\text{N3 fundamental uncentered}
\;|\;
\text{N4 absolute primitive but subject-neutral}.
\]

N4 来自 Bricker-style absolute actuality：actuality 可以同时具有

\[
ABS+PRIM+PERSP+DESE
\]

——absolute、primitive、perspectival，并支持 de se actuality knowledge——同时仍然没有 subject argument。

因此：

\[
\boxed{
ABS+PRIM+PERSP+DESE
\not\Rightarrow
FPAR.
}
\]

这是 **Actuality–Arity Orthogonality**。

### C1 — Plural subject-bearing actuality

Whitehead 提供目前最重要的中间模型。

他直接拒绝：

\[
VacuousActuality
=
Actuality\land\neg SubjectiveImmediacy.
\]

actual entity 被分析成 `subject-superject`；concrete actuality 在体系内包含 experiential / prehensive interiority。

因此可以有：

\[
\forall x\,[ActualEntity(x)\Rightarrow Subjective(x)]
\]

同时：

\[
\neg\exists!s\;GlobalSubject(s).
\]

所以：

\[
\boxed{
ActualityHasSubjectiveArity
\not\Rightarrow
OneGlobalSubject.
}
\]

这就是 **Actuality Arity–Singularity Gap**。

C1 的重要性在于：它能承认现实不是一个完全“死的第三人称清单”，甚至把 interiority 放进 actuality 的 concrete form，同时仍拒绝唯一 absolute first person。

### C2 — Singular centered actuality

当前 strongest positive model 写作：

\[
\boxed{\Omega[R;E^*]}.
\]

其中：

- orientation 与 locus 共同 individuate complete centered totality；
- exact automorphic relabelings quotient；
- 不需要 detachable selector / occupancy primitive；
- `WorldActuality = AbsoluteI = AbsoluteNOW = Ω` 是同一个 centered actuality kind 的不同 aspects。

这使 positive model 比旧 pointer / selector reading 更干净，也削弱 bare-token haecceitistic lottery 批评。

详见 [`../research/models/role-first-absolute-opening.md`](../research/models/role-first-absolute-opening.md)。

## 4. Completion Fork 现在变成两级升级

原二分：

\[
C_N\quad vs\quad C_C
\]

现在需要写成：

\[
\boxed{
C0\to C1\to C2.
}
\]

其中：

### WAAP — Weak Actuality-Arity Principle

\[
\boxed{
CompleteActuality(R)
\Rightarrow
SubjectiveArity(R).
}
\]

它负责：

\[
C0\to C1.
\]

### SAP — Singularity Principle

\[
\boxed{
SubjectiveArity(R)
\Rightarrow
\exists!s\;GlobalSubjectPole(R,s).
}
\]

它负责：

\[
C1\to C2.
\]

### LOC — Localization Principle

即使 C2 成立，项目原始 target 还需要：

\[
\boxed{
\exists!s\;GlobalSubjectPole(R,s)
\Rightarrow
\exists!E^*\;LocalAbsoluteLocus(E^*,s).
}
\]

所以最终正方链现在最准确地写成：

\[
\boxed{
Vacuity
\to
Arity
\to
Singularity
\to
Localization.
}
\]

三关必须分开赢。

## 5. 三条 centered-completion 路线的当前结果

### CC1 — Independent completion witness

此前 tested witness 包括 phenomenal immediacy、mineness、felt presence、why-me、de se、IEM、prudential concern、fission、temporal passage、NOW、one-world unity、modal centeredness、causal structure、manifestation 等。

Whitehead 现在给出一个真正新的 candidate：

\[
\boxed{X=NonVacuousSubjectiveImmediacy.}
\]

如果能证明 subject-neutral actuality只是把 concrete actuality抽空成 bare specification，那么 C0 会失去 complete-actuality资格。

但当前只能说：

\[
WhiteheadPackage\vdash\neg VacuousActuality,
\]

还不能说：

\[
Meaning(Actual)\vdash Subjectivity.
\]

所以：

\[
\boxed{CC1\text{ has a new serious candidate, not yet a surviving witness}.}
\]

### CC2 — Neutral actuality incoherence

Actuality–Arity Orthogonality 仍然给 C0 强反例压力：Bricker-style package 能提供：

\[
ABS+PRIM+PERSP+DESE+\neg FPAR.
\]

Whitehead 则从另一边主张这种 subject-neutral picture 是 `vacuous actuality`，来自把 abstraction 错当成 concrete metaphysical category。

因此 CC2 的 exact fight 现在是：

\[
\boxed{
Vacuous/ThinActuality
\quad vs\quad
SubjectBearingActuality.
}
\]

当前没有：

\[
SubjectNeutralActuality\vdash\bot.
\]

所以：

\[
\boxed{CC2\text{ still fails}.}
\]

### CC3 — Primitive replacement advantage

strongest neutral rival 仍可取：

\[
A_B=\text{Bricker-style absolute primitive actuality without subject arity}.
\]

如果 WAAP 成功，C1 会第一次获得一个 genuine common-job advantage：它可以声称 actuality 的 concrete form 本来就需要 subjective immediacy / interiority。

但 Whitehead 同时阻止 centered side免费拿走这个优势：

\[
\boxed{WAAP\not\Rightarrow SAP.}
\]

也就是说，C1 对 C0 的胜利不会自动成为 C2 对 C1 的胜利。

C2 仍需独立解释：

\[
ExactOneSubject
+
GlobalSubjectUnity
+
Localization.
\]

所以 CC3 当前也没有 decisive replacement win。

---

## 6. Presence / manifestation 路线的地位发生了细化

Fasching / Henry / Hegel 等路线此前主要承担：

\[
Actuality/Presence
\to
Manifestation
\to
Subjectivity.
\]

Whitehead 使这一层获得更 direct metaphysical formulation：

\[
Actuality\to SubjectiveImmediacy
\]

作为 anti-vacuous actuality thesis。

因此 manifestation route 现在不再只是一条 local phenomenology route；它可能真正参与 WAAP。

但旧限制仍然成立：

\[
\boxed{
\text{Phenomenal/Experiential Depth}
\not\Rightarrow
\text{Global Subject Singularity}.}
\]

Whitehead 甚至把这个限制变得更强：subject-bearing actuality 可以直接 pluralize。

所以 presence / manifestation 最多先帮助 C0→C1，不能独立完成 C1→C2。

---

## 7. Epistemic result：evidence no-go 稳定，但 knowledge no-go 需要收窄

真正 self-location 问题仍是：

\[
\boxed{L_{self}=G\ ?}
\]

若普通 evidence 在 coincidence / non-coincidence 下同样可能：

\[
P(e\mid L_{self}=G)
=
P(e\mid L_{self}\neq G),
\]

则：

\[
BF_{=/\neq}=1.
\]

有限 symmetric case 中：

\[
\boxed{P(L_{self}=G\mid e,K)=1/N.}
\]

ordinary first-person evidence 因此不能自动升级成对 absolute-role coincidence 的 near-certainty。

但 Bricker-style epistemology 给出范围校正：

\[
\boxed{SameEvidence\not\Rightarrow SameEpistemicStatus.}
\]

一个 theory 可以让 actuality / absolute-status 本身进入 knowledge 或 entitlement condition，于是 structurally identical subjects 即使拥有相同 ordinary evidence，也可能具有不同 factive epistemic status。

这不会改变：

\[
BF=1.
\]

也不会为 absolute orientation 提供新的 evidential confirmation。它只说明旧结论应精确表述为 **evidential discrimination no-go**。

当前 epistemic options：

\[
\boxed{
\text{silence}
\;|\;
\text{unique signature}
\;|\;
\text{absolute acquaintance}
\;|\;
\text{status-sensitive entitlement}.
}
\]

## 8. 当前 strongest judgement

当前理论空间的最公平排序已经不是简单二选一，而是：

\[
\boxed{
C0:\ SubjectNeutralActuality
\quad|\quad
C1:\ PluralSubjectBearingActuality
\quad|\quad
C2:\ SingularCenteredActuality.
}
\]

现有研究尚未裁决：

\[
C0\quad vs\quad C1.
\]

因为 Whitehead 给 WAAP 严肃 positive support，而 Bricker / Soames / Adams 仍给 subject-neutral actuality coherent-looking alternatives。

但即使未来 C1 战胜 C0，当前也没有理由直接升级到 C2：

\[
\boxed{WAAP\not\Rightarrow SAP.}
\]

因此 Completion Underdetermination 现在被进一步分层：

### Arity underdetermination

\[
SubjectNeutralActuality
\quad vs\quad
SubjectBearingActuality.
\]

### Singularity underdetermination

若 subject-bearing actuality成立：

\[
PluralSubjectBearingActuality
\quad vs\quad
SingularCenteredActuality.
\]

目前 provisional ranking 仍给 weaker commitments 一个 abductive lead：

- 若 WAAP 未建立，C0 相对 C1/C2 更轻；
- 即使 WAAP 建立，C1 相对 C2 仍更轻，因为 SAP/LOC 尚无独立 payoff。

因此当前最稳妥的总原则是：

\[
\boxed{
\text{do not infer singularity from arity, and do not infer localization from singularity}.}
\]

这仍然不是：

\[
\neg AbsoluteOrientation
\]

的证明。

---

## 9. 当前项目已经走到哪里

最初问题：

> 为什么偏偏是这个人、这个时代、这个当前经验？

现在已经拆成三个真正独立的问题：

### Q1 — Vacuity / Arity

\[
\boxed{
\text{Can complete actuality be genuinely subject-neutral / vacuous?}
}
\]

Whitehead 给“不可以”的 strongest current positive model。

### Q2 — Singularity

若 actuality 必须 subject-bearing：

\[
\boxed{
\text{Why must its subjectivity be globally one rather than many?}
}
\]

Whitehead、Lipman、Eker 都使 pluralization 成为 serious option。

### Q3 — Localization

若真的有一个 global subject：

\[
\boxed{
\text{Why must that global subject have exactly one local absolute locus, and why here?}
}
\]

当前几乎没有 independent derivation。

所以项目已从一个模糊的 “why me?” 收缩成：

\[
\boxed{
Vacuity\ ?
\quad\to\quad
Singularity\ ?
\quad\to\quad
Localization\ ?
}
\]

这是目前最清楚的 endgame decomposition。

---

## 10. 接下来只值得沿三条窄路径推进

1. **WAAP / anti-vacuity**：直接比较 Whitehead 的 reformed subjectivist principle、causal efficacy、prehension 与 Bricker/Soames thin actuality；目标是判断 C0 是否真的遗漏 concrete actuality。
2. **SAP / anti-plurality**：寻找任何 independent reason 说明 plural subject-bearing actuality 仍然 incomplete；重点看 absolute idealism、priority monism、global integration / exclusion，而不能只重复“现实是一个整体”。
3. **LOC / localization**：即使 one global subject 成立，也要独立解释为什么存在一个 ordinary local absolute locus，而不是所有 local selves 都只是 manifestations / derivatives。

低收益路线保持降级：重复 local phenomenology、bare selector、death transfer、trajectory、bare duplicate identity。
