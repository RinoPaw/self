## 1. Core target

项目研究 ordinary first-personhood 之外的更强命题：

\[
\boxed{\exists!E^*\;AbsoluteOrientation(E^*)}
\]

同时保留 genuine other minds。

必须严格区分：

\[
Consciousness
\neq LocalFirstPersonOrganization
\neq PhenomenalMineness
\neq IrreducibleFirstPersonFact
\neq AbsolutePrivilege.
\]

普通 for-me-ness、de se、mineness、immediacy 不能直接充当 absolute layer 的证据。

## 2. 当前 theory space：三分

完整 ontology space 至少包括：

### C0 — Subject-Neutral Actuality

现实 genuinely actual，但 actuality 本身没有 irreducible first-person obtaining mode。

可以保留 multiple conscious subjects、local first-person organization、phenomenal mineness、de se 等。

### C1 — Plural First-Person Actuality

现实包含 multiple irreducible first-person modes of obtaining，但没有一个 mode globally privileged。

当前 strongest constructive model：

\[
\boxed{Plural\ Opening\ Manifold.}
\]

### C2 — Singular Centered Actuality

complete actuality 本身具有 one globally privileged first-person opening / orientation。

Role-First Centered Actuality 属于这一类。

因此 original absolute-first-person target 需要连续赢两场：

\[
\boxed{C0\to C1/C2}
\]

建立 actuality-level first-person arity；再：

\[
\boxed{C1\to C2}
\]

建立 singularity / absoluteness。

## 4. Plural Opening Manifold：C1 已获得 explicit model

构造：

\[
\mathcal P=\langle W,C,M,F,A\rangle
\]

其中：

- one objective / causal history \(W\)；
- multiple genuine centers \(C\)；
- multiple irreducible first-person obtaining modes \(M\)；
- one structured fact system \(F\)；
- one actual totality status \(A\)。

核心实例：

\[
m_a\Vdash X,
\qquad
m_b\Vdash Y,
\qquad
X\perp Y.
\]

`m` 属于 fact 的 constitutive obtaining manner，而不是 neutral content 中的 relation argument。

模型当前通过四项压力：

1. 不自动 collapse 为 third-person meta-facts；
2. 不自动 split 成 many actual worlds；
3. 保持 mode-local classical consistency；
4. 与 List quadrilemma 相容——它选择 one-world fragmentalist / pluralist horn。

所以：

\[
\boxed{
OneActuality+PluralIrreducibleFirstPersonModes
\text{ is coherent-looking}.
}
\]

详见 [`../research/models/plural-opening-manifold.md`](../research/models/plural-opening-manifold.md)。

## 5. Singularity chain：从 FPNC 下压到 SPC

### LE — Local Exclusivity

同一个 perspective 不能同时完整处于 mutually exclusive complete states：

\[
X\perp Y
\Rightarrow
\neg\exists m\;[m\Vdash X\land m\Vdash Y].
\]

### SPC — Single-Perspective Closure

若两个 genuine first-person facts globally compossible，则必须能从 one perspective jointly obtain：

\[
Compossible_{FP}(F,G)
\Rightarrow
\exists m\;[m\Vdash F\land m\Vdash G].
\]

所以：

\[
\boxed{LE+SPC\Rightarrow FPNC.}
\]

再加 List-style NF：

\[
FPNC+NF_{SPC}\Rightarrow AtMostOneOpening.
\]

再加 ALO：

\[
\boxed{ExactlyOneOpening.}
\]

因此旧 USL 的 anti-plurality content 主要来自 SPC/LE，而不是 one-world count 本身。

## 6. Singularity chain 继续下压到 MEP

对 List 的 formalization 再审计后，SPC 还可以继续分解。

List 用 first-personally centred world：

\[
\boxed{\langle\omega,\pi\rangle}
\]

作为 first-person fact 的完整 evaluation locus。

这里每个 maximal centered point只有 one perspective \(\pi\)。

定义：

### MEP — Monocentric Evaluation Principle

\[
\boxed{
Every\ maximal\ first\!\!\text{-}\!person\ evaluation\ locus
contains\ exactly\ one\ perspective.
}
\]

标准 centered-proposition semantics 再配合 pointwise/intersection compossibility，会自然给：

\[
\boxed{MEP+IntersectionCompossibility\Rightarrow SPC.}
\]

于是完整 singularity chain 现在写成：

\[
\boxed{
MEP
\to SPC
\to FPNC
\to AtMostOne
\to ExactlyOne\;( +ALO).
}
\]

当前 deepest live burden 因此不再只是 `Why SPC?`，而是：

\[
\boxed{
Why\ must\ complete\ first\!\!\text{-}\!person\ actuality\ have\ a\ monocentric\ maximal\ evaluation\ locus?
}
\]

详见 [`../research/arguments/evaluation-locus-cardinality-gap.md`](../research/arguments/evaluation-locus-cardinality-gap.md)。

## 7. Evaluation-Locus Cardinality Gap

first-person fact 的 perspective variance 表示：

\[
\exists\pi_i,\pi_j\;[V(F,\pi_i)\neq V(F,\pi_j)].
\]

这要求 semantic/metaphysical structure保留 perspective sensitivity。

但它不推出：

\[
ExactlyOnePerspectivePerMaximalActualityState.
\]

因此：

\[
\boxed{
PerspectiveVariance
\not\Rightarrow
MEP.
}
\]

也就是：

- `variance` 决定 evaluation **依赖** perspective；
- `MEP` 决定 complete structure 允许 **多少** perspectives。

这是两个不同问题。

## 8. Polycentric actuality semantics

C1 可以直接表示为：

\[
\boxed{
\mathfrak R=\langle\omega,\Pi,\mathcal V,A\rangle,
\qquad |\Pi|>1.
}
\]

其中：

- \(\omega\)：shared third-person history；
- \(\Pi\)：multiple first-person standpoints；
- \(\mathcal V_{\pi_i}\)：each standpoint's irreducible fact/obtaining structure；
- \(A\)：one actuality status。

这保留：

\[
V(F,\pi_a)\neq V(F,\pi_b)
\]

所以 perspective sensitivity 未丢失。

该结构是否最终只是 third-person collection，仍需独立 collapse theorem；当前没有。

因此：

\[
\boxed{
FirstPersonIrreducibility
+PerspectiveVariance
+OneActuality
\not\Rightarrow
MonocentricActuality.
}
\]

## 9. 两种 unity / non-fragmentation

### NF-L — List / monocentric compossibility

first-person facts若共同属于一个 nonfragmented actuality，必须 one-perspective-co-obtainable。

### NF-M — Mode-Preserving / polycentric global coherence

all facts jointly belong to one structured actuality，但保留 multiple irreducible modes。

所以：

\[
\boxed{OneActuality\not\Rightarrow NF\text{-}L/MEP.}
\]

List 的 quadrilemma 仍有效；C1 明确走：

\[
FPR+NS+OW+\neg NF_L.
\]

当前争点是这种 plural internal structure 是否有 independently unacceptable cost，而不是 bare contradiction。

## 11. Fragmentalism / pluralism 当前评价

C1 是 serious but costly rival。

它可能需要：

- nonstandard global logic；
- standpoint-sensitive inference；
- fact-stack / mode structure；
- protection against explosion / belief pathologies。

但 C2 也有 distinctive costs：

- one global orientation；
- singular privilege；
- global role / occupant structure；
- locality / assignment / dynamics burden。

因此必须做同尺度 comparison，不能把 `fragmented` 当作 `refuted`。
