# 研究前沿快照：Two Architectures for Absolute First-Person

> 日期：2026-10-04
>
> 这是继 `frontier-2026-10-04-anchored-dominance.md` 之后的新阶段快照。

## 1. 当前最大的结构修正

项目此前越来越把 absolute-first-person 的完整理论写成 staged transition：

\[
D
\to
H^*
\to
\mathcal C(H^*)
\xrightarrow{T_{C\to A}}
E^*
\to
LIVE(E^*).
\]

这条路线非常有价值，因为 Hartle–Srednicki、Page、Albert–Loewer 等成熟理论清楚显示：

- complete third-person history 不自动给 self-location；
- psychophysical mapping 不自动给 global singleton；
- per-observer singleton 不自动给 global first-person singleton。

但最新研究发现：这个 staged picture 不是唯一可能的 metaphysical architecture。

---

## 2. Architecture T：Transition Architecture

### 形式

\[
H
\to
\mathcal C(H)
\xrightarrow{T_{C\to A}}
E^*.
\]

### 核心问题

在 multiple real conscious candidates 已经给定后，寻找：

\[
T_{C\to A}:\mathcal C(H)\to E^*.
\]

### 当前主要路线

- structural/global selector；
- generative / grounding asymmetry；
- ontic stochastic actualization；
- nested/global dominance；
- primitive center；
- reject singleton。

### 当前 no-go 压力

- symmetry obstruction；
- locality–duplication no-go；
- local-to-global singleton obstruction；
- rank ties；
- priority–liveness gap；
- selection-process requirement；
- non-factorization / global coupling。

### 最大优点

理论解释目标非常明确：center 的来源必须从 prior structure 得到。

### 最大困难

到目前为止仍没有成熟的 non-solipsistic theory 提供：

\[
\boxed{\text{one global first-person actualization transition}}
\]

并同时解释 LIVE simpliciter。

---

## 3. Architecture C：Constitutively Centered Architecture

### 形式

从一个 complete actual state 开始：

\[
R^*.
\]

它同时具有投影：

\[
P_U(R^*)=H,
\]

\[
P_C(R^*)=\mathcal C,
\]

\[
P_A(R^*)=E^*.
\]

这里 center 不是从 \(H\) 后来生成；\(H\) 反而是把 complete centered reality 的 center-related structure 忘掉后的投影。

### Centered Total State

一个候选表示：

\[
\mathcal C^*
=
\langle W,\Pi,\rho,E^*,\ldots\rangle.
\]

并借 Soames 的 actuality-as-instantiation 模板：

\[
Inst_G(U,\mathcal C^*).
\]

absolute center 是 globally instantiated complete centered state 的 center component。

### 核心直觉

\[
\boxed{
\text{center change}\Rightarrow\text{complete reality change}
}
\]

而非：

\[
\text{same complete reality + different external pointer}.
\]

这正面实现项目早期的重要想法：也许不存在“其余所有完整事实完全相同，只交换绝对第一人称”的两个现实。

### 最大优点

不需要先假定完整现实是 neutral / uncentered，再神秘地选择一个 center。

### 最大困难

Centeredness 可能只是 disguised primitive：

\[
R^*=\langle H,Center=E^*\rangle
\]

若 `Center=E*` 没有更深结构理由，解释只是改变表示方式。

---

## 4. 两条架构共享的 Two-Tier First-Person Realism

无论 T 还是 C，都可以使用两层 first-person ontology。

### Ordinary layer

\[
\forall i\;F_i^{rel}.
\]

所有 genuine conscious subjects 都有真实 local / perspectival first-person facts。

### Absolute layer

\[
\exists!i\;F_i^{abs}.
\]

只有一个 first-person fact 作为 unrelativized / simpliciter centered fact 属于 metaphysical reality。

这忠实表达：

\[
\boxed{
\text{many genuine ordinary first-persons}
+
\text{one absolute first-person}
}
\]

而无需否定 other minds。

---

## 5. Cardinality 的新分解

此前一直寻找一个机制一次性推出：

\[
\exists!E^*.
\]

现在拆成：

### At-most-one

List / Fine 型 first-person fact 的 non-compossibility 加上 coherent single reality，可以原则上推出：

\[
|AbsoluteCenters|\le1.
\]

即：不同 center 的 simpliciter first-person facts 不能在同一个 coherent reality 中共同成立。

### At-least-one + identity

真正困难剩下：

\[
|AbsoluteCenters|\ge1
\]

以及：

\[
Which(E^*)?
\]

Transition architecture 把这交给：

\[
T_{C\to A}.
\]

Centered architecture 把它交给：

\[
Inst_G(U,R^*)
\]

与 centeredness 作为 complete-state structure。

---

## 6. Effingham 的 recombination 压力怎样改变模型

如果 LIVE 被理解成普通 fundamental intrinsic property：

\[
LIVE(E),
\]

metaphysical recombination 会产生多个 bearer 同时 instantiate LIVE 的压力。

因此当前越来越倾向：

\[
\boxed{
\text{absolute first-personhood 应优先建模成 global role / centered fact / complete-state feature}
}
\]

而不是 freely recombinable local intrinsic property。

这样 uniqueness 可以来自：

- compossibility constraints；
- maximal-state incompatibility；
- global relational topology。

而不是额外 brute cardinality clause。

## 7. Soames actuality-as-instantiation 提供的第五种模板

成熟 actuality strategies 此前主要分成：

1. existence asymmetry；
2. frontier / becoming；
3. priority / fundamentality；
4. primitive actuality。

Soames 提供一个重要第五种原型：

\[
Actual(W)\iff Inst(U,W),
\]

其中 actual world-state 是 universe 实际实例化的 maximally informative property。

这提示：

\[
Absolute(E^*)
\]

或许可以通过 complete centered state 的 global instantiation，而不需要 LIVE 本身是 primitive property。

但普通 experience 已经 plural-instantiated，所以 first-person version 需要区分：

\[
Inst_L
\]

与：

\[
Inst_G.
\]

目前 `Inst_G` 仍是候选结构，尚未获得独立本体论说明。

## 8. Absolutization Epistemic Fork

无论 T 还是 C，都面临：absolute status 对 phenomenology 是否有影响？

### Phenomenally active

\[
Absolute(E^*)\Rightarrow\Delta Phen(E^*).
\]

优点：当前 absolute-feeling 可以成为证据；privileged subject 可以有特殊 self-knowledge。

代价：必须找出真正 unique phenomenal signature，并解释为什么其他 ordinary subjects 没有相同 signature。

### Phenomenally inert

\[
Absolute(E^*)\not\Rightarrow\Delta Phen(E^*).
\]

优点：ordinary minds 可以 phenomenal-symmetrical。

代价：内省不能告诉主体哪个 center absolute；当前 absolute intuition 只能作为 motivation，不能当决定性 evidence。

因此：

\[
\boxed{
\text{完全 phenomenal-inert 的 absolute status 无法同时 straightforwardly introspectively evident}
}
\]

---

## 9. 当前 strongest opponent

Pluralist 可以接受：

\[
\forall i\;F_i^{rel}
\]

并拒绝：

\[
\exists i\;F_i^{abs}.
\]

这样可以：

- 保留所有真实 ordinary first-person phenomenology；
- 不需要 global selector；
- 不需要 centered total-state primitive；
- 避免 privilege arbitrariness；
- 与 Process Pluralism 结合，甚至可以给 ordinary liveness 真实生成来源。

所以正方当前不能只展示形式一致性，必须证明或至少说明：

\[
\boxed{
\text{为什么 reality simpliciter 还需要一个 absolute centered layer}
}
\]

---

## 10. 当前真正最深的研究问题

现在可以把整个项目压缩成两种回答方式。

### Derivation Question

\[
\boxed{
\text{What global structure makes exactly one local first-person fact simpliciter?}
}
\]

对应 Architecture T。

### Constitution Question

\[
\boxed{
\text{Is irreducible centeredness a genuine constituent of complete reality, and if so why?}
}
\]

对应 Architecture C。

前者寻找机制；后者质疑机制是否本来就建立在错误的 uncentered-first picture 上。

两条都必须继续与 standpoint / fragmentalist / process pluralism 对打。

## 11. 当前建议的研究优先级

第一优先：继续研究 Centered Total State 能否避免 disguised primitive，尤其比较：

\[
\text{instantiation / obtaining / reality operator / centered facts}
\]

之间的区别。

第二优先：在 Transition Architecture 内继续寻找 genuine global \(T_{C\to A}\)，但不再假设这一定是最终正确架构。

第三优先：加强 pluralist 反方，特别检验：

\[
\forall iF_i^{rel}
\]

是否已经穷尽全部可解释现象。

如果是，absolute layer 的 explanatory necessity 会显著下降。
