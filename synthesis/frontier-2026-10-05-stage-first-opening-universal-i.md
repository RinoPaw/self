# Frontier — Stage-First Opening vs Universal-I

> 日期：2026-10-05
>
> 状态：最新 endgame frontier。
>
> 一句话：`why this one?` 已被拆成更深的 `why only one local opening at all?`；与此同时 Stage-First + stochastic grounding 让 selective route 的 candidate ontology、relativity、fission mechanics明显更成熟。

## 1. Three live architectures

当前不应再把所有正方资源强行串成唯一梯子。

### A — Global Route

\[
Actuality
\to
SubjectiveArity
\to
GEU
\to
GlobalSubject
\to
Localization.
\]

主要资源：Whitehead、Roelofs、Osborn/Goff、Christmann。

主要问题：即使 global subject成立，仍不推出 unique privileged local locus。

### B — Direct Opening Route

\[
\boxed{
World/HistoryActualization
\to
OneAbsoluteI\text{-}NOWStage
\to
OpeningPath.
}
\]

主要资源：Nagai、Conitzer、psychophysical collapse、Halvorson、Bader/Moorfoot。

该 route 不要求先证明 cosmic subject。

### C — Universal-I Route

\[
\boxed{
Experience
\to
UniversalImmediacy/Mineness
\to
OneUniversalI\text{ or universal mine-status}.
}
\]

主要资源：Zuboff、Fasching、Builes 2026。

它直接拒绝 local winner category。

---

## 2. Why Stage-First is now preferred formulation of selective opening

Schwitzgebel–Nelson 2026说明 ordinary subjects未必总能 crisply数成：

\[
1,2,3,\ldots
\]

所以 whole-person selector：

\[
\{S_1,\ldots,S_N\}\to S^*
\]

预设太多。

Conitzer 2020直接给：

\[
\boxed{\text{one distinguished living person-stage}.}
\]

因此 selective target先写：

\[
\boxed{O(w,\sigma^*)}
\]

其中 \(\sigma^*\) 是 localized conscious person-stage / experiential event。

这样：

- 不先要求 persistent subject count crisp；
- `NOW` 内置于 stage；
- 不需要 universe-wide present hypersurface；
- 与 consciousness-driven collapse 的 total-conscious-state-at-a-time unit自然对接。

---

## 3. Candidate Ontology Problem is reduced, not erased

Stage-first不要求：

\[
SubjectCount(R)=N.
\]

但若 conscious stages本身边界 vague：

\[
\Sigma(R)
\]

仍可能不 crisp。

所以：

\[
\boxed{SFO\text{ reduces COP; it does not prove a crisp candidate ontology}.}
\]

---

## 4. Local NOW is enough for core target

Conitzer 的 αA-theory把 I 与 NOW统一为一个 localized person-stage。

因此 core thesis不需要：

\[
AbsoluteNOW=GlobalSimultaneitySlice.
\]

可写：

\[
\boxed{AbsoluteNOW=TimeAspect(\sigma^*).}
\]

这使 relativity 的 no-global-simultaneity objection主要打 stronger global-time variant，而非 core local opening。

---

## 5. Factorization correction remains

UIWO 不能仅靠：

\[
A(w)+P(t)+I(s)
\]

改写成：

\[
O(w,t,s)
\]

就声称 unification。

若：

\[
O(w,t,s)
\equiv
A(w)\land P(t)\land I(s)\land Compat(w,t,s),
\]

则只是 factorized repackaging。

真正 Opening payoff要求：

\[
\boxed{\text{non-factorizable cross-domain constraint}.}
\]

psychophysical collapse给 local prototype：同一 dynamics同时确定 physical outcome + definite conscious state + subject-at-time stage。

---

## 6. Persistence becomes a separate problem

一个 stage-level opening：

\[
O(\sigma_t)
\]

不自动给：

\[
O(\sigma_{t'}).
\]

所以定义：

### PSP — Path Selection Problem

\[
\boxed{
Open(\sigma_t)
+
C^+(\sigma_t)
\to
\exists!\sigma'\;Succ_O(\sigma_t,\sigma').
}
\]

Conitzer 本人列出 single-individual、reincarnation、rapidly-changing I–NOW，直接说明 current stage privilege不决定 movement law。

---

## 7. Bader/Moorfoot upgrade PSP

Bader 2020 stochastic grounding给 exact fission：

\[
A\to B+C.
\]

对称 base可概率性地 ground：

\[
A=B
\]

或：

\[
A=C,
\]

恰一 outcome实际成立，而无需 deterministic tie-breaker。

Moorfoot 2026进一步为 indeterministic building 的 coherence提供系统辩护。

因此 Stage-First Opening可升级：

\[
\boxed{
G_t
\overset{stoch}{\ground}
Succ_O(\sigma_t,\sigma_{t+1}).
}
\]

并形成：

\[
\boxed{\Pi_O=\text{stochastically grounded rooted path}.}
\]

重要结果：

\[
\boxed{\text{exact chancy continuation fact can be derivative, not fundamental}.}
\]

PSP从“只有项目自建 random selector”升级为“有成熟 metaphysical mechanism template”。

---

## 8. But the deeper problem moved earlier: LNP

Builes 2026 / Zuboff / Fasching 提供：

\[
\boxed{\text{Universal-I / Universal Presence}.}
\]

其核心挑战：

\[
\forall e\;Mine(e)
\]

而无需：

\[
\exists!e^*\;Absolute(e^*).
\]

因此 selective theory在问：

> 哪一个 stage？

之前必须先回答：

> 为什么 first-person reality 必须 localize 成 exactly-one stage？

定义：

### LNP — Localization Necessity Principle

\[
\boxed{
FirstPersonActuality(R)
\Rightarrow
ExactlyOneLocalRealization(R).
}
\]

当前：

\[
\boxed{LNP\text{ is unproven}.}
\]

---

## 9. Universalism is serious but not free

Universal-I有两种主要实现。

### U-S — substantive universal subject

\[
\exists!S_U\;\forall e\;ExperienceOf(e,S_U).
\]

压力：Bayne/Dainton-style subject-unity：

\[
SameSubject(e_i,e_j)
\Rightarrow
PhenomenalUnity(e_i,e_j).
\]

跨大量 mutually inaccessible / non-co-conscious fields的 one subject需要拒绝或修正这一传统。

### U-M — universal mine-status without one bearer

\[
\forall e\;Mine(e)
\]

但没有 one substantive owner。

压力：

\[
\boxed{\text{Mine-without-Owner Gap}.}
\]

必须解释 `mine` 如何仍具 singular first-person content。

---

## 10. Immediacy does not settle Universal-I

Guillot：

\[
ForMeNess\neq MeNess\neq Mineness.
\]

Nida-Rümelin / Schlicht给 subject-bearing readings of subjective character / mineness。

因此：

\[
\boxed{UniversalImmediacy\not\Rightarrow UniversalOwnership.}
\]

Universalism需要额外 Subject-Identity Bridge：

\[
\forall e_i,e_j\;S_{e_i}=S_{e_j}
\]

或 equivalent identity thesis。

Sá Pereira 2026更进一步：primitive phenomenal for-me-ness本身也不是已确立的 universal starting point。

所以最新纪律：

\[
\boxed{
Perspective
\neq
PhenomenalMineness
\neq
UltimateOwnership
\neq
AbsolutePrivilege.
}
\]

---

## 11. Strongest exact comparison is now fission

令当前 opening stage：

\[
\sigma_0.
\]

exact fission产生：

\[
\sigma_L,\sigma_R.
\]

### Selective Stage-First Opening

\[
Open(\sigma_L)\oplus Open(\sigma_R).
\]

Bader-style stochastic grounding可给 one-path mechanism。

### Universal-I

\[
Mine(\sigma_L)\land Mine(\sigma_R).
\]

无需 branch selection。

因此 fission现在是两 theory 最清晰的 structural contrast。

但 ordinary evidence可能仍不能 discrimination；这仍是 metaphysical theory comparison。

---

## 12. Current burden map

### Selective Opening

1. **LNP** — 为什么只 localize 一个？
2. **Opening semantics** — 为什么 privileged stage是 actuality-opening，不只是 mark？
3. **COP** — candidate stage ontology多 crisp？
4. **PSP** — opening怎么跨时间延续？
5. **Grounding weights** — stochastic continuation probabilities由什么 independent structure决定？

其中 PSP已有 Bader/Moorfoot 真实机制；其余仍开放。

### Universal-I

1. universal immediacy是否真实；
2. immediacy如何推出 universal mineness；
3. one universal subject如何跨 phenomenal disunity；或 bearerless mine-status如何获得语义；
4. local prudence / agency / memory isolation如何解释。

所以当前没有 cheap winner。

---

旧 map过于线性。

最新版：

\[
\boxed{
FirstPersonReality
\to
\begin{cases}
PluralCentered\\
UniversalI\\
SelectiveOpening
\end{cases}}
\]

SelectiveOpening：

\[
\boxed{
CandidateOntology
\to
LNP
\to
StageOpening
\to
PSP
\to
StochasticGroundedPath.
}
\]

UniversalI：

\[
\boxed{
Immediacy
\to
Ownership
\to
UniversalSubject/MineStatus.
}
\]

Global Route可以为 FirstPersonReality / global unity 提供背景，但不再是 selective opening 的必经前提。

---

## 14. Current judgement

Absolute-local thesis仍 coherent，且 selective architecture比此前成熟：

\[
\boxed{
NomologicalStageOpening
+
StochasticallyGroundedPath
}
\]

已经能避免：

- whole-person candidate-set assumption；
- global simultaneity requirement；
- deterministic fission tie-breaker；
-每个 branch outcome都是 fundamental brute fact。

但目前最深的 open question 已不再是：

\[
\text{why this one?}
\]

而是：

\[
\boxed{\text{why is first-person actuality selective/local at all?}}
\]

这就是最新 frontier。
