# 核心未决问题

> 当前版本：2026-10-05 terminal actuality frontier。
>
> 本文件只列**会改变当前 theory ranking** 的问题。历史 selector、process、symmetry、presence 与 phenomenology 问题继续保留在各 argument/model 文件，不再在这里冒充 active gates。

## 0. 当前 control pair

当前真正的上游竞争是：

### Neutral Actuality

\[
N\text{-}ACT=K+A_N
\]

`K` 已允许：one coherent world/history、multiple genuine conscious subjects、local first-person organization、phenomenal mineness / for-me-ness、de se cognition，以及所有 independently required perspectival / temporal structure。

Actuality 本身保持 first-person-neutral。

### Centered Actuality

\[
C\text{-}ACT=K+\Omega[R;E^*]
\]

这里 `Ω` 是 constitutive role-first centered actuality：world actuality、absolute I 与 absolute NOW 是同一个 centered actuality kind 的 aspects，而非在 neutral world 上后贴一个 pointer。

所以当前首要问题是：

\[
\boxed{Why\ CenteredActuality\ rather\ than\ NeutralActuality?}
\]

## 1. N1 — Independent completion witness

寻找一个可在 contested vocabulary 之外独立指定的事实 `X`：

\[
Independent(X)
\land
N\text{-}ACT\not\models X
\land
C\text{-}ACT\models X.
\]

到目前为止，phenomenal immediacy、mineness、vertiginous why-me、de se、normativity、fission、temporal passage、NOW、actuality/facticity、manifestation 与 `PresenceSimpliciter` 都没有提供 surviving witness。

任何新候选先过 **Interpretation Capture Test**：若 `X` 能完整用 neutral/common vocabulary 描述，只在加入 disputed centered interpretation 后才区分理论，则它不算 independent witness。

## 2. N2 — Neutral incoherence theorem

寻找真正的：

\[
N\text{-}ACT\vdash\bot.
\]

已测试但未成功的方向包括：actuality must be for someone、uncentered actuality collapses into possibility、all local perspectives need an ultimate anchor、one world needs one actuality perspective、actuality must self-manifest、relational presence is incoherent/regressive。

需要的是 contradiction 或严格 incompatibility，不是“我难以想象 uncentered actuality”。

## 3. N3 — Privilege-sensitive evidence

当前 ordinary first-person evidence 对 absolute-role permutations 基本 invariant：

\[
P(e\mid Centered_i)=P(e\mid Centered_j)
\]

且尚没有 established channel 给：

\[
P(e\mid Centered)\neq P(e\mid Neutral).
\]

真正的新 epistemic 进展必须改变 likelihood，而非仅说明若 absolute bearer 存在，它可以用 acquaintance 知道自己。

详见 [`xerographic-discrimination-tests.md`](xerographic-discrimination-tests.md) 与 [`../arguments/absolute-orientation-epistemic-no-go.md`](../arguments/absolute-orientation-epistemic-no-go.md)。

## 4. N4 — Genuine primitive replacement theorem

Centered side最强的非加法式 defense 是：`Ω` 取代 neutral actuality primitive，而不是额外叠加。

真正需要证明的是：neutral theory independently 必须支付一个至少同样昂贵的 primitive `A_N`，而 `Ω` 在共同 explananda 上有严格更好的 compression / integration。

仅比较 primitive 数量 `1 vs 1` 不够；还要比较 primitive content、structural commitments 与 common explanatory work。

## 5. N5 — New global structure

来自 physics / metaphysics 的新结构，只有在**独立进入双方 common core** 后，才可能 naturalize centered completion。

它必须真正带来 first-person arity，而不能只给：unique structural node、causal maximum、largest whole、global subject、one field、one branch 或 stochastic winner。

这里继续执行：

\[
Selection\neq Privileging.
\]

## 6. N6 — Subject-identity theorem that changes locality

若 Centered Actuality 独立成立，USL 已把 exact-one burden 大幅压缩；下一个实质问题是：

\[
ExactlyOneIrreducibleCenter
\Rightarrow ?
\quad
SelectiveLocalOpening\;|\;UniversalI.
\]

Universal-I 目前面对 PFIP、BDP、CUSP、GSM 与 primitive-assignment pressure，但仍未被逻辑排除。

一个真正新的 subject-identity theorem 若能证明 disconnected phenomenal fields 必须或不可能属于同一 numerical subject，会改变 locality ranking，因此仍值得重开。

## 7. Centered horn 内已经较稳定的 conditional architecture

若上游 Centered Actuality 被独立支持：

\[
CenteredActuality\Rightarrow AtLeastOneOpening.
\]

再加：

\[
OneWorld+NonFragmentation+FPNonCompossibility
\]

由 USL 得：

\[
ExactlyOneIrreducibleOpening.
\]

因此 exact-one 不再是独立 active gate。

Locality 解决后，diachronic path 才进入 stochastic grounding / continuation dynamics。除非上游已推进，否则继续优化 trajectory 不改变当前 top-level ranking。

## 8. 默认关闭的旧问题

除非出现比现有 audit 更强的新结果，以下问题不再重复投入：

- structural dominance / causal centrality / information maximum → absolute privilege；
- ordinary first-person phenomenology / mineness → global absolute status；
- bare actuality thickness → first-person arity；
- ordinary temporal phenomenology → `PresenceSimpliciter`；
- semantic irreducibility of tense → monadic presentness fact；
- differential experiential availability → objective presentness；
- self-manifestation bottleneck → unique absolute local locus；
- global subject / cosmic field → unique local opening；
- primitive Universal-I ownership without assignment principle；
- exact-one as a separately brute selector under unitary reality。

## 9. Research stop condition

新工作在进入主线前至少回答一个问题：

1. 它提供新的 independent completion witness 吗？
2. 它证明 neutral actuality incoherent 吗？
3. 它改变 Neutral vs Centered 的 evidence likelihood 吗？
4. 它建立 genuine primitive-replacement advantage 吗？
5. 它把新的 independently motivated global structure加入 common core 并推出 first-person arity 吗？
6. 它实质改变 Universal-I vs local/selective opening 的 subject-identity comparison 吗？

若全部为否，该结果最多是历史补强或 conditional downstream work，不应制造新的 top-level frontier。
