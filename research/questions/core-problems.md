# 核心未决问题

> 更新：2026-10-08；原始问题与历史推导在 [旧 frontiers](../../synthesis/README.md) 及相应 arguments 中保留。  
> 当前基准：[synthesis/current-position.md](../../synthesis/current-position.md)；[依赖图](../DEPENDENCIES.md)。

## 理论空间

- **C0 Subject-Neutral**：一个实际现实 + 多个真实意识主体；actuality 本身无需独立的 first-person mode。
- **C1 Plural First-Person**：一个实际现实 + 多个不可还原的 first-person modes；无全局唯一特权。
- **C2 Singular Centered**：完整现实以唯一 I–NOW global opening 取得 actuality。

C2 必须分别说明 actuality 为什么需要 first-person arity（抗 C0），以及为何必须 singleton（抗 C1）。当前没有任何一方获得决定性排他证明。

## 新工作优先级：B1 explanatory residue

先读 [B1 解释剩余与 Conitzer 案例审计](../arguments/b1-explanatory-residue-audit.md)。C0 可承认全部真实 local phenomenality（**descriptive saturation**），但其本体 grounding 仍需解释。优先寻找：
- C0 B1 的具体 local phenomenal constitution 为什么不足；
- 或一个可在 absolute vocabulary 之外确认的 \(X\)，无法被 C0 / C1 低成本解释。

Mary 的 phenomenal knowledge / ordinary de se 与宇宙的 global winner fact 是不同问题。Conitzer 的已知 external renderer 证明一个**受限模拟基底**有额外 display fact，但不能未经外部机制证据就推到 complete actual world。

[本轮 C0-I/F/Q 构成模型](../models/c0-phenomenal-constitution-packages.md)与[双向对手审计](../arguments/b1-grounding-adversarial-test.md)已给出具体 grounding 候选：I 身份同一，F 基础局部体验，Q 范畴构成。重点是 F 的 bearer-indexed 真实 (P_i) 是否仍必须包含不可还原的 ontic mode。证明缺失的深层解释并不等于证明 C2 global singleton。
## Q1 — 独立 first-person arity

寻找一个在争议术语之外可以识别的 datum \(X\)，证明 C0 的 strongest neutral actuality model 无法合理容纳它。ordinary mineness、self-location、actuality 厚度、现象学强烈感受均未通过。

## Q2 — GCR：global actuality 能否推出单点共真

区分：

\[
MEP\text{-}S\quad|\quad GCR\quad|\quad MEP\text{-}O.
\]

[本轮 GCR defense audit](../arguments/gcr-unity-principle-audit.md) 已确认 one actual world、因果相容与共同 overall truthmaker 并不足以推出 GCR；GCR-2 与 GCR-All 也不等价。[U3 进一步审计](../arguments/co-conscious-unity-to-mode-audit.md) 将 global unity 分成 Cover、MI、Reflection；[U4 进一步审计](../arguments/actuality-quantifier-scope-audit.md) 显式分离 “逐事实有中心” 与 “全体同一中心” 的量词差别。下一步检验 MI/AIM 的**不预置 singleton** 的独立根据。

## Q3 — C1 的双重模型缺口

对 Plural Opening Manifold 分别检查：

- **不可还原性**：从 mode-relative semantics 到 metaphysical irreducible obtaining 的桥梁在哪里？如何排除 genuine neutral reduct？
- **统一与相容**：一个 shared \(W\) 与一个 \(A\) 是否足够？哪些 objective-invariance / cross-mode constraints 必须被显式满足？

[跨 mode SAT / reduct 检验](../models/mode-amalgamation-neutral-reduct.md) 已给出有限相容构造与失败案例，也说明 N0 的弱投影和 N+ 的中立编码都不能决定 ontic reduction。[B1-grounding 审计](../models/neutral-contrast-grounding-audit.md) 将允许 local phenomenality 的强中立基底与 modes 对照；下一步需要非循环的 modal possibility class、hyperintensional grounding 与 compatible constitutional obtaining 理论。

[MI/AIM 最新审计](../arguments/mi-aim-incidence-audit.md) 确认 MI-Share、one actualizer 和 mode→source 反向唯一性都不足以推出 singleton；C2 需要独立的 MI-Excl / AIM-Functionality 以及通往全局事实和 local I–NOW 的后续桥梁。

## Q4 — 独立支持绝对 singleton

任何 C2 witness 需同时抵抗 C0 和 C1。若结论只在加入 SPC、GCR、ALO 或带唯一性的全局 opening 定义后成立，应诚实标为**条件性**结果。

## Q5 — 原始承诺替代与同尺度成本

比较 neutral actuality、plural mode ontology 与 global role-first actuality 在共同 explananda 上的解释收益、primitive content、模态与认识论代价。比较“理论原始项数量”本身不足够。

## Q6 — 下游：局部性与连续性

若 C2 得到独立支持，继续讨论 Selective Local Opening vs Universal-I，以及 stage / temporal trajectory / fission。当前不能把这些细节优化反向计作 absolute existence 的证据。

## 研究停止条件

新工作至少应当：

1. 提供 GCR 或 first-person arity 的非循环论证；
2. 找到 C1 真正不可满足的明确条件，或证成它的独立不可还原性／全局一致性；
3. 发现会同时改变 C0/C1/C2 比较的 evidence 或解释成本；
4. 实质改变经过明确条件化的下游理论结论。

否则应在旧文档补充限定、关系与评价，避免将重复分析包装成新突破。
