# Neutral One-World Baseline (N-W)

> 状态：当前 absolute one-world theory 的**最近反方**。
>
> 核心发现：一旦 A-W 为了保留 one coherent world 而放弃 universal strong FPR，就不能再只和 costly strong pluralism 比。存在一个更近、更便宜的 baseline：保留同样的 other minds、phenomenology、one world 与 non-fragmentation，但不加入 absolute orientation。

## 0. 为什么这个模型之前被漏掉了

当前 endgame matrix 主要比较：

- P-F：strong FPR + fragmentation；
- P-MW：strong FPR + many worlds；
- A-W：weak ordinary FP + one world + one absolute orientation。

这会产生一个误导性的 trade-off：

\[
\text{strong FP equality + fragment/MW cost}
\quad vs\quad
\text{one coherent world + absolute center}.
\]

但 List 的 quadrilemma 本身明确提供第四 horn：

\[
\boxed{\neg StrongFPR+NonSolipsism+NonFragmentation+OneWorld.}
\]

这正是 mainstream one-world consciousness metaphysics 的结构。

因此必须加入：

\[
\boxed{N\text{-}W}
\]

作为 A-W 的 closest foil。

---

## 1. 核心结构

N-W 接受：

\[
\forall i\;Conscious(S_i),
\]

以及：

\[
\forall i\;LocalFPPhen(S_i).
\]

包括：

- real pains / colours / emotions；
- for-me-ness；
- first-personal givenness；
- mineness / self-representation if independently supported；
- memory / agency / lived continuity；
- ordinary self-location。

同时：

\[
OneWorld
\land
NonFragmentation.
\]

但拒绝两项：

\[
\neg UniversalStrongFPR
\]

和：

\[
\boxed{\neg AbsoluteOrientation.}
\]

因此最简形式：

\[
\boxed{
T_{NW}=\langle W,S,P,\rho,\ldots\rangle
}
\]

其中 first-person phenomenology 可以由 phenomenal / relational / representational / acquaintance structure 承担，而 fact inventory 不需要包含 mutually non-compossible strong `I`-facts。

---

## 2. N-W 与 A-W 的差别只剩一项

A-W：

\[
T_{AW}=T_{NW}+\Omega[R;E^*]
\]

在最直接读法下，二者共享：

- same conscious subjects；
- same ordinary phenomenology；
- same physical / causal history；
- same memories / cognition / reports；
- same one-world unity；
- same non-fragmentation；
- same rejection of universal strong FPR。

A-W 唯一新增：

\[
\boxed{\Omega.}
\]

所以对 absolute orientation 的最严格 explanatory-delta test 不该首先比较 A-W 与 P-F/P-MW，而应比较：

\[
\boxed{N\text{-}W\quad vs\quad A\text{-}W.}
\]

---

## 3. Closest-Foil Principle

理论比较应优先找共享最多 commitments 的 competitor。

定义：若：

\[
T_2=T_1+X
\]

并且二者对当前 independently motivated explananda 的预测/解释完全相同，则：

\[
X
\]

承担完整增量负担。

应用到这里：

\[
T_{AW}=T_{NW}+\Omega.
\]

因此 A-W 不能用：

> “pluralism 要 fragmentation / many worlds”

作为对 \(\Omega\) 的直接辩护，因为 N-W 根本不需要那些 machinery。

Fragment/MW cost 只在：

\[
UniversalStrongFPR
\]

被额外设为 non-negotiable 时才进入。

---

## 4. N-W 是否否认 first-person phenomenology？

不。

必须严格区分：

\[
PhenomenalFirstPersonality
\]

和：

\[
StrongFactLevelFPR.
\]

N-W 可以完整接受 Bridge A 的 A0：

\[
Consciousness\Rightarrow ForMeNess.
\]

甚至可以接受丰富的 me-ness / mineness。

它只在 A2 停止：

\[
Me/MineStructure
\not\Rightarrow
StrongFPFact.
\]

所以 N-W 不是 illusionism，也不是 zombie theory。

List 明确把类似路线描述为 analytic philosophy of consciousness 中最常见的 quadrilemma escape：consciousness 仍 real，first-/third-person difference 放在 language / cognition / modes of presentation，而 facts themselves remain impersonal / aperspectival。

---

## 5. N-W 对 A-W 的新压力

此前 A-W 的一项优势是：

\[
OneWorld+NonFragmentation
\]

而 P-F / P-MW 要付架构成本。

N-W 夺走这一优势：

\[
\boxed{
N\text{-}W\text{ has the same one-world coherence without }\Omega.
}
\]

于是 A-W 的正面 case 现在必须完全落到：

1. independent residual fact；
2. independent need for absolute actuality；
3. genuine unification/compression that replaces other primitives；
4. derived reason for \(\Omega\)；
5. 或直接接受 primitive intuition as theoretical commitment。

不能再靠“否则只能 fragmentation/many worlds”。

---

## 6. Absolute-Orientation Erasure 现在有真正 baseline

A-W：

\[
T_{AW}=K+\Omega.
\]

定义：

\[
U_\Omega(T_{AW})=K=T_{NW}.
\]

现在问：删除 \(\Omega\) 后，哪一个 independently identified fact 丢失？

当前 Strong Pluralist Exhaustion Test 已经测试大量候选，但那里的 competitor 太强。

对 N-W 必须重新逐项检查：

- ordinary for-me-ness：保留；
- mineness：可保留；
- I/NOW self-location：保留；
- conscious liveness in ordinary sense：保留；
- world actuality：N-W 直接承认 this world obtains；
- one-world coherence：保留；
- passage：可按独立 time metaphysics 加入；
- other minds：保留。

删除后明显失去的只有：

\[
\boxed{\text{“there is one absolute orientation”}.}
\]

若该 explanandum 只由 A-W 自己 postulate，则触发 explanatory circularity / surplus pressure。

---

## 7. OIP 的替代性解释问题

A-W 可以回应：\(\Omega\) 不只是 additive，它**取代** neutral actuality：

\[
WorldActuality=AbsoluteI=AbsoluteNOW=\Omega.
\]

这比：

\[
Actuality+I+NOW
\]

三个 primitives 更统一。

但 N-W 不必承认：

\[
AbsoluteI
\]

或：

\[
AbsoluteNOW
\]

是 independently established explananda。

甚至不必把 `actuality` 建模成额外 primitive property；它可以只承认：

\[
W\text{ obtains}.
\]

所以 OIP 的 compression benefit 必须按**共同承认的 primitives**计算，不能先加入 absolute I/NOW 再通过 identity 把它们压缩。

这就是 Unification Bootstrapping 在 closest-foil comparison 中的最干净版本。

---

## 8. Current abductive relation

若当前事实是：

1. N-W coherent；
2. Bridge A 尚未迫使 StrongFPR；
3. 没有 independent residual fact 迫使 \(\Omega\)；
4. \(\Omega\) 默认 epistemically inert；
5. A-W 的 why-this-one 停在 brute contingency；

那么在普通理论比较标准下：

\[
\boxed{
N\text{-}W\text{ currently has a prima facie abductive advantage over primitive A-W.}
}
\]

这是**当前研究状态的比较结论**，不是逻辑证明：

\[
\neg\exists\Omega.
\]

A-W 仍完全 coherent。

但它现在清楚地承担：

\[
\boxed{\text{one extra primitive with no currently independent explanatory delta}.}
\]

---

## 9. 什么能让 A-W 重新反超

至少一种以下突破：

### Residual fact

找到：

\[
X
\]

使：

\[
T_{NW}\not\models X,
\qquad
T_{AW}\models X,
\]

且 \(X\) 的识别不预设 Abs。

### Bridge B derivation

找到：

\[
D\Rightarrow\Omega(E^*).
\]

使 \(\Omega\) 不是 arbitrary addition。

### Epistemic signature

找到 non-replicating、truth-sensitive evidence：

\[
Evidence(\Omega(E^*)).
\]

### Genuine replacement

证明 N-W 自己必须 postulate 一个 primitive \(A\)，而 centered \(\Omega\) 能以更低总成本同时承担 \(A\) 和其他 independently needed jobs。

当前四项都未完成。

---

## 10. 对 endgame 的修正

旧三方：

\[
P\text{-}F/P\text{-}MW
\quad|\quad
A\text{-}W
\quad|\quad
D-*.
\]

现在必须加入：

\[
\boxed{N\text{-}W.}
\]

更正确的 baseline 顺序：

\[
\boxed{
N\text{-}W
\longleftrightarrow
A\text{-}W
}
\]

用于测试 absolute layer；

以及：

\[
\boxed{
N\text{-}W
\longleftrightarrow
P\text{-}F/P\text{-}MW
}
\]

用于测试 strong fact-level FPR。

这正好对应两座独立桥：

### Bridge A

\[
Phenomenology\Rightarrow StrongFPR?
\]

### Bridge B

\[
Reality\Rightarrow AbsoluteOrientation?
\]

N-W 是两座桥都回答“No”的交叉点，因此是整个 theory matrix 必不可少的 control theory。
