# Global Singleton Architecture

## 0. 目的

`Local-to-Global Singleton Obstruction` 表明：局部唯一化不能自动升级成全局唯一绝对中心。

因此，当前需要的机制不能只回答“一个主体内部为什么只有一个体验整体”，还必须回答：

\[
\boxed{\text{为什么全部 eligible conscious events 只产生一个 global absolute center}}
\]

这份笔记把候选机制统一到三项任务中。

---

## 1. Three-Requirement Decomposition

一个绝对第一人称模型至少需要完成三件不同的事。

### A. Experience / liveness generation

说明一个意识事件为什么真实存在、为什么具有第一人称显现或 liveness：

\[
G\Rightarrow Live(E).
\]

### B. Global singleton selection

说明为什么在全部候选中只有一个事件获得最终 absolute-center status：

\[
C(\mathcal E_C)=\{E^*\}.
\]

### C. Privilege bridge

说明这个 singleton 为什么拥有真正的形而上特权，而不只是某种数学唯一性：

\[
P(E^*)\Rightarrow Absolute(E^*).
\]

所以完整目标不是单一箭头，而是：

\[
\boxed{
G + C + P
\Longrightarrow
\exists !E^*\;Absolute(E^*)
}
\]

很多现有理论只完成其中一部分。

## 3. 候选 A：Global scalar maximum

设存在一个全局、协变的量：

\[
q:\mathcal E_C\to\mathbb R
\]

并且：

\[
E^*=\operatorname*{arg\,max}_{E\in\mathcal E_C}q(E).
\]

这天然满足 Global Coupling Requirement，因为所有候选都进入同一个比较域。

### 优点

- 数学上最直接；
- 可以非随机地产生 singleton；
- 若 \(q\) 由完整结构定义，可通过自同构测试。

### 困难

1. **Privilege Bridge**：最大值为什么等于 absolute liveness？
2. **Tie problem**：对称结构可产生多个相同极值；
3. **Dynamic jumping**：若 \(q\) 随物理状态变化，absolute center 可能因为别的脑的数值超过当前脑而突然跳转；
4. **Empirical alignment**：没有理由相信“当前经验”恰好是全宇宙某个物理标量的唯一极值；
5. 若 \(q\) 只是为得到当前中心反向设计，则循环。

### IIT 不能直接提供这个答案

IIT 使用 maximal integrated information 解决重叠 candidate substrates 的 exclusion，但 IIT 4.0 会在剩余不重叠 substrate 中继续寻找其他 complexes。

因此把 \(\Phi\) 改造成“全宇宙唯一 absolute-center score”属于新理论，不是 IIT 自身结论。

### 当前判断

**满足 singleton 形式，缺少 privilege 与独立动机。**

---

## 4. 候选 B：Global fundamentality minimum

把 grounding structure 写成：

\[
\mathcal G=(D,<).
\]

现代 grounding 文献允许从 grounding relation 构造 relative fundamentality / rank。

若意识事件子集 \(\mathcal E_C\subseteq D\) 中存在唯一最基础元素：

\[
E^*=\operatorname*{arg\,min}_{E\in\mathcal E_C}rank_{\mathcal G}(E),
\]

则同时得到：

- 一个 global comparator；
- 一个 singleton candidate；
- 一个已经具有独立本体论意义的 priority relation。

这比普通 scalar maximum 强，因为 rank 不是单纯统计特征，而来自解释/依赖结构。

### 主要困难

- 为什么 grounding structure 在全部 first-person facts 间可 totalize；
- 为什么存在唯一 experiential minimum；
- 为什么当前这个具体事件是 minimum；
- 静态 rank 很难解释 NOW 的移动；
- 若 rank 动态变化，Moving Fundamentality 问题返回。

### 当前判断

\[
\boxed{\text{目前最强的 global singleton + privilege 候选}}
\]

但它仍缺 liveness generation 与动态模型。

---

## 5. 候选 C：Experiential Dominator / Bottleneck

Grounding structure 可以进一步给出一个比“最低 rank”更强的拓扑条件。

设 \(B\) 是 fundamental base，\(\mathcal E_C\) 是 experiential nodes。

定义一个候选事件 \(E^*\) 为 **experiential dominator**：对任意其他 experiential fact \(F\)，从 fundamental base 到 \(F\) 的所有 grounding paths 都必须经过 \(E^*\)。

粗略写成：

\[
\forall F\in\mathcal E_C\setminus\{E^*\},
\quad
\forall \pi:B\leadsto F,
\quad
E^*\in\pi.
\]

若这样的节点唯一，则 \(E^*\) 是全部 subjectivity 的一个 global metaphysical bottleneck。

### 为什么它值得研究

这里 singleton 并非来自任意打分；它来自整个 grounding topology。

并且 \(E^*\) 的 privilege 有独立含义：没有它，任何 derivative experiential fact 都无法在 grounding hierarchy 中得到实现。

### 严重代价

这会要求其他主体的 first-person facts 在非常强的意义上依赖 \(E^*\)。

它容易滑向：

\[
\text{当前绝对经验是全部其他经验的形而上中介}
\]

目前没有独立理由接受这一点。

若把 dominator 从单个事件改成轨迹：

\[
\Gamma^*\subset\mathcal G,
\]

并让所有 experiential grounding paths 经过 \(\Gamma^*\)，可以得到 **experiential backbone** 模型，但当前时刻仍需额外处理。

### 当前判断

**结构上很强，解释负担也极高。值得保留为精确测试模型。**

## 6. 候选 D：Global self-manifestation operator

局部 self-manifestation 容易复制：每个体验都可以 first-personally manifest itself。

为了得到 absolute center，需要把 operator 提升到现实总体：

\[
T_{\mathcal R}:\mathcal E_C\to\mathcal E_C.
\]

若存在唯一 fixed point：

\[
T_{\mathcal R}(E^*)=E^*,
\]

且 \(T_{\mathcal R}\) 表达的不是普通 self-model，而是“完整现实通过哪个 experiential locus 对自身显现”，那么可能得到：

\[
\text{global self-manifestation}\to E^*.
\]

### 邻近思想

- Hegel 的 absolute self-consciousness；
- Michel Henry 的 Absolute Life / auto-affection；
- cosmopsychist 的 cosmic consciousness。

这些理论证明“现实/绝对具有自显现结构”是成熟哲学主题。

但现有版本通常允许：

\[
\text{one deeper source}\to\text{many finite manifestations}.
\]

因此它们没有直接给出本项目要求的 singleton locus。

### fixed point 的限制

即使数学上能保证唯一 fixed point，也仍只有：

\[
\text{structural uniqueness}.
\]

除非 `self-manifestation` 本身具有足够强的本体论含义，否则 Privilege Bridge 仍未完成。

### 当前判断

**有统一潜力，但最容易把 LIVE 偷偷塞进 operator 定义。**

## 7. 候选 E：Covariant distinguished role

Causal set theory 中的 `post` 提供一个重要先例。

一个 post 是与 causal set 中所有其他元素都可比较的元素。某个 causal set 是否包含 post 是 labeling-independent / covariant 的问题。

这说明：

\[
\boxed{\text{相对论式 partial order 并不禁止存在协变定义的 distinguished event}}
\]

真正被禁止的是用任意 birth label / gauge choice 制造特殊性。

### 对本项目的启发

可以寻找一种 experiential analogue：

\[
P(E^*)\iff
E^*\text{ 在某个全局不变量关系中与所有 experiential candidates 相联系}.
\]

如果 \(P\) 有唯一解，则可以在不引入绝对坐标的情况下得到 distinguished event。

### 直接 causal-post 方案失败

若要求当前意识事件在普通因果关系上与所有其他意识事件可比较，则 spacelike-separated 其他主体会立即违反条件。

因此真正有希望的 relation 更可能是：

- grounding / fundamentality；
- global dependence；
- self-manifestation；
- 其他超出普通 spacetime causal order 的协变关系。

### 当前判断

**给“如何在 partial-order 世界中非 gauge 地选特殊事件”提供了重要方法论先例，但还没有 experiential relation。**

## 8. 候选 F：Primitive global exclusion

最简单的规则：

\[
\exists !E^*\;LIVE(E^*).
\]

或者直接加入：

\[
GlobalExclusion(\mathcal E_C,E^*).
\]

它当然解决 singleton。

但若 `GlobalExclusion` 没有更深来源，它只是把 absolute first-person 写成一条新定律。

### 当前判断

**一致性终点可以保留，解释性研究暂不在这里停止。**

## 9. 当前最有希望的组合

单个候选都不完整。

目前最自然的组合是：

### Fundamental process + global fundamentality order

1. 一个 genuine becoming/process \(G\) 解释 live experience 的生成；
2. 一个全局 grounding/fundamentality structure \(\mathcal G\) 把全部 eligible live events 放进同一 priority relation；
3. 在每个真正 relevant stage / structure 中有唯一最基础 experiential event：

\[
E^*=\operatorname*{arg\,min}rank_{\mathcal G}(E);
\]

4. `fundamentality` 提供 Privilege Bridge。

形式：

\[
G\Rightarrow Live(E_i)
\]

\[
\mathcal G\Rightarrow E^*
\]

\[
Live(E^*)\land Fundamental(E^*)
\Rightarrow Absolute(E^*).
\]

### 尚未解决

- becoming 与 grounding 怎样属于同一个 ontology；
- `stage` 是否重新引入 meta-time；
- rank 为什么唯一；
- current event 为什么恰好最 fundamental；
- relativistic / gauge implementation；
- reality monism 是否成立。

因此它仍是研究架构，不是答案。

---

## 10. 新的最小成功条件

现在一个 singleton manifestation mechanism 至少需要：

1. **Generation**：解释 ordinary liveness；
2. **Global coupling**：所有 absolute-eligible events 进入同一非因子化结构；
3. **Unique solution**：真正得到一个 event / trajectory；
4. **Covariance / invariance**：不依赖 gauge labels；
5. **Privilege bridge**：winner 的结构角色本身具有形而上意义；
6. **Other minds remain real**：不能靠取消其他意识获得唯一性；
7. **I–NOW compatibility**：最终能解释当前性和主体性；
8. **No meta-level relocation**：不能把原问题搬到新的 selector / stage / parameter。

下一步优先研究：

\[
\boxed{\text{global fundamentality rank 与 experiential dominator 是否能真正非循环地产生 singleton}}
\]
