# Global Center Relation：非 primitive 绝对中心的目标规格

## 0. 为什么需要这个对象

经过当前几轮筛选，正方同时受到两道夹击。

### Locality–Duplication No-Go

任何只依赖可复制 local / event-relative profile 的统一规则，在精确复制处必须给出同样的 LIVE 值。

### Global-to-Center Gap

一个 global world / history / cosmos / process 即使具有唯一 actuality 或 fundamentality，也不会自动把这种地位传递到一个局部意识事件。

因此，如果绝对第一人称实在论成立，同时拒绝 primitive pointer，成功理论需要一种此前没有单独命名的结构：

\[
\boxed{\text{Global Center Relation}}
\]

暂记：

\[
R_G(\mathcal R,E).
\]

它直接把完整现实的全局结构与某个 consciousness event 联系起来。

---

## 1. 最小目标

需要存在唯一：

\[
\exists !E^*\in\mathcal E_C:\;R_G(\mathcal R,E^*).
\]

并且该关系足以承担：

\[
R_G(\mathcal R,E^*)
\Longrightarrow
LIVE(E^*).
\]

这两个条件分别处理：

\[
\text{Center Uniqueness}
\]

与：

\[
\text{Privilege Bridge}.
\]

仅满足其中一个都不够。

---

## 2. 七项硬条件

### G1. Globality

\(R_G\) 必须能够访问足以区分局部精确复制体的全局结构。

若：

\[
N(E_a)\cong N(E_b),
\]

仍应允许：

\[
R_G(\mathcal R,E_a)\neq R_G(\mathcal R,E_b)
\]

但这种差异必须来自真实全局关系，而非坐标标签。

### G2. Structural invariance

关系必须尊重完整现实的物理 / 形而上同构与 gauge equivalence。

若：

\[
f:\mathcal R\cong\mathcal R',
\]

则应满足相应的等变条件：

\[
R_G(\mathcal R,E)
\Longleftrightarrow
R_G(\mathcal R',f(E)).
\]

不能用 representation-dependent address 偷偷制造中心。

### G3. Singleton extension

在实际完整现实中：

\[
|\{E\in\mathcal E_C:R_G(\mathcal R,E)\}|=1.
\]

全局关系若自然落在一整个 hypersurface、frontier、branch 或 subject family 上，仍然失败。

### G4. Privilege relevance

\(R_G\) 本身必须具有独立的 actuality / grounding / generation / ontological-priority 意义。

需要说明：

\[
R_G(\mathcal R,E)
\]

为什么与：

\[
LIVE(E)
\]

相关，而不只是把 \(E\) 唯一编号。

这是 Global Relevance Requirement 的核心。

### G5. Non-circularity

不能定义：

\[
R_G(\mathcal R,E)\iff E\text{ 是绝对第一人称}.
\]

也不能把同一内容换成 `chosen`、`actual channel`、`special root` 等词后当作解释。

### G6. Scale match / privilege localization

若全局结构先给出一个 privileged bearer \(X^*\)，还需要一个非任意关系把其特权定位到 \(E^*\)：

\[
P(X^*)\land R_G(X^*,E^*)
\Longrightarrow LIVE(E^*).
\]

单独的：

\[
P(X^*)
\]

不够。

### G7. I–NOW compatibility

关系的目标应该是 event-level：

\[
E^*=(C,p),
\]

从而同时允许主体维度与当前时刻维度进入理论。

只选择 world、time slice、worldline 或 subject 都没有完成当前目标。

## 3. 次级条件

### 相对论 / gauge

尽量以 covariant / invariant 结构表达；若引入 preferred foliation、hidden total order 或 absolute coordinate，需要独立物理理由。

### 多元宇宙扩展

若 domain 扩展为多个 disconnected universes，不能自动得到“每宇宙一个”。理论必须明确 \(\mathcal R\) 的最大 domain 与 \(R_G\) 的作用域。

### 认识论接口

如果 \(R_G\) 对 phenomenal structure 完全没有影响，则从当前第一人称体验到该结构的证据链会很弱。

这不是存在条件，但会显著影响理论的可支持性。

## 5. Uniqueness–Privilege Orthogonality

表格揭示了当前最稳定的模式：

\[
\text{U-mechanisms}
\]

擅长制造 singleton，却缺少 actuality / liveness 意义；

\[
\text{P-mechanisms}
\]

擅长提供 grounding / becoming / actuality，却自然作用于 whole、history、frontier 或多个 manifestations。

成功的 \(R_G\) 必须把二者非偶然地耦合：

\[
\boxed{U+P\text{ must arise from one explanatory structure}}
\]

而不能：

\[
D_U + D_P + \text{ad hoc bridge}.
\]

否则新的 bridge 本身会成为原问题的新名字。

## 6. 当前最值得检验的关系族

### A. Whole-to-part grounding relation

不是单纯问 cosmos 是否 fundamental，而是寻找：

\[
Grounds_{whole}(X^*,E)
\]

是否可能在 consciousness domain 上只有一个具有特殊 grounding role 的局部事件。

主要压力：priority cosmopsychism 通常得到多个 local subjects。

### B. Boundary-to-event constitutive relation

全局边界 / boundary condition 不只是产生时间箭头，而直接 constitutively determine 某个 event-level closure：

\[
Boundary(\mathcal R)\Rightarrow Closure(E^*).
\]

必须避免所有 boundary events 共同满足同一条件。

### C. Global closure relation

让 \(E^*\) 成为完整现实中一个不可复制的 relational closure / fixed point / root。

但 `closure is unique` 还没有自动得到 `closure is LIVE`；需要额外 privilege bridge。

### D. Actual-history-to-center relation

一个 single actual history 已经带 actuality。需要研究 history 内是否存在不依赖 indexical pointer 的关系：

\[
R(H_{actual},E^*)
\]

能够唯一继承 actuality。

这是目前最直接符合 G4 的路线之一，同时也是最容易遭遇 Global-to-Center Gap 的路线。

### E. Global generative channel

不是把整个 process 当作 actuality bearer，而是让 process 的生成结构本身形成唯一 experiential channel：

\[
G\Rightarrow\Gamma^*\Rightarrow E^*.
\]

其关键任务是证明 channel uniqueness 来自 covariant process law，而非 hidden total birth order。

## 7. 当前“针眼”结论

若同时坚持：

1. absolute center 全局唯一；
2. 不使用 primitive haecceity / pointer；
3. local exact duplication 原则上允许；
4. privilege 需要解释来源；
5. 相对论 / gauge 结构不能被随意破坏；

那么理论搜索空间被压缩为：

\[
\boxed{
\exists !E^*:\;R_G(\mathcal R,E^*)
}
\]

其中 \(R_G\) 必须同时是：

\[
\text{global}
+\text{invariant}
+\text{center-localizing}
+\text{privilege-bearing}
+\text{non-circular}.
\]

这就是当前项目下一阶段真正要寻找的数学 / 形而上对象。

如果长期搜索后所有候选都只能落入“局部可复制”“全局但无法定位”“可定位但无 privilege”“primitive center”四类，standpoint/process pluralism 会得到越来越强的优势。
