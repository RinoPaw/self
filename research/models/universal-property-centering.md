# Universal-Property Centering

> 状态：建设性研究模板。它不是具体 ontology，而是 `Centered Total State` 在避免 primitive center 后留下的最干净正向方向之一。

## 0. 核心想法

“distinguished point” 不必等于 “primitive chosen point”。

一个对象可以因为满足独立结构中的唯一角色而成为 distinguished。

简单数学类比：群的单位元 \(e\) 不是靠外部 pointer 任意指定；它由群运算满足：

\[
\forall x,\quad e\cdot x=x\cdot e=x
\]

唯一确定。

因此 absolute center 若能获得类似解释，理想形式不是：

\[
Center=E^*
\]

作为额外 slot，而是存在 independently motivated relation / algebra：

\[
\mathfrak R
\]

使：

\[
\boxed{E^*\text{ 是 }\mathfrak R\text{ 中满足某个 universal property 的唯一 experiential event}}
\]

---

## 1. 形式模板

给完整 relevant structure：

\[
\mathcal R=\langle X,Rel_1,Rel_2,\ldots\rangle
\]

其中 conscious events 构成：

\[
\mathcal E_C\subseteq X.
\]

定义一个与 `Absolute` 概念独立的条件：

\[
Q_{\mathcal R}(E).
\]

要求：

\[
\exists!E^*\in\mathcal E_C\;Q_{\mathcal R}(E^*).
\]

并且 \(Q\) 具有三项独立内容：

1. **structural**：由 \(\mathcal R\) 的关系定义；
2. **global**：不是每个 local domain 都能各自实例化同一个角色；
3. **first-person relevant**：该角色本身涉及 manifestation / grounding / actuality，而非任意地址。

若满足，则可以定义：

\[
Center(\mathcal R)=E^*.
\]

此时 centeredness 是 derived distinguished role，而非 primitive basepoint。

---

## 2. 与 Structural Selection 的关系

该模板承认：成功后形式上确实存在：

\[
\sigma(\mathcal R)=E^*.
\]

所以它属于 Structural Selection。

这不是缺点。

真正关键的改进是：selector 不再是任意 score / pointer，而是来自一个 independently motivated universal role。

因此目标从：

\[
\text{invent a selector}
\]

变成：

\[
\boxed{\text{discover a metaphysically meaningful universal property}}
\]

---

## 3. 候选 universal roles

### A. Root

存在唯一 experiential root：

\[
\forall F\in\mathcal E_C,\quad E^*\leadsto F.
\]

若箭头表示 grounding / generative dependence，则 \(E^*\) 是所有 subjectivity 的 root。

风险：容易滑向“其他 minds 由当前 experience grounding”的极强学说。

### B. Dominator / bottleneck

所有从 fundamental base 到 experiential facts 的 path 都经过：

\[
E^*.
\]

比 root 更结构化，但仍有 de-combination / other-minds pressure。

### C. Terminal manifestation locus

所有 global manifestation arrows 最终在一个 experiential locus 收敛：

\[
\forall x\in X_{manifest},\quad x\to E^*.
\]

风险：content explosion 与 cosmic-subject pressure。

### D. Unique fixed point

存在 global operator：

\[
T_{\mathcal R}:\mathcal E_C\to\mathcal E_C
\]

且：

\[
T_{\mathcal R}(E^*)=E^*
\]

为唯一 fixed point。

风险：若 \(T\) 只是为了得到当前 center 反向设计，则循环；若每个 subsystem 都有 fixed point，则 local-to-global obstruction 返回。

### E. Global section / anchoring compatibility

perspectival structures形成某种 bundle-like system；一个 global section：

\[
s^*
\]

同时满足所有 anchoring / compatibility constraints，并在某个 event 上给出唯一 absolute locus。

这是目前较抽象但值得探索的方向，因为它可以把 `center` 当作全局 consistency solution，而非单点打分。

风险：必须说明 section 的 first-person / actuality 意义。

---

## 4. Universal-Property Adequacy Test

一个候选 \(Q\) 必须通过：

### Independence

\[
Q(E)\not\equiv Absolute(E).
\]

### Uniqueness

\[
\exists!E\;Q(E).
\]

### Globality

不能存在多个独立 domain 各有自己的 `Q-winner`，除非只有 top-level role 对 absolute status relevant。

### Covariance

若 \(g\) 是 relevant isomorphism / gauge transformation：

\[
Q_{g\mathcal R}(gE)\leftrightarrow Q_{\mathcal R}(E).
\]

### Non-haecceitism

不能靠 proper name / thisness / coordinate label 定义。

### Privilege relevance

必须有独立理由支持：

\[
Q(E^*)\Rightarrow LIVE_{simpliciter}(E^*).
\]

这是最难一项。

## 5. 为什么 causal-set post 是重要方法论先例

causal-set `post` 表明，在不依赖 arbitrary labeling 的 partial-order structure 中可以存在一个 globally distinguished element。

它说明：

\[
\boxed{\text{covariance does not forbid distinguished events}}
\]

真正的问题是找到适合第一人称的关系。

普通 causal comparability 不行，因为多个意识事件可 spacelike-separated。

但 grounding / manifestation / anchoring compatibility 等非时空关系仍可继续研究。

---

## 6. 对 Centered Total State 的意义

若找到合格的 \(Q\)：

\[
E^*=\iota E\,Q_{\mathcal R}(E),
\]

则 centered total state 可写成：

\[
\mathcal C^*=\langle\mathcal R,E^*\rangle
\]

但 center component 已经是 redundant / derived structure：

\[
E^*=Center(\mathcal R).
\]

此时 CTS 的价值主要在完整状态表示与 actuality semantics，而 center 来源由 universal property 解释。

如果找不到 \(Q\)，CTS 继续停在 primitive centeredness。

---

## 7. 当前最值得尝试的具体版本

下一步优先比较：

1. **global grounding section**：所有 ordinary perspectival facts 的 grounding / anchoring relations 是否存在唯一 global compatibility solution；
2. **manifestation bottleneck**：是否有非 cosmic-subject 的唯一 manifestation locus；
3. **dynamic universal role**：\(Q\) 是否可随 genuine becoming 变化，形成 \(\Gamma^*\)，同时不需要 meta-time；
4. **two-level role**：local contexts 给普通 centers，global universal property 只给其中一个已有 local event 一个 additional actuality role。

理想结果是：

\[
\forall i\;LocalFP(E_i)
\]

同时：

\[
\exists!E^*\;Q_{\mathcal R}(E^*).
\]

再证明：

\[
Q_{\mathcal R}(E^*)\Rightarrow AbsoluteFP(E^*).
\]

这比直接把 `center` 写入 complete state 更有解释内容。
