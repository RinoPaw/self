## 当前主线

- **C0**：neutral actuality 是否足够完整？见 [neutral actuality](models/neutral-actuality-core.md)。
- **C1**：多个不可还原第一人称模式如何共同属于一个现实？见 [plural opening manifold](models/plural-opening-manifold.md)。
- **C2**：为什么存在一个唯一特权中心？见 [role-first absolute opening](models/role-first-absolute-opening.md)。

- **证据约束**：支持 C2 需同时处理 C0 和 C1；见 [non-singular accommodation](arguments/neutral-accommodation-test.md)。

## 读旧稿的规则

`research/` 是**论证档案**，文件越多不表示某个观点证据越强。

- 推导可在显式前提下有效，但前提未必得到独立支持。
- 反模型展示推论缺口，不自动证明模型所含 primitive 在现实中成立。
- `frontier` / `handoff` 的时效信息统一在 [synthesis](../synthesis/README.md)；旧论证遇到冲突时按该目录的 authority 阅读。

新增研究请遵守 [根目录 AGENTS.md](../AGENTS.md) 的状态与证据规则。
