# Global Closure Construction Test

> 状态：2026-10-05 GEUP constructive audit；已纳入 Mørch overlap audit。
>
> 目标：把 `SubjectiveArity -> GlobalExperientialUnity` 拆成可检验的 sufficient packages，并明确 global closure 对 subject ontology 的额外成本。

## 0. Target

无条件 GEUP：

\[
GEUP:\quad SubjectiveArity(R)\Rightarrow GlobalExperientialUnity(R)
\]

仍然太强，因为 Whitehead / IIT / plural standpoints给直接 countermodels。

本轮寻找：

\[
SubjectiveArity+X\Rightarrow GEU/GlobalSubject.
\]

目前有两条主要 constructive route：

1. **composition-first**：Osborn/Goff universalism；
2. **field-first**：Roelofs continuism。

---

## 1. Route A — Universal Subject Composition

令 \(B\) 是 jointly exhaustive 的 fundamental subjects。

### A1 — Cosmic fusion

\[
C=\bigoplus B.
\]

### A2 — Subject universalism

\[
\forall \Gamma\subseteq Subjects,
\quad Subject(\bigoplus\Gamma).
\]

于是：

\[
\boxed{Subject(C).}
\]

若 classical extensional mereology保证 total concrete fusion唯一，并且 every subject is concrete / part of C，则：

\[
\boxed{C\text{ is a unique maximal subject by parthood}.}
\]

### Important correction

这不等于：

\[
\exists!s\;Subject(s).
\]

universalism反而产生大量 ordinary、overlapping、gerrymandered subjects。

所以这里只得到：

\[
\boxed{UniqueMaximalSubject}
\]

而非：

\[
\boxed{OnlySubject}.
\]

---

## 2. Fusion-to-Field Gap

即使：

\[
Subject(C),
\]

仍需问 constituent experiences 与 cosmic subject experience 的关系。

至少三种 possibility：

### F0 — Mere subjecthood

C 是 subject，但其 phenomenal state不 token-share local experiences。

### F1 — Higher-order composition

local experiences ground / compose C 的 distinct global experience。

### F2 — Shared co-conscious field

local experiences themselves belong to / are jointly experienced within C。

只有 F2 最直接给：

\[
GlobalExperientialUnity.
\]

因此：

\[
\boxed{
UniqueMaximalCosmicSubject
\not\Rightarrow
GEU
}
\]

除非加入 **Experience-Inheritance / Co-Experience Principle**：

\[
EIP:\quad PartSubjectExperience(e_i)
\Rightarrow
IncludedInGlobalField(e_i,C).
\]

这就是 **Fusion-to-Field Gap**。

---

## 3. Bonding universalism can close the gap, at a cost

若使用 phenomenal bonding：

\[
Bond(\Gamma)
\Rightarrow
\exists S_\Gamma\;JointlyExperiences(S_\Gamma,\Gamma).
\]

再假定：

\[
\forall\Gamma\subseteq B\;Bond(\Gamma),
\]

则 total set B直接给：

\[
\boxed{GEU(B).}
\]

真正承担 GEUP content 的不是 bare mereology，而是：

\[
\boxed{UniversalPhenomenalBonding.}
\]

这也是 giant-subject pressure 的来源。

---

## 4. Route B — Roelofs Continuism

Roelofs从 phenomenal boundaries 起步，而非 subject composition。

核心 package：

### R1 — Fundamental consciousness

\[
Fundamental(PhenomenalConsciousness).
\]

### R2 — Fundamental phenomenal unity

若 consciousness fundamental，phenomenal unity也更自然作为 fundamental relation，而不是高阶 informational pattern 的副产物。

### R3 — Informational boundaries are graded

\[
InformationalIntegration\in continuum.
\]

没有自然 sharp cutoff说明 exactly where one phenomenal field ends and another begins。

### R4 — Fundamental causal continuity

fundamental relations跨越 organism / brain boundaries；ordinary informational boundaries不是 fundamental partition。

于是 abductively：

\[
\boxed{
R1+R2+R3+R4
\Rightarrow_{IBE}
PhenomenalUnboundedness.
}
\]

若 fundamental causal structure globally connected：

\[
\boxed{PhenomenalUnboundedness\Rightarrow GEU.}
\]

---

## 5. Continuism pressure test

### C1 — Tracking Gap

为什么 phenomenal unity必须 track fundamental-causal relation？

\[
Fundamental(PU)
\not\Rightarrow
PU\text{ tracks all fundamental causal connectivity}.
\]

### C2 — Threshold Gap

informational boundary渐变不证明 phenomenal boundary不能 sharp；lawlike phase transition / emergent threshold原则上可能。

### C3 — Global Connectivity Gap

local physical continuity不自动给 entire reality one connected component。

### C4 — Field-to-Subject Gap

Roelofs明确允许：

\[
GEU\land\neg GlobalMind.
\]

因此 continuism主要填 C1→C2；还需要 Christmann-style GSP 才对 C2→C3施压。

---

## 6. Mørch: Subject-Ontology Fork

Mørch 的 anti-overlap result把 Global Closure 的 subject ontology显式化。

若采用 deflationary bundle view，并定义：

\[
Subject(B)
\iff
Unified(B)
\land
ExclusivelyBounded(B),
\]

且所有 subjects使用同一种 relevant unity relation，则 overlapping subjects会要求同一 experiences 同时：

\[
U(AB,C)
\]

和：

\[
\neg U(AB,C),
\]

因此：

\[
\boxed{
DeflationaryBundle
+
ExclusiveBoundedness
+
SingleUnityType
\Rightarrow
NoPhenomenalOverlap.
}
\]

但该结论不是 unconditional。至少有三种 escape：

1. substantive subjects；
2. multiple unity relations；
3. drop exclusive boundedness / accept overlapping subjects。

Mørch认为这些 alternatives增加本体或简约成本，但没有证明逻辑不可能。

因此 GCP必须新增一项 subject-ontology choice：

\[
SO\in\{ExclusiveBundle,OverlapTolerant\}.
\]

### If `SO = ExclusiveBundle`

literal phenomenal-sharing / nested-subject reading of SU+EIP受到直接冲突。

Global Closure 必须改写为：

- non-overlapping derivative streams；或
- copies / transfers / grounding relations；或
- one global field without local phenomenally bounded subjects as proper phenomenal parts。

### If `SO = OverlapTolerant`

Osborn/Goff/Roelofs-style GCP保持 coherent，但承担：

- many overlapping subjects；
- weaker privacy / exclusivity；
- parsimony burden；
- ordinary subject-individuation需要重新解释。

所以：

\[
\boxed{
GlobalClosure\;requires\;an\;explicit\;subject-boundary\;metaphysics.}
\]

Mørch 没有推翻 GEU；她主要削弱“overlap 是免费机制”。

---

## 7. The two routes remain complementary

### Composition-first

\[
Subjects
\to
UniversalFusion
\to
CosmicSubject.
\]

强项：global subject construction直接。

弱项：GEU需 EIP / phenomenal bonding，并面临 overlap ontology cost。

### Field-first

\[
FundamentalSubjectivity
\to
PhenomenalUnboundedness
\to
GEU.
\]

强项：直接命中 GEUP。

弱项：GEU不自动是 subject；local subject boundaries 仍需独立理论。

因此：

\[
\boxed{
Osborn/Goff\text{ strengthen GlobalSubject construction};
\quad
Roelofs\text{ strengthens GEUP}.
}
\]

---

## 8. Revised Global Closure Package

旧版：

\[
GCP=SU+MF+FC+EIP.
\]

现在必须写成：

\[
\boxed{
GCP^*=SU+MF+FC+EIP+SO.
}
\]

其中：

- SU = Subject Universalism；
- MF = unique maximal cosmic fusion；
- FC = phenomenal field continuity；
- EIP = constituent experiences enter/share global field；
- SO = explicit subject-ontology / boundary rule。

在 overlap-tolerant SO 下：

\[
\boxed{
GCP^*
\Rightarrow
\exists!G\;MaximalGlobalSubject(G)
\land
GEU(G).
}
\]

在 exclusive-bundle SO 下，SU/EIP 必须被替换成 non-overlap architecture，因此原 direct derivation不再成立。

所以 Mørch 使 GCP 从“一个 package”升级成真正的 **forked package family**。

---

## 9. Does GCP solve the original project?

没有。

即使某个 GCP variant 成立：

\[
\exists!G\;MaximalGlobalSubject(G)
\]

且：

\[
GEU(G),
\]

仍然没有：

\[
\exists!E^*\;AbsoluteLocalLocus(E^*,G).
\]

universalism / continuism天然更接近：

- many overlapping subjects；或
- one global field with many informational regions；或
- plural derivative local streams。

因此：

\[
\boxed{
GCP^*\not\Rightarrow PLP.
}
\]

---

## 10. Current verdict

无条件：

\[
SubjectiveArity\Rightarrow GEU
\]

仍未建立。

但 GEUP 已拥有 serious routes：

\[
\boxed{
FundamentalConsciousness
+
NaturalContinuity
+
AntiArbitraryBoundary
\Rightarrow_{IBE}
GEU.
}
\]

global subject也有 constructive route：

\[
\boxed{
SubjectUniversalism
+
CosmicFusion
\Rightarrow
UniqueMaximalCosmicSubject.
}
\]

Mørch新增的关键约束是：

\[
\boxed{
GlobalClosure
\text{ cannot remain neutral about subject boundaries}.}
\]

这提高了 GCP 的成本，但没有关闭它。

最终 hard gap仍集中到：

\[
\boxed{GlobalClosure\not\Rightarrow UniqueLocalPrivilege.}
\]
