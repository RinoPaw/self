# Order-Parameter Semantics Audit

> 状态：2026-10-05 Privilege-Sensitive-Law refinement。
>
> 目标：`Spontaneous Absolute-Orientation Breaking` 已经可以 lawfully 产生 one distinguished root；本文件检验这个 root 为什么具有 **absolute first-person** semantics，而不是普通的 `marked / dominant / selected` semantics。

## 0. Target gap

SAOB 允许：

\[
\exists!E^*\;A(E^*)=1.
\]

但如果 \(A\) 只是一个 primitive mark，则最多得到：

\[
UniqueMarkedLocus.
\]

项目需要：

\[
AbsoluteOrientation(E^*).
\]

所以核心缺口是：

\[
\boxed{
OrderParameterSemanticsGap:
\quad A(E)=1\;?\;AbsoluteOrientation(E).
}
\]

这里不能再靠 uniqueness / dominance / centrality 偷渡。

---

## 1. Hare — monadic presence

Hare-style perspectival realism / egocentric presentism 给一个非常直接的 semantic primitive：某些 experiences / objects不是 merely present-to-a-subject，而是 **present simpliciter**。

因此可以把 order parameter解释为：

\[
A_H(E)=1
\iff
ExperiencesOf(E)\text{ are present simpliciter}.
\]

这确实比 graph dominance 更 privilege-sensitive，因为 `presence` 从一开始就是 metaphysical first-person privilege。

### Strength

\[
\boxed{Mark\to PrivilegeSemantics}
\]

在定义层已经成立。

### Cost

它没有从 neutral structure derive privilege；它把 privilege直接放进 property content。

而 Hare原版又有 solipsistic / asymmetrical-consciousness pressure：若只有一组 experiences simpliciter present，其他 subjects的 consciousness如何保持 genuine 而非 merely relative，需要额外 two-tier ontology。

本项目可构造：

\[
LocalConsciousness(E_i)\quad\forall i
\]

同时：

\[
\exists!E^*\;PresentSimpliciter(E^*),
\]

但这是对 Hare 的改造，不是其原 theory。

### Verdict

Hare能 **name the target semantic role**，不能 independently ground why such a role exists。

---

## 2. Bitbol — identification supplies first-person semantics

Bitbol 的 One Mind–many points of view template：objective description列出多个 available POVs，而 placeless/timeless Mind `identifies` with one POV。

抽象：

\[
AvailablePOVs(R)
+
Mind(M)
+
Identifies(M,E^*)
\]

一旦 identification 成立，该 POV从内部不是 merely one candidate among others，而是：

\[
\boxed{my\ point\ of\ view}.
\]

而且 Bitbol把 identification看作 objective spacetime world 与 placeless/timeless Mind 的 connection。

所以可解释：

\[
A_B(E)=1
\iff
Identifies(M,E).
\]

### Strength

这是目前最接近：

\[
\boxed{selection\ relation\ whose\ content\ is\ intrinsically\ first\!\!\text{-}\!personal}
\]

的邻近模型。

### Cost

Bitbol明确拒绝把 identification理解成普通 physical transition：

- no objective element distinguishes adopted POV；
- Mind没有 ordinary biography / content；
- identification不是可定位在某时刻的物理过程。

因此 Bitbol给：

\[
PrivilegeSemantics
\]

但不给：

\[
SelectionLaw.
\]

这与 Kadić 正好互补。

---

## 3. Nagai — opening gives the strongest actuality semantics

Nagai 的 Opening theory最强，因为它不把 `I!` 看成一个 externally marked subject。

核心结构：

\[
\boxed{
WorldActuality
=
AbsoluteI
=
AbsoluteNOW
=
Opening.
}
\]

其 opening 是整个 world/mechanism 得以 **actually exist** 的方式，而不是 world内部又一个普通 property。

可把 order parameter重写为 relation：

\[
Open(R,E).
\]

并定义 complete actuality：

\[
Actual(R)
\Rightarrow
\exists!E^*\;Open(R,E^*).
\]

其中：

\[
Open(R,E^*)
\Rightarrow
AbsoluteOrientation(E^*).
\]

这里 `AbsoluteOrientation` 不再是 arbitrary gloss；其 content来自：

\[
\boxed{\text{this is the locus through which the totality is actual/open}.}
\]

### Strength

Nagai是目前最强 **Order-Parameter Semantics** source。

它把 mark承担的 job具体化：

\[
\boxed{Actualization / Opening of complete reality.}
\]

### Cost

Nagai并没有从 neutral actuality证明 Opening Identity Principle。

其最终解释允许 sheer contingency / God’s will；所以：

\[
\boxed{
Nagai\ closes\ semantic\ arbitrariness,
not\ metaphysical\ derivation.
}
\]

---

## 4. Acquaintance — epistemic consequence, not core semantics

ordinary acquaintance theory允许一个 subject 对自己的 current mental states拥有 direct / non-inferential awareness。

若扩展 absolute model：

\[
Absolute(E^*)
\Rightarrow
Acquainted(E^*,Absolute(E^*)).
\]

则 winner可拥有 factive self-knowledge。

但 acquaintance自己不能推出：

\[
Absolute(E^*).
\]

所以：

\[
\boxed{
Acquaintance\ explains\ access\ to\ privilege,
not\ privilege\ itself.
}
\]

如果 acquaintance有 unique phenomenal signature，它可能成为 evidence channel；当前无独立证据。

## 5. Four candidates compared

| Candidate | gives selection? | gives FP semantics? | independently grounds privilege? |
|---|---:|---:|---:|
| Hare presence | no | yes | no |
| Bitbol identification | no dynamics | yes | no |
| Nagai opening | no derived selector | **yes, via actuality** | no proof from neutral actuality |
| acquaintance | no | epistemic only | no |

所以最强组合不是任选一个，而是：

\[
\boxed{
\text{Nagai semantics}
+
\text{Bitbol identification template}
+
\text{SAOB law-form}.
}
\]

## 6. Important correction: do not temporalize the law for free

Nagai / Bitbol都给一个警告：actualization / identification不应轻易当成 world-time 内发生的 process。

因此：

\[
R\xrightarrow{t}Open(R,E^*)
\]

这种“先有 neutral world，后来被选中”的故事可能 category mistake。

更稳妥的是把 law理解成对 complete possible structures 的 **atemporal constraint**：

\[
\Lambda_O:\quad
Complete(R)
\Rightarrow
\exists!E^*\;Open(R,E^*).
\]

若还有 objective chance，则 chance可以理解为对 admissible complete extensions / symmetry-broken realizations的 measure，而非一定发生在 physical time 中的 lottery。

这避免自动重开：

- meta-time；
- pre-actual world；
- temporal selection process。

---

## 7. Semantic success does not equal evidential success

即使采用：

\[
Open(R,E^*)=AbsoluteI(E^*)=Actuality(R),
\]

仍没有 external evidence证明：

\[
\exists!E^*\;Open(R,E^*).
\]

所以 Order-Parameter Semantics Gap可以被 **model-internally closed**：我们知道这个 role 是干什么的。

但 Completion Underdetermination仍可能保留：neutral actuality theory可以拒绝世界需要这种 opening role。

因此必须区分：

\[
\boxed{
SemanticNonArbitrariness
\neq
IndependentMotivation.
}
\]

---

## 8. Current verdict

本轮不再适合说：

> any absolute-order parameter is merely an arbitrary mark.

Nagai / Bitbol / Hare都提供成熟的 privilege-sensitive semantic templates。

尤其 Nagai给：

\[
\boxed{
A(E)=1
\iff
E\text{ is the opening locus of complete actuality}
}
\]

这一 interpretation明显强于 `central / dominant / selected`。

所以更新：

\[
\boxed{
OrderParameterSemanticsGap
\text{ has a coherent positive closure candidate}.
}
\]

但该 closure是 **primitive/constitutive semantic closure**，不是从 neutral base derived 的 theorem。

于是项目最新 hard question变成：

\[
\boxed{
Does\ complete\ actuality\ independently\ require\ an\ Opening\ relation?
}
\]

如果答案为 yes，则 SAOB 可以给它 law/symmetry structure；如果答案为 no，Nomological Opening只是在更精致地组织 primitive centered actuality。
