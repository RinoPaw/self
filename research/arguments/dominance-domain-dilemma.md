# Dominance–Domain Dilemma

> 状态：工作论证。由 Kadić 2024 的 Dynamic Monadic Panpsychism 提供最清楚的现成机制原型。

## 1. Single-output mechanism 可以存在

此前很多候选只会得到：

\[
\text{one source}\to\text{many manifestations}.
\]

Kadić 的 Static / Dynamic Monadic Panpsychism 提供不同结构：

\[
D\xrightarrow{R}\{e^*\},
\]

其中 \(D\) 是 relevant relational / causal structure，整个结构只把 full human phenomenal content 给一个 dominant microsubject。

因此：“复杂 relational structure 只有一个 experiential endpoint”作为理论模板是可构造的。

## 2. 关键参数其实是 domain

single-output property 应写成：

\[
|Out(D)|=1.
\]

这句话没有说明：

\[
D=\text{什么范围？}
\]

Kadić 的相关 domain 是产生当前 human experience 的 brain / neural causal structure。

于是：

\[
|Out(D_A)|=1,
\qquad
|Out(D_B)|=1
\]

完全可以同时成立。

若：

\[
D_A\cap D_B\approx\varnothing,
\]

则现实中仍然有：

\[
e_A^*,e_B^*.
\]

所以：

\[
\boxed{
\text{single-output rule}
+
\text{multiple eligible domains}
\Rightarrow
\text{multiple outputs}
}
\]

这就是 Local-to-Global Singleton Obstruction 的一个非常具体的 consciousness-theory 实例。

## 3. Dilemma

若想把 dominant-locus mechanism 升级为 Absolute First-Person，需要决定 domain。

### A. Domain = local organism / brain

则：

\[
D_1,D_2,\dots,D_n
\]

各自产生自己的 dominant experiential locus：

\[
e_1^*,e_2^*,\dots,e_n^*.
\]

结果是 ordinary multi-subject consciousness，很合理，但没有 global absolute center。

### B. Domain = total reality

设：

\[
D=\mathcal R
\]

并要求：

\[
|Out(\mathcal R)|=1.
\]

形式上可以得到 global singleton。

但马上出现 other-minds 问题：

- 若只有 global winner 获得真正 full consciousness，其他 minds 被降格；
- 若其他 minds 仍各自拥有真实 full consciousness，则 `global winner` 和这些 minds 的关系需要额外的 absolute-privilege theory。

因此：

\[
\boxed{
\text{globalize the domain}
\text{ either threatens other minds or restores the privilege gap}
}
\]

## 4. Dynamic dominance 与 I–NOW

Dynamic Monadic Panpsychism 还有一个与项目高度相关的特征：dominant microsubject 可以动态变化。

形式上：

\[
e^*_1\to e^*_2\to e^*_3.
\]

它证明“体验 locus 本身动态转移”不是完全无法构造的思想。

但 Kadić 的动态由 brain process / causal structure 决定，因此仍然只解释一个 organism 内的 locus dynamics。

若推广到全部 existence：

\[
E^*_1\to E^*_2\to\dots
\]

仍需要：

1. 全局 domain；
2. covariant dynamics；
3. other minds remain conscious；
4. 为什么 dominance = absolute liveness；
5. 为什么不重新引入 meta-time。

因此它更适合作为 \(\Gamma^*\) 的机制模板，而不是现成答案。

## 5. 新增成功条件：Domain Closure

任何 single-output theory 以后都必须明确：

\[
D_{abs}=\text{全部有资格竞争 absolute status 的候选所共同属于的同一个 domain}.
\]

并证明：

\[
\boxed{|Out(D_{abs})|=1}.
\]

暂称 **Domain Closure Requirement**。

它比单纯 Global Coupling 更具体：不能只说“规则是全局的”，还要说明所有其他 local competition domains 为什么没有产生同等级 absolute output。

## 6. 当前评价

Kadić 2024 是目前找到的最有价值的 **single-output experiential prototype**。

它给正方带来一点真正的正面信息：

\[
\boxed{\text{single experiential endpoint need not be a bare primitive pointer}}
\]

但它同时证明：只找到 single-output mechanism 还不够；真正决定 absolute uniqueness 的是 mechanism 的 **competition domain**。

因此当前搜索目标从：

\[
\text{找 single-output mechanism}
\]

进一步收紧为：

\[
\boxed{
\text{找一个以 total eligible reality 为闭合竞争域、仍保留 other minds、且 winner 自带 privilege 的 single-output mechanism}
}
\]
