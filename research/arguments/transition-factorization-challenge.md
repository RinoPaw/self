# Transition Factorization Challenge

> 状态：对 `First-Person Transition Gap` 的前提审查。
>
> 它不否定该 gap 的条件性结果；它质疑完整现实是否必须先被分解成 uncentered history，再经过 transition 得到 absolute center。

## 1. 当前 transition picture

仓库当前有一条很清楚的正方任务链：

\[
D
\to
H^*
\to
\mathcal C(H^*)
\xrightarrow{T_{C\to A}}
E^*
\to
LIVE(E^*).
\]

其中：

- \(H^*\)：actual universe/history；
- \(\mathcal C(H^*)\)：全部真实 conscious candidates；
- \(T_{C\to A}\)：global first-person transition；
- \(E^*\)：唯一绝对 center。

这套分解非常适合检验 third-person theories 为什么不自动给 first-person actuality。

但它含有一个额外结构假设。

---

## 2. Hidden Factorization Assumption

该 picture 假定：

1. \(H^*\) 可以在 metaphysically complete enough 的意义上先被指定；
2. conscious candidates 可以在 \(H^*\) 中被确定；
3. absolute center status 是在这些结构之后额外获得的。

也就是一种本体论 staging：

\[
\boxed{
\text{uncentered actuality first}
\rightarrow
\text{centered actuality later}
}
\]

暂称：

\[
\boxed{\text{Transition Factorization Assumption}}
\]

更抽象地，它要求 complete relevant reality 可以按某种方式 factorize 为：

\[
\mathcal R_{complete}
\sim
\langle H,\mathcal C,A\rangle
\]

且 \(A\) 可以被视为从前两个层级产生 / 添加。

---

## 3. Centered Total State 反例架构

考虑一个完整 fundamental state：

\[
R^*.
\]

它从一开始就包含：

- objective / third-person structure；
- ordinary perspectives；
- anchoring structure；
- simpliciter center-related structure。

我们可以从它做不同投影：

\[
P_U(R^*)=H,
\]

\[
P_C(R^*)=\mathcal C,
\]

\[
P_A(R^*)=E^*.
\]

这里：

\[
E^*
\]

不需要是：

\[
T_{C\to A}(H,\mathcal C)
\]

的输出。

反过来，\(H\) 只是把 centered structure 忘掉后的 uncentered projection：

\[
H=ForgetCenter(R^*).
\]

因此：

\[
H\not\Rightarrow E^*
\]

完全可以成立，同时：

\[
R^*\Rightarrow E^*.
\]

---

## 4. 这怎样重读 Copy-to-I Gap

Hartle–Srednicki 式结果表明：

\[
H+\text{all copies}
\not\Rightarrow
I=E_i.
\]

Centered Total State 的回应不是从 \(H\) 里继续找一个更聪明 selector，而是：

> 如果 absolute center 是完整现实的一部分，那么一个不含 center-structure 的 \(H\) 从一开始就不是 complete metaphysical input。

因此 Copy-to-I Gap 可以被重读为：

\[
\boxed{
\text{uncentered description underdetermines centered reality}
}
\]

而不是自动升级成：

\[
\boxed{
\text{no complete reality can determine a center}
}.
\]

这与 centered-world / self-location literature 的基本教训一致。

---

## 5. 这没有让问题消失

如果拒绝 transition factorization，原来的：

\[
T_{C\to A}
\]

问题会转化成：

### Completeness Problem

为什么 centered structure 真是 complete reality 的组成，而不是人为附加？

### Centered-State Source Problem

为什么实际 fundamental state 是：

\[
R^*=R_A
\]

而不是：

\[
R_B?
\]

### Disguised Primitive Problem

如果：

\[
R^*=\langle H,Center=E^*\rangle,
\]

但 `Center=E*` 没有独立解释，那么只是把 primitive pointer 放进 complete state。

所以：

\[
\boxed{
\text{rejecting transition does not automatically explain centeredness}
}
\]

它只是改变正确的 explanatory architecture。

---

## 6. 两种正方架构应该并行保留

### Architecture T — Transition

\[
H
\to
\mathcal C(H)
\xrightarrow{T_{C\to A}}
E^*.
\]

适合：

- structural selector；
- stochastic selection；
- grounding/generative role；
- psychophysical transition theory。

### Architecture C — Co-Fundamental Centered State

\[
R^*
\xrightarrow{P_U}H,
\]

\[
R^*
\xrightarrow{P_A}E^*.
\]

这里 objective history 与 absolute center 是同一个 complete state 的不同 aspects / projections。

适合：

- Centered Total State；
- enriched-world approaches；
- metaphysics in which first-person structure is fundamental rather than derived。

不能在尚未论证时强迫 Architecture C 转写成 Architecture T。

---

## 7. Structural Selection 的新版本

此前：

\[
\mathcal R\Rightarrow E^*
\]

经常被默认为：

\[
\mathcal R_{uncentered}\Rightarrow E^*.
\]

现在应区分：

### Derivational Selection

\[
R_0\Rightarrow E^*,
\]

其中 \(R_0\) 本身没有 center structure。

### Constitutive Centering

\[
E^*\in Structure(R^*)
\]

其中 complete state 自身 irreducibly centered。

第二种不一定有 selector。

这正好对应用户早期的重要直觉：可能不存在两个“完整现实完全相同，只换 absolute first-person”的 cases，因为 center change 本身就是 complete-state change。

---

## 8. 与 Stage 0 Reality-Monism 的关系

Architecture C 更依赖一个强的 Totalization claim：存在一个足以容纳 centered + uncentered aspects 的 complete metaphysical state \(R^*\)。

Radical perspectival pluralism 可以拒绝：

\[
\exists R^*.
\]

所以 centered-total-state route 没有绕过 Stage 0；它反而使 Stage 0 更重要。

---

## 9. 与 Two-Tier First-Person Realism 的关系

如果：

\[
R^*
\]

包含：

\[
\forall i\;F_i^{rel}
\]

并且：

\[
F_*^{abs},
\]

则 ordinary / absolute 两层可以 co-fundamentally 出现在一个 state 中，而无需 local facts 先经过 \(\mathsf A\) 变换。

此时 \(\mathsf A\) 可以仅是我们的表述工具：

\[
\mathsf A(F_i^{rel})=F_i^{abs}
\]

描述 complete state 中的 role difference，而非真实发生的 metaphysical process。

这进一步说明：

\[
\boxed{
\text{Absolutization operator may be representational rather than ontic}
}
\]

需要独立判断。

---

## 10. 当前结论

`Global First-Person Transition Problem` 是一个真实且重要的条件性缺口：**任何先给 uncentered history/candidate set，再试图产生 absolute center 的理论都必须填它。**

但它还不能被提升成所有 absolute-first-person theory 都必须接受的 architecture。

一个 alternative 是：

\[
\boxed{
\text{the complete actual state is irreducibly centered}
}
\]

在这种 theory 中，中心并不是从 neutral base 中“被选中”，而是 neutral base 本来就是 complete centered reality 的投影。

这条路线的真正敌人变成：

\[
\boxed{
\text{irreducible centeredness 是否只是 disguised primitive？}
}
\]

而不是：

\[
\boxed{
T_{C\to A}\text{ 怎么实现？}
}
