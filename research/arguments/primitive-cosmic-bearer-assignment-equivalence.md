# Primitive Cosmic Bearer — Assignment Equivalence Pressure

> Date: 2026-10-05
>
> Status: argument-level stress test of the last primitive Universal-I horn.

## 1. Setup

Let the shared base reality be:

\[
R=\{F_1,F_2,\dots,F_n;\;P;\;C\}
\]

where:

- `F_i` are local phenomenal fields / experience bundles;
- `P` contains all physical facts;
- `C` contains all causal, informational, functional, and phenomenal-unity relations already fixed by the base theory.

Assume the fields are not globally phenomenally unified and that no independently motivated global maximality criterion has selected the cosmos as one subject.

Now compare bearer assignments over the same `R`.

### U — Primitive Universal Bearer

\[
Own_U(F_i)=I_U\quad\forall i.
\]

All local fields belong to one primitive cosmic bearer.

### L — Local Bearers

\[
Own_L(F_i)=I_i.
\]

Each maximal local field has its own bearer.

### G — Arbitrary Grouped Bearers

Partition the fields into arbitrary groups `G_k` and assign one bearer per group.

The base phenomenal/physical/causal facts remain fixed.

## 2. Assignment Equivalence

If bearer identity is primitive and does not alter any fact in `R`, then:

\[
R+Own_U,
\]

\[
R+Own_L,
\]

and

\[
R+Own_G
\]

can agree on all ordinary phenomenology, causal structure, behavior, access relations, and field-unity facts.

Their difference is solely the extra ownership partition.

Call this:

### AEP — Assignment Equivalence Pressure

\[
\boxed{
SameBase(R)+DifferentPrimitiveOwnershipPartitions
\Rightarrow
NeedIndependentAssignmentExplanandum.
}
\]

Without such an explanandum, the ownership partition faces surplus-structure pressure.

## 3. Why primitive Universal-I is not uniquely helped by primitiveness

The universalist can say:

\[
Primitive(Own_U).
\]

But the localist can equally say:

\[
Primitive(Own_L),
\]

and a grouped-bearer theorist can say:

\[
Primitive(Own_G).
\]

Primitiveness blocks reductive demands but does not choose among primitive assignments.

Thus:

\[
\boxed{
Primitive\neq Unique.
}
\]

The question becomes comparative:

\[
Why\ U\ rather\ than\ L\ or\ G?
\]

## 4. Permutation / repartition symmetry

Suppose the base theory admits a transformation that changes only the bearer assignment while preserving `R`:

\[
\pi:R+Own_a\mapsto R+Own_b.
\]

If all independently motivated facts are invariant under `\pi`, then the competing ownership structures are observationally and explanatorily tied relative to the base.

This mirrors earlier orientation-permutation results:

\[
P(e\mid R+Own_a)=P(e\mid R+Own_b)
\]

for ordinary evidence `e` whenever ownership is causally/phenomenally inert.

So primitive ownership inherits the same basic challenge as primitive absolute orientation: extra modal resolution is not automatically explanatory gain.

## 5. Universal assignment is not privileged by simplicity alone

One might argue that U uses one bearer whereas L uses many.

But counting bearer tokens is not yet a fair simplicity comparison if the bearer layer itself is optional extra structure.

The relevant comparison is:

\[
Cost(R+Own_U)
\quad vs\quad
Cost(R+Own_L)
\quad vs\quad
Cost(R).
\]

If `R` already explains all phenomenal organization and local ownership-like structure, then adding even one primitive cosmic bearer can be more costly than adding none.

Therefore:

\[
OneBearer<ManyBearers
\]

inside the extra layer does not show:

\[
OneBearer<NoPrimitiveBearerLayer.
\]

This is the same Common-Explananda discipline used in the Absolute-Layer Surplus Pressure argument.

## 6. What would break Assignment Equivalence

The primitive Universal-I can escape AEP only by finding a non-inert delta.

### Escape A — Phenomenal delta

\[
Own_U\Rightarrow GlobalPhenomenalFeature
\]

that cannot occur under local/grouped assignments.

But this returns to the global phenomenal-unity horn.

### Escape B — Causal / dynamical delta

\[
Own_U\Rightarrow DistinctCausalDynamics.
\]

Then ownership is no longer primitive-inert; it becomes part of a psychophysical law and must face empirical/reliability tests.

### Escape C — Grounding/compression delta

Universal ownership explains independently required facts more economically than local/grouped ownership.

This requires a common-explananda comparison, not merely the claim that one owner sounds simpler.

### Escape D — Necessary assignment theorem

Derive:

\[
R\Rightarrow Own_U.
\]

But PFIP/BDP/CUSP/GSM audits have not found such a derivation.

## 7. Stronger comparison with ownerless Mine

The ownerless Universal-Mine theory says:

\[
\forall e\;Mine(e)
\]

without one bearer.

Primitive Universal-I says:

\[
\exists I_U\forall e\;OwnedBy(e,I_U).
\]

If adding `I_U` changes no phenomenal or causal facts, then the second theory must explain what the bearer contributes beyond reifying the universal mine-status.

Thus the old Mine-Without-Owner gap and the new Primitive-Bearer Surplus gap form opposite horns:

\[
UniversalMine
\Rightarrow
\begin{cases}
NoOwner &\to MineWithoutOwnerGap\\
PrimitiveOwner &\to AssignmentEquivalencePressure
\end{cases}
\]

## 8. Current verdict

The primitive cosmic bearer remains logically coherent.

It is not refuted by AEP.

But its comparative status is now sharply weaker:

\[
\boxed{
PrimitiveUniversalBearer\ is\ underdetermined\ among\ ownership\ partitions\ unless\ it\ adds\ an\ independent\ explanatory\ delta.
}
\]

This means the strongest Universal-I fallback is now structurally analogous to the project's earlier primitive absolute-orientation problem.

## 9. Consequence for locality

The locality endgame can now be written:

\[
UniversalI
\Rightarrow
\begin{cases}
GlobalPhenomenalUnity,\\
GlobalSubjectMaximality,\\
PrimitiveCosmicBearer.
\end{cases}
\]

with pressures:

\[
GlobalPhenomenalUnity\to PFIP/DisconnectionPressure,
\]

\[
GlobalSubjectMaximality\to GSMBurden,
\]

\[
PrimitiveCosmicBearer\to AEP/SurplusPressure.
\]

No horn is formally impossible, but none is currently cost-free.

## 10. Next research move

The most useful next step is no longer another Universal-I variant. It is to return to **ALO** and ask whether the project can actually secure at least one irreducible opening.

Reason: locality has now been reduced to a clear rival-cost structure, while ALO remains a genuine existence gap. Further locality work without a new positive bridge risks diminishing returns.
