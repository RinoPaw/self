# Collapse–Temporal Synchronization Fork

> 状态：2026-10-05 COS / UIWO temporal-gate audit。
>
> 目标：检验 collapse-driven actualization 是否能承担 `NOW` projection，还是必须额外引入 privileged temporal structure。

## 0. Target

Collapse-Opening Synthesis 已得到 serious local pattern：

\[
Collapse(C)
\Rightarrow
PhysicalActualization
+
ExperientialActualization
+
LocalTemporalActualization.
\]

UIWO需要更强：

\[
\exists!T^*\;Present(T^*).
\]

缺失原则：

\[
\boxed{
TSP:\quad LocalActualizations\Rightarrow OneGlobalNOW.
}
\]

---

## 1. Relativistic collapse countermodel

Tumulka-style rGRWf说明可以有：

\[
\boxed{
StochasticCollapseHistory
+LorentzCovariance
+NoPreferredSlicing.
}
\]

因此：

\[
\boxed{
CollapseDynamics
\not\Rightarrow
PreferredGlobalFoliation.
}
\]

而 one global NOW若要以 hypersurface形式存在，至少通常需要更强 temporal structure。

所以 collapse alone不能建立 TSP。

---

## 2. Becoming pressure

Esfeld–Gisin 的 audit可重构为：

若 collapse flashes只作为 whole four-dimensional distribution存在：

\[
F_{4D},
\]

则 Lorentz-covariant reading更自然，但：

\[
\neg GenuineGlobalBecoming.
\]

若再要求 actual distribution真的逐步 come into being，并对 spacelike-related dependencies有 determinate temporal development，则出现：

\[
\boxed{
GenuineGlobalBecoming
\Rightarrow
PreferredFoliationPressure.
}
\]

所以 temporal route出现 fork。

---

## 3. Temporal Synchronization Fork (TSF)

### Horn A — Covariant whole-history

\[
ActualHistory(H^*)
+\neg GlobalNOW.
\]

collapse law给 actual events / history，但不加 one privileged present。

优点：避免额外 absolute simultaneity。

代价：无法给 UIWO 的 `NOW` projection。

### Horn B — Privileged-foliation becoming

\[
ActualHistory(H^*)
+\mathcal F^*
+NOW(\Sigma^*).
\]

其中 \(\mathcal F^*\) 是 privileged foliation。

优点：可承载 universe-wide synchronized becoming。

代价：需要解释：

1. 为什么有该 foliation；
2. 为什么其中 exactly-one slice 是 NOW；
3. 如何处理 relativity / Lorentz-covariance cost。

### Horn C — Local / relational becoming

\[
Become(e,worldline/causal\ context).
\]

只保留 local becoming，无 universe-wide simultaneity。

优点：更贴 relativistic structure。

代价：得到多个 local “nows” / becoming relations，无法直接给 Nagai-style absolute NOW。

因此：

\[
\boxed{
TSF=A|B|C.
}
\]

---

## 4. Preferred foliation still does not equal NOW

即使物理结构天然 / dynamical 地选出：

\[
\mathcal F^*,
\]

也只有 ordered family：

\[
\{\Sigma_t\}.
\]

还没有：

\[
\exists!t^*\;Present(\Sigma_{t^*}).
\]

所以需再次区分：

\[
\boxed{
TemporalOrder/Foliation
\neq
PresentnessPrivilege.
}
\]

这与 DPO 同型：

\[
Structure/Uniqueness\not\Rightarrow Privilege.
\]

因此 Horn B内部还有：

### Foliation–Presentness Gap (FPG)

\[
\boxed{
PreferredFoliation
\not\Rightarrow
ObjectiveNOW.
}
\]

---

## 5. Cosmological boundary route

可以尝试利用 cosmology：

- expansion；
- Ricci eigenlines；
- cosmic time；
- EBU future boundary；
- Past Hypothesis / global temporal orientation。

它们可能给 canonical temporal structure。

但即使成功：

\[
CanonicalTimeFunction(R)
\]

仍只给：

\[
t:R\to\mathbb R,
\]

而不直接给：

\[
Present(t_0).
\]

所以 cosmology最多帮助 Horn B 的 first burden，不能单独关闭 FPG。

---

## 6. Relation to UIWO non-factorization

UIWO要一个 genuinely coupled Opening：

\[
O(w,t,s).
\]

COS/CDCP已经让 `w-like actualization + e/s` coupling有 serious prototype。

TSF说明 time-coordinate promotion不能直接继承：

\[
CollapseEventAt(t)
\Rightarrow Present(t).
\]

否则把 parameter / event location偷换成 metaphysical presentness。

所以 UIWO 的 temporal requirement变成两个明确条件：

### T1 — Synchronization

\[
LocalActualizations\Rightarrow OneGlobalTemporalSlice/Boundary.
\]

### T2 — Presentness semantics

\[
GlobalSlice(\Sigma^*)\Rightarrow Present(\Sigma^*).
\]

当前两条都没有被 collapse理论普遍建立。

---

## 8. Impact on Opening strategy

这不是 UIWO fatal blow。

它说明 Opening若要把 NOW真正统一进去，有两种 honest 路径：

### Route O1 — Primitive / nomological presentness inside Opening

\[
O(w,t,s)
\]

本身就含 presentness semantics。

代价：temporal privilege仍部分 primitive。

### Route O2 — Deeper temporal law

找到 independent dynamics：

\[
GlobalActualizationStructure
\Rightarrow
OnePrivilegedPresent
\]

并显示该 dynamics与 psychophysical / subject-selection law genuine non-factorizable。

目前没有这样的成熟统一理论。

Collapse route对 UIWO 的贡献需要重新分账：

### 已有

\[
\boxed{
local physical + phenomenal + temporal actualization coupling
}
\]

### 缺失

\[
\boxed{
local\to global temporal synchronization
}

\boxed{
