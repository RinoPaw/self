# Presence Localization vs Universalism Fork

> 状态：2026-10-05 first-person frontier audit。
>
> 目标：在 `Opening / PLP` 之外加入一个此前没有被充分隔离的对手：presence / immediacy 可能属于所有 experience，而非通过 law localize 到 exactly-one stream。

## 0. Target

本项目 absolute-local thesis：

\[
H_L:\quad \exists!E^*\;AbsoluteOrientation(E^*).
\]

2026 Builes-style Universalism：

\[
H_U:\quad \forall e\,[Experience(e)\to Immediate(e)\land Mine(e)].
\]

两者不是 ordinary realism vs anti-realism；它们都可以认为 first-person structure metaphysically serious。

真正 dispute：

\[
\boxed{\text{first-person presence is selective or universal?}}
\]

---

## 1. Why this fork is prior to PLP

PLP 形式：

\[
Candidates(R)\to\exists!E^*\;Absolute(E^*).
\]

但这已经假定：

\[
\boxed{\text{exactly-one privilege is a required output type}.}
\]

Universalism挑战这一点：

\[
Experience(e)\Rightarrow Presence(e).
\]

如果 presence 是 experience 的 constitutive feature，则没有 candidate competition：

\[
\boxed{\text{no winner must be selected}.}
\]

所以 logical order 应改成：

\[
\boxed{
PresenceOntology
\to
\{Selective,Plural,Universal\}
\to
PLP\text{ only if Selective}.
}
\]

---

## 2. Three-way first-person ontology

### P1 — Selective presence

Hare / Merlo / absolute-opening邻域：

\[
\exists!E^*\;Present(E^*).
\]

其他 experiences可以 conscious，但缺 simpliciter privilege。

### P2 — Plural centered presence

List / standpoint pluralism：

\[
\forall i\;PresentRelativeTo(E_i,S_i)
\]

或多个 first-personally centred worlds / fragments equally real。

### P3 — Universal presence

Builes / Zuboff / Fasching-nearby Universalism：

\[
\boxed{\forall e\,[Experience(e)\to Immediate(e)\land Mine(e)]}.
\]

local separation由 access / causal / informational organization，而非 ownership/presence exclusion承担。

因此：

\[
\boxed{
FirstPersonRealism
\not\Rightarrow
P1.
}
\]

---

## 3. Access–Ownership Separation

Universalism最重要的结构原则：

\[
\boxed{
\neg JointAccess(e_i,e_j)
\not\Rightarrow
\neg SameFirstPersonStatus(e_i,e_j).
}
\]

定义 access graph：

\[
\mathcal A=(E,R_A),
\]

其中：

\[
R_A(e_i,e_j)
\]

表示两个 experiences可 jointly access / informationally integrate。

ordinary persons可以对应 graph 中的 dense connected regions：

\[
A_1,A_2,\ldots,A_n.
\]

同时 universal first-person status满足：

\[
\forall e\in E\;Mine(e).
\]

于是：

\[
\boxed{
ManyLocalAgents
+
ManyAccessIslands
+
OneUniversalFirstPersonStatus
}
\]

在形式上完全 coherent-looking。

这直接削弱旧推理：

\[
ManyAccessStreams\Rightarrow ManyUltimateOwners.
\]

---

## 4. Selective thesis now owes a Localization Necessity Principle

过去我们问：

\[
Why\ this\ one?
\]

现在必须先问：

\[
\boxed{Why\ only\ one?}
\]

因此 absolute-opening side 需要：

### LNP — Localization Necessity Principle

\[
\boxed{
FirstPersonActuality(R)
\Rightarrow
ExactlyOneLocalRealization(R).
}
\]

这与 PLP 不同。

PLP：

\[
\text{给定需要 exactly-one，哪一个？}
\]

LNP：

\[
\text{为什么 first-person actuality 必须 exactly-one-local，而不能 universal？}
\]

因此：

\[
\boxed{LNP\text{ is logically prior to PLP}.}
\]

---

## 5. Existing arguments for local privilege do not yet establish LNP

### Phenomenal isolation

\[
NoJointAccess\not\Rightarrow DifferentUltimateMine.
\]

Builes明确以 access disunity作 countermodel。

### Local mineness

若每个 experience intrinsically for-me：

\[
Experience\to ForMeNess,
\]

这反而更自然支持 universal immediacy，而不是 local exclusion。

### Structural dominance

Kadić-style dominance可以区分一个 local bearer，但：

\[
Dominance\not\Rightarrow PresenceExclusivity.
\]

Universalist可以接受一个 local informational/dominant role，同时说所有 experiences仍 ultimately mine。

### Self-manifestation

Henry / Fasching-style manifestation naturally pluralizes or universalizes；没有直接给 one-local-only rule。

### Actuality / NOW analogy

actual world / present time exact-one 只能提供 structural analogy，仍需说明 subject domain 为什么不能像 Universalism 那样 unify all experiential tokens。

所以当前：

\[
\boxed{LNP\text{ lacks independent support}.}
\]

---

## 6. Universalism also pays real costs

这不是免费胜利。

### U1 — Negative first-person intuition

我们强烈判断：

\[
\neg Mine(e_{other}).
\]

Universalism必须给 error theory，把这种 intuition解释为 access separation / biological self-model / memory-control boundaries。

### U2 — Moral/prudential identity

如果 all experiences mine，为什么 ordinary prudential concern 仍 strongly tracks one organism / memory stream？

需要：

\[
UniversalMine
+
LocalPrudentialStructure.
\]

### U3 — Subject semantics

single universal subject版本可能走向 cosmopsychism / open individualism；bundle版本则需解释 `mine` 在无 bearer情况下是什么意思。

### U4 — phenomenal unity

Universalism本身不 entail：

\[
GEU.
\]

若 all experiences mine但没有 phenomenal co-consciousness，需要解释同一 first-person ownership与 phenomenal disunity如何共存。

### U5 — empirical indistinguishability

与 local singleton theory一样，Universalism可能缺乏 public discriminative evidence。

因此：

\[
\boxed{Universalism\text{ is a live rival, not a cheap solution}.}
\]

---

## 7. Interaction with Global Closure

有趣的是，Universalism和此前 GCP / Roelofs / Christmann可以组合。

### U0

\[
UniversalMine+\neg GEU.
\]

### U1

\[
UniversalMine+GEU.
\]

若加 Christmann-style bearer pressure：

\[
GEU\Rightarrow GlobalSubjectPressure,
\]

则 U1 很自然地收敛到：

\[
\boxed{OneUniversalSubject+ManyLocalAccessRegions}.
\]

这与项目原始 target极其接近，但关键差异是：

\[
\boxed{\text{没有唯一 privileged local locus}.}
\]

所以 global-subject route本身甚至可能 favour Universalism，而非 PLP。

---

## 8. Interaction with I–NOW

Universalism可以接受 ordinary local `I-now` stages：

\[
\langle s_i,t_i\rangle
\]

作为 access / self-model / organism-relative centers。

但它拒绝：

\[
\exists!\langle s^*,t^*\rangle AbsoluteOpening(s^*,t^*).
\]

或者可以采取更 radical version：一个 universal I 在多个 local stages 上具有 distributed / non-jointly-accessible experiences。

因此 Conitzer-style local I–NOW并不能单独排除 Universalism。

---

## 9. New burden for Nomological Opening

NOM / SAOL以前的 burden：

\[
\text{why does law select }E^*?
\]

现在新增更基础的一层：

\[
\boxed{\text{why does law select at all?}}
\]

如果：

\[
Experience\Rightarrow Presence
\]

是更简单的 law/essence，那么：

\[
\Lambda_O
\]

不仅增加 selection mechanism，还增加 **exclusion content**：

\[
\forall E_j\neq E^*\;\neg Absolute(E_j).
\]

所以公平比较必须计入：

\[
\boxed{Cost(LocalExclusion)}.
\]

这使 `exactly-one` 从 theorem target变成需要单独 motivation 的强约束。

---

## 10. Localization Necessity Test

任何 future argument for unique local absolute-I 都先过四关：

### T1 — Access independence

argument不能把 lack of access偷换成 lack of ultimate ownership。

### T2 — Universalization resistance

若 proposed property `X` 可赋给所有 experiences而不 contradiction：

\[
\forall e\;X(e),
\]

则 X 本身不能支持 LNP。

### T3 — Exclusion job

必须有 independent explanandum 要求：

\[
X(E^*)\land\forall E_j\neq E^*\neg X(E_j).
\]

否则 exactly-one只是额外限制。

### T4 — Locality job

即使 one universal subject / field成立，也必须说明为什么 ultimate first-person actuality必须 localize到一个 access island。

若四关不过：

\[
\boxed{PLP\text{ should not even be invoked}.}
\]

---

## 11. Current verdict

这一 fork 显著改变 endgame。

过去：

\[
\text{PluralLocalSubjects}
\to
\text{OneGlobalSubject?}
\to
\text{WhichLocalLocus?}
\]

现在必须插入：

\[
\boxed{
\text{OneGlobal/FirstPersonReality}
\to
\text{Localize or Universalize?}
}
\]

所以新 ladder：

\[
\boxed{
FirstPersonReality
\to
\{PluralCentered,UniversalI,SelectiveOpening\}
}
\]

只有 SelectiveOpening 分支继续进入：

\[
LNP\to PLP\to winner.
\]

因此本轮最强新结果：

\[
\boxed{
\text{Why only one local locus? is prior to Why this local locus?}
}
\]

这将 Builes 2026 Universalism提升成 absolute-first-person project 的 strongest conceptual rival之一。
