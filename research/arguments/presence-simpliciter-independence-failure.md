# Presence Simpliciter Independence Failure

> Date: 2026-10-05
>
> Status: argument-level result from the CC1 presence audit.

## 1. Target

The hoped-for CC1 route was:

\[
OrdinaryTemporalPhenomenology
\Rightarrow
PresenceSimpliciter
\Rightarrow
PersonalizedPresence
\Rightarrow
CenteredCompletion.
\]

The audit shows that the first implication is not currently established.

## 2. Neutral package

Let the common phenomenological package be:

\[
P=\{Immediacy,ForMeNess,PhenomenalNow,TemporalFlowJudgment,DeSeCurrentness\}.
\]

A neutral relational model can represent this as:

\[
\exists S,t,E\;PresentTo(E,S,t)
\]

plus memory, anticipation, temporal integration, and self-model structure.

So:

\[
NeutralActuality+P
\]

is coherent-looking without:

\[
PresentSimpliciter(E).
\]

## 3. Centered interpretation

The centered side proposes:

\[
PresentSimpliciter(E^*).
\]

Conitzer then supplies a serious consistency pressure toward personalizing the privileged Now:

\[
PresentSimpliciter(E^*)
\Rightarrow
DistinguishedI\text{-}NOW(E^*).
\]

This remains a useful positive conditional.

But it begins **after** the contested step.

## 4. Independence failure

For CC1, the witness must be identified independently of the target theory.

If the candidate witness is described as:

\[
\text{“this experience is present simpliciter”},
\]

then the description already includes the disputed monadic metaphysical status.

What introspection more securely supplies is:

\[
\text{“this experience is immediately present to me now.”}
\]

That is compatible with relational presence.

Therefore:

\[
\boxed{
PresenceSimpliciter\text{ currently fails the CC1 independence condition}.
}
\]

## 5. Presence Interpretation Fork

Record the live fork:

### R — Relational reading

\[
PhenomenalPresence(E,S,t)
\to
PresentTo(E,S,t).
\]

### S — Simpliciter reading

\[
PhenomenalPresence(E,S,t)
\to
PresentSimpliciter(E).
\]

Current phenomenological data do not select between R and S.

So:

\[
\boxed{Phenomenology\Rightarrow R\lor S,\quad not\ currently\ S.}
\]

## 6. Implication for ALO

The previous conditional ALO route remains valid:

\[
CenteredActuality\Rightarrow AtLeastOneOpening.
\]

And the presence route remains:

\[
PresenceSimpliciter\Rightarrow PersonalizedOpeningPressure.
\]

But no new unconditional existence bridge has been obtained:

\[
OrdinaryPhenomenology\not\Rightarrow AtLeastOneIrreducibleOpening.
\]

## 7. Implication for Completion Fork

This result strengthens the actuality-endgame framing.

The disagreement is still best represented as:

\[
\boxed{
NeutralActuality
\quad vs\quad
IntrinsicallyCenteredActuality.
}
\]

Presence phenomenology does not currently function as an external referee between them, because each side can interpret the same common data according to its own presence ontology.

This is a specific case of **Interpretation Capture**:

> A proposed completion witness fails if the supposedly independent datum can be exhaustively described in neutral vocabulary and only becomes theory-discriminating after the contested metaphysical interpretation is added.

## 8. New narrow target

The remaining productive question is no longer “is the present special?”

It is:

\[
\boxed{
Is\ there\ any\ phenomenal,\ semantic,\ or\ explanatory\ residue\ that\ relational\ presence\ cannot\ capture?
}
\]

A future positive result must establish at least one of:

1. a phenomenal residue;
2. semantic indispensability of monadic presentness;
3. explanatory failure of relational presence;
4. incoherence/regress in pure relational presence.

Without one of these, `PresenceSimpliciter` stays a coherent metaphysical option rather than an independent CC1 witness.

## 9. Verdict

\[
\boxed{
PresenceSimpliciter\text{ does not currently break Completion Underdetermination.}
}
\]

It remains valuable downstream of an A-theoretic premise, but it does not currently provide the upstream premise itself.
