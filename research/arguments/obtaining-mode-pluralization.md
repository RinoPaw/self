# Obtaining-Mode Pluralization Challenge

> 状态：当前对 `Centered Actuality` / `Opening Identity Principle` 的最高优先级压力测试之一。
>
> 核心结论：把 first-person direction 从 fact-content 移到 fact 的 obtaining mode，虽然避开了 Constituent Collapse，却仍然没有获得 absolute singleton。

## 0. 问题

`Center-in-Content / Center-in-Obtaining Gap` 已经指出：

\[
\langle W,c\rangle
\]

与：

\[
Obtaining_c(W)
\]

是两种不同的 metaphysical architecture。

后一种更强，因为 first-person direction 属于 reality 如何 obtain，而不只是所获得内容的一个参数。

但一个新的问题随即出现：

\[
\boxed{
\text{obtaining itself perspectival}
\not\Rightarrow
\text{exactly one perspective is absolute}
}
\]

成熟的 constitutional perspectivalism 与 standpoint pluralism 已经提供这种反模型。

---

## 1. Direct countermodel from subjective facts

Lipman 2023/2026 的核心框架允许 subjects 本身是 metaphysical standpoints。

对每个真实 subject \(s_i\)，存在一些 facts：

\[
@_{s_i}(p)
\]

即 `p` obtains relative to / from the standpoint of \(s_i\)。

这里重要的是：

- 这不是 mere experiential relativity；
- world itself varies across subjects；
- phenomenal facts 可以 genuinely obtain only from certain subjects；
- 多个 subjects 都是真实 standpoints；
- 没有一个 subject 必须 ultimately privileged。

于是可以构造：

\[
R_{OP}
=
\langle
W,
S,
\{@_{s}(p)\}_{s\in S}
\rangle
\]

满足：

\[
\forall s\in S\;FirstPersonalStandpoint(s)
\]

以及：

\[
\neg\exists!s\;AbsoluteStandpoint(s).
\]

这个 countermodel 已经比“把 center 写进 relation argument”更强，因为它明确把 **obtaining relative to subjects** 当成 world-side metaphysical structure。

因此：

\[
\boxed{
\text{world-side first-personal obtaining}
\not\Rightarrow
\text{absolute first-person obtaining}
}
\]

---

## 2. Eker makes the problem constitutional

Eker 2023 更进一步地区分：

### Componential perspectivality

perspective 在 fact content 中：

\[
[\Pi_t(\varphi)]_a.
\]

### Constitutional perspectivality

perspective 属于 fact 的 mode / manner of obtaining：

\[
[\varphi]_t.
\]

后者不能被简单还原为：

\[
Instantiation(x,F,t)
\]

在一个更基础的 neutral / atemporal layer 上成立。

所以我们不能再说 pluralist 的 perspectivality 一定只是参数化 content。它可以和 OIP 一样深入到 reality 的 constitutive form。

仍然：

\[
[\varphi_1]_{t_1},
[\varphi_2]_{t_2},
\ldots
\]

可以由多个 perspectives constitutively obtain。

first-person analogue：

\[
[P_1]_{s_1},
[P_2]_{s_2},
\ldots
\]

所以：

\[
\boxed{
\text{constitutional first-personality}
\not\Rightarrow
\text{global first-person singularity}
}
\]

---

## 3. Non-relationalizability is insufficient

此前 `Obtaining-Level Centering` 要求 O1：absolute first-person fact 不能完整消去为普通：

\[
F(R,c).
\]

这是合理条件，但现在可见它不够。

一个 pluralist 完全可以接受：

\[
\boxed{\text{perspective is not a fact constituent}}
\]

同时接受：

\[
\boxed{\text{many perspectives are fundamental modes of obtaining}}
\]

因此：

\[
\boxed{
NonRelationalizablePerspectivality
\not\Rightarrow
AbsoluteCenter
}
\]

从 relation/content 层的 `Relativization Collapse` 逃出以后，理论仍可能发生 **Mode Pluralization**。

---

## 4. Center-Erasure Test 也需要加强

旧测试问：删掉 center 后，是否仍得到 complete actual reality？

若：

\[
EraseCenter(R)
\]

会使 reality 不完整，我们曾把这看作 centeredness 可能 constitutive 的证据。

但 obtaining-level pluralism 给出反例：

- 每个 subject-relative obtaining structure 都可能是 reality 的 fundamental constituent；
- 删除所有 perspectival obtaining，当然会使 reality 不完整；
- 甚至删除某一个 genuine subject 的 perspectival facts，也可能丢掉真实事实；
- 然而没有任何一个 subject 是 absolute。

所以：

\[
\boxed{
\text{center/perspective erasure destroys completeness}
\not\Rightarrow
\text{one perspective is simpliciter center}
}
\]

更强测试必须是：

> 能否删除 **absolute-orientation structure itself**，同时完整保留所有 ordinary / plural perspectival obtaining？

形式化：设：

\[
R=R_{plural}+A^*.
\]

真正 relevant 的 erasure 是：

\[
U_A(R)=R_{plural},
\]

而不是把全部 perspectival structure 一并删掉。

正方需要证明：

\[
\boxed{
U_A(R)\text{ 无法成为 complete actual reality}
}
\]

这正是当前最难的 existence claim。

---

## 5. Mode-Type / Mode-Token Gap

Eker 对 constitution monism / pluralism 的区分暴露出一个更精确的新 gap。

假设理论说：

\[
\boxed{\text{there is one fundamental kind of perspectival obtaining}}
\]

这只给：

\[
ModeType=Perspectival.
\]

它不排除大量 token：

\[
M_{s_1},M_{s_2},\ldots,M_{s_n}.
\]

因此：

\[
\boxed{
\text{one fundamental mode type}
\not\Rightarrow
\text{one obtaining center token}
}
\]

这与已有：

\[
\exists!G\not\Rightarrow\exists!E^*LIVE(E^*)
\]

高度同构。

一个统一 process 可以 manifest many live events；一个统一 perspectival mode type 也可以 manifest many perspectival obtainings。

---

## 6. The Opening Semantics Trilemma

考虑 OIP：

\[
Actual(R)\Rightarrow\exists c\;Open(R,c).
\]

`Open` 现在有三种主要读法。

### Route A — `Open` = ordinary constitutional perspectival obtaining

则对多个 subjects：

\[
Open(R,s_1),Open(R,s_2),\ldots
\]

自然成立。

结果：

\[
\text{obtaining-level pluralism}.
\]

无法推出 absolute singleton。

### Route B — `Open` = absolute / simpliciter obtaining by stipulation

例如直接规定：

\[
Open^*(R,c):=\text{reality obtains absolutely from }c.
\]

再写：

\[
Actual(R):=\exists!c\;Open^*(R,c).
\]

此时 OIP 可以给 `≥1`，但它靠的是 `Open*` 已经携带 absolute semantics。

解释停止在：

\[
\boxed{primitive absolute obtaining}.
\]

这是 coherent ontology，不是 derived explanation。

### Route C — `Open*` 从 independent actuality / structure 导出

若存在：

\[
D(R)\Rightarrow Open^*(R,c)
\]

则重新进入：

- Natural Pointing；
- Independent Definability；
- Actuality-to-Center Bridge；
- Privilege / Manifestation Bridge；
- symmetry / duplication / global relevance

等既有门槛。

因此：

\[
\boxed{
\begin{array}{lll}
A.&\text{ordinary perspectival opening}&\Rightarrow\text{pluralism};\\
B.&\text{absolute opening by semantics}&\Rightarrow\text{primitive};\\
C.&\text{derived absolute opening}&\Rightarrow\text{old bridge problems return}.
\end{array}}
\]

暂称 **Opening Semantics Trilemma**。

---

## 7. Stronger pluralist package

以前 strongest opponent 常写：

\[
R_P=\langle W,\Pi,\rho,A\rangle
\]

其中 `A` 是 uncentered actuality。

现在可以升级成：

\[
\boxed{
R_{COP}
=
\langle
W,
S,
M,
A
\rangle
}
\]

其中：

- `W`：objective / third-person structure；
- `S`：全部 genuine conscious subjects；
- `M`：不可 relationalize 的 constitutional first-person modes of obtaining；
- `A`：actuality / brute obtaining；
- 对每个 subject 都有 genuinely perspectival phenomenal facts；
- 无一 subject 被 absolute privileged。

这比旧的 `Uncentered Actuality + Perspectival Plurality` 更强，因为 perspectival facts 不再只是 content / anchor relation，而可以进入 reality 的 fundamental form。

若这个 package coherent，则 OIP 不能通过说：

> pluralist 只有 center-in-content，而我有 center-in-obtaining。

来胜出。

---

## 8. What OIP would now need

真正需要证明的已经不是：

\[
\text{actuality has perspectival form}.
\]

而是：

\[
\boxed{
\text{actuality has a globally singular, non-relativizable first-person orientation}
}
\]

至少包含三个独立命题：

### Directionality

\[
Actuality\Rightarrow PerspectivalForm.
\]

### Singularity

\[
PerspectivalForm\Rightarrow\exists!c\;Orientation(c).
\]

### Absoluteness

\[
Orientation(c)\not\equiv\text{one perspective among equally fundamental perspectives}.
\]

目前 literature 给了很多 Directionality 邻近模型，却没有给出 Singularity + Absoluteness 的非 primitive bridge。

---

## 9. Current negative result

可以暂时记录一个条件性结论：

> 若一个理论对 absolute first-person 的全部新增解释资源仅仅是 “facts/reality constitutively obtain from perspectives”，且没有 independent structure 区分一个 perspective-token 的 global status，那么该理论至多得到 obtaining-level first-person pluralism，不能得到 grounded absolute first-person singleton。

形式化：

\[
\boxed{
ConstitutionalPerspectivality
+
NoIndependentGlobalAsymmetry
\not\Rightarrow
\exists!E^*Absolute(E^*)
}
\]

这不是对 primitive centered actuality 的反驳。

它关闭的是一个重要伪出口：

\[
\boxed{
\text{“把 center 移进 obtaining mode” 本身不能完成项目。}
}
\]

---

## 10. 对研究方向的影响

`Centered Actuality` 现在剩两条诚实路线。

### Primitive-unificatory route

接受：

\[
WorldActuality=AbsoluteI=AbsoluteNOW
\]

是一个 primitive but unified metaphysical structure。

目标转为比较其：

- ideological cost；
- unification gain；
- phenomenological fit；
- modal / fission consequences；
- 与 fragmentalist pluralism 的总体解释成本。

### Derived route

寻找 independent structure：

\[
D\Rightarrow Open^*(R,E^*)
\]

继续 Grounded Centering Ladder。

目前没有第三条只靠 “mode of obtaining” 就能自然跨越 absolute singleton 的路线。
