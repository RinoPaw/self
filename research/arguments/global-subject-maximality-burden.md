# Global Subject Maximality Burden

> Date: 2026-10-05
>
> Status: argument-level result after the global-maximality audit.

## 1. Remaining non-primitive Universal-I route

After PFIP, BDP, and CUSP, the strongest non-primitive Universal-I strategy is no longer generic causal unity. It is a **maximality theory**:

\[
\exists M\;[Max_M(Cosmos)\land SubjectSensitive(M)].
\]

That is, there must be some non-arbitrary property by which the cosmos beats all competing local systems as the bearer of one subject.

## 2. GSM requirement

### GSM — Global Subject Maximality

A successful Universal-I theory must provide both:

\[
\boxed{M(Cosmos)>M(S)\text{ for every competing }S}
\]

and:

\[
\boxed{Max_M(S)\Rightarrow OneSubject(S)}.
\]

The first is a **winner condition**.

The second is an **identity bridge**.

Neither may simply restate `CosmosIsOneSubject`.

## 3. Why size / inclusion / causal reach fail

The following are insufficient by themselves:

\[
Largest(S),
\]

\[
ContainsMostParts(S),
\]

\[
CausallyConnectedToEverything(S),
\]

\[
FundamentalWhole(S).
\]

None of these properties is independently subject-sensitive.

A system can be larger, more causally connected, or more mereologically inclusive without thereby forming one experiential perspective.

So:

\[
\boxed{
M\text{ must track experiential unity/boundedness, not generic globality.}
}
\]

## 4. IIT as the existence proof for the right architecture

IIT shows that a serious maximality theory can be formulated:

\[
MaximalIntrinsicIrreducibility\Rightarrow Complex.
\]

It compares overlapping systems and selects a definite winner by a subject/experience-motivated criterion.

This validates the architecture of GSM in principle.

But it also reveals the burden on Universal-I: the cosmos is not the default winner. IIT recursively permits multiple disjoint maxima.

Thus:

\[
\boxed{
A\ maximality\ principle\ can\ exist\ without\ being\ cosmic.
}
\]

## 5. Field continuity does not solve GSM

A globally extended field can be one physical entity or one field type without being one numerical subject.

Therefore:

\[
OneGlobalField\not\Rightarrow OneI.
\]

Cosmopsychist field models must still show why the field's global extent forms one subject rather than a phenomenal medium containing multiple local subjects or fields.

## 6. Priority monism does not solve GSM

Priority monism gives one fundamental concrete whole.

But:

\[
FundamentalWhole\not\Rightarrow Subject.
\]

To obtain cosmopsychism one adds cosmic consciousness / subjecthood as a further thesis. Hence priority monism does not supply an independent winner condition or identity bridge.

## 7. Updated locality funnel

Universal-I now faces:

\[
\boxed{
UniversalI
\Rightarrow
GlobalMaximalityBridge
\quad|\quad
PrimitiveCosmicBearer.
}
\]

The global-maximality horn requires GSM.

The primitive-bearer horn requires BDP's independent assignment principle if it is to explain rather than merely stipulate ownership.

This is the narrowest locality fork reached so far.

## 8. Current result

No reviewed theory establishes GSM for the cosmos.

Therefore:

\[
\boxed{
UniversalI\ currently\ lacks\ a\ non\!\text{-}\!primitive\ locality\ bridge.
}
\]

This does **not** refute Universal-I. It changes its status:

- from a relatively cheap unitary rival;
- to a theory that must either produce a global subject-sensitive maximality criterion;
- or openly accept primitive cosmic bearer identity.

## 9. Next move

The highest-value next test is the primitive horn.

Construct permutation-equivalent ownership models over the same total experiential base:

\[
R+Own_1,
\]

\[
R+Own_2,
\]

where one model assigns all fields to one cosmic bearer and another assigns them to several bearers, while holding all phenomenal/causal facts fixed.

Then ask:

\[
\boxed{
What\ observable,\ explanatory,\ or\ grounding\ difference\ distinguishes\ the\ assignments?
}
\]

If none exists, primitive Universal-I faces an **Assignment Equivalence / Surplus Structure** problem analogous to earlier privilege-selection no-go results.
