# Global Context Dilemma

> 状态：工作论证。承接 `Ordinary–Absolute Centering Gap`。

## 0. 问题

ordinary centering 可以通过 attitude / utterance / experiential token 的 context 来获得独立解释：

\[
K_i=\langle subject_i,time_i,place_i,\ldots\rangle
\]

并由：

\[
Center(K_i)=C_i
\]

确定局部第一人称中心。

若要把同一思路升级成 absolute centering，就需要唯一 global context：

\[
K_G
\]

满足：

\[
Center(K_G)=E^*.
\]

问题是：**什么东西真正承担 \(K_G\)？**

---

## 1. Perspective-bearing role

现代 perspectivism 的一个常见结构是：perspective 不是裸 coordinate，而是 holder / vehicle 与 world/object 之间的非对称关系。

粗略写：

\[
Perspective(x,o)
\]

其中 \(x\) 可以是：

- subject；
- observer；
- instrument；
- representational vehicle；
- concrete local system / context。

这使 ordinary perspective 有独立的 relational basis。

因此若 `global context` 也想获得同等级解释，就应存在某个 bearer：

\[
B_G
\]

使：

\[
Perspective(B_G,R)
\]

真正成立。

---

## 2. Horn A — Reality is a genuine global perspective-bearer

若：

\[
B_G=Reality
\]

并且 reality-as-a-whole 真正具有 perspective-bearing / self-representational / self-manifesting role，那么 global context 不再只是一个形式 index。

这是最有解释力的版本。

但它立即承担：

### Cosmic-subject pressure

如果 perspective-bearing role 足够接近 conscious perspective：

\[
Reality\text{ has a perspective}
\]

很容易升级成：

\[
Reality\text{ is a subject}.
\]

理论滑向 cosmopsychism / superpsychism。

### Localization pressure

即使 reality 有 global perspective，仍需解释为什么它的 locus 是一个已有 local human experience：

\[
E^*\in\{E_1,E_2,\ldots\}
\]

而非：

\[
E^*=E_{cosmic}.
\]

### Content pressure

若 global perspective 真的携带 global content，为什么 \(E^*\) 不呈现 cosmic-scale phenomenal content？

因此 genuine global bearer 会把问题转换成：

\[
\boxed{\text{global perspective without a new cosmic subject}}
\]

与：

\[
\boxed{\text{global perspective localized to one existing experience}}
\]

---

## 3. Horn B — Reality is not a genuine perspective-bearer

若 reality-as-a-whole 没有 subject / vehicle / interaction / representation / manifestation role，那么：

\[
K_G
\]

就不能像 ordinary context 那样由 bearer-role 解释。

此时把 complete reality 写成：

\[
\langle R,K_G\rangle
\]

并指定：

\[
Center(K_G)=E^*
\]

很可能只是增加一个 formal evaluation parameter。

若没有进一步机制：

\[
M(R)\Rightarrow K_G,
\]

则 global context 面临：

\[
\boxed{\text{stipulative / primitive context pressure}}
\]

也就是把 `absolute center` 改名为 `global context coordinate`。

---

## 4. Dilemma

因此，试图用 context strategy 非任意地解释 absolute centering，会遇到：

\[
\boxed{
\begin{array}{lll}
A.&\text{global context has a genuine bearer}&\Rightarrow\text{cosmic-subject / localization pressure};\\
B.&\text{global context has no genuine bearer}&\Rightarrow\text{stipulative / primitive pressure}.
\end{array}}
\]

这就是 **Global Context Dilemma**。

它没有排除中间方案，但任何中间方案必须明确一种：

\[
\boxed{\text{non-conscious but metaphysically genuine perspective-bearing relation}}
\]

并说明该关系为什么：

1. 是全局的；
2. 只有一个；
3. 能以某个 local conscious event 为 locus；
4. 不把该 event 的 phenomenal content 扩展成 cosmic content；
5. 与 actuality / liveness 有独立关联。

---

## 5. 对 Nested Dominance / Centered Total State 的作用

### Nested Dominance

若 top-level dominance 被解释成 reality 的 global perspective-bearing role，则要防止：

\[
d(D_{top})=S_{cosmic}.
\]

理想版本要求：

\[
d(D_{top})=E^*
\]

其中 \(E^*\) 已经是某个 local experience。

### Centered Total State

若 centeredness 来自 global context，CTS 必须告诉我们 \(K_G\) 的 bearer 是什么。

若答案只是“complete state itself”，还要继续区分：

\[
\text{being a structured total state}
\]

与：

\[
\text{actually bearing a perspective}.
\]

不允许把后者从前者无论证地推出。

---

## 6. 当前最窄的建设性目标

现在一个真正突破性的候选应给出某种关系：

\[
G(R,E)
\]

满足：

- `G` 是 reality-level；
- `G` 不以 `Absolute(E)` 定义；
- `G` 不只是普通 subject-relative perspective；
- `G` 不要求 reality 成为另一个 conscious subject；
- 恰有一个 conscious event 满足：

\[
\exists!E\;G(R,E);
\]

- 并有独立理由认为：

\[
G(R,E)\Rightarrow LIVE_{simpliciter}(E).
\]

如果找不到这种中间关系，global-context 路线最终会在 cosmic subject 与 primitive pointer 之间摇摆。
