# Centering Reduction Trilemma

> 状态：条件性工作框架。目标是压力测试 `Centered Total State Hypothesis` 中的 center 是否具有独立解释内容。

## 0. 问题

Centered Total State 把完整现实写成：

\[
\mathcal C=\langle R,c\rangle,
\]

其中 \(R\) 是去掉 absolute center 后的完整 relevant structure，\(c\) 是 centered component。

定义 forgetful map：

\[
U:\mathsf{Centered}\to\mathsf{Uncentered},
\qquad
U(\langle R,c\rangle)=R.
\]

核心问题：

\[
\boxed{c\text{ 是否能由独立于 absolute-first-person 概念的结构解释？}}
\]

数学上，pointed object 的 basepoint 是额外 structure；forgetful functor 会把它遗忘。仅仅把一个对象写成 `pointed` 不会解释为什么该点被 distinguished。

---

## 1. Route A — Recoverable centering

假设存在一个统一、同构不变、独立动机的规则：

\[
\sigma:R\mapsto c
\]

使：

\[
\sigma(U(\mathcal C))=c.
\]

并对 relevant isomorphism \(g\) 满足：

\[
\sigma(gR)=g\sigma(R).
\]

那么 center 并没有增加独立本体论信息：

\[
\mathcal C\simeq\langle R,\sigma(R)\rangle.
\]

此时 `Centered Total State` 在解释上退回：

\[
\boxed{R\to c}
\]

即 Structural Selection。

它仍可能是一个很好的表示法，但不能用“现实从根上 centered”绕开 selector 的解释负担。

此外，即使 \(c\) 在结构中 uniquely definable，仍只有：

\[
\text{individualization}
\]

还需独立的：

\[
\text{privilege / liveness bridge}.
\]

---

## 2. Route B — Context-generated centering

Lewis / Openshaw / Jackson–Stoljar 路线表明，普通 de se centering 并不一定需要 primitive basepoint。

一个 attitude / utterance token 自带 context coordinates：

\[
k=\langle subject,time,place,\ldots\rangle.
\]

centering 可以由该 token 的功能角色与 context initialization 给出：

\[
Center_{local}(k)=\langle subject(k),time(k),\ldots\rangle.
\]

这给了真正独立的 centering explanation：为什么 Zeus 的第一人称 thought 以 Zeus 为 center，而不以 Odin 为 center，与该 attitude token 的 causal / functional / contextual role 有关。

但该成功恰好只解释 ordinary first-personhood。

现实中若有：

\[
k_1,k_2,\ldots,k_n
\]

多个真实 attitude / experiential contexts，则自然得到：

\[
Center_{local}(k_1),Center_{local}(k_2),\ldots,Center_{local}(k_n).
\]

所以：

\[
\boxed{\text{context-generated centering}\Rightarrow\text{center proliferation}}
\]

而非：

\[
\exists !c_{absolute}.
\]

要把这一路升级成 absolute centering，理论必须再给一个唯一的 global context：

\[
\exists!k_G,
\qquad
Center_{abs}=Center(k_G).
\]

但“现实整体为什么拥有唯一 global context”就是新的核心问题；若 \(k_G\) 只是被宣布存在，primitive pressure 返回。

---

## 3. Route C — Irrecoverable fundamental centering

假设：

\[
U(\langle R,c_1\rangle)=U(\langle R,c_2\rangle)=R,
\qquad c_1\neq c_2,
\]

且没有任何 independently motivated relation / process / context 从 \(R\) 生成哪个 center obtains。

那么：

\[
c
\]

就是 complete reality 的额外 fundamental structure。

这在逻辑上完全一致。它甚至可能比“外部 pointer”更自然，因为 center 不是附加在 complete reality 之后，而是 complete reality 的组成部分。

但对本项目当前的解释目标而言：

\[
\boxed{\text{fundamentally centered}\neq\text{non-primitive explanation}}
\]

如果唯一说明只是：

> 现实就是以 \(c\) 为 center 的 complete centered state，

那么模型仍停在 primitive centeredness。

这不构成反驳；它构成一个清晰的终点分类。

---

## 4. Expanded-structure escape 不形成第四类

可能回应：center 并非从贫化的 \(R\) 可恢复，但可以从更丰富的：

\[
R'=\langle R,\rho,Q,\ldots\rangle
\]

恢复。

其中 \(\rho\) 可以是 perspective anchoring，\(Q\) 可以是 grounding / manifestation relation。

此时继续检查：

### 若 \(\rho,Q\) 有独立动机

则：

\[
R'\to c
\]

属于 Route A，只是此前的 uncentered base 选得太贫。

### 若 \(\rho,Q\) 的唯一功能就是编码 `c is absolute`

则它属于 Route C 的 disguised primitive。

所以 expanded structure 不自动形成第四条路线。

---

## 5. Trilemma

在拒绝纯 verbal redescription 的条件下，Centered Total State 的 center 大体落入：

\[
\boxed{
\begin{array}{lll}
A.&\text{recoverable from independent structure}&\Rightarrow\text{Structural Selection};\\
B.&\text{generated by local context/functional role}&\Rightarrow\text{ordinary plurality};\\
C.&\text{irrecoverable from any independent structure}&\Rightarrow\text{primitive centeredness}.
\end{array}}
\]

这就是 **Centering Reduction Trilemma**。

它不证明 absolute centered reality 不存在。

它说明 `Centered Total State` 若想提供比 primitive absolute-first-person fact 更强的解释，必须找到一种很特殊的结构：

1. genuinely global；
2. independently motivated；
3. 不随每个 local context 复制；
4. 能生成一个 center；
5. 同时说明该 centering 为什么具有 actuality / liveness 意义。

---

## 6. 与自同构条件的关系

如果 \(\sigma(R)=c\) 是结构规则，则必须尊重相关同构：

\[
\sigma(gR)=g\sigma(R).
\]

因此若存在保持完整 relevant structure 的自同构：

\[
g(c_1)=c_2,\qquad c_1\neq c_2,
\]

就不能由该结构唯一恢复一个 center。

但反方向要谨慎：

\[
c\in Fix(Aut(R))
\]

一般只是一项必要性线索，并不在任意无限结构中自动保证 definability。有限结构等特殊情形可得到更强等价。

所以本项目继续使用“uniform structural recoverability / equivariance”而非简单把 automorphism-fixed 与 definable 无条件等同。

---

## 7. 对当前模型的结论

Centered Total State 的真正研究问题已经从：

\[
\text{can reality be represented as centered?}
\]

升级成：

\[
\boxed{\text{what independently motivated structure makes reality centered exactly here?}}
\]

如果答案存在，CTS 会重新汇入 Structural / Generative route，但可能以更正确的 complete-state ontology 表述。

如果答案不存在，CTS 仍是一个 coherent primitive theory，但不再被视为对 absolute center 来源的非 primitive 解释。
