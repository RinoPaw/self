# Actuality Arity–Singularity Gap

> 状态：由 Whitehead `vacuous actuality` audit 触发的 endgame refinement。
>
> 目标：防止把“actuality 内含 subjectivity”直接升级成“actuality 内含唯一 global subject”。

## 0. 新的拆分

此前 strong target 常写成：

\[
AAP:\quad CompleteActuality(R)\Rightarrow\exists!s\;SubjectArity(R,s).
\]

Whitehead-style process metaphysics说明这把两个不同命题压在了一起。

因此拆成：

### WAAP — Weak Actuality-Arity Principle

\[
\boxed{
CompleteActuality(R)
\Rightarrow
SubjectiveArity(R).
}
\]

这里 `SubjectiveArity(R)` 只要求 complete actuality 的 metaphysical form 不能完全 subject-neutral / interiority-free。

### SAP — Singularity Principle

\[
\boxed{
SubjectiveArity(R)
\Rightarrow
\exists!s\;GlobalSubjectPole(R,s).
}
\]

### LOC — Localization Principle

\[
\boxed{
\exists!s\;GlobalSubjectPole(R,s)
\Rightarrow
\exists!E^*\;LocalAbsoluteLocus(E^*,s).
}
\]

项目原始 absolute-first-person target 需要三者共同成立。

---

## 1. Whitehead countermodel shape

Whitehead 拒绝：

\[
VacuousActuality
=
Actuality\ without\ subjective\ immediacy.
\]

其 actual occasions 都是 experiential / prehensive subjects in becoming。

所以可以接受：

\[
WAAP.
\]

同时其 ontology 明确 pluralize：

\[
S_1,S_2,\ldots,S_n
\]

都可以是 genuine subject-bearing actual occasions。

因此：

\[
\boxed{
WAAP\not\Rightarrow SAP.
}
\]

这就是 **Actuality Arity–Singularity Gap**。

---

## 2. 与 Lipman / Eker 的关系

此前已有：

\[
PerspectivalObtaining
\not\Rightarrow
PerspectiveSingleton.
\]

Whitehead 提供一个更强压力：即使 neutralist 让步，承认 actuality 本身具有 interior / experiential arity，仍然可以有：

\[
PluralSubjectiveActuality.
\]

所以不能再把争论只写成：

\[
SubjectNeutralActuality
\quad vs\quad
SubjectiveActuality.
\]

完整空间至少有三项：

\[
\boxed{
SubjectNeutralActuality
\quad|\quad
PluralSubjectBearingActuality
\quad|\quad
SingularCenteredActuality.
}
\]

这第三分支非常重要，因为它阻止任何 WAAP 成果被错误计成 centered-completion 胜利。

---

## 3. 对 Completion Fork 的重写

原来：

\[
C_N
\quad vs\quad
C_C.
\]

现在理论空间更细：

### C0 — Subject-neutral completion

\[
Complete(R)\land\neg SubjectiveArity(R).
\]

Bricker / Soames / Adams-style。

### C1 — Plural subject-bearing completion

\[
Complete(R)
\land
SubjectiveArity(R)
\land
\neg\exists!s\;GlobalSubjectPole(R,s).
\]

Whitehead-style；也与 standpoint pluralism形成邻近结构。

### C2 — Singular centered completion

\[
Complete(R)
\land
\exists!s\;GlobalSubjectPole(R,s).
\]

Role-First / Nagai-style target。

所以 centered side 现在必须连续赢两场：

\[
C0\to C1
\]

和：

\[
C1\to C2.
\]

B1 / vacuous-actuality critique最多主要攻击第一场。

---

## 4. 为什么 singularity 不能从 unity 免费获得

可能的 bad inference：

\[
RealityIsOne
+
SubjectBearingReality
\Rightarrow
OneSubject.
\]

但：

\[
OneSystem\not\Rightarrow OnePerspective.
\]

一个 metaphysically unified totality可以包含 many irreducible subject-poles / actual occasions / standpoints。

所以任何 SAP 必须增加至少一种结构：

- priority monism strong enough to make the whole one subject；
- absolute idealist subject-object unity；
- global integration / exclusion principle；
- one ultimate self-manifesting act；
- independent reason why plural subjectivity is incomplete。

没有这些额外 premises：

\[
\boxed{
Unity\not\Rightarrow SingularityOfSubject.
}
\]

---

## 5. 对 SMAA 的修正

旧 Self-Manifesting Actuality Argument：

\[
Actuality
\to
SelfManifestation
\to
Subjectivity
\to
OneFundamentalSubject
\to
OneLocalAbsoluteLocus.
\]

现在更准确：

\[
\boxed{
Actuality
\xrightarrow{WAAP}
SubjectBearingActuality
\xrightarrow{SAP}
OneGlobalSubject
\xrightarrow{LOC}
OneLocalAbsoluteLocus.
}
\]

其中：

- Whitehead makes WAAP serious；
- Hegel / Fichte / Gentile / cosmopsychism主要尝试 SAP；
- Nagai / Hare-like local privilege仍然承担 LOC pressure。

这把文献分工变得更清楚。

---

## 6. 新的 theory-comparison consequence

如果 WAAP 最终成功，而 SAP 失败，那么 neutral side不会简单回到 Bricker-style subject-neutral actuality。

它会升级成：

\[
\boxed{Plural Subject-Bearing Actuality}.
\]

这会是一种很强的中间理论：

- actuality genuinely has interiority；
- reality is not vacuous；
- multiple subjects / perspectives are metaphysically real；
- no one subject is absolute simpliciter。

这可能比当前 `N-ACT` 更接近用户原始 vertiginous intuition，同时仍否定 unique absolute first-person。

因此未来 positive evidence 必须明确自己支持：

\[
WAAP
\]

还是：

\[
SAP.
\]

不能混算。

---

## 7. Current verdict

当前：

\[
\boxed{WAAP\text{ now has a serious Whiteheadian positive model}.}
\]

但：

\[
\boxed{SAP\text{ remains independently unsupported}.}
\]

甚至 Whitehead 是一个很自然的 WAAP-without-SAP countermodel。

所以 strongest current positive progress 是：

> thin/vacuous actuality 现在有了真正成熟的挑战；但就算这个挑战获胜，unique absolute first-person 仍不会随之出现。

这使 endgame 比此前更严格：

\[
\boxed{
First win subjectivity;
then separately win singularity;
then separately win localization.
}
\]
