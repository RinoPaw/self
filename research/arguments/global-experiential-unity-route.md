# Global Experiential Unity Route

> 状态：2026-10-05 singularity-route refinement。
>
> 目标：吸收 Christmann 2026 的 global-subject pressure，区分 `subjective arity`、`global experiential unity` 与 `one global subject`。

## 0. New factorization

此前 SAP 写作：

\[
SubjectiveArity(R)
\Rightarrow
\exists!s\;GlobalSubject(R,s).
\]

Christmann 2026表明一个更精确的中间结构：

\[
\boxed{
SubjectiveArity
\xrightarrow{G_1}
GlobalExperientialUnity
\xrightarrow{G_2}
GlobalSubjectPressure.
}
\]

其中：

- \(G_1\)：Global Experiential Unity Principle；
- \(G_2\)：Global Unity → Subject Pressure。

Christmann主要支持 \(G_2\)，不支持 actuality-general \(G_1\)。

---

## 1. Define Global Experiential Unity

令：

\[
GEU(R)
\]

表示完整 reality 的 fundamental experiential contents 不是一组彼此独立的 local subjectivities，而属于一个 single overarching experiential/co-conscious structure。

至少包含：

\[
\forall e_i,e_j\in FundamentalExperience(R),
\]

它们处在同一 global unity architecture 中，而不是分散在多个 mutually disjoint subject domains。

GEU 比：

\[
\exists many\ conscious\ subjects
\]

强得多，也比：

\[
Reality\ is\ one\ whole
\]

强得多。

---

## 2. Christmann's G2

Yetter-Chappell-style phenomenal tapestry 已经承诺一个 global experiential whole：所有 possible sensory perspectives由 unity-of-consciousness / property-binding / spatial-temporal relations织成一个 tapestry。

Christmann给两条 pressure。

### 2.1 Bearer pressure

若整个 tapestry genuine experienced，则存在一个 experiencer of the whole。

若该 experiencer只是语法占位符，就无法承担“这些 experiences 都被一个 act experienced”的角色。

若它 genuine承担该角色，就已经具有 determinate global experiential scope。

所以：

\[
\boxed{
GEU+GenuineExperiencer
\Rightarrow
GlobalSubjectPressure.
}
\]

### 2.2 Pattern-grounding pressure

global tapestry具有特定 synchronic co-consciousness pattern：

\[
Pattern_t.
\]

Christmann 认为 unified experiential act提供：

\[
Ground(Pattern_t)
\]

因为 co-present contents共同作为 one subject's intentional act 的 contents。

所以 abductively：

\[
\boxed{
GEU+SpecificCoConsciousPattern
\Rightarrow_{abductive}
OneUnifiedExperientialAct
\Rightarrow
GlobalSubjectPressure.
}
\]

这使 \(G_2\) 有了 contemporary direct support。

---

## 3. G1 is now the real bottleneck

项目真正需要：

\[
G_1:\quad SubjectiveArity(R)\Rightarrow GEU(R).
\]

但 Whitehead-style process metaphysics、IIT-style multiple complexes、Lipman-style standpoint pluralism都提供：

\[
SubjectiveArity+\neg GEU.
\]

因此：

\[
\boxed{SubjectiveArity\not\Rightarrow GEU.}
\]

这是当前最直接的 pluralist countermodel pressure。

---

## 4. Whole-unity cannot substitute for experiential unity

设：

\[
OneWorld(R)
\]

或：

\[
OneFundamentalWhole(R).
\]

仍不能推出：

\[
GEU(R).
\]

一个 metaphysical whole可以包含多个 mutually non-co-conscious subjects。

所以：

\[
\boxed{
WorldUnity
\not\Rightarrow
ExperientialUnity.
}
\]

同理：

\[
CausalUnity
\not\Rightarrow
CoConsciousUnity.
\]

这防止从 one-world / priority-monism 直接偷渡 GEU。

---

## 5. Local co-consciousness cannot be globally closed for free

每个 local subject可能满足：

\[
Unity(S_i).
\]

但：

\[
\forall i\;Unity(S_i)
\]

没有推出：

\[
Unity(\bigcup_i S_i).
\]

IIT 的 recursive multiple-complex construction特别清楚地显示：local maximal unity可以在多个 disjoint domains 上同时成立。

因此：

\[
\boxed{
LocalUnity^{*}
\not\Rightarrow
GlobalUnity.
}
\]

要得到 GEU，需要新的 **Global Closure Principle**。

---

## 6. Candidate Global Closure Principles

### C1 — One actuality, one experiential field

\[
OneActuality(R)\Rightarrow OneExperientialField(R).
\]

当前没有独立支持；这正会被 Bricker/Whitehead/Lipman路线拒绝。

### C2 — All experiential relations compose transitively into one unity

但 co-consciousness通常不能简单假定 transitive；而 Yetter-Chappell本身在 perception模型中使用 non-transitive unity relations。

所以不能靠 relation closure免费得到 global tapestry。

### C3 — All phenomenal facts need one ultimate bearer

这已经接近 Global Subject 结论本身，容易 circular。

### C4 — One synchronic world-pattern requires one experiential act

这是 Christmann最有希望的 pressure，但 antecedent 已要求 world structure fundamentally experiential。

因此它更准确是：

\[
PhenomenalWorldStructure
\Rightarrow
GlobalActPressure,
\]

不是 actuality-general principle。

---

## 7. New singularity ladder

当前 positive route应更新为：

\[
\boxed{
Actuality
\xrightarrow{W}
SubjectiveArity
\xrightarrow{G_1}
GlobalExperientialUnity
\xrightarrow{G_2}
GlobalSubject
\xrightarrow{L}
LocalAbsoluteLocus.
}
\]

其中：

- \(W\)：Whitehead / self-manifesting actuality route；
- \(G_1\)：当前新主瓶颈；
- \(G_2\)：Christmann 2026提供 serious conditional support；
- \(L\)：仍完全开放。

因此此前泛写的 SAP 应被拆成：

\[
SAP=G_1+G_2.
\]

---

## 8. Consequence for theory space

理论空间现在至少四层：

### A0 — Subject-neutral actuality

\[
Actuality+\neg SubjectiveArity.
\]

### A1 — Plural subject-involving actuality

\[
SubjectiveArity+\neg GEU.
\]

### A2 — Globally unified experiential actuality

\[
GEU+GlobalSubjectPressure.
\]

### A3 — Local absolute orientation

\[
GlobalSubject+LocalAbsoluteLocus.
\]

所以即使 WAAP淘汰 A0，仍要 separately 淘汰 A1。

Christmann 给了从 A2 到 global subject 的新动力，但没有把 A1 推进到 A2。

---

## 9. Current verdict

新的 strongest positive singularity result：

\[
\boxed{
GlobalExperientialUnity
\Rightarrow
GlobalSubjectPressure
}
\]

现在有 serious contemporary argument，而不是 pure stipulation。

但项目还没有：

\[
\boxed{
CompleteActuality
\Rightarrow
GlobalExperientialUnity.
}
\]

所以 absolute-first-person route 的 exact frontier再次缩窄：

\[
\boxed{
Why should all fundamental subjectivity belong to one global co-conscious unity?
}
\]

若找不到 Global Closure Principle，Whitehead/Lipman-style plural subjective actuality继续是完整 competitor。
