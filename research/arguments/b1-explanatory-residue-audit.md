# B1 Explanatory Residue Audit — Does a Complete Neutral Reality Still Miss a Fact?

> 2026-10-08 · 研究方向：**先挑战 C0 对普通意识和原始「偏偏是我」问题的充分性**。  
> 状态：独立文献核对 + strongest-foil reconstruction + 分层反方测试；**尚无决定性的 metaphysical residual witness**。  
> 参阅旧档：[Residual Fact Problem](residual-fact-problem.md)、[Vertiginous Question–Fact Gap](vertiginous-question-fact-gap.md)、[Neutral One-World Exhaustion](neutral-one-world-exhaustion-test.md)、[B1 Grounding](../models/neutral-contrast-grounding-audit.md)、[当前研究立场](../../synthesis/current-position.md)。

## 0. 最重要的收获：把「解释完」拆成三种，避免两侧各自作弊

设 \(\mathcal B_1\) 为**一个完整 actual history**、实际存在的全部 subjects、各主体真实的全部 qualitative phenomenal facts、local mineness、de se capacities / utterances、心理物理关系、subjective continuity、interpersonal relations 及普通的 truthmakers / actuality treatment。这里 **local phenomenality 自身是真实的**，不先假定它可以由 neurophysics 还原，也不预先附加全球 singular opening。

三种不同的 completeness：

1. **D — Descriptive saturation**：\(\mathcal B_1\) 明确列出全部普通第三人称及各 subject 的真实局部现象事实。它不是「只列神经事实」的稻草人。
2. **G — Grounding/explanatory completion**：除列出 \(P_i\) 外，还说明 \(P_i\) 以何种机制、identity、dependence 或 fundamental laws obtain。仅把 \(P_i\) 写进事实清单**没有**证明已完成 G。C0 可以让局部 phenomenal properties 是 primitive；其 explanatory cost 必须计算。
3. **A — Absolute-pointed completion**：完整世界必须再有一个唯一、非相对化 \(\Omega(E^*)\)，且整个 reality 以它取得 absolute I–NOW status。把 A 当作「complete」的定义，是待审的 **C2 公理**，不能用它攻击 D/G 后说已经发现独立遗漏。

**本轮新判据**：研究者须分别问「C0 缺了可指认的 fact 吗？」与「C0 虽容纳该事实，却没给出满意的 grounding 吗？」。第一种是 potential *ontic residue*；第二种可能只是多个理论共同面对的 *explanatory debt*，必须比较 C2 是否真正还掉债务。

## 1. 四个常被混成同一问题的 gap

| 问题类型 | 可以独立确定的对象 | strongest C0 的合法答复 | 是否足以推出 \(\Omega\)？ |
| --- | --- | --- | --- |
| **Q-PH**：为什么有真实的这种痛感 / 红色体验？ | \(P_i\) 及其 qualitative content | 承认 \(P_i\)，提出 psychophysical laws、identity、grounding 或 explicit phenomenal primitives | **否**；若 C0 失败，优先触及普遍经验 ontology（C1/C2 均可能） |
| **Q-DESE**：为什么我不知道自己是谁 / 现在何时？ | 同一 uncentered history 的 centered cognitive states | situated epistemic state + de se/self-location；知道所有 uncentered facts 未必知道自己的 centered position | **否**；认知缺口不自动生成客观新 winner |
| **Q-ACT**：为什么这些事实在这个世界实际成立？ | 一份 actual totality / actualizer | instantiation、brute obtaining、fundamental uncentered actuality 等至少是具体候选 | **否**；需要「actuality 本质上含唯一第一人称」的独立论据 |
| **Q-SEL**：在全部真实 subject-stage 里，何者具有唯一 **simpliciter** privilege？ | 若存在，\(\Omega(E^*)\) 与其 alternatives 间存在事实差别 | 在 C0 下可能没有这种进一步的全局挑选事实；原疑问的体验、语言和动机仍需解释 | 只有预先确立 **non-indexical global selection fact** 才是正方关键 |

「世界已知但我未知自己位置」可能是 **epistemic** incompleteness；「世界并未决定哪位 absolute winner」必须有独立的 ontic target。二者不能同词替换。

## 2. Saturation Trial：两个完整意识主体

考虑一份已实际化的现实 \(R\)，其中 \(a,b\) 都有完整且真实的 phenomenal lives：

\[
\mathcal B_1(R)=
\{Actual(R),Person(a),Person(b),P_a,P_b,
DeSe_a,DeSe_b,Hist(R),Rel(R),\ldots\}.
\]

- \(a\) 的视角中，直接「这就是我的痛」；\(b\) 的视角中也一样。
- 两人还可能拥有相同强度的「为什么是我？」之感及相似的报导/信念，甚至某些体验 token 发生 overlap。
- 在 C0 的客观事实全清单里，\(P_a,P_b\) **都 obtain**，各人的 self-location 可以作为独立的认知状态变化。

提出新增对比：

\[
T_0=\mathcal B_1;\quad T_1=\mathcal B_1+\Omega(a);\quad
T_2=\mathcal B_1+\Omega(b).
\]

如果 C2 对 \(a,b\) 的局部体验、行为、证据完全 inert，三种方案在**共同数据**上不能区分。这**没有证明** \(T_1,T_2\) 不可能；只是确定了新增 \(\Omega\) 当前处于 underdetermined position。

不能单凭写出 \(T_1,T_2\) 就声称「存在同 B1 但不同 absolute winner 的两个 metaphysically possible worlds」：modal admissibility 仍须独立证明。也不能说「因 B1 没有 \(\Omega\) 字符，它必然遗漏一项 fact」；除非已在**不含 \(\Omega\) 同义词**的语言里独立识别了这项现实差异。

### C0 的完整性由两条不同责任构成

- **Coverage**：列入真实 local qualitative / phenomenal truth，避免把感受当 illusion；
- **Constitution**：说明 local conscious facts 在一套可行 ontology 中如何成立，以及整个现实如何 obtain。

C0 暂时达到比较强的 coverage，但 constitution 可以仍未完成；这是 **C0 的真实解释负担**。必须进一步测试「一个 primitive local phenomenal field」是否较 \(\Omega\) 更昂贵，以及 \(\Omega\) 究竟能不能解释 *所有* 人的意识事实。单独增加一个 global absolute opening，不能自动 ground \(P_b\) 或 ordinary consciousness 的起源。

## 3. Mary 检验：知识增加 ≠ 事实增加 ≠ absolute selection

知识论证（Mary）目标是 complete physical information 与 direct acquaintance / phenomenal knowledge 之间是否存在余量。SEP [Knowledge Argument](https://plato.stanford.edu/entries/qualia-knowledge/)（2024 实质修订，§4.3–4.9）记录：
- ability/acquaintance 回应；
- phenomenal concept / *new knowledge, old fact*；
- 强抗物理主义回应，认为新认识揭示了 physical base 所缺的 phenomenal nature。

**双方都有尚未裁决的论点**。即使 Mary 成功证明 **physical-base incompleteness**，至多首先支持不能由纯物理事实完整解释 qualia。C0 的 **subject-neutral actuality** 并不等于严格物理主义：它可以承认真正 local phenomenal primitives，而仍无任何独立的 unique absolute subject。

如果后来证明所有主体的 phenomenality 都要求某种不可还原的 first-person obtaining manner，那会向 C1/C2 增加压力；**不能从这一共性直接跳到 only-one**。

本轮不把「Mary 出来才知道某种感受」当作 \(\Omega(a)\) 的独立证据，因为她的 cognitive transition 可以在每一个有经验的主体中重复发生。

## 4. Conitzer 模拟案例：真正的正方样板，与它不成立的外推

Vincent Conitzer, [*A Puzzle about Further Facts*](https://doi.org/10.1007/s10670-018-9979-6), *Erkenntnis* 84 (2019) 727–739（2018 在线），在**公开全文 §1–5**明确区分：

- **Case A**：Fonda 看着模拟里的 Alpha 被显示在现实屏幕上。除了模拟本身的物理规律/初始条件，还有真实的 **display mapping / external code / monitor**。只改显示 code、不改模拟宇宙的内部规律，便能令屏幕显示 Beta。这是**相对于模拟内部事实基底**确有独立的进一步事实。
- **Case B**：Fonda 戴着 VR，彻底忘记外部世界；我们作为外部描述者知道存在外部 display selector，**但她自身认识上难以区分有无更外层机制**。
- **Case C**：我们的通常世界。文章未宣称 Case C 的外部 selector 已被证明；作者强调从 B 到 C 的 *epistemic justification* 难题。他倾向认为「Case A 论证成立、Case B 不具备足够推断正当性」是反对进一步事实者的最有希望路线，但同样指出相关认知障碍需要更多论证。

**重要逻辑提醒**：在 A，所谓 further fact 是相对于 \(\mathcal B_{\text{simulation}}\) 而言；若改拿包含 Fonda、头显、显示机器及代码的 \(\mathcal B_{\text{total}}\) 做基础，external display 的 physical truth 本来就在完整事实里。因此「一套受限描述有额外事实」不能直接证明「完整 actuality 有非物理的绝对 opening」。

### 如何把模拟例子真正变成我们的独立 witness

如果现实里能独立识别类似：

\[
SelectorRelation(a^*,e),\quad\text{且可在固定内部 world / local phenomenality 时改动},
\]

且这种 selector **不是另一位普通局部 subject、不是单纯 epistemic de se，也不只是从外部视角观察/播放影像的 relation**，那么才可能得到 C0 不易容纳的世界侧差异。

但证明「有外部显示设备」依旧未必推出「宇宙只允许一个绝对 observer」：一个外部系统可以有多个 monitors、多个 viewers 或 parallel selectors。C1 的多元模式仍是对手。还需要 unique cardinality / global reflection 的独立证据。

## 5. 原始 Why-Me 题目的 Presupposition Ledger

每一次说「偏偏是我」，先固定该句实际声称的内容：

| 原始说法 | 最小可独立承认的事实 | 要支持额外 \(\Omega\) 尚欠 |
| --- | --- | --- |
| 「我在这里感到痛」 | 某实际主体 \(s\) 的 \(P_s\)，真实的 de se/qualitative facts | 世界外进一步 singular mode 必要性 |
| 「我不能直接感觉他人的痛」 | 有感知/认识渠道的主体界限 | 从 epistemic access 排他推得 actuality exclusivity 的桥梁 |
| 「我知道所有人物经历却不知自己是谁」 | 一个 centered uncertainty state | 证明不确定性对应 world-level further fact，而非 agent-position |
| 「此刻显得唯一活着」 | 某主体的 liveness seeming 及其可信度 | 证明 seeming 是对 globally privileged fact 的可靠检测，不只 local phenomenal presence |
| 「我本来可以变成别人」 | 可能的 identity/self-location counterfactual 或外部 selector 映射 | 指定跨世界 self-identity / mapping law；排除纯替换说 |
| 「模拟中的一台屏幕显示 Alpha」 | 模拟外 hardware/render mapping （Case A） | 独立说明我们的 complete actual world 也有相应 extra-world observer |
| 「其他主体也真实」 | 多个 local conscious lives 均 obtain | 为什么全体共真仍需 one-and-only-one fundamental centered actualizer |

把争论中的 \(\Omega\) 含义直接放进左列，就是 **explanandum inflation**：先把 C2 的独特前提称为「被解释现象」，再批评 C0 没解释这条定义出来的现象。

## 6. Explanatory Remainder Gate：两条通道，按顺序

### Gate A：Residual identification（当前失败，未证明不可能）

给出一个 \(X\)，满足：

1. **Pre-theoretic / independent individuation**：描述 \(X\) 不使用 absolute winner、global opening、simply-live subject 或其同义词。
2. **Non-epistemic truth-condition**：\(X\) 表示全现实如何取得事实地位，不仅是 agent 知识状态/新概念/注意力/感知局限。
3. **C0 B1 stress**：在完整 local phenomenality + actual world base 里仍有真正解释剩余；不能通过引入最普通的 local facts 消除。
4. **C1 stress**：即使允许多个 primitive FP modes，也不能低成本解释 \(X\)。
5. **Explanation delta**：加入 C2 后提供可说明的 grounding/constraint/prediction 增益，而不仅复写 \(\Omega\) 本身。

### Gate B：Neutral constitution failure（尚未获得独立证明）

不依赖一个特殊 \(X\)，也可尝试提出：

\[
B1\text{-}Constitution \text{ is metaphysically incoherent or insufficient},
\]

并详细说明何处 fail（local fact identity、grounding asymmetry、truthmaking、actuality）。**这个判据首先可能迫使 C0→C1 或 C2**；不能把 C1 的失败当作 C2 成功。

### 解释债务不自动转移

若「完整 local phenomenal world 为什么存在」仍是 brute cosmological existence question，C2 的 global role 也需解释「为什么有该 role / 为什么这个 local stage」；以 \(\Omega\) 替换 ordinary actuality primitive 可能只是**转移了而非减少解释债务**。真正进展应显示 C2 使对手必须额外 stipulate 的某条事实/规律变得可推导。

## 7. 本轮 verdict 与停止条件

已找到的独立事实：

- 真实 local phenomenal facts 与 direct felt presence；
- epistemic de se 与 phenomenal knowledge 的局限；
- 在 Conitzer Case A 受限模拟物理基底之外的已知 display-mapping facts。

**目前这三类都不能单独推出 universality、ontic first-person arity 或 singleton absolute I–NOW**。

本轮完成的工作是更严格地把 **描述充分性 D** 与 **本体奠基 G** 分开，同时校准了 Conitzer 的外部 selector 相对何种 basis 是 genuinely further。这比继续重复 \(\forall F\exists c\) 的非蕴涵更贴近问题的实质，但**没有得到独立支持 C2 的 witness**。

若下一轮仍无法从 Gate A/B 产生可争论的新前提，应将研究结论保持为 **C0/C1/C2 explanatory underdetermination**，并记录 C0 的 local consciousness constitution 未必已获解决、C1/C2 的超出 common facts 的动机尚缺充分支持。**不要将 C0 的低额外承诺写成它解释完了一切。**
