# Universal-Property–Manifestation Dilemma

> 状态：工作论证。

## 0. 问题

当前希望找到一个全局 universal property：

\[
Q_{\mathcal R}(E)
\]

使：

\[
\exists!E^*\;Q_{\mathcal R}(E^*)
\]

并且 \(Q\) 本身具有 manifestation / first-person / actuality 意义。

Category theory 提供了大量天然 unique-existence roles，例如 terminal object、initial object、limit、colimit、representing object。

但“universally distinguished”与“absolutely manifest”之间仍有系统性距离。

---

## 1. Universal-property uniqueness is relational

设 category \(\mathbf C\) 的 objects 是 experiential / perspectival candidates。

例如 terminal object \(T\) 满足：

\[
\forall X\in\mathbf C,\quad \exists!f_X:X\to T.
\]

这确实给出一个完全关系性的 distinguished role。

优点：

- 不需要额外 scalar score；
- 不依赖内部标签；
- 如果 category / morphisms 本身独立合理，specialness 由结构产生。

这正是当前项目需要的那类形式。

---

## 2. Domain relativity

Universal property 永远相对于：

\[
(\mathbf C,\operatorname{Hom})
\]

而成立。

同一个现实可以有许多合理 categories；每个主体内部也可以形成自己的 experiential category，并各自拥有 terminal / universal objects。

因此：

\[
\boxed{\text{local universal object}\not\Rightarrow\text{global absolute object}}
\]

这与 Local-to-Global Singleton Obstruction 同型。

Imants Baruss 2019 的 categorical model 就提供了直接先例：每个 individual 的 experiential topos 都可以用 terminal object 表示 phenomenological subject。

这说明 terminality 可以很好地 formalize a subject，但自然结果是：

\[
T_A,T_B,T_C,\ldots
\]

而非一个全局 \(T^*\)。

---

## 3. Globalization option

可以把 category 扩成包含所有 ordinary perspectives 的：

\[
\mathbf C_{global}.
\]

然后要求唯一 terminal / initial object：

\[
E^*=T_{global}.
\]

这解决 formal singleton，但立刻产生 morphism-semantics 问题。

---

## 4. Dilemma

### Horn A — Morphisms have genuine manifestation meaning

假如：

\[
f:X\to E^*
\]

表示：

- X is presented to E*；
- X is experienced by E*；
- X manifests in E*；
- E* is acquainted with X；

那么 terminality：

\[
\forall X\;\exists!X\to E^*
\]

意味着全部 experiential contents / perspectives 以某种强方式 manifest to \(E^*\)。

这容易导致：

\[
\boxed{\text{Cosmic-Content / Cosmic-Subject Pressure}}
\]

即 \(E^*\) 不再像普通局部经验，而更像包含 / confront / experience 全部 perspectives 的 cosmic subject。

这与项目要求：

\[
E^*\text{ can be an ordinary local human experience}
\]

发生张力。

### Horn B — Morphisms are structurally thin

若 arrows 只表示：

- abstract dependence；
- comparison；
- formal map；
- ordering；

那么 terminality 可以保持 content-silent，但：

\[
\boxed{\text{Terminality}\not\Rightarrow\text{Liveness}}
\]

即重新出现 Privilege Bridge。

所以：

\[
\boxed{
\text{phenomenally thick arrows}\Rightarrow\text{cosmic-content pressure}
}
\]

而：

\[
\boxed{
\text{phenomenally thin arrows}\Rightarrow\text{priority/liveness gap}
}
\]

---

## 5. Initial-object dual

若改成 initial object：

\[
\forall X\;\exists!E^*\to X,
\]

并把 morphisms 理解成 generative / grounding / manifestation-source relation，则 \(E^*\) 成为所有 perspectives 的 source。

这避免“E* 接收全部 content”的一种读法，却进入：

\[
\boxed{\text{Experiential Grounding Bottleneck}}
\]

即所有其他 minds 的 first-person facts 都依赖于 \(E^*\)。

当前没有独立理由接受这种极强 dependence，而且会重新触发 de-combination / individuation pressure。

---

## 6. Uniqueness up to isomorphism

Universal objects 通常只保证：

\[
\text{unique up to (unique) isomorphism}.
\]

而 absolute first-person 假说要求 token-level：

\[
\exists!E^*.
\]

若两个 physically / metaphysically distinct events 在选定 category 中 isomorphic，则 universal role 最多确定一个 isomorphism class。

要得到 token identity，category 必须含足够丰富的 relational structure 以区分 tokens。

这又连接到：

\[
\text{Yoneda-style individuation}
\]

但 complete relational individuation 仍不自动给 privilege。

---

## 7. Relation to Phillips–Tsuchiya

Phillips & Tsuchiya 2024/2025 明确提出用 universal mapping properties formalize IIT 的 intrinsicality、information、integration、exclusion、composition，并用 slogan：

> Consciousness is a universal (mapping) property.

这是重要的正面先例：first-person / intrinsic structure 确实可以尝试用 universal property 表达。

但这些 axioms 是每个 conscious experience 的 essential properties，因此自然得到：

\[
\forall E_i\in\mathcal E_C,\quad UMP(E_i)
\]

而非：

\[
\exists!E^*\quad UMP_{absolute}(E^*).
\]

所以它支持 universal-property methodology，却没有直接解决 global absolute centering。

---

## 8. 当前剩余突破口

成功的 universal-property theory 需要一种 morphism \(M\)，同时满足：

1. genuinely global；
2. non-factorizable；
3. independently motivated；
4. first-person / manifestation relevant；
5. 不把所有 contents phenomenally 汇入 \(E^*\)；
6. 不把其他 minds grounding 到当前经验这种极强依赖硬塞进去；
7. unique solution 真正是 token-level。

可以暂称目标：

\[
\boxed{\text{content-silent but actuality-bearing relation}}
\]

目前尚未找到成熟现成关系满足这些条件。
