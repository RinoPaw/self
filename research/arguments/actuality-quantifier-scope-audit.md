## A precise scope error

For actual first-person facts F and centered points pi, let T(F,pi) mean that F is true from pi. Then, in general:

\[
\forall F\,\exists\pi\,T(F,\pi)
\not\Rightarrow
\exists\pi\,\forall F\,T(F,\pi).
\]

A finite witness uses two facts Fa, Fb and two points a, b with support(Fa)={a}, support(Fb)={b}. Each fact has a pointwise witness; no *shared* witness exists. This is the difference between **each actual first-person fact has some viewpoint** and **all actual first-person facts have a common viewpoint**. The latter is GCR-All. This demonstration is logical; it does not claim the two facts are metaphysically irreducible.

## Four meanings of one actuality

| Reading | Exact claim | Consequence |
| --- | --- | --- |
| A0 One actual totality | One actual R | Does not constrain count of standpoints |
| A1 One ultimate truthmaker | One T_R grounds all facts | Does not determine how many ontic modes T_R realizes |
| A2 Each fact pointwise obtains | For each F some pi supports F | No shared point follows |
| A3 One viewpoint obtains all facts | One pi supports every actual F | GCR-All; essentially the sought strong bridge |

Even one truthmaking source and a single actualization event leave an explanatory question: why must all realized first-person *modes* be numerically the same?

An independently defensible **Actualizer–Mode Identity (AIM)** principle would state that every first-person realization supported by the same ultimate actualizer has exactly one ontic mode. Then:

\[
OneActualizer + AIM + EveryActualModeRealizedThere
\Rightarrow AtMostOneMode.
\]

This is a valid conditional result, not a theorem from OneActualizer alone. If AIM is justified merely by calling the actualizer an absolute first-person opening, it is circular; even successful AIM leaves the further mode-to-centered support and localization gaps.
