# Causal Unity–Subjecthood Gap

> Date: 2026-10-05
>
> Status: argument-level result following BDP causal/global bearer audit.

## 1. Target

BDP requires that if several phenomenally disconnected fields are assigned to one subject, there must be an independent bearer discriminator.

A natural Universal-I reply is:

\[
TheUniverseIsOneCausalWhole.
\]

Can that do the job?

## 2. Gap

No reviewed theory licenses the neutral inference:

\[
\boxed{
OneCausalWhole\Rightarrow OneSubjectOfExperience.
}
\]

Causal connectedness is too weak: many systems, organisms, brains, societies, and environments can stand in causal relations without thereby forming one experiential subject.

What is needed is a **subject-sensitive discriminator**.

## 3. Three serious ways to add one

### 3.1 Organismic identity

Animalism can stipulate/argue:

\[
Subject=Animal.
\]

Then one organism can remain one subject through substantial functional or phenomenal disunity.

This is a coherent countermodel to phenomenal-field individuation, but the subject-unity comes from the identity thesis, not from causal unity alone.

### 3.2 IIT-style maximal intrinsic integration

IIT supplies an actual structural discriminator:

\[
MaximalIrreducibleCauseEffectPower
\Rightarrow
Complex.
\]

But IIT reaches this through phenomenological axioms of intrinsic existence, integration and exclusion, plus an identity claim between the relevant intrinsic causal structure and experience.

Therefore the bridge is theory-loaded:

\[
Phenomenology
\to
PhysicalPostulates
\to
MaximalComplex
\equiv
Experience.
\]

This is not:

\[
GenericCausalUnity\to Subjecthood.
\]

Moreover, IIT's recursive exclusion naturally yields multiple disjoint complexes unless the entire universe itself wins as one maximal complex.

### 3.3 Cosmopsychist priority

Cosmopsychism posits the cosmic whole as a conscious ultimate. Priority monism can explain why the cosmos is metaphysically fundamental, but does not by itself explain why that whole is a subject.

Once cosmic subjecthood is granted, the de-combination problem appears:

\[
CosmicSubject\stackrel{?}{\Rightarrow}LocalSubjects.
\]

So this route assumes the target at the cosmic level and then owes local individuation.

## 4. CUSP — Causal Unity–Subjecthood Principle

The negative result can be stated as:

### CUSP

\[
\boxed{
CausalUnity(S)
\not\Rightarrow
ExperientialSubject(S)
}
\]

unless supplemented by a subject-sensitive bridge such as:

- organism identity;
- phenomenal constitution;
- maximal intrinsic integration plus an identity theory;
- primitive bearer law;
- another explicit psychophysical assignment principle.

CUSP is not the claim that causal structure is irrelevant. It says causal unity does not by itself settle **which causal whole is a subject**.

## 5. Consequence for BDP

BDP now sharpens:

\[
DisconnectedFields+OneBearer
\Rightarrow
IndependentBearerDiscriminator.
\]

CUSP blocks the weakest proposed discriminator:

\[
IndependentBearerDiscriminator=GlobalCausalConnectedness.
\]

Hence:

\[
\boxed{
GlobalCausalConnectedness\ is\ insufficient.
}
\]

The Universal-I must instead provide something closer to:

\[
GlobalMaximalExperientialIntegration,
\]

or:

\[
PrimitiveCosmicBearer+AssignmentLaw.
\]

## 6. Why IIT is especially informative

IIT functions as a useful existence proof that a non-arbitrary structural discriminator is possible in principle.

It shows what a serious bridge must look like:

1. identify phenomenological features that constrain subject/experience boundaries;
2. map them to an intrinsic physical criterion;
3. use a maximality/exclusion rule to choose one substrate rather than every causally connected superset.

This is exactly what generic Universal-I appeals to “the whole universe” currently lack.

But IIT also pressures Universal-I because its maximality architecture does **not** infer cosmic consciousness merely from universal causal connection. A cosmic subject requires the cosmos to satisfy the stronger maximal irreducibility condition.

## 7. Updated Universal-I funnel

The substantive Universal-I now faces:

\[
UniversalI
\Rightarrow
\begin{cases}
GlobalPhenomenalUnity,\\
GlobalMaximalIntrinsicIntegration+IdentityBridge,\\
Organismic/OtherIndependentBearerCriterion,\\
PrimitiveCosmicBearer+AssignmentPrinciple.
\end{cases}
\]

The first is pressured by PFIP / local disconnection.

The second is a substantive empirical-theoretical proposal, not a free metaphysical consequence.

The third needs a credible global bearer criterion; ordinary organismic identity does not scale automatically to the cosmos.

The fourth remains logically hardest to exclude, but maximally brute.

## 8. Current verdict

\[
\boxed{
Causal\ unity\ does\ not\ close\ the\ locality\ gap.
}
\]

This is a real narrowing of the Universal-I escape route. The strongest non-primitive escape now looks like an IIT-like theory in which **subject boundaries are fixed by a maximal intrinsic integration criterion**, rather than by causal connectedness simpliciter.

Accordingly, the next high-value question is no longer “is the universe connected?” but:

\[
\boxed{
Is\ there\ any\ plausible\ global\ subject-sensitive\ maximality\ criterion\ under\ which\ the\ cosmos\ wins?
}
\]

If not, the Universal-I increasingly collapses into the primitive cosmic-bearer horn.
