# Local I–NOW vs Global NOW

> 状态：2026-10-05 temporal-target correction。
>
> 目标：修正 Collapse–Temporal Synchronization Fork 的适用范围。项目的 absolute `NOW` 不必等同于 universe-wide simultaneity hypersurface；Conitzer-style personalized A-theory提供一个更弱、也更贴 absolute-first-person target 的 local I–NOW reading。

## 0. Two notions of NOW

此前 collapse / EBU audit容易把：

\[
AbsoluteNOW
\]

理解成：

### G-NOW — Global-Slice NOW

存在一个 spacelike/global hypersurface：

\[
\Sigma^*
\]

满足：

\[
Present(\Sigma^*)
\]

并对宇宙各 spatial locations定义 objective simultaneity。

但项目 target还有更弱、更 centered 的解释：

### C-NOW — Centered / Local I–NOW

存在唯一 privileged person-stage / event：

\[
\boxed{
\langle s^*,e^*,t^*\rangle
}
\]

其 `NOW` 只意味着：

\[
\boxed{
ThisStageIsNowForTheAbsoluteOpening(s^*,t^*).
}
\]

不要求：

\[
\forall x\;SimultaneousPresent(x,t^*).
\]

---

## 1. Conitzer gives a direct mature template

Conitzer 的 personalized \(\alpha A\)-theory明确把 `I-Now` 做成 local structure。

其关键点：

- I-Now associated with an observer；
- observer可定位于 spacetime；
- privileged frame可按 relativity定义方便的 simultaneity notion；
- theory本身甚至不需要跨空间 objective simultaneity；
- special-relativity objection对 local I-Now明显弱于对 global A-theoretic Now。

所以：

\[
\boxed{
MetaphysicallyPrivilegedI\text{-}NOW
\not\Rightarrow
GlobalAbsoluteSimultaneity.
}
\]

这是项目 temporal architecture 的重要 correction。

---

## 2. TSP was too strong as a mandatory gate

此前写：

\[
TSP:\quad LocalActualizations\Rightarrow OneGlobalNOW.
\]

若项目坚持 G-NOW，TSP仍是 serious burden。

但若 target是 C-NOW，则不需要：

\[
LocalEvents\to GlobalSynchronization.
\]

只需：

\[
\boxed{
AbsoluteOpening(E^*)
\Rightarrow
DistinguishedStage(E^*,t^*).
}
\]

而 person-stage本来就是 local subject structure的一部分。

因此：

\[
\boxed{
TSP\text{ is optional unless the project independently requires G-NOW}.}
\]

---

## 3. Collapse route improves under C-NOW

CDCP 已有：

\[
(p^*,e^*,s,t)
\]

作为 one jointly actualized psychophysical event。

若 later PLP / Opening law给：

\[
AbsoluteI(s^*)
\]

且 event belongs to the privileged stage：

\[
Stage(s^*,t^*),
\]

则可定义：

\[
\boxed{
AbsoluteI\text{-}NOW(s^*,t^*)
}
\]

而无需再选 global slice。

所以 local collapse prototype与 C-NOW 的 shape 更自然地匹配：

\[
\boxed{
PsychophysicalEvent
\to
Subject\text{-}Stage
}
\]

已经给 temporal coordinate；真正缺的是该 subject-stage 的 **absolute rank**。

---

## 4. This collapses two burdens into one

在 G-NOW architecture 中，最终 burden是：

\[
PLP+TSP+PresentnessSemantics.
\]

在 C-NOW architecture 中：

\[
AbsoluteRank(s^*,t^*)
\]

可以同时给：

- absolute-I；
- absolute-NOW-as-stage。

所以：

\[
\boxed{
C\text{-}NOW\text{ turns temporal privilege into an aspect of centered local privilege}.}
\]

这与 Nagai-style：

\[
I=NOW=Opening
\]

更相容，也与 UIWO 原始 `t = time/person-stage coordinate` 的定义更一致。

---

## 5. But it does not solve privilege

这个修正减少一个 burden，没有生成 absolute rank。

普通 subject也都有 current stages：

\[
\forall s_i\;Current/ExperiencedStage(s_i,t_i).
\]

所以：

\[
\boxed{
LocalNow(s,t)
\not\Rightarrow
AbsoluteI\text{-}NOW(s,t).
}
\]

仍需区分：

\[
OrdinaryDeNunc(s,t)
\]

与：

\[
AbsoluteOpening(s^*,t^*).
\]

换言之，时间问题被重新吸收到 PLP / Opening semantics，而没有消失。

---

## 6. Relativity impact

### If G-NOW

relativistic collapse / GRW literature给强压力：

\[
GlobalSynchronization
\]

通常需要额外 foliation / simultaneity structure。

### If C-NOW

只要求一个 local spacetime event / person-stage：

\[
(x^*,\tau^*)
\]

作为 I-Now。

这不需要宇宙范围 absolute simultaneity。

所以：

\[
\boxed{
RelativityPressure(G\text{-}NOW)
>
RelativityPressure(C\text{-}NOW).
}
\]

但 local I-Now仍需要 privilege ontology；relativity只是不再直接反驳其 temporal form。

---

## 7. Revised temporal fork

项目现在应显式区分：

### T-A — Global Opening Time

\[
O(w,\Sigma,s).
\]

要求 one global privileged slice。

额外 burden：TSP + foliation/presentness。

### T-B — Centered Opening Event

\[
\boxed{
O(w,e_{s,t})
}
\]

或：

\[
O(w,t,s)
\]

其中 \(t\) 仅是 privileged subject-stage coordinate。

无需 global simultaneity。

对于当前项目，除非有独立理由要求 world-wide present slice，**T-B 应成为 default**。

---

## 8. Impact on UIWO

UIWO 原式：

\[
O(w,t,s)
\]

不应默认把 \(t\) 解释为 global hypersurface。

更准确：

\[
\boxed{
t=\text{local time/person-stage coordinate of the opening bearer}.}
\]

World actuality / subject / NOW 统一的主张变成：

\[
\boxed{
ActualWorld
+
AbsoluteSubjectStage
}
\]

其中 `I` 与 `NOW` 已经在 stage 中 jointly represented。

所以 UIWO 从 three-axis unification部分收缩成：

\[
\boxed{
WorldActuality
\leftrightarrow
AbsoluteI\text{-}NOWStage.
}
\]

这可能比 world + global NOW + I 三个独立 dimensions更稳。

---

## 9. New burden map

采用 C-NOW 后：

### 已弱化 / optional

\[
GlobalTemporalSynchronization.
\]

### 仍核心

\[
\boxed{
WorldActuality\to CenteredOpening
}
\]

以及：

\[
\boxed{
Why\ exactly\ one\ subject\text{-}stage\ has\ absolute\ rank?
}
\]

因此 original `why this person, this time?` 可以重写成一个真正 joint question：

\[
\boxed{
Why\ this\ person\text{-}stage\ is\ the\ actual\ opening?
}
\]

而不必先问“宇宙哪一整张 slice 是现在”。

---

## 10. Current verdict

本轮 temporal correction：

\[
\boxed{
AbsoluteNOW\neq RequiredGlobalNOW.
}
\]

更适合本项目的 default：

\[
\boxed{
AbsoluteNOW=NOW\text{-}aspect\ of\ one\ privileged\ local\ I\text{-}stage.
}
\]

因此 Collapse–Temporal Synchronization Fork保留为 **global-time variant audit**，但不再是 core Opening必经关卡。

这使 current exact bottleneck重新集中：

\[
\boxed{
World/HistoryActualization
\to
OneAbsoluteI\text{-}NOWStage.
}
\]

即：**privilege rank 又成为最后核心。**
