# Uncentered Actuality Challenge

> 状态：当前核心分歧。目标是检验 `Opening Identity Principle` 是否真的为 absolute-center existence 提供必要性，而不只是一个统一而 primitive 的正方模型。

## 0. 决战命题

Opening Identity Principle（OIP）主张：

\[
Actual(R)\Rightarrow\exists c\;Open_{simpliciter}(R,c).
\]

最强 pluralist 反模型主张：

\[
Actual(R_P)
\land
\neg\exists c\;Open_{simpliciter}(R_P,c),
\]

其中：

\[
R_P=\langle W,\Pi,\rho\rangle
\]

包含：

- 全部 objective facts；
- 全部真实 conscious subjects；
- 每个主体的 ordinary first-person perspective；
- 每个 perspective 与 objective subject/event 的 anchoring；
- 需要时还可包含 objective becoming / passage / causation 等结构。

所以问题已经压缩为：

\[
\boxed{\text{uncentered actuality 是否 coherent？}}
\]

---

## 1. Nagai 自己允许 uncentered content

Nagai 的重要点并不是否认一个没有 `I!` 的世界内容可以被设想。

相反，他明确允许：

- Hitoshi Nagai 仍按完全相同的物理与心理方式存在；
- 全部普通 subjects / self-consciousnesses 仍然存在；
- 整段历史内容保持不变；
- 但 Hitoshi Nagai 不再是 `I!`，甚至世界中没有 `I!`。

所以他已经区分：

\[
\text{world-content}
\]

与：

\[
\text{actual opening}.
\]

他真正拒绝的是：

\[
\boxed{\text{world-content can be actual without an actual opening}.}
\]

因此 OIP 并不来自 ordinary consciousness facts，而来自 Nagai 对 **actuality 本身** 的理解。

---

## 2. OIP 的三种可能辩护

### A. Transcendental constitution

主张：一个 world 要作为 objective world 获得统一成立，本身就需要一个 unified apperceptive origin。

形式：

\[
WorldObtains(R)\Rightarrow\exists c\;Constitutes(c,R).
\]

Nagai 借 Kant 提供这一路线。

#### 压力

Kantian constitution 最多容易推出：

\[
\text{world-as-experienced-from-a-subject needs a subject}.
\]

List / perspectival pluralism 可以复制成：

\[
\forall i\;WorldFor(\pi_i).
\]

并没有得到 one simpliciter subject。

而 Nagai 自己也承认：Kant 的统一世界条件不能决定 **the sole actual world**；actuality 还需要 Leibnizian layer。

所以：

\[
\boxed{\text{transcendental unity}\not\Rightarrow\text{absolute actuality}.}
\]

### B. Epistemic / manifestation indispensability

主张：actuality 永远只能作为 “this actuality / here-now” 被给予；没有无中心的 actuality experience。

#### 压力

这可能只证明：

\[
\text{access to actuality is centered},
\]

而非：

\[
\text{actuality itself is centered}.
\]

Hartle–Srednicki、Lewis、Stalnaker、List 等都提供各种把 first-person access 与 world actuality 分开的资源。

于是出现：

\[
\boxed{\text{Centered Access}\not\Rightarrow\text{Centered Actuality}.}
\]

### C. Constitutive identity

最强 OIP 直接说：

\[
Actuality=Opening.
\]

因此问“能不能 actual but uncentered”就像问：

\[
\text{能不能有一个未实际化的 actuality？}
\]

#### 优点

它最能保住 Nagai 的直觉，也最能统一 I / NOW / actuality。

#### 压力

如果 identity 没有独立 argument，这会接近定义或 primitive metaphysical posit：

\[
Actuality:=CenteredOpening.
\]

pluralist 完全可以使用另一个 primitive：

\[
Actuality:=UncenteredObtaining
\]

再加全部 relative perspectives。

因此真正需要的是一个理由说明第二种 primitive package incoherent / incomplete / explanatorily inferior。

## 3. Counter-Centered World Test

构造：

\[
R_P=\langle W,\Pi,\rho\rangle.
\]

要求：

1. `W` 是一个 single actual objective history；
2. 所有真实 subjects 都包含在 `W`；
3. 每个 subject `S_i` 都有真实 `π_i`；
4. 对每个 `π_i`，全部 phenomenal / de se / for-me facts 都真实；
5. 所有 perspective-to-world anchors 都完整给定；
6. 没有：

\[
Center_{simpliciter}(R_P,c).
\]

然后检查该模型是否存在内部矛盾或事实遗漏。

### 若模型 coherent

则：

\[
\boxed{OIP\text{ is not metaphysically necessary}.}
\]

Nagai / Centered Total State 仍可是真实理论，但它需要独立 abductive / primitive 支持。

### 若模型 incoherent

必须精确指出矛盾：

\[
R_P\vdash\bot
\]

或者指出一个不能被任何 relative fact 表达、但又 independently real 的：

\[
X.
\]

这才会首次给 Centered Completeness / OIP 真正的正面证明。

---

## 4. List 是当前最强 Counter-Centered Model

List 的 many-worlds theory 可以理解成把不同 subjects 的完整 first-person facts 放在不同：

\[
\langle\omega,\pi_i\rangle
\]

中。

这使每个 subject 的 first-person facts 都 genuinely real，而不需要一个 global actual-I。

严格说，它放弃 one-world picture；因此它不是 `R_P` 的唯一实现。

但它证明了一点：

\[
\boxed{\text{first-person reality does not by itself require one global center}.}
\]

Lipman / Solomyak 则提供 one-reality / perspectival-pluralist 风格的进一步反方资源。

---

## 5. Coherence 只解决 `≤1`，不解决本挑战

假设：

\[
F_i^{abs}\perp F_j^{abs}.
\]

one coherent reality 可以推出：

\[
|AbsoluteCenters|\le1.
\]

但 uncentered actuality 恰好取：

\[
|AbsoluteCenters|=0.
\]

因此：

\[
\boxed{\text{coherence cannot distinguish 0 from 1}.}
\]

这正是为什么 `Centered Completeness / OIP` 仍然必要。

---

## 6. Actuality Analogy 的双刃性

### 支持 OIP

Nagai 的类比：

- one actual world among possible worlds；
- one NOW among times；
- one actual I among persons。

如果 absolute actuality 本身是 irreducible，则 absolute I 也可以是同类 irreducible actuality。

### 支持反方

Lewis 式 indexical actuality 正好否认：

\[
\exists!w\;AbsolutelyActual(w).
\]

如果 actuality 自己都能被 indexical / relative 化，那么从 actuality 向 absolute I 的类比反而失去力量。

所以 OIP 最终依赖一个更基础的分歧：

\[
\boxed{\text{Absolute Actuality}\quad vs\quad\text{Indexical / Relational Actuality}.}
\]

这与本项目最初的：

\[
\text{Absolute Liveness}\quad vs\quad\text{Perspectival Liveness}
\]

完全同构。

---

## 7. OIP 的真正解释增益

即使 OIP 无法被证明为 necessary，它仍比 bare primitive pointer 有一个优势。

bare model：

\[
Actual(R)+Pointer(E^*).
\]

OIP model：

\[
Actual(R)=Opening(R,E^*).
\]

后者减少了 primitive kinds：

- world actuality；
- absolute I；
- absolute NOW

被统一成同一结构。

因此其最佳辩护可能不是 deduction，而是：

\[
\boxed{\text{unification / compression}.}
\]

需要比较：

### Pluralist package

\[
T_P=UncenteredActuality+\Pi+\rho+RelativeFP.
\]

### Opening package

\[
T_O=CenteredActuality(I,NOW)+OrdinaryFP.
\]

然后比较 primitive 数量、解释覆盖、认识论代价、relativity compatibility、branching cost。

---

## 8. 当前工作结论

Nagai 让 `AtLeastOne Absolute Center` 第一次有了比 “加一个 center property” 更统一的来源：

\[
\boxed{\text{actuality itself may be centered}.}
\]

但我们还没有证明：

\[
\boxed{\text{actuality must be centered}.}
\]

因此当前最核心的前沿已经成为：

> 构造最强的 uncentered-but-actual pluralist reality，并尝试从内部击穿它。

只要它保持 coherent，OIP 就是一个强 positive model 而非 forced conclusion。

若它无法保持 coherent，absolute-first-person realism 会获得目前最重要的正面突破。
