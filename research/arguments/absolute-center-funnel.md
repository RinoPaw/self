# Absolute-Center Funnel：非 primitive 唯一绝对中心的必要架构

> 状态：综合性工作约束。它不是“绝对第一人称不存在”的 no-go theorem；它把目前已经得到的几个独立禁阻串成一条条件性漏斗，说明任何**结构性、非 haecceitistic、非 primitive**的 absolute-center 理论至少需要经过哪些关。

## 0. 目标

项目目标仍记为：

\[
\exists !E^*\in\mathcal E_C:\;Absolute(E^*),
\]

其中：

\[
E^*=(C,p)
\]

是一个意识事件，而其他主体仍然是真实意识。

当前还坚持一个方法论要求：优先寻找

\[
D\Longrightarrow E^*\Longrightarrow LIVE(E^*)
\]

这样的结构解释，而不直接加入 primitive pointer：

\[
Chosen(E^*).
\]

在这些条件下，理论搜索空间被三道主要结构墙压缩。

# Wall 1 — Locality / Duplication

## 1. 条件

设候选机制 \(D\) 对事件 \(E\) 的判断只依赖一个 rooted relevant profile：

\[
N_D(E).
\]

并使用统一、同构不变的规则：

\[
\Lambda_D(E)=F([N_D(E),E]).
\]

若存在两个不同事件：

\[
(N_D(E_a),E_a)\cong(N_D(E_b),E_b),
\]

则必有：

\[
\Lambda_D(E_a)=\Lambda_D(E_b).
\]

## 2. 结果

因此，在允许精确 \(D\)-duplicates 的情况下：

\[
\boxed{\text{pure local supervenience cannot guarantee one global LIVE center}}
\]

这堵住了把绝对中心完全建立在以下可复制 profile 上的简单方案：

- phenomenal profile；
- neural / computational profile；
- local causal structure；
- local process / frontier status；
- ordinary for-me-ness；
- 任意只读取 event-relative bounded structure 的标量或模式。

## 3. IIT 给出的重要边界

IIT 的 exclusion / maximality 说明，机制可以读取一个系统与 overlapping candidates 的关系，因此两个内部物理复制体在不同外部 context 中可以得到不同 classification。

这证明 Wall 1 并没有禁止 relational/contextual theories。

它真正迫使理论做的是：

\[
\text{local intrinsic profile}
\longrightarrow
\text{larger relational structure}.
\]

# Wall 2 — Local-to-Global Factorization

## 4. 条件

即使一个机制能在某个 competition domain 中唯一选择 winner，它也可能在多个互相独立的 domain 中重复运行。

设：

\[
D_1,D_2,\ldots,D_k
\]

各自产生：

\[
s_i(D_i)=E_i.
\]

如果全局机制可因子化：

\[
M(\mathcal R_A\oplus\mathcal R_B)
=
M(\mathcal R_A)\cup M(\mathcal R_B),
\]

那么两个含意识的独立 domain 可以同时产生两个中心。

## 5. 结果

因此：

\[
\boxed{\text{local singleton}\not\Rightarrow\text{global singleton}}
\]

absolute-center mechanism 必须在相关意义上满足：

\[
\boxed{\text{Non-Factorization Requirement}}
\]

以及：

\[
\boxed{\text{Global Coupling Requirement}}.
\]

所有具有 absolute-center 资格的候选必须进入同一个足以影响最终结果的全局比较、约束、依赖或生成结构。

IIT 是很清楚的 near miss：它可以在 overlapping substrate family 中做 exclusion，但 universal substrate 上仍会递归找到第一、第二、第三个 non-overlapping complex。

同样结构也出现在：

- one workspace winner per brain；
- one fixed point per reflexive system；
- one phenomenal whole per subject-time；
- one self-manifestation per experience；
- one local frontier center per domain。

# Wall 3 — Global-to-Center Localization

## 6. 条件

Wall 1 与 Wall 2 会自然把理论推向真正全局结构。

设更深结构 \(D\) 成功产生一个唯一全局 bearer：

\[
D\Longrightarrow\exists !X^*\;P(X^*),
\]

其中 \(X^*\) 可以是：

- fundamental cosmos；
- actual world / history / coevent；
- unique generative process；
- global boundary condition；
- globally constrained solution；
- 其他 whole-level actuality bearer。

但只要：

\[
|\mathcal E_C(X^*)|>1,
\]

仍然没有：

\[
\exists !E^*\;LIVE(E^*).
\]

## 7. 结果

所以：

\[
\boxed{
\text{unique privileged global bearer}
\not\Rightarrow
\text{unique privileged experiential part}
}
\]

需要额外的 privilege-preserving localization：

\[
\ell:(D,X^*)\longrightarrow E^*.
\]

并且不能只满足唯一性，还要有：

\[
P(X^*)\land R_G(X^*,E^*)
\Longrightarrow
LIVE(E^*).
\]

这就是 **Global-to-Center Gap**。

Priority monism、single actual history、global temporal arrow、all-at-once solution 都说明：全局 actuality / fundamentality / asymmetry 可以非常真实，却自然被许多局部意识共同包含或继承。

# Wall 4 — Privilege Bridge

前三墙即使全部通过，仍然可能只得到：

\[
\exists !E^*\;R_G(\mathcal R,E^*).
\]

这只说明一个事件处在独特的全局角色。

还必须解释：

\[
R_G(\mathcal R,E^*)
\Longrightarrow
LIVE(E^*).
\]

因此真正最后一墙仍是此前的：

\[
\boxed{\text{individualization}\not\Rightarrow\text{privilege}}.
\]

一个 global centrality maximum、unique fixed point、canonical address、unique extremum，即使全都 mathematically distinguished，也没有自动成为 absolute first-person center。

这要求 \(R_G\) 本身具有独立的：

- grounding；
- generation；
- actuality；
- ontological priority；
- 或其他足够强的 metaphysical significance。

# 8. Funnel Proposition

在以下工作前提下：

1. 至少存在两个真实 consciousness events；
2. 目标是一个 simpliciter 唯一 absolute center；
3. 不把其他主体降格为无意识；
4. unique status 希望由结构解释，而非 primitive haecceity / pointer；
5. 机制尊重相关 isomorphism / gauge equivalence；
6. local exact duplication 原则上不被先验禁止；

那么任何成功理论至少需要：

### F1 — 超越可复制局部 profile

\[
LIVE(E)\neq F(N_{local}(E))
\]

作为完整解释。

### F2 — 全局不可因子化

absolute-center-generating law 必须把所有 eligible candidates 放入同一个 non-factorizable global structure。

### F3 — 具有 event-level singleton

全局结构必须直接或通过非任意关系产生：

\[
\exists !E^*.
\]

不能只停在唯一 world / history / cosmos / process。

### F4 — privilege-preserving localization

用于定位 \(E^*\) 的全局角色必须与 actuality / liveness 有独立形而上联系。

### F5 — invariant / non-circular

这套结构不能靠坐标、gauge labels、姓名、hidden total birth order 或 `absolute` 的同义改写完成。

合起来：

\[
\boxed{
\text{Successful non-primitive absolute-center theory}
\Rightarrow
\text{global + non-factorizable + singleton + privilege-bearing + invariant relation}
}
\]

这是一项必要架构约束，不是充分条件。

# 10. 现在真正剩下的搜索空间

此前研究问题还很宽：

\[
\text{什么结构能选出 }E^*?
\]

经过漏斗以后，搜索目标已经压缩成：

\[
\boxed{
R_G(\mathcal R,E)
}
\]

其中 \(R_G\) 必须同时具有：

\[
\text{globality}
+\text{non-factorization}
+\text{singleton extension}
+\text{privilege relevance}
+\text{invariance}
+\text{non-circularity}.
\]

这意味着下一阶段不应继续宽泛搜寻：

- 最大值；
- 特殊边界；
- 唯一历史；
- 唯一 whole；
- 普通 fixed point；
- 普通 self-reference；

除非候选能说明它怎样通过整个 funnel。

当前仍值得重点攻击的只剩几类：

1. **global experiential fundamentality rank**；
2. **experiential dominator / grounding bottleneck**；
3. **actual-history-to-center privilege transfer**；
4. **covariant global generative channel**；
5. 某种尚未发现的 **global self-manifestation relation**。

如果这些候选长期都在 Wall 3 或 Wall 4 失败，那么 standpoint / process pluralism 会获得一个非常强的解释经济性优势。

如果其中一类真的跨过四墙，我们才第一次得到一个非 primitive 的 absolute-first-person architecture。
