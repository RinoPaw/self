# Non-Solipsistic Common-Core Constraint

> 状态：前沿比较框架。
>
> 目标：在 `Constitutional Obtaining Pluralism` 与 `Primitive / Derived Absolute Opening` 之间进行公平理论比较，防止 absolute theory 通过忽略其他真实主体所需的 ordinary first-person machinery 获得虚假的“统一/简约”优势。

## 0. 起点

本项目坚持：

\[
\boxed{\text{other minds are genuinely conscious}}
\]

并且普通第一人称性属于多个主体：

\[
\forall s\in S\;LocalFP(s).
\]

经过 Lipman / Eker / centered-world / self-ascription literature，ordinary first-person layer 已经可以被赋予很强的本体论形式：

\[
P=\{M_s:s\in S\},
\]

其中 \(M_s\) 可以表示：

- subject-relative facts；
- constitutional modes of obtaining；
- local self-presentation / for-me-ness；
- perspective–event anchoring。

absolute theory 另外主张：

\[
\Omega(c^*)
\]

其中 \(\Omega\) 是一个 simpliciter / global first-person orientation。

关键问题是：\(\Omega\) 与 ordinary layer \(P\) 的关系是什么？

---

## 1. Common-Core Principle

只要正方仍承认：

\[
\forall s\in S\;LocalFP(s),
\]

那么用于解释这些 ordinary first-person facts 的结构不能因为加入 absolute center 就凭空消失。

因此 pluralist 与 non-solipsistic absolute realist 至少共享一个 common core：

\[
K=\langle W,S,P,\ldots\rangle.
\]

这里：

- \(W\)：objective / physical / causal reality；
- \(S\)：多个 genuine conscious subjects；
- \(P\)：ordinary first-person / standpoint structure。

于是最直接的理论比较是：

\[
T_P=K+A_P
\]

与：

\[
T_A=K+A_A,
\]

其中：

- \(A_P\)：plural / uncentered actuality architecture；
- \(A_A\)：absolute centered actuality / opening architecture。

不能把 \(T_A\) 描述成“只需一个 centered actuality primitive”，同时忘记它还必须保留 \(K\) 中所有其他主体的 ordinary first-person reality。

暂称这一约束 **Non-Solipsistic Common-Core Constraint**。

---

## 2. Supplement Route — absolute layer 只是额外层

最自然的 Two-Tier model 是：

\[
T_A=K+\Omega(c^*).
\]

其中：

\[
\forall s\;M_s
\]

解释 ordinary consciousness，而：

\[
\Omega(c^*)
\]

只给其中一个 perspective 额外 absolute status。

这最忠实于：

\[
\text{many genuine ordinary first-persons}
+
\text{one absolute first-person}.
\]

但此时 \(\Omega\) 明确是 **supplementary ontology**。

于是产生一个不可回避的问题：

\[
\boxed{\Delta E(\Omega)=?}
\]

也就是：相比已经能解释 ordinary subjectivity 的 \(K\)，\(\Omega\) 新解释了哪个 independently motivated fact？

如果答案只是：

> 它解释为什么 \(c^*\) 是 absolute，

而 “\(c^*\) 是 absolute” 本身没有独立于 \(\Omega\) 的证据或 explanandum，那么解释会循环。

---

## 3. Replacement Route — 用 absolute layer 取代 ordinary perspective machinery

为了避免“额外一层”的成本，可以试图让：

\[
\Omega
\]

生成 / grounding 全部 ordinary perspectives：

\[
\Omega(c^*)\Grounds\{M_{s_1},M_{s_2},\ldots\}.
\]

此时 absolute structure 不再是 add-on；它承担统一 source 的角色。

但理论立即进入强 dependence ontology：

\[
\boxed{\text{one absolute orientation}\to\text{many bounded genuine subjects}}
\]

需要解释：

- phenomenal privacy；
- subject boundaries；
- ordinary first-person autonomy；
- 为什么其他 subjects 不是 absolute center 的 mere aspects / simulations；
- 为什么 one source 的 manifestations 中只有一个 manifestation 与 source 的 absolute orientation 同一。

这就是 `Relevance–Dependence Trilemma` / cosmopsychist de-combination problem 的第一人称版本。

因此：

\[
\boxed{
\text{replacing the common core avoids addition cost only by assuming a much stronger generation theory}
}
\]

---

## 4. Promotion Route — \(\Omega\) 只是 ordinary perspectives 中一个被提升

第三种方式不额外生成新 perspective，也不 grounding others：

\[
\Omega(c^*)=Promote(M_{c^*}).
\]

也就是同一个 local perspective 同时承担：

\[
M_{c^*}
\]

和：

\[
Absolute(M_{c^*}).
\]

这样 other minds 完整保留，且没有 cosmic-source burden。

但问题精确回到 Absolutization：

\[
\boxed{\text{why is exactly this }M_{c^*}\text{ promoted?}}
\]

若 promotion：

- 从 \(K\) 结构决定 → Natural Pointing / Definability / Privilege Bridge；
- stochastic → objective chance + liveness bridge；
- primitive → primitive absolute fact；
- 由 phenomenology 决定 → duplication / Epistemic Fork。

所以 promotion 不是新逃生口。

---

## 5. Identity Route — “absolute actuality = ordinary perspective actuality”

OIP 的 strongest slogan：

\[
WorldActuality=AbsoluteI=AbsoluteNOW.
\]

可能回应：这里根本没有 `K + Ω`，而是把 actuality 本身识别成 centered opening，因此 primitive 数目没有增加。

这个回应有真实力量，但 Common-Core Constraint 要求再问一步：

### 其他主体的 ordinary first-personhood 从哪里来？

若对每个 \(s\neq c^*\) 仍有：

\[
M_s,
\]

那么 theory 仍包含：

\[
\{M_s\}_{s\in S}
\]

以及一种不同的：

\[
AbsoluteOpening(c^*).
\]

所以即使 `WorldActuality` 与 `Ω` 同一，**ordinary perspectival machinery + absolute orientation** 两层仍然存在。

OIP 的真正 compression 因而不是：

> 从两层变成一层。

更准确是：

> 把本来可能分开的 `world actuality / absolute I / absolute NOW` 三个 absolute-level commitments 压成一个 absolute-level primitive。

这仍然可能是很好的 unification，但不能拿来消除 ordinary layer。

---

## 6. Unification Bootstrapping Objection

理论统一度必须统一 **independently motivated explananda** 才有解释收益。

假设 OIP 声称一次解释：

\[
ActualWorld,
\quad
AbsoluteI,
\quad
AbsoluteNOW.
\]

但 pluralist 只独立承认：

\[
ActualWorld
\]

以及多个 local I / NOW standpoints；它不承认 `AbsoluteI` 和 `AbsoluteNOW` 是额外待解释事实。

那么不能这样计分：

1. 先 postulate `AbsoluteI`；
2. 再 postulate `AbsoluteNOW`；
3. 用 OIP 将三者 identify；
4. 宣布理论一次统一三个独立事实。

因为第 1、2 项恰好是争议内容。

暂称：

\[
\boxed{\text{Unification Bootstrapping Objection}}
\]

它不否认 identity theory 可以更优；它要求：

\[
\boxed{
\text{被统一的 absolute explananda 必须先有独立动机}
}
\]

否则 compression gain 会被高估。

---

## 7. Explanatory Delta Test

对任意 absolute theory：

\[
T_A=K+\Omega
\]

与强 pluralist：

\[
T_P=K
\]

或更公平地：

\[
T_P=K+A_P,
\qquad
T_A=K+A_A,
\]

比较的核心不应是简单 primitive count，而是：

### D1. Independent Explanandum

是否存在独立于 \(\Omega\) 识别出的现象 / 真理 \(X\)，使：

\[
K\not\models X,
\qquad
K+\Omega\models X?
\]

### D2. Non-circular relevance

\(X\) 不能只是：

\[
X:=\text{“there is an absolute center”}.
\]

除非该命题本身已有 independent evidence。

### D3. Replacement credit

\(\Omega\) 是否真正替代了 pluralist 所需的某项 independent structure，而不是单纯叠加？

### D4. Counterfactual / modal work

改变 \(\Omega\) 是否改变理论解释的某些独立事实、modal profile、fission prediction、temporal dynamics 或 self-location structure？

### D5. Epistemic role

若 \(\Omega\) phenomenally inert，理论如何获得对 \(X\) 的认识论支持？

若 phenomenally active，则它必须通过 unique-signature / duplication tests。

把这些合称：

\[
\boxed{\text{Explanatory Delta Test}}
\]

---

## 8. 对 primitive OIP 的公平评价

Primitive OIP 不应被简单批评为“多一个 primitive，所以更差”。

更公平的是：

### 可能的优势

- 把 absolute actuality / I / NOW 视为同一个 primitive kind；
- 不需要 post-actual selector；
- 对原始 “这里-现在真正开启” 直觉高度贴合；
- exact-one 可以由 primitive opening + coherence 组合；
- 可能有比 bare `LIVE(E*)` 更强的系统统一度。

### 当前缺口

- strong pluralist common core 已经解释 ordinary I / NOW / consciousness；
- `AbsoluteI` / `AbsoluteNOW` 是否为独立 explananda 仍是 Residual Fact Problem；
- 如果 absolute status phenomenal-inert，local evidence 无法挑出它；
- why-this-one 仍停在 contingency / chance / primitive identity；
- 如果 OIP 不 replace ordinary perspective machinery，它仍是额外 absolute layer。

因此 primitive OIP 当前是一个**有竞争力但未获 abductive 胜利的 ontology package**。

---

## 9. 一个更强的比较结论

在 non-solipsism 下，absolute theory 大致无法同时免费获得：

1. ordinary other-minds first-person plurality；
2. one absolute orientation；
3. no extra ontology；
4. no cross-subject grounding burden。

因为：

- 保留 ordinary layer + absolute layer → extra absolute structure；
- 用 absolute layer grounding ordinary layer → strong dependence/de-combination；
- 从 ordinary layer promote one → Absolutization problem；
- 直接否定 ordinary layer → 违反 non-solipsism。

因此得到一个条件性约束：

\[
\boxed{
\text{Non-solipsistic absolute realism must pay either an Addition Cost, a Dependence Cost, or an Absolutization Cost.}
}
\]

这不是反驳；它使理论比较的账本变得透明。

---

## 10. 当前用途

经过 `Obtaining-Mode Pluralization`，项目不应再只问：

\[
\text{absolute orientation 能否被形式化？}
\]

也不应只问：

\[
\text{它能否被设成 primitive？}
\]

现在更有判别力的问题是：

\[
\boxed{
\text{absolute layer 相比 strongest non-solipsistic pluralist common core，到底增加了什么解释？}
}
\]

若这个 delta 找不到，pluralism 取得 abductive 优势。

若能找到一个 \(K\) 真正遗漏、又由 \(\Omega\) 非循环解释的 residual fact，absolute-first-person realism 才会取得新的正面进展。
