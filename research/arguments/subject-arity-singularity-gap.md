# Subject-Arity / Singularity Gap

> 状态：2026-10-05 positive-route refinement。
>
> 目标：把 `actuality has subject arity`、`all subjectivity forms one global experiential unity`、`there is exactly one global subject` 三层分开，防止 Whitehead-style arity result 被误升级成 absolute-first-person singularity。

## 0. Core distinction

定义弱主体论：

\[
WAAP:\quad CompleteActuality(R)\Rightarrow SubjectiveArity(R).
\]

定义全局经验统一原则：

\[
GEUP:\quad SubjectiveArity(R)\Rightarrow GlobalExperientialUnity(R).
\]

定义 global-subject pressure：

\[
GSP:\quad GlobalExperientialUnity(R)\Rightarrow GlobalSubjectPressure(R).
\]

项目最终目标还需要 localization：

\[
LAP:\quad GlobalFundamentalSubject(R,s)\Rightarrow\exists!E^*\;LocalAbsoluteLocus(E^*,s).
\]

所以当前 strongest positive ladder 是：

\[
\boxed{
WAAP+GEUP+GSP+LAP
}
\]

任何只证明 WAAP 的理论，都不能直接记作 absolute-center support。

---

## 1. Whitehead is a direct separation model

Whitehead-style process metaphysics拒绝 `vacuous actuality`，并把 actual entity理解为 subject-superject / experiential becoming。

这给出 strong template：

\[
Actuality\Rightarrow SubjectiveInterior/Experience.
\]

但 Whitehead universe同时包含 many actual occasions。

因此存在：

\[
WAAP
+\neg GEUP.
\]

于是：

\[
\boxed{WAAP\not\Rightarrow GEUP.}
\]

actuality arity 与 global experiential unity 已经是两个独立理论问题。

---

## 2. Priority cosmopsychism gives a conditional singularity construction

priority cosmopsychism可写成：

\[
PriorityMonism
+
CosmosConscious
+
ConsciousnessBelongsToSubject
\Rightarrow
\exists!s_c\;FundamentalCosmicSubject(s_c).
\]

该构造表明 global-subject theory coherent。

但 uniqueness来自：

\[
PriorityMonism,
\]

subjecthood来自：

\[
CosmosConscious+SubjectBearerPremise.
\]

因此 one-global-subject 不是 WAAP 的简单展开。

---

## 3. Whole-to-subject gap

设：

\[
\exists!W_f\;FundamentalWhole(W_f).
\]

仍不能推出：

\[
Subject(W_f).
\]

所以记录：

\[
\boxed{
OneFundamentalWhole
\not\Rightarrow
OneFundamentalSubject.
}
\]

若理论需要后者，必须加入：

\[
Conscious(W_f)
\]

以及：

\[
Conscious(W_f)\Rightarrow Subject(W_f).
\]

这两条都不能由 mere priority / fundamentality 获得。

---

## 4. Consciousness-to-subject gap

Albahari-style universal consciousness提供更强 countermodel：

\[
OneGround
+
FundamentalConsciousness
+
Aperspectivality.
\]

即 fundamental consciousness可以不属于一个 subject。

所以：

\[
\boxed{
FundamentalConsciousness
\not\Rightarrow
FundamentalSubject.
}
\]

这意味着 global-subject theory还需一个 **Subject-Bearer Principle**：

\[
SBP:\quad FundamentalConsciousness(R)\Rightarrow\exists s\;Bears(s,R).
\]

SBP 当前没有 neutral proof。

---

## 5. Maximality does not solve singularity

一个诱人的策略是加：

\[
MaximalSubject(s).
\]

然后声称 maximality自动给唯一主体。

IIT 4.0提供成熟反例：Exclusion只在 overlapping candidate systems 中选择 maximally irreducible complex；对 universal substrate 递归寻找多个互不重叠 complexes。

因此：

\[
\boxed{
LocalExclusion/Maximality
\not\Rightarrow
GlobalSingleton.
}
\]

若要真正得到 singularity，需要：

\[
GlobalMaximality(R,s),
\]

并额外证明为什么所有 candidate subjects都处于一个共同竞争域，而不是形成多个 disjoint complexes / standpoints。

当前没有这样的 independent principle。

---

## 6. Christmann 2026 gives a serious conditional GSP bridge

Christmann 对 Yetter-Chappell-style phenomenal tapestry提出两条 global-subject pressure。

该 target theory 已经假定：

\[
GEU(R),
\]

即 all possible sensory perspectives / phenomenal threads 由 co-consciousness、property-binding、spatial-temporal relations织成一个 single global experiential structure。

### 6.1 Thin Mind dilemma

若整个 tapestry genuine experienced，则它有一个 experiencer of global scope。

若这个 experiencer只是 grammatical placeholder，就不能承担 genuine experiencing role。

若它 genuine承担该 role，它就已经是一个 non-trivial globally unifying subject。

所以：

\[
\boxed{
GEU+GenuineExperiencer
\Rightarrow
GlobalSubjectPressure.
}
\]

### 6.2 Synchronic pattern problem

整个 tapestry 的 co-consciousness pattern并非任意。Christmann问：为什么恰好这些 threads 在一个 moment共同出现、绑定成这些 objects、形成这个 spatial world？

他认为 laws of temporal evolution不自动解释 synchronic phenomenal pattern；brute pattern又失去 explanatory virtue。

一个 unified experiential act则可以把 pattern解释为 one subject's intentional content。

因此 abductively：

\[
\boxed{
GEU+SpecificGlobalPattern
\Rightarrow_{abductive}
UnifiedGlobalExperientialAct
\Rightarrow
GlobalSubjectPressure.
}
\]

这使 GSP 不再只是 stipulation。

但 Christmann 的 antecedent已经很厚，所以他没有证明：

\[
SubjectiveArity\Rightarrow GEU.
\]

真正新瓶颈因此移到 GEUP。

---

## 7. De-combination pressure

即使 global subject成立，它仍必须与 genuine local subjects兼容。

Miller 的 de-combination problem指出：subject–subject proper parthood 会让 phenomenal unity / boundedness变得困难。

所以 absolute theory不能只写：

\[
LocalSubjects\subset CosmicSubject.
\]

还必须给出：

- local phenomenal boundaries；
- local autonomy / subject unity；
- whole/part subject relation；
- why local subjectivity remains genuine rather than merely modes of one subject。

因此：

\[
\boxed{
OneGlobalSubject
\not\Rightarrow
SuccessfulNonSolipsisticLocalPlurality.
}
\]

---

## 8. Four-level actuality space

当前最公平的理论空间至少有四层：

### A0 — Subject-neutral actuality

Bricker / Soames / Adams-style：

\[
Actuality+\neg SubjectiveArity.
\]

### A1 — Plural subject-involving actuality

Whitehead / plural process / standpoint-style：

\[
Actuality+SubjectiveArity+\neg GEU.
\]

### A2 — Globally unified experiential actuality

Yetter-Chappell-style tapestry：

\[
Actuality+SubjectiveArity+GEU.
\]

Christmann对这一层施加：

\[
GEU\Rightarrow GlobalSubjectPressure.
\]

### A3 — Singular global-subject actuality

priority cosmopsychism / idealist monism / global-subject interpretation：

\[
Actuality+GEU+\exists!GlobalSubject.
\]

项目最终的 local absolute first-person还比 A3 更强，因为还需要 LAP。

所以理论升级顺序应写成：

\[
\boxed{
A0
\xrightarrow{WAAP}
A1
\xrightarrow{GEUP}
A2
\xrightarrow{GSP}
A3
\xrightarrow{LAP}
AbsoluteLocalOrientation.
}
\]

---

## 9. Consequences for CC1 / CC2 / CC3

### CC1

即使 Whitehead成功把 self-manifestation / subjectivity变成 independent completion witness，它最多要求从 A0升级到 A1。

Christmann提供另一个 possible witness structure：如果 one global experiential unity本身能 independently established，则 A1还会被推向 A2。

但当前：

\[
GEU
\]

还不是 common explanandum。

### CC2

证明 `subject-neutral actuality` incoherent最多淘汰 A0。

A1仍然是完整 competitor；所以 centered singular theory还需第二轮 insufficiency argument against plural subject-involving actuality。

现在该第二轮的 exact target就是：

\[
\neg GEU.
\]

### CC3

centered Ω若比 A0多 subject arity，Whitehead式资源可能帮助消除这一部分 surplus。

相对 A1，Ω仍增加 global unity / singularity。

若 Christmann式 GSP在 A2 成功，则 relative to A2，global subject本身的 surplus会减小；但 LAP与 I–NOW unity仍残留。

因此 centered Ω 的 distinctive residual content现在按层级递减为：

\[
SubjectiveArity
\to
GEU
\to
GlobalSubject
\to
AbsoluteLocalization+I\text{-}NOW.
\]

---

## 10. Current verdict

当前：

\[
\boxed{WAAP\text{ has serious positive resources}.}
\]

Whitehead尤其使 `vacuous actuality`成为一个真正可审计的靶点。

Christmann 2026 又使：

\[
\boxed{GSP\text{ has serious conditional support}.}
\]

即：如果 complete reality already forms one global experiential/co-conscious structure，则一个 globally unifying subject不再只是 gratuitous posit。

但：

\[
\boxed{GEUP\text{ remains unproven}.}
\]

Whitehead、Lipman、IIT-style multiple complexes都允许：

\[
SubjectiveArity+\neg GEU.
\]

所以当前新的 exact bottleneck是：

\[
\boxed{
What independently requires all fundamental subjectivity to belong to one global co-conscious unity?
}
\]

在回答这一点之前：

\[
Actuality\Rightarrow Subjectivity
\]

即使成功，也仍然没有得到：

\[
Actuality\Rightarrow AbsoluteI.
\]
