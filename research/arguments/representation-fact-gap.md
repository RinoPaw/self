# Representation–Fact Gap

> 状态：Bridge A2 的核心压力测试。
>
> 结论：即使 first-person representation / de se cognition 本身不可还原，也不能由此推出 reality 含有 irreducible first-person facts。A2 需要一个独立的 truth/obtaining-level bridge。

## 0. Target

Bridge A2 现在要检验：

\[
A_2:\quad
FirstPersonStructure(S)
\Rightarrow
StrongFPFact(S)?
\]

`FirstPersonStructure` 可以已经非常厚：

\[
R_S=\langle
IThought,
DeSe,
SelfLocation,
Mineness,
IEM,
Memory,
Agency,
FirstPersonAccess,
\ldots
\rangle.
\]

关键问题是：即使 \(R_S\) 无法翻译成 ordinary non-indexical cognition，是否因此必须有：

\[
F_S^{FP}
\]

作为 reality-level, perspective-non-invariant fact？

---

## 1. Perry countermodel

Perry-style architecture 允许：

\[
\boxed{
IrreducibleModeOfThought(S)
}
\]

同时：

\[
\boxed{
Fact(F,S)=F(S)
}
\]

仍是 ordinary fact。

例如主体相信：

\[
I\ am\ making\ a\ mess.
\]

这一 belief 的 first-person cognitive significance 不可由 “John Perry is making a mess” 替代；但二者仍可由同一 worldly fact：

\[
MakingMess(Perry)
\]

为真。

因此：

\[
\boxed{
FirstPersonRepresentationalIrreducibility
\not\Rightarrow
FirstPersonFactIrreducibility.
}
\]

这不是一个 bare logical possibility；它是 essential-indexical literature 中成熟的 positive architecture。

---

## 2. 两类 irreducibility 必须区分

### Cognitive / representational irreducibility

\[
IThought
\not\equiv
NonFirstPersonThought.
\]

它解释：

- de se action；
- self-location；
- indexical cognitive significance；
- first-person practical reasoning；
- some forms of self-knowledge。

### Fact-level irreducibility

\[
F_S^{FP}
\not\le
ThirdPersonFacts.
\]

它主张 reality 本身包含会随 subjective standpoint 改变的 facts。

二者之间没有形式蕴涵：

\[
\boxed{
IrreducibleRepresentation
\not\Rightarrow_{established}
IrreducibleFact.
}
\]

所以只证明 essential indexicality 不能关闭 A2。

---

## 3. Strong-FPR positive model

List / Lipman 路线加入更强 world-side commitment。

### List

真正 first-person fact：

\[
F_S^{FP}
\]

在 subjective perspective shift 下不 invariant。

若 third-person facts 保持 fixed，而：

\[
F_S^{FP}\neq F_{S'}^{FP},
\]

则：

\[
F_S^{FP}
\]

不 supervene on third-person facts。

### Lipman

subject 是 metaphysical standpoint，某些 facts：

\[
@_S(p)
\]

从该 standpoint obtain。

于是 perspectivality 不只属于 how S represents p，而进入：

\[
\boxed{\text{how reality/facts obtain}.}
\]

这是真正 A2-positive architecture。

---

## 4. Same-profile test

固定完整 first-person profile：

\[
R_S.
\]

构造：

### Model P — representation-only

\[
T_P=K+R_S+F(S).
\]

其中所有第一人称差异位于 mode / cognition / access。

### Model F — fact realism

\[
T_F=K+R_S+F_S^{FP}.
\]

其中 reality 本身 additionally contains perspective-sensitive fact。

如果两者可以保持完全相同：

- phenomenal profile；
- first-person thought；
- action；
- reports；
- memory；
- de se updating；
- local self-knowledge；

则：

\[
\boxed{
R_S\text{ alone underdetermines }T_P\text{ vs }T_F.
}
\]

这就是 **Representation–Fact Gap**。

---

## 5. Truth/Obtaining Delta Requirement

StrongFPR 正方不能再用 cognitive phenomena 作为充分理由，因为 Model P 本来就保留这些。

需要一个 independently identified：

\[
X_{truth/obtaining}
\]

满足：

\[
T_F\models X,
\]

而：

\[
T_P\not\models X.
\]

暂称：

\[
\boxed{\text{Truth/Obtaining Delta Requirement}.}
\]

候选可以包括：

- phenomenal appearance itself obtains only from S；
- reality contains genuinely standpoint-relative truths；
- unrestricted factivity from `@_S(p)` to `p`；
- a world-side subjective fact that cannot be represented as mode-of-access to an ordinary fact。

但这些候选都已经属于 substantive metaphysics；不能从 essential indexicality本身读取出来。

---

## 6. Mode-to-Fact Bootstrapping

一种常见无效路径：

1. `I-thought` 有特殊 mode；
2. 这个 mode 是 irreducible；
3. 因此 `I am F` 对应特殊 irreducible fact。

第 3 步不成立。

形式上：

\[
Mode_{FP}(Rep(S,p))
\]

不推出：

\[
Mode_{FP}(Obtaining(p)).
\]

所以：

\[
\boxed{
\text{representation-level first-personality cannot bootstrap fact-level first-personality}.}
\]

暂称 **Mode-to-Fact Bootstrapping Error**。

这与项目已有的：

- Center in Content / Center in Obtaining Gap；
- Constituent Collapse；
- Relative First-Person Demotion

属于同一层级纪律：必须持续区分 representation、content、obtaining、absolute status。

---

## 7. Strong fact realism 若获胜，会得到什么

假设 future argument 真正建立：

\[
A_2.
\]

那么每个 genuine conscious subject 若均满足前序条件，会有：

\[
\forall i\;F_i^{FP}.
\]

接受 List 的 non-invariance criterion 后，再得：

\[
Irreducible(F_i^{FP}).
\]

这会加强：

- P-F fragmentalism；
- P-MW many-world FPR；
- A-F / A-MW ordinary layer。

同时削弱 N-W / A-W 的 weak-fact version。

但它仍不会给：

\[
\exists!i\;Absolute(F_i).
\]

因此：

\[
\boxed{
A_2\text{ closure does not close Bridge B}.}
\]

---

## 8. 若 A2 继续开放

若没有 Truth/Obtaining Delta，N-W / A-W 可以非常强地承认：

- irreducible `I`-thought；
- genuine self-location；
- thick lived mineness；
- first-person access；
- de se practical organization；

同时仍说：

\[
\boxed{\text{the worldly fact inventory need not contain strong FP facts for every subject}.}
\]

这比“第一人称只是语言幻觉”强得多，也因此是 StrongFPR 必须真正击败的 closest foil。

---

## 9. 当前判定

Bridge A2 现在可以写得非常窄：

\[
\boxed{
\text{What independently forces first-personality from the mode of representation into the mode of obtaining?}
}
\]

截至目前：

\[
\boxed{
\text{essential indexicality does not force that move}.}
\]

List/Lipman 提供 coherent positive ontology；Perry 提供 coherent-looking negative ontology。裁决必须发生在 truth/obtaining level，而不能继续依赖 first-person cognition 本身。
