# Ordinary–Absolute Centering Gap

> 状态：工作论证。

## 0. 动机

Centered-world literature 已经有相当成熟的资源解释 ordinary de se / self-location：一个 attitude holder 的 perspective 可以由其 tokening event、functional role、context coordinates 等结构确定。

这容易诱导一个过快推论：

\[
\text{ordinary centering can be explained}
\Rightarrow
\text{absolute centering can be explained by the same mechanism}.
\]

本文件拒绝这一跳跃。

---

## 1. Ordinary centering

对一个真实 experiential / attitude context \(k_i\)，定义：

\[
Loc(k_i)=\langle S_i,t_i,p_i,\ldots\rangle.
\]

ordinary first-person center 可以由：

\[
C_i=Loc(k_i)
\]

给出。

这类结构具有独立动机：

- utterance / thought token 有实际 producer；
- sensory input 与 action output 有局部 causal organization；
- attitude states 的 functional role 以该 organism / token 为基准；
- indexical expression 的 context coordinates 来自实际 utterance context。

Skibra 2026 对 Lewis / Openshaw / Jackson–Stoljar 的讨论说明，self-ascription 的 primitiveness complaint 可以通过 functional / initialization resources 部分消解；但 center-arbitrariness 仍是单独问题。

---

## 2. 为什么普通机制自然产生多个 center

若现实中存在多个真实主体：

\[
S_1,S_2,\ldots,S_n,
\]

则通常存在多个真实 contexts：

\[
k_1,k_2,\ldots,k_n.
\]

统一的 context-centering rule 给：

\[
C_1,C_2,\ldots,C_n.
\]

因此普通 centering mechanism 最自然支持：

\[
\boxed{\forall i\;LocalCenter(S_i)}
\]

而非：

\[
\boxed{\exists!i\;AbsoluteCenter(S_i)}.
\]

这正好符合 Two-Tier First-Person Realism 的下层，但不会自动生成上层。

---

## 3. Global Context Requirement

若想复用 context strategy 来解释 absolute center，需要存在唯一 global context：

\[
K_G.
\]

并满足：

\[
Center_{abs}=Init(K_G).
\]

于是 absolute-center problem 变成：

\[
\boxed{\text{什么东西是 }K_G\text{，为什么它唯一？}}
\]

候选包括：

- reality-as-a-whole 的 self-manifestation context；
- unique actualization event / global token；
- unique metaphysical evaluation context；
- unique top-level dominance context。

每一项都必须说明：

1. 它不是把 `absolute center` 改名为 `global context`；
2. 它为什么能以已有 local experience 为 center，而不产生 cosmic subject；
3. 它为什么不在 multiverse / disconnected sectors 中复制；
4. 它怎样兼容 relativity / gauge invariance。

---

## 4. Center-Arbitrariness Test

Skibra 2026 重构 Cappelen–Dever 的 arbitrariness objection 时指出：仅仅把 possibility space 切得足够细并不迫使理论采用 self-center；还需要说明为什么由这个 coordinate set 初始化，而非别的 coordinate set。

迁移到本项目：

即使我们写出：

\[
\mathcal C=\langle W,S,t,p\rangle,
\]

也必须继续回答：

\[
\boxed{\text{为什么 complete reality 的 center-coordinate 由这一 }S,t,p\text{ 初始化？}}
\]

因此 tuple representation 本身没有解释力。

真正有解释力的是一个独立机制：

\[
M(R)\Rightarrow \langle S,t,p\rangle.
\]

若没有 \(M\)，centered-state notation 只是 bookkeeping。

---

## 5. Pagin-style Anchoring Pressure

Pagin 的 world-construction / self-location 结果强调：即使全部 experience facts 与全部 objective facts 都给定，二者之间的 correlation 仍可能欠定。

用本项目记号：

\[
W=\text{objective structure},
\]

\[
\Pi=\text{perspectival/experiential structures}.
\]

仍需要某种 anchoring：

\[
\rho:\Pi\to E(W).
\]

所以 centered reality 至少有两层问题：

### Anchoring

\[
\rho(\pi_i)=E_i
\]

解释每个 ordinary perspective 对应客观世界里的哪个 subject/event。

### Absolutization

\[
\mathsf A(\pi_i)=1
\]

只对一个 perspective 给 simpliciter status。

即使 ordinary anchoring 全部解决：

\[
\rho(\pi_1),\ldots,\rho(\pi_n),
\]

仍没有：

\[
\exists!\pi^*\;\mathsf A(\pi^*)=1.
\]

因此：

\[
\boxed{\text{Anchoring}\neq\text{Absolutization}}
\]

---

## 6. 当前结论

现代 de se 理论提供了一个重要正面结果：

\[
\boxed{\text{ordinary centeredness can have independent functional/contextual structure}}
\]

这说明“center”概念本身不必总是 primitive。

但同一结果反而让 absolute-first-person 问题更尖锐：

\[
\boxed{\text{ordinary centering mechanisms naturally pluralize}}
\]

所以 absolute center 需要一个第二层结构，其形式至少是：

\[
\{C_1,\ldots,C_n\}
\xrightarrow{G}
C^*.
\]

或者完整现实从根上已经包含一个不可还原的 global centeredness。

前者回到 Global First-Person Transition；后者回到 Centering Reduction Trilemma。
