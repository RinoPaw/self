# Presence Route Four-Way Closure

> Date: 2026-10-05
>
> Status: argument-level terminal result for the `PresenceSimpliciter` route.
>
> Goal: determine whether ordinary temporal/presence data can independently force `PresenceSimpliciter`, thereby supplying a CC1 witness for Centered Completion.

## 1. Target chain

The strongest hoped-for positive chain was:

\[
OrdinaryPresenceData
\Rightarrow
PresenceSimpliciter
\Rightarrow
Distinguished\ I\text{-}NOW
\Rightarrow
AtLeastOneOpening.
\]

The last two arrows can be made coherent conditionally. The first arrow is the unresolved bridge.

The previous audit isolated four possible ways to force it:

\[
\boxed{
PhenomenalResidue
\;|\;
SemanticIndispensability
\;|\;
ExplanatoryResidue
\;|\;
RelationalIncoherence.
}
\]

The terminal audit finds that none currently succeeds.

---

## 2. Shared neutral datum

Let:

\[
D_P
=
\{Immediacy,PhenomenalNow,ForMeNess,Change,Succession,Memory,Anticipation,Agency,TemporalIntegration\}.
\]

A relational model can represent the core as:

\[
PresentTo(E,S,t)
\]

plus the appropriate causal, phenomenal, mnemonic, anticipatory, and person-stage structure.

The centered interpretation adds:

\[
PresentSimpliciter(E^*).
\]

So the issue is whether:

\[
D_P
\]

contains anything that cannot be captured without that monadic status.

---

## 3. Closure 1 — No surviving phenomenal residue

A successful residue would require:

\[
\exists P^*\;[
Phenomenal(P^*)
\land
CenteredModel\models P^*
\land
RelationalModel\not\models P^*
].
\]

No such feature has been isolated.

Candidates such as:

- vividness;
- immediacy;
- liveness;
- flow;
- experienced change;
- succession;
- the specious present;
- currentness;
- passivity with respect to time;
- phenomenal novelty;

all admit at least one serious relational/B-compatible treatment.

Recent empirical variation in robust-passage reports makes a universal introspective residue even harder to defend.

Therefore:

\[
\boxed{
NoKnownPhenomenalResidue.
}
\]

This is a research-status result, not a theorem that no such residue could exist.

---

## 4. Closure 2 — Semantic irreducibility stops at representation

Suppose:

\[
TensedContent\not\equiv TenselessContent.
\]

That does not entail:

\[
TensedTruthmaker.
\]

More generally:

\[
\boxed{
RepresentationalIrreducibility
\not\Rightarrow
OntologicalIrreducibility.
}
\]

The same lesson already appears on the project's first-person axis:

\[
IrreducibleDeSeRepresentation
\not\Rightarrow
IrreducibleAbsoluteFPFact.
\]

So the temporal and first-person cases line up:

\[
\boxed{
Indexical/TensedPerspective
\not\Rightarrow
SimpliciterOrientation.
}
\]

Prosser-style person-stage relations further show how distinctive temporal attitudes can retain their cognitive role within a relational ontology.

Therefore:

\[
\boxed{
NoSemanticToOntologyBridge.
}
\]

---

## 5. Closure 3 — No mandatory explanatory residue

The strongest explanatory challenge is differential availability:

\[
PastExperience\text{ exists tenselessly},
\]

yet:

\[
CurrentExperience\text{ is available/presented in a special way}.
\]

But the neutral side has several coherent response families:

### R1 — time-relative availability

\[
Available(E,S,t).
\]

### R2 — stage-relative simpliciter availability

\[
AvailableSimpliciter(E,S_t).
\]

### R3 — temporal-part availability

experiences are available simpliciter to temporal stages/parts rather than to a four-dimensional persisting whole.

These replies differ in cost and plausibility. But their existence blocks:

\[
DifferentialAvailability
\Rightarrow
PresentnessSimpliciter.
\]

Thus the presence realist may claim a cleaner explanation, but cannot currently claim explanatory monopoly.

Therefore:

\[
\boxed{
NoMandatoryExplanatoryResidue.
}
\]

---

## 6. Closure 4 — No relational incoherence theorem

The strongest possible result would be:

\[
RelationalPresence\vdash\bot.
\]

No such theorem has been found.

Relational accounts can specify:

- temporal order;
- simultaneity;
- causal direction;
- subject/time location;
- memory asymmetry;
- anticipation;
- person-stage perspective;
- temporally extended experience;
- truth conditions for tensed discourse.

They may face costs or contested commitments, but those are not contradictions.

Moreover, regress pressure is not asymmetric. A-theoretic changing presentness itself faces McTaggart-style regress/incompatibility challenges.

Therefore:

\[
\boxed{
NoNeutralIncoherenceResult.
}
\]

---

## 7. Interpretation Capture Principle — final form

The four failures support a general principle useful beyond time.

### ICP

Let `D` be a datum shared by rival theories, and `M(D)` a contested metaphysical interpretation of that datum.

If:

1. `D` can be stated without target vocabulary;
2. rival theory `N` can model `D` without `M`;
3. no phenomenal residue selects `M`;
4. no semantic-to-ontology bridge selects `M`;
5. no explanatory impossibility excludes `N`;
6. no incoherence theorem excludes `N`;

then:

\[
\boxed{
D\text{ cannot currently function as independent evidence for }M.
}
\]

Applied here:

\[
D=D_P,
\qquad
M(D)=PresenceSimpliciter.
\]

Hence:

\[
\boxed{
OrdinaryPresenceData
\not\Rightarrow
PresenceSimpliciter.
}
\]

## 8. Conitzer survives as a downstream bridge

Do not discard the useful part.

Conitzer's pressure is approximately:

\[
DistinguishedNOW
\Rightarrow
DistinguishedI\text{-}NOW\ Pressure.
\]

Or in the presence form:

\[
PresenceSimpliciter(E)
\Rightarrow
DistinguishedPersonStage(E).
\]

This is valuable because it says an A-theoretic privilege should not be artificially confined to the temporal coordinate when the allegedly privileged item is a subject's experience.

But it cannot supply its own antecedent.

So:

\[
\boxed{
ConitzerBridge\ survives;
PresenceWitness\ fails.
}
\]

### Presence route

## 10. Consequence for Completion Fork

The Completion Fork remains:

\[
\boxed{
C_N:\ K\text{ can be complete actual reality}
}
\]

versus:

\[
\boxed{
C_C:\ K\text{ is incomplete unless actuality is intrinsically centered}.
}
\]

Presence was the best remaining candidate for CC1:

\[
IndependentCompletionWitness.
\]

The four-way closure removes it from that role.

Therefore:

\[
\boxed{
CC1\ remains\ unsatisfied.
}
\]

It also provides no CC2 incoherence theorem and no CC3 replacement theorem.

Hence:

\[
\boxed{
CompletionUnderdetermination\ survives\ the\ strongest\ presence\ audit.
}
\]

## 11. Research Stop Rule

Do not keep reopening this route on ordinary variants of:

- `the present feels special`;
- `experience is only now`;
- `time seems to flow`;
- `current experience is vivid/live`;
- `we cannot eliminate tense from thought`;
- `past experiences are not available now`.

These have been absorbed by the four-way audit.

Reopen only if a new source provides a result of one of these exact forms:

\[
PhenomenalFeatureF
\land
ImpossibleUnderRelationalPresence(F),
\]

or:

\[
SemanticFeatureF
\Rightarrow
MonadicWorldlyPresentness,
\]

or:

\[
RelationalPresence
\vdash
Contradiction/Regress,
\]

or:

\[
P(Evidence\mid PresenceSimpliciter)
\neq
P(Evidence\mid RelationalPresence).
\]

Otherwise further Presence work is literature accumulation without frontier movement.

---

## 12. Terminal verdict

\[
\boxed{
\text{The Presence route is closed as an independent route to Centered Completion.}
}
\]

This is deliberately weaker than:

\[
\neg PresenceSimpliciter.
\]

`PresenceSimpliciter` remains a coherent primitive/metaphysical reading and a useful antecedent for Conitzer-style personalization.

But after phenomenal, semantic, explanatory, and coherence audits, it no longer has a live claim to be an **independently forced** bridge from common experience to absolute opening.
