# Top-Domain / Center Gap

> 状态：条件性结构结论。它不否定绝对第一人称，而是区分此前被 `D_top` 混在一起的几种唯一性。

## 1. 问题

Nested Dominance 当前要求一个唯一最高 domain：

\[
\exists !D_{\top}.
\]

此前容易把下面几件事视为同一件事：

1. 现实有一个唯一最大整体；
2. 所有意识都属于一个共同 competition domain；
3. 该 domain 有一个唯一 experiential winner；
4. 这个 winner 是 absolute center。

它们实际上是四个独立主张。

---

## 2. Top whole 不等于 top competition domain

Priority monism 可以提供一种成熟的 top-whole ontology：存在唯一最基础或最包容的 cosmos / fundamental whole。

记为：

\[
\exists !U_{\max}.
\]

但 Nested Dominance 真正需要的是：

\[
\exists !D_{\mathrm{comp}}
\]

且全部 absolute-eligible conscious loci 都进入同一 dominance relation。

因此：

\[
\boxed{
\exists !U_{\max}
\not\Rightarrow
\exists !D_{\mathrm{comp}}
}
\]

一个整体可以在 mereological / grounding 意义上唯一，却完全没有定义一场跨全部局部主体的 competition。

### Top-Domain Equivocation

把“唯一最大现实整体”直接当成“唯一意识竞争域”会发生概念偷换。

任何 Nested Dominance 实现都必须独立说明：

\[
U_{\max}\Rightarrow D_{\mathrm{comp}}
\]

中的关系是什么。

---

## 3. 完整 uncentered world 不等于唯一 center

Self-location 文献提供一个几乎同型的成熟框架。

标准 centered world 可以写成：

\[
\langle w,t,i\rangle,
\]

其中：

- \(w\)：uncentered world；
- \(t\)：时间位置；
- \(i\)：个体 / subject position。

同一个 \(w\) 可以支持多个不同 centers：

\[
\langle w,t_1,i_1\rangle,
\langle w,t_2,i_2\rangle,
\dots
\]

Christian List 的 first-personally centered world 版本可写成：

\[
\langle \omega,\pi\rangle,
\]

其中 \(\pi\) 是 locus of subjectivity。

因此，在 `w` / `omega` 只表示第三人称或 uncentered totality 的条件下：

\[
\boxed{
\exists !w
\not\Rightarrow
\exists !\pi
}
\]

这与此前的 Source-Locus Gap 同型：

\[
\text{one totality}
\not\Rightarrow
\text{one experiential locus}.
\]

---

## 4. Center Underdetermination

若存在：

\[
\pi_1\neq\pi_2
\]

但：

\[
Base(\pi_1)=Base(\pi_2)=w,
\]

则仅从 uncentered base 无法推出：

\[
\pi^*=\pi_1
\]

或：

\[
\pi^*=\pi_2.
\]

暂称：

\[
\boxed{\text{Center Underdetermination}}
\]

它并不证明完整现实永远无法决定 center；它只证明**贫化的 uncentered totality** 不够。

---

## 5. Enriched-World Escape

Stalnaker 式 propositionality 提供一个重要逃生口：把 possible world 描述得更丰富，使 self-location 差异最终对应 world-level differences。

因此本项目不能直接把 Center Underdetermination 当作终局。

可以设：

\[
w^+=\langle w,X\rangle,
\]

其中 \(X\) 是额外的 center-relevant structure。

若：

\[
w^+\Longrightarrow\pi^*,
\]

则 center 可以原则上由更丰富的完整结构决定。

### 但必须通过 Enrichment Test

任何额外结构 \(X\) 都必须回答：

1. \(X\) 是否有独立于 absolute-center 定义的来源；
2. \(X\) 是否只是把 `this is the center` 改写成别的符号；
3. \(X\) 是否在复制 / 对称情况下仍然可定义；
4. \(X\) 为什么与 first-person liveness / privilege 有关；
5. \(X\) 是否兼容 gauge / covariance。

因此：

\[
\boxed{
\text{enrichment is a legitimate escape only if it is non-circular and privilege-relevant}
}
\]

---

## 6. 对 Nested Dominance 的影响

Nested Dominance 不能再只写：

\[
D_{\top}\to E^*.
\]

至少需要区分：

\[
U_{\max}
\]

——唯一整体；

\[
D_{\mathrm{comp}}
\]

——所有 eligible loci 进入的共同竞争域；

\[
d(D_{\mathrm{comp}})
\]

——single-output winner；

以及：

\[
Absolute(d(D_{\mathrm{comp}}))
\]

——winner 的 privilege / liveness 解释。

所以完整链条至少是：

\[
\boxed{
U_{\max}
\Rightarrow?
D_{\mathrm{comp}}
\Rightarrow
E^*
\Rightarrow?
Absolute(E^*)
}
\]

第一与最后一个问号都仍未解决。

---

## 7. 与 2026 Superpsychism 的关系

Schneider–Bailey 的 Superpsychism 给出一个当前很强的 top-domain 先例：fundamental maximally entangled prototime structure 被赋予最高层 consciousness，普通 minds 和 spacetime 则作为 emergent projections。

它说明：

\[
\text{one conscious top structure}
\]

在现代意识形而上学里完全可构造。

但它自然得到的是：

\[
S_{cosmic / super}
\]

而非：

\[
E^*\in\{E_{Alice},E_{Bob},E_{Rino},\dots\}.
\]

因此它强化一个独立问题：

\[
\boxed{\text{Top-Winner Localization Problem}}
\]

即 top-level privilege 为什么落在某个既有 local experience，而不会成为新的 cosmic subject。

---

## 8. 当前结论

`D_top` 以后不再作为模糊单项使用。

任何 top-domain 模型必须依次通过：

1. **Top Whole**：是否有唯一总体；
2. **Competition Closure**：为何所有 eligible centers 进入同一 relation；
3. **Single Output**：为何 relation 只产生一个 winner；
4. **Localization**：winner 为何是现有 local experience；
5. **Privilege Bridge**：winner 为何拥有 LIVE simpliciter。

这五层中的任何一层都不能由上一层仅凭“唯一”自动推出。
