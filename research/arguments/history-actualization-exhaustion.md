# History Actualization Exhaustion

## 0. 目标

此前的 `History Actualization Trilemma`：

\[
\text{Branching}\;|\;\text{Extra Seed}\;|\;\text{Stochastic Actualization}
\]

不是穷尽分类。

它遗漏了至少两类成熟路线：

- actuality 本身是 standpoint-relative / indexical，而不存在 global unary actuality；
- actuality / determinate history 在本体上是不确定的。

本文件尝试把问题改写成一个更接近穷尽的结构分类。

---

## 1. 基本对象

设：

\[
D
\]

是当前层级的理论输入，包括允许进入该层解释的 laws、global/boundary conditions、fundamental structures 等。

令：

\[
\Omega_D
\]

是 `D` 允许的 complete candidate histories / first-person trajectories。

真正需要分类的是 **actualization structure**。

若存在全局 unary actuality predicate：

\[
Actual(H),\qquad H\in\Omega_D,
\]

则可以定义：

\[
A_D=\{H\in\Omega_D:Actual(H)\}.
\]

absolute-first-person 路线最强版本通常要求：

\[
|A_D|=1.
\]

但一些成熟理论会拒绝 unary `Actual(H)` 本身，或拒绝 `A_D` 必须是 singleton。

---

## 2. 第一分叉：有没有 determinate global actuality？

### Branch U — 有唯一、确定的 global actual history

\[
A_D=\{H^*\}.
\]

此时继续追问：`H*` 的唯一性从哪里来？

### Branch N — 不接受这样的 singleton global actuality

这里至少分三种：

1. **Plural Actualization**：多个 histories / branches 都 actual；
2. **Perspectival Actualization**：actuality 是关系，而非 unary global property；
3. **Indeterminate Actualization**：现实并未确定哪一个精确 history 是 uniquely actual。

所以：

\[
\boxed{\text{拒绝唯一 global actuality}}
\]

本身不是一个单一路线。

---

# Part I — Singleton Global Actuality

## 3. Route S：Structural / Strong Determination

若：

\[
D\vdash H^*,
\]

并且：

\[
\Omega_D=\{H^*\},
\]

则 actuality 不需要额外 token selector。

这对应 Eddy Keming Chen 定义的 strong determinism：physical theory 只允许一个 possible history of the universe。

Everettian Wentaculus 是现实物理中的重要先例：canonical initial density matrix + unitary dynamics 可以使 fundamental universal history nomologically unique。

### 对 self

这是解释力最强的一类：

\[
D\Rightarrow H^*.
\]

但仍有两道独立困难：

\[
\text{unique global history}\not\Rightarrow\text{unique experienced branch},
\]

以及：

\[
H^*\not\Rightarrow LIVE(E^*).
\]

因此 strong determination 只解决 actual-history 层，不能自动解决 first-person center。

---

## 4. Route Z：Extra Seed / Primitive Actuality

若：

\[
|\Omega_D|>1,
\]

但实际世界额外包含：

\[
Z^*,
\]

使：

\[
(D,Z^*)\Rightarrow H^*,
\]

则实际 history 的唯一性来自额外 contingent actualizer。

### 物理先例：Bohmian configuration

Bohmian mechanics 的完整状态包含 wave function 与 actual configuration：

\[
(\psi,Q).
\]

即使 nomological / wave-function structure 高度受约束，actual trajectory 仍需要实际 configuration。

### 形而上先例：absolute actuality

Bricker 式 absolute actuality 允许多个 possible worlds 都真实，同时有 primitive fact 决定哪部分 reality 是 absolutely actual。

在这个分类中：

\[
Z^*=\text{primitive actuality fact}
\]

和：

\[
Z^*=\text{actual configuration}
\]

形式上属于同一家族：`D` 本身不推出 token actuality，完整实际状态还包含一个额外 actualizer。

### 对 self

若直接加入：

\[
Z^*=E^*,
\]

就只是重命名 absolute center。

所以 Route Z 只有在 `Z*` 具有独立理论角色时才有解释增益。

---

## 5. Route C：Stochastic Actualization

这里：

\[
D\Rightarrow \mathbb P(H),
\]

但：

\[
D\not\Rightarrow H^*.
\]

实际世界通过 fundamental stochastic process 实现：

\[
H^*\sim\mathbb P.
\]

GRW / GRWf 是成熟先例。

### 与 Extra Seed 的差别

两者都承认实际 history 没有被 deterministic `D` 唯一推出。

区别在于 Route C 中：

\[
\mathbb P
\]

本身属于 law-governed actualization structure，并给不同 continuation / outcome 客观 chance。

Route Z 则只需要额外 actual state / seed；它不必带 objective stochastic transition law。

### 对 self

Route C 可以绕过 deterministic symmetry obstruction：

\[
P(E_1)=P(E_2)
\]

仍允许一次 realization 只产生：

\[
E^*=E_1.
\]

但解释停在：

\[
\boxed{\text{why this one?}=\text{objective chance outcome}}
\]

并且仍需：

\[
Actualized(E^*)\Rightarrow LIVE(E^*).
\]

---

# Part II — Rejecting Singleton Global Actuality

## 6. Route P：Plural Actualization / Branching

这里：

\[
|A_D|>1.
\]

最强形式甚至是：

\[
A_D=\Omega_D.
\]

Everett 路线提供标准物理模板：没有从 possible 到 actual 的 single-out transition；分支并不需要一条被提升为唯一 actual。

### 对 self

这种路线直接拒绝：

\[
\exists !H^*.
\]

first-person 问题随后转化为：

\[
\text{self-location among real branches / centers}.
\]

所以它不是 selector 的竞争实现，而是拒绝 selector 的必要性。

---

## 7. Route R：Relational / Perspectival Actualization

更激进地，理论可能拒绝全局 unary：

\[
Actual(H).
\]

改用：

\[
Actual(H,S)
\]

或：

\[
F_{S}(p).
\]

此时不同 standpoint 可以各自拥有真实 perspectival facts，而没有一个更高层 actuality predicate 将其中一个升级成 simpliciter actual。

Lewis 式 indexical actuality、Lipman 的 standpoint pluralism、Solomyak 的 perspectival pluralism 都是这类结构的邻近模型。

### 对 self

这条路线最直接地消解：

\[
\text{which one is globally actual?}
\]

它要求正方先证明：

\[
\boxed{\text{global unary actuality / liveness is genuinely missing}}
\]

而不能把它直接当成问题定义的一部分。

---

## 8. Route I：Indeterminate Actualization

还有一种此前遗漏的逻辑空间：

现实可能**本体上没有确定**哪一个精确 history / actuality configuration 唯一成立。

粗略写成：

\[
\neg Determinate(A_D=\{H_1\}),
\]

同时也：

\[
\neg Determinate(A_D=\{H_2\}).
\]

Barnes–Williams 的 metaphysical indeterminacy / multiple actualities 框架表明，这类观点在成熟形而上学中是可表达的；量子形而上学中也有将部分物理性质理解成 worldly / metaphysical indeterminacy 的路线。

### 与 Plural Actualization 的区别

Plural route 说：

\[
Actual(H_1)\land Actual(H_2).
\]

Indeterminate route 不必说二者都 actual；它可以说 actuality itself 尚未/根本没有精确 determinate 到某一个。

### 对 self

如果 absolute first-person status 本身可能 ontically indeterminate，那么：

\[
\exists !E^* LIVE(E^*)
\]

甚至不是必须满足的 metaphysical completeness condition。

这给正方增加一个此前没有面对的反方：**determinacy requirement 本身也需要论证。**

---

## 9. 近似穷尽的决策树

当前可以写成：

```text
Does the theory posit a determinate global actuality relation?
│
├─ YES
│   │
│   └─ Is there exactly one actual complete history?
│       │
│       ├─ YES
│       │   │
│       │   ├─ D itself entails it        → S: Structural / Strong Determination
│       │   ├─ extra actual state selects → Z: Extra Seed / Primitive Actuality
│       │   └─ chancy law realizes it     → C: Stochastic Actualization
│       │
│       └─ NO → P: Plural Actualization / Branching
│
└─ NO
    │
    ├─ actuality is standpoint-relative   → R: Relational / Perspectival Actualization
    └─ actuality is ontically unsettled   → I: Indeterminate Actualization
```

因此当前得到一个 **六路线 schema**：

\[
\boxed{S\;|\;Z\;|\;C\;|\;P\;|\;R\;|\;I}
\]

---

## 10. 这是否真的“穷尽”？

目前只能称 **near-exhaustive schema**，不能称定理。

理由：

1. 一个理论可以混合路线，例如先有 extra initial seed，再用 stochastic dynamics；
2. `global actuality`、`history`、`determinacy` 的定义本身可能被某些非标准形而上学拒绝；
3. metaphysical indeterminacy 可以有多种实现，不一定都等价于 multiple actualities；
4. process ontology 可能把 history-level 分类改写成 event-generation classification。

但对于任何仍然愿意谈：

\[
\Omega_D
\]

以及“哪些 complete histories / trajectories 实际成立”的理论，这六类已经覆盖目前找到的主要成熟结构。

---

## 11. 一个更重要的结果：原问题被拆成两个层级

以前我们把：

\[
\text{actual history}
\]

和：

\[
\text{absolute first-person liveness}
\]

混得太近。

现在必须严格分层：

### History Actualization Layer

理论属于：

\[
S,Z,C,P,R,I
\]

哪一种？

### First-Person Privilege Layer

在给定上述 history ontology 后，再问：

\[
\exists !E^*\;LIVE(E^*)\ ?
\]

例如：

- `S` 可以有唯一 universe-history，但很多 conscious branches / centers；
- `Z` 可以给唯一 material trajectory，但没有说明哪段 experience 是 LIVE simpliciter；
- `C` 可以生成一个 actual event history，但 actual occurrence ≠ first-person liveness；
- `P/R/I` 则分别从 plural、perspectival、indeterminate 三个方向挑战 unique absolute center 的必要性。

所以：

\[
\boxed{\text{History Actualization}\not\Rightarrow\text{Absolute First-Person Actualization}}
\]

这是这轮最重要的结构结论。

---

## 12. 对当前正方路线的影响

如果坚持 absolute first-person，至少需要先选择一个 history-actualization 背景。

### 最强解释路线

\[
S + \text{Global Singleton} + \text{Privilege Bridge}
\]

目标最漂亮，但承受 symmetry / duplication / local-to-global 压力最大。

### 最强一致性路线

\[
C + \text{ontic single-center realization} + \text{Privilege Bridge}
\]

可以保持 law-level symmetry，但 `why this one` 停在 chance。

### 最弱 primitive 路线

\[
Z + \text{primitive center fact}
\]

一致性容易，解释力最低。

而 `P/R/I` 构成三个不同方向的强反方：

\[
\boxed{\text{many actual}}
\]

\[
\boxed{\text{actual only relative to a standpoint}}
\]

\[
\boxed{\text{no determinate unique actuality}}
\]

正方以后不能只击败其中一个。
