# 绝对第一人称

## 工作定义

“绝对第一人称”用于指一种强于普通第一人称性的假设结构。

普通第一人称允许多个主体分别拥有自己的主观体验：

\[
FP(C_1),\ FP(C_2),\ldots,FP(C_n)
\]

绝对第一人称假说进一步考虑：全部存在中可能只有一个经验位置具有不可继续相对化的绝对地位：

\[
\exists !E^*\; Absolute(E^*)
\]

## 与普通第一人称的区别

普通第一人称关注：

- 经验怎样以“对我而言”的方式被给予；
- 主体怎样自我定位；
- de se 信念、for-me-ness、mineness；
- 每个主体内部的第一人称组织结构。

绝对第一人称关注：

- 多个真实第一人称中心之间是否仍存在一个全局不对称；
- 完整现实是否还包含一个无法还原为“对某主体而言”的绝对中心；
- 这一中心是否唯一；
- 它是否与当前性、时空事件和现实整体结构有关。

## 当前约束

1. 其他意识可以是真实的。
2. 绝对地位不等于价值、重要性、道德地位或认知能力更高。
3. 唯一性应作用于全部存在，而不随光锥、宇宙或可能世界简单复制。
4. 暂不假定绝对第一人称绑定完整人生。
5. 暂不假定存在一个可独立于现实结构任意切换的“指针”。
6. 必须区分现象学上的绝对感与本体论上的绝对地位。

## 工作术语

仓库中以下词语暂时区分使用：

- **first person / 第一人称**：普通主体内部的第一人称结构。
- **absolute first person / 绝对第一人称**：假设存在的全局唯一绝对中心。
- **absolute experiential event / 绝对经验事件**：把主体与当前时空事件共同作为绝对性的最小候选单位。
- **absolute experiential trajectory / 绝对经验轨迹**：若绝对性具有某种展开或流逝结构，记录其经过经验事件的唯一轨迹 \(\Gamma^*\)。
