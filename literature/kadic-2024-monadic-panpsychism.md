# Nino Kadić — Monadic Panpsychism

论文：Nino Kadić, “Monadic panpsychism”, *Synthese* 203 (2024), DOI: 10.1007/s11229-023-04464-0.

## 为什么对本项目重要

这是目前找到的少数真正提出 **single-output experiential locus mechanism** 的现代理论之一。

Kadić 的 microphenomenal structuralism 假设 fundamental microsubjects 的 relational structure 可以把丰富的人类级 phenomenal content 集中到一个 microsubject 上，而无需额外产生一个 higher-level macrosubject。

## Static Monadic Panpsychism

Static 版本大致写成：

\[
\{m_1,m_2,\dots,m_n\}
\xrightarrow{R}
 m^*.
\]

所有相关 microsubject 的关系共同决定 **only one particular microsubject** 的 phenomenal character，使它拥有完整 human experience；这个 microsubject 扮演 dominant role。

这非常接近当前项目要找的：

\[
\text{many contributors}\to\text{one experiential output}.
\]

但 Kadić 自己认为 static 版本会面临 dominant microsubject 被移除等困难，因此更偏向 dynamic 版本。

## Dynamic Monadic Panpsychism

Dynamic 版本仍维持：

\[
|Output(R)|=1,
\]

但 dominant role 可以随脑过程动态转移：

\[
m^*_1\to m^*_2\to m^*_3\dots
\]

Kadić 把关键困难分成：

1. metaphysical individuation：什么机制让某个 physical ultimate 成为 complex consciousness 的 locus；
2. epistemological individuation：如何知道当前是哪一个 ultimate dominant。

他提出 phenomenal structure 可能 mirror causal structure，并把 dominant locus 的变化与 brain integration 动力学连接。

这和本项目早期的：

\[
E^*(w)=\Gamma^*(w)
\]

在形式上有明显相似性，但 Kadić 的 domain 是一个 organism / relevant brain structure，而非全部存在。

## Global Monadic Panpsychism

值得注意的是，Kadić 称作 “global” 的第三版本并不做我们这里的 global singleton。

它反而取消单一 dominant microsubject，让 relevant structure 中的所有 microsubject 都获得完整 human experience：

\[
R\to\{m_1,\dots,m_n\}
\]

且它们 qualitative content 相同，因此主体从内部感觉像一个 “I”。

这正好再次展示：phenomenal sameness / unity feeling 并不能推出 numerical singleton。

## 对绝对第一人称的压力测试

### 优点

Kadić 至少证明一种结构构想是清楚的：

\[
\boxed{\text{relational causal structure can be hypothesized to have a single experiential endpoint}}
\]

这比简单 scalar maximum 更接近 liveness generation，因为 winner 本身就是 phenomenal point of view。

### Dominance Domain Problem

Kadić 的 single-output 只相对于：

\[
D=\text{relevant causal structure}
\]

成立。

若每个人的脑分别形成：

\[
D_A,D_B,D_C,
\]

则完全可能分别得到：

\[
m_A^*,m_B^*,m_C^*.
\]

所以：

\[
\text{one dominant locus per brain}
\not\Rightarrow
\text{one dominant locus in reality}.
\]

这直接落入项目的 Local-to-Global Singleton Obstruction。

### 若把 domain 扩成整个宇宙

可以想象新理论：

\[
D=\mathcal R,
\qquad
Output(\mathcal R)=\{E^*\}.
\]

但此时出现两种可能：

1. 只有 \(E^*\) 获得完整 subjectivity —— 其他 ordinary minds 的真实性受到破坏；
2. 其他 minds 仍 independently conscious —— 那么 global dominant 的 absolute privilege 需要额外解释。

因此 Kadić 提供了 mechanism template，却没有直接解决 absolute-first-person problem。

## 当前价值

把它保留为 **single-output mechanism prototype**。

它说明未来成功模型不一定只能靠 primitive pointer；一个 relational structure 原则上可以有一个 experiential endpoint。

但要升级为 absolute-first-person theory，至少还需解决：

- global domain；
- other-minds compatibility；
- privilege bridge；
- I–NOW dynamics；
- 为什么 output 唯一且不会在复制 domain 中重复。
