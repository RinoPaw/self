# Category Theory, Universal Properties, and Centering

## 0. 用途

本文件整理 category-theoretic structures 对 absolute-first-person problem 的直接启发。

目标不是把 category theory 当作 metaphysical evidence，而是用它精确地区分：

- relational individuation；
- global coherence；
- universal distinguished role；
- absolute centering。

---

## 1. Tsuchiya & Saigo 2021 — Yoneda / relational characterization

Naotsugu Tsuchiya 与 Hayato Saigo 在 *Neuroscience of Consciousness* 提出用 category theory 描述 level / content of consciousness。

核心方法是 Yoneda lemma：object 可以通过它与 category 中其他 objects 的全部 relationships 被刻画到 isomorphism。

对本项目的价值：

\[
\boxed{\text{complete relational profile can individuate a conscious structure}}
\]

但：

\[
\boxed{\text{relational individuation}\not\Rightarrow\text{privilege}}
\]

Yoneda 对每个 object 都成立；它没有产生一个全局 preferred object。

来源：

- Tsuchiya, N. & Saigo, H. (2021), “A relational approach to consciousness: categories of level and contents of consciousness”, *Neuroscience of Consciousness*, niab034.

---

## 2. Phillips & Tsuchiya 2024/2025 — universal mapping properties

该 preprint 试图用 universal mapping properties 统一/形式化 IIT 的 phenomenological axioms：

- intrinsicality；
- information；
- integration；
- exclusion；
- composition。

论文明确强调 unique-existence / universal mapping property，并提出：

> consciousness is a universal (mapping) property.

对本项目很重要，因为它证明一种严肃路线：

\[
\text{first-person / intrinsic phenomenal constraints}
\]

可以尝试由 universal relational structure formalize。

但它的 universal properties 是 experience-generic：每个 conscious experience 都应满足相应形式。

因此：

\[
UMP_{experience}
\]

主要解决 local experiential unity / definiteness，而没有推出：

\[
\exists!E^*\;Absolute(E^*).
\]

来源：

- Steven Phillips & Naotsugu Tsuchiya, “Towards a (meta-)mathematical theory of consciousness: universal (mapping) properties of experience”, arXiv:2412.12179, v2 2025.

## 3. Baruss 2019 — subject as terminal object

Imants Baruss 的 categorical consciousness model 中：

- each topos represents potential experiential content of an individual；
- meaning fields 是 objects；
- phenomenological subject 由 terminal object 表示；
- morphisms from terminal object to objects 表示 attentional targeting / subjective experience。

它是目前很直接的先例：

\[
\boxed{\text{phenomenological subject can be represented by a universal categorical role}}
\]

但该 construction 明确是 **per individual**。

所以它同时是 Local-to-Global Obstruction 的好例子：

\[
T_A,T_B,T_C,\ldots
\]

可以分别存在，而没有一个 global terminal subject。

来源：

- Imants Baruss (2019), “Categorical Modelling of Conscious States”, *CONSCIOUSNESS: Ideas and Research for the Twenty-First Century* 7(7).

## 4. Sheaf / global-section work

近期有多种工作用 sheaf / global sections formalize phenomenal integration：compatible local sections glue into a unique global section。

它们展示：

\[
\boxed{\text{many local phenomenal descriptions}\to\text{one coherent global state}}
\]

但 global section 本身为所有 points / contexts 同时赋值，不选择一个 distinguished point。

因此：

\[
\boxed{\text{one global section}\not\Rightarrow\text{one absolute standpoint}}
\]

用途更接近：

- unity；
- binding；
- totalization；
- one-world coherence。

---

## 5. Universal properties are only as meaningful as the category

一个 terminal / initial / limit / colimit role 的解释内容依赖：

\[
\mathbf C
\]

的 objects 与 morphisms 如何解释。

因此不能仅说：

\[
E^*\text{ is terminal}
\]

就获得哲学进展。

必须独立说明：

1. 为什么这些 objects 是 relevant candidates；
2. morphisms 表达什么 real relation；
3. category 为什么是 global，而非 per-subject；
4. universal role 为什么具有 first-person actuality meaning。

否则 universal property 只是把 selector 写成更漂亮的数学语言。

---

## 6. Token identity issue

Category-theoretic universal constructions常给：

\[
\text{uniqueness up to isomorphism}.
\]

而本项目要求的是一个 token event：

\[
E^*=(C,p).
\]

如果 candidate category 忽略了某些 token-level relation，两事件可以 categorically isomorphic。

因此 universal-property model 还必须通过：

\[
\boxed{\text{Token Adequacy Requirement}}
\]

即 category 的 structure 足够丰富，使 universal object 对 metaphysical token identity 的精度与理论目标一致。

---

## 7. 当前判断

Category theory 给出了目前最漂亮的 **形式方法**，尤其适合：

- naturality；
- invariance；
- global compatibility；
- universal relational roles；
- fixed-point / limit / terminality tests。

但它不会自动生成 metaphysical significance。

当前项目最值得追的 categorical target 是：

\[
\boxed{\text{a natural, global, manifestation-relevant universal construction}}
\]

它必须避免：

- per-subject replication；
- cosmic subject / content explosion；
- purely formal privilege；
- token-indeterminacy。
