# Collapse, Becoming, and Global-Mind Routes

> 状态：2026-10-05 globalization literature map。
>
> 目标：在已经找到的 local psychophysical coactualization 之上，检查 quantum-collapse literature 是否能进一步承担 UIWO 的 time/world/global-subject dimensions。
>
> 阅读层级：Ellis–Drossel 2020 — Springer abstract + article metadata，结合其 arXiv abstract；Riggs 2024 critique — Springer full-text HTML relevant sections；Squires 1991 — Springer metadata/abstract，Monton secondary discussion / indexed excerpts 用于解释 universal-consciousness coordination，不标 primary fulltext-read；GRW-flash / collapse ontology仅作边界参考。

## 1. 起点：CDCP 已给 local physical–phenomenal coupling

已有 psychophysical coactualization route：

\[
\{(p_i,e_i)\}
\xrightarrow{L_C}
(p^*,e^*)
\]

其中 \(e_i\) 是 subject \(s\) at time \(t\) 的 possible conscious state。

所以：

\[
\boxed{
PhysicalActualization
+
ExperientialActualization
}
\]

可以由 one stochastic law jointly constrain。

现在的问题是：能否继续把 **temporal becoming / world actualization / global subject** 接进同一个 event。

---

## 2. Ellis–Drossel 2020：collapse → becoming / present boundary

Ellis 与 Drossel 的 Evolving Block Universe (EBU) 把未来视为 indefinite / not-yet-fixed，而 past 为 definite。

其 2020 *Emergence of Time* 摘要明确写：

\[
\boxed{
IndefiniteFuture
\xrightarrow{QuantumCollapse}
DefinitePast.
}
\]

EBU 的 broader proposal把 spacetime理解成向未来扩展的 block；present / becoming与 events becoming determinate 相关。

因此相对于 UIWO，EBU 提供一种重要 law-form precedent：

\[
\boxed{
CollapseActualization
\to
TemporalBecoming.
}
\]

这比 ordinary collapse theory只给 definite physical outcome更接近：

\[
Actuality+NOW
\]

joint structure。

---

## 3. Riggs 2024：collapse-defined present 的 exact failure mode

Peter J. Riggs 2024 对 Ellis–Drossel EBU 做 focused critique。

其 reconstruction 更明确：EBU 把 present moment理解为 indefinite / non-existent future becoming actualized，且把这种 actualization归因于 wave-function collapse。

但 Riggs 指出至少两个对本项目直接相关的困难。

### 3.1 Locality problem

collapse发生在 local physical contexts 时，最多自然得到：

\[
LocalPresent_i.
\]

并没有自动得到：

\[
\exists!T^*\;GlobalNOW(T^*).
\]

所以：

\[
\boxed{
LocalActualization
\not\Rightarrow
GlobalPresent.
}
\]

### 3.2 Uniqueness / synchronization problem

如果不同 local collapses不形成一个 unique global boundary，就不能从 quantum actualization直接推出 global passage。

这与 self 项目此前的 local→global gap 完全同构。

因此 EBU 是 valuable positive prototype，同时也是 clean warning：

\[
\boxed{
Collapse\text{-}Becoming
\text{ does not automatically supply one global NOW}.}
\]

---

## 4. GRW / flash ontology：actual-history content without privileged NOW

objective-collapse theories如 GRW 可以产生 stochastic actual events / flashes，并给一个 determinate actual history ontology。

这有助于：

\[
\boxed{\text{many possible histories}\to\text{one realized history}}
\]

的 law-form。

但 relativistic GRW flash approaches尤其提醒：one actual distribution of flashes并不等于 one globally privileged simultaneity slice。

所以：

\[
\boxed{
OneActualCollapseHistory
\not\Rightarrow
OneObjectiveNOW.
}
\]

这会约束任何想用 collapse同时解决 world actuality + NOW 的 UIWO 版本。

---

## 5. Squires 1991：universal consciousness as global coordination option

Squires 的 *One mind or many* 直接把 Everett-style observer problem表述成一个 fork：

\[
ManyMinds
\quad|\quad
OneUniversalConsciousness.
\]

Springer abstract明确说，他比较无限多个 conscious minds associated with brains 与 one universal consciousness 两种方案。

后续 secondary discussion通常把 Squires route理解为：universal consciousness协调 individual minds / preferred branch，使不同 observers的 experienced outcomes保持 quantum correlations。

对本项目最安全的抽象是：

\[
\boxed{
UniversalMind
\to
GlobalObserverCoordination.
}
\]

它提供一个比 ordinary per-observer single-mind更 global 的 mental coordination template。

### 但它不提供 local absolute-I

即使有：

\[
\exists!M\;UniversalMind(M),
\]

仍可能有许多 local person-level viewpoints / parts / manifestations。

所以：

\[
\boxed{
UniversalMind
\not\Rightarrow
UniquePrivilegedLocalPerson.
}
\]

这与我们已有 LOC / Localization Reappearance Result一致。

## 6. Three-domain near-Opening

把 literature prototypes放在一起：

### Psychophysical collapse

\[
CollapseEvent
\to
PhysicalOutcome+ConsciousOutcome.
\]

### EBU becoming

\[
CollapseEvent
\to
Actualization/Becoming.
\]

### Universal-mind coordination

\[
GlobalMentalStructure
\to
CrossObserverCoordination.
\]

于是可以构造一个 project-level intersection：

\[
\boxed{
CollapseEvent(C)
\Rightarrow
PhysicalActuality(p)
+ExperientialActuality(e,s)
+TemporalBecoming(t).
}
\]

这第一次让 UIWO 的三个 coordinates中的两类 half-plus：

- outcome/world-like actuality；
- time / becoming；
- subject-at-time experience；

进入同一个 causal / nomological neighborhood。

---

## 7. Why this still falls short of UIWO

### Gap W — event/history vs world actuality

\[
OneDefiniteCollapseHistory
\not\Rightarrow
MetaphysicalActualWorldPrivilege.
\]

actual history ontology与 modal actuality仍需解释关系。

### Gap T — becoming vs one objective NOW

\[
CollapseDrivenBecoming
\not\Rightarrow
UniqueGlobalNOW.
\]

Riggs pressure直接命中这一点。

### Gap S — conscious bearer vs absolute-I

\[
ConsciousOutcome(s,t)
\not\Rightarrow
AbsoluteI(s).
\]

多个 observers都可以获得 definite states；universal mind也可通过 many local viewpoints表现。

### Gap U — same law vs stitched theories

目前三块来自不同 theories / programs。

因此：

\[
\boxed{
LiteratureIntersection
\not\Rightarrow
OneUnifiedOpeningLaw.
}
\]

---

## 8. Current verdict

这轮的真正 advance 是：

\[
\boxed{
\text{collapse / becoming / consciousness literature contains all three local ingredients needed for a non-factorized Opening architecture}.}
\]

但没有一个 established theory把它们组合成：

\[
\exists!\langle w,t,s\rangle O(w,t,s).
\]

尤其 exact bottleneck 已变成：

\[
\boxed{
\text{Global synchronization + local privilege rank}.}
\]

所以这条路线值得继续，但应定位为 **near-Opening architecture**, 不是 evidence that absolute-I exists。
