# Whitehead — Vacuous Actuality, Subjective Immediacy, and the Arity–Singularity Gap

> 阅读状态：**primary-text excerpt-read + reference/secondary cross-check**。已核对 *Process and Reality* 中 `vacuous actuality`、`subject-superject`、reformed subjectivist principle 的关键段落，并以 SEP、Whitehead Encyclopedia、Process Studies 二级文献交叉检查；尚不标记为 fulltext-read。
>
> 项目用途：这是目前对 `Thin Actuality` 最直接的成熟 metaphysical alternative。Whitehead 不只把 experience 加进世界，而是明确拒绝一种“真实却完全没有 subjective immediacy”的 actuality。

## 1. 核心 target：vacuous actuality

Whitehead 把下面的 conception 称为 **vacuous actuality**：

\[
VacuousActuality(x)
:=
Actual(x)\land\neg SubjectiveImmediacy(x).
\]

在 *Process and Reality* 的 categoreal scheme 中，他把这种 conception 描述成：

> `res vera devoid of subjective immediacy`

并说对它的 repudiation 是 philosophy of organism 的 fundamental commitment。

因此，Whitehead 和当前 `self` 中 Bricker / Soames / Adams 所代表的 thin actuality 发生的是正面冲突：

\[
\boxed{
Actuality\text{ without any interior / experiential pole}
}
\]

在 Whitehead framework 中不是 metaphysically ultimate actuality。

这比 Hegel-style `Wirklichkeit = self-manifestation` 更容易和 analytic metaphysics 对接，因为 Whitehead直接使用 `actual entity`、`actuality`、causation、relativity、experience 等术语来构造 ontology。

---

## 2. Actual entity = subject-superject

Whitehead 的 actual entity 不是 enduring substance，也不是 bare fact-token。

其完整结构至少有两面：

\[
ActualEntity
=
Subject\text{-}Superject.
\]

作为 `subject`，actual entity 是一个正在 concresce / self-form 的 experiential process；作为 `superject`，它已经完成并作为 datum / causal ingredient 进入后续 actualities。

因此 subjectivity 不是一个在完成 actuality 之后附加的 accidental layer。

可压缩成：

\[
\boxed{
ActualEntity(x)
\Rightarrow
HasSubjectivePhase(x).
}
\]

这正是当前 B1+B2 所需要的一种 positive realization：

\[
Actuality
\to
Interiority/Experience
\to
Subjectivity.
\]

需要注意：Whitehead 的 `experience` 很宽，不等于 reflective human consciousness。panexperientialism 允许低级 actual occasions 有 experience / prehension，却没有 human-level consciousness。

所以不能把该结果写成：

\[
Actuality\Rightarrow HumanConsciousness.
\]

---

## 3. Reformed subjectivist principle

Whitehead 的 strongest formulation 不是普通 idealist slogan `to be is to be perceived`。

相关结构由几个原则联动：

### 3.1 Principle of relativity

一个 actual being 的 nature 包含它作为 potential datum 进入新的 becoming。

粗略：

\[
Being(x)
\Rightarrow
PotentialForBecoming(x,y).
\]

### 3.2 Objectification / prehension

一个过去 actual entity 对新 actual entity 的 causal relevance，被理解成前者在后者经验中的 objectification / prehension。

所以 causal passage 不只是 externally juxtaposed facts：

\[
CausalRelevance(x,y)
\Rightarrow
PrehendedBy(y,x).
\]

### 3.3 Reformed subjectivist result

Whitehead 最强的总结是：reality 的 primary togetherness 是 togetherness in experience；actual entities 的 causal / relational integration最终落在 subjects 的 prehensions 上。

于是：

\[
\boxed{
NoVacuousActuality:
Actual(x)\Rightarrow SomeSubjectiveImmediacy(x).
}
\]

或者更 Whiteheadian：actuality 在其 concrete complete form 中已经包含 experiential togetherness。

---

## 4. 这是不是从 `actuality` 概念推出的 theorem？

当前裁决：**不是。**

Whitehead 给的是一套 substantive metaphysical reconstruction，而不是仅凭 ordinary concept `actual` 做分析真理证明。

其拒绝 vacuous actuality 依赖：

- 对 substance-quality ontology 的批评；
- reformed subjectivist principle；
- principle of relativity；
- causal efficacy / objectification 的 process interpretation；
- 从 concrete experience 向 metaphysical categories 的 generalization。

所以不能写成：

\[
Meaning(Actual)\vdash Subjectivity.
\]

更准确：

\[
WhiteheadPackage
\vdash
\neg VacuousActuality.
\]

因此 Bricker / Soames 仍可以拒绝 Whitehead 的 package，并坚持：

\[
Actuality\land\neg Subjectivity
\]

coherent。

但和此前不同，现在 `Thin Actuality` 有了一个真正成熟的正面 rival，而不只是 Hegelian / phenomenological pressure。

---

## 5. 对 B1 的真正贡献

此前 B1 写作：

\[
Actuality\Rightarrow SelfManifestation.
\]

Whitehead提示应把它拆成一个稍弱、也更可辩护的版本：

\[
\boxed{
B1_W:\quad ConcreteActuality\Rightarrow SubjectiveImmediacy/ExperientialInteriority.
}
\]

这不要求 actuality 是一个 global self-conscious subject，也不要求 Hegelian absolute self-manifestation。

因此新的正方策略可以绕开一个过强前提：

\[
Actuality\Rightarrow SelfManifestation
\]

先争：

\[
Actuality\Rightarrow NonVacuousInteriority.
\]

如果 `B1_W` 能独立获胜，再研究这种 interiority 是否足以进入 first-person arity。

这比直接从 actuality 跳到 self-conscious manifestation 更有希望。

---

## 6. 但 Whitehead 同时给出新的反限制：Arity ≠ Singularity

Whitehead ontology 是 pluralist。

世界由许多 actual occasions 构成；每个 actual occasion 都有自己的 subjective immediacy / prehensive perspective。

所以即使接受：

\[
\forall x\,[ActualEntity(x)\Rightarrow Subjective(x)],
\]

也完全不推出：

\[
\exists!s\;GlobalSubject(s).
\]

反而 Whitehead 提供一个明确 countermodel：

\[
\boxed{
SubjectBearingActuality
+
PluralActualSubjects
+
NoSingleGlobalHumanLocus.
}
\]

这产生新的 **Arity–Singularity Gap**：

\[
\boxed{
ActualityHasSubjectiveArity
\not\Rightarrow
ActualityHasOneGlobalSubjectPole.
}
\]

这与 Lipman / Eker 的 obtaining-pluralism 从不同方向收敛：

- Lipman/Eker：perspectival obtaining 可以 pluralize；
- Whitehead：actuality 本身就算内含 subjectivity，也可以 pluralize。

因此任何 strong AAP 都必须再增加一个 singularity bridge。

---

## 7. 对当前 AAP 的重写

原强式：

\[
AAP:\quad CompleteActuality(R)\Rightarrow\exists!s\;SubjectArity(R,s).
\]

现在应拆成：

### WAAP — Weak Actuality-Arity Principle

\[
\boxed{
CompleteActuality(R)
\Rightarrow
SubjectiveArity(R).
}
\]

Whitehead 给 WAAP 一个严肃 metaphysical implementation。

### SAP — Singularity Principle

\[
\boxed{
SubjectiveArity(R)
\Rightarrow
\exists!s\;GlobalSubjectPole(R,s).
}
\]

Whitehead 本身反而是 SAP 的 countermodel candidate。

### LOC — Localization Principle

\[
\boxed{
\exists!s\;GlobalSubjectPole(R,s)
\Rightarrow
\exists!E^*\;LocalAbsoluteLocus(E^*,s).
}
\]

这一步仍然没有 Whiteheadian support。

于是项目真正的 positive chain 现在变成：

\[
\boxed{
Actuality
\xrightarrow{WAAP}
SubjectiveArity
\xrightarrow{SAP}
OneGlobalSubject
\xrightarrow{LOC}
OneLocalAbsoluteLocus.
}
\]

比旧四桥结构更干净。

---

## 8. 对 CC1 / CC2 / CC3 的影响

### CC1

Whitehead 提供一个新的 candidate witness：

\[
X=NonVacuousSubjectiveImmediacy.
\]

若能证明 thin actuality 缺失该结构，则 Neutral Completion 不再 complete。

当前尚未证明。

### CC2

Whitehead 最接近 CC2 的攻击是：`vacuous actuality` 来自对 abstraction 的误用，而 concrete actuality 必须 experiential / relational。

但这仍是 package-level critique，不是 neutral actuality contradiction theorem。

所以 CC2 仍未成功。

### CC3

如果 subjective immediacy 被证明是 actuality 的 common job，那么 centered/subject-bearing actuality第一次可能获得 genuine replacement work。

但 Whitehead 同时说明：这个 payoff 只支持 **subject-bearing actuality**，没有免费支持 **one absolute subject**。

因此 CC3 即使在 WAAP 层获益，也必须另外支付 SAP/LOC 的结构成本。

---

## 9. 当前价值

Whitehead 是目前找到的最重要的新 B1 资源，因为他直接把项目正在争论的 neutral option 命名成 `vacuous actuality`，并建立一整套 non-vacuous actuality ontology。

但他同时阻止我们过早庆祝：

\[
\boxed{
NoVacuousActuality
\not\Rightarrow
OneAbsoluteFirstPerson.
}
\]

因此研究 frontier 从：

\[
Thin\ Actuality
\quad vs\quad
SelfManifesting\ Actuality
\]

进一步精炼为：

\[
\boxed{
Vacuous\ Actuality
\quad vs\quad
SubjectBearing\ Actuality
}
\]

之后再独立处理：

\[
\boxed{
Plural\ Subjectivity
\quad vs\quad
Singular\ Global\ Subjectivity.
}
\]
