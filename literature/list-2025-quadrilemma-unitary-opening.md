# Christian List 2025 — Quadrilemma and the Unitary-Opening Consequence

> 状态：2026-10-05 focused literature audit。
>
> 核心来源：Christian List, “A Quadrilemma for Theories of Consciousness”, *The Philosophical Quarterly* 75(3), 2025, 1026–1048, DOI `10.1093/pq/pqae053`。publisher full-text HTML core argument read。
>
> 目标：检验 List 的 consciousness quadrilemma 对本项目 `ordinary FP != absolute FP`、Non-Solipsism、One World、Non-Fragmentation 与 exactly-one Opening 的含义。

## 1. List 的四个命题

List 定义：

### FPR — First-Person Realism

\[
\forall S\,[Conscious(S)\to \exists F\,FirstPersonalFact(F,S)].
\]

即每个 conscious subject 都有 genuine first-person facts。

### NS — Non-Solipsism

\[
\exists S_i\neq S_j\,[Conscious(S_i)\land Conscious(S_j)].
\]

### NF — Non-Fragmentation

一个 world 中全部 obtaining facts 必须 compossible：

\[
\forall F,G\in Facts(w),\quad Compossible(F,G).
\]

### OW — One World

\[
\exists!w\;RealityWorld(w).
\]

List 的 quadrilemma：

\[
\boxed{FPR+NS+NF+OW\text{ mutually inconsistent}.}
\]

任取三个可以，四个不能同时成立。

---

## 2. 真正驱动结果的是 First-Person Non-Compossibility

List 的核心 lemma 比 quadrilemma 本身更重要。

设两个不同主体分别处于 mutually exclusive complete conscious states `X` 与 `Y`。

对应 genuine first-person facts：

\[
F_X=\text{I am in }X,
\]

\[
F_Y=\text{I am in }Y.
\]

List 强调：第三人称 facts：

\[
S_X\text{ is in }X,
\qquad
S_Y\text{ is in }Y
\]

完全 compossible。

但 genuine first-person facts `F_X` / `F_Y` 不能从同一 perspective 共同 obtain，因此：

\[
\boxed{DistinctIrreducibleFPFacts\Rightarrow NonCompossibility.}
\]

这正是 fragmentalism / many-centred-worlds pressure 的来源。

---

## 3. List 对普通 FP realism 的要求很强

List 不把第一人称语言、first-person data、indexical mode of presentation 自动当作 irreducible first-person fact。

他明确指出，一个理论可以保留：

- phenomenal consciousness；
- first-person representation / data；
- special cognitive access；
- genuine other minds；

同时拒绝：

\[
\forall S\;IrreducibleFPFact(S).
\]

主流 one-world / non-fragmented theories通常正走这条路：first-person/third-person difference主要在 representation / access 层，而非额外 fact 层。

因此：

\[
\boxed{Consciousness+LocalFPOrganization\not\Rightarrow List\text{-}FPR.}
\]

这与本项目长期区分完全吻合：

\[
OrdinaryFP\neq AbsoluteFP.
\]

---

## 4. Two-Tier Escape

本项目无需接受 List 的 universal FPR。

可保留：

\[
\forall i\;Conscious(S_i),
\]

以及：

\[
\forall i\;LocalFirstPersonOrganization(S_i),
\]

但只对一个 opening stage / locus承认 irreducible simpliciter first-person fact：

\[
\exists!\sigma^*\;AbsoluteFPFact(\sigma^*).
\]

其他主体的：

- phenomenal states；
- self-models；
- first-person representations；
- de se beliefs；

仍全部真实，只是不全部提升为 mutually non-compossible simpliciter FP facts。

于是理论明确拒绝：

\[
FPR_{universal}.
\]

但保持：

\[
NS+NF+OW.
\]

这不是 solipsism：他人的 consciousness 仍真实。

因此 List quadrilemma 与项目并不冲突；它反而给 **Two-Tier First-Person Architecture** 一个非常精确的逻辑位置。

---

## 5. Reversing the lemma: Unitary Singularity

List 的 non-compossibility lemma 可以反过来使用。

若 theory 独立坚持：

\[
NF+OW,
\]

那么一个 complete world 中不能同时包含两个 distinct irreducible simpliciter first-person openings：

\[
NF+OW+NonCompossibility(F_i,F_j)
\Rightarrow
\neg(F_i\land F_j).
\]

所以：

\[
\boxed{NF+OW\Rightarrow AtMostOne\ Irreducible\ FP\ Opening}
\]

条件是 candidate openings确实属于 List 意义上的 genuine first-person facts，而不是第三人称事实中嵌入 first-person quotation。

若另有独立 `AtLeastOne`：

\[
\exists \sigma\;AbsoluteFPFact(\sigma),
\]

则：

\[
\boxed{
OW+NF+AtLeastOneAbsoluteFP
\Rightarrow
ExactlyOneAbsoluteFP.
}
\]

这称为 **Unitary Singularity Lemma (USL)**。

---

## 6. USL 解决什么

它第一次让：

\[
\text{why exactly one?}
\]

不必完全作为独立 primitive multiplicity condition。

此前 selective Opening通常直接写：

\[
\exists!\sigma\;Open(\sigma).
\]

USL 把它拆成：

\[
\underbrace{\exists\sigma\;Open(\sigma)}_{AtLeastOne}
+
\underbrace{OW+NF+FPNonCompossibility}_{AtMostOne}.
\]

因此 uniqueness burden 从：

\[
ExactlyOne\quad\text{primitive}
\]

降为：

\[
AtLeastOne\quad+\quad UnitaryReality.
\]

这是 substantive progress。

---

## 7. 它不解决什么

### 7.1 At-least-one 仍未免费获得

USL 不推出：

\[
\exists\sigma\;AbsoluteFPFact(\sigma).
\]

该前提仍需要：

- Hare/Conitzer-style `presence simpliciter`；
- Nagai Opening；
- nomological Opening；
- 其他 actuality-sensitive witness。

### 7.2 Universal-I 仍是 live rival

USL 排除的是多个 **distinct irreducible FP centers** 在 one coherent world 中并存。

它不排除：

\[
\exists!I_U\;\forall e\;ExperienceOf(e,I_U).
\]

Universal-I 可说所有 local experiential streams 最终属于 one first-person center，因此不产生 List 式 many-center non-compossibility。

所以 unitary one-world first-person theory space 被压缩为：

\[
\boxed{
SelectiveOpening
\quad|\quad
UniversalI
}
\]

而非直接证明 SelectiveOpening。

### 7.3 Dynamic path 仍独立

USL 最自然地作用于一个 complete actuality index / current stage：at most one currently absolute opening。

它不自动给：

\[
\sigma_t\to\sigma_{t+1}
\]

的 persistence / continuation law。

因此 PSP 与 stochastic-grounding path 仍独立。

---

## 8. Fragmentalism 的代价因此更精确

List 明确指出，保留 universal FPR + non-solipsism + one world 时，就必须拒绝 NF；这会要求对 metaphysics、logic、scientific modelling 中标准 world 概念做显著 revision。

Merlo 2023 又显示 unstructured fragmentalism 面对 Tensed Belief Explosion；Lipman 2026 的成熟修复需要：

- internal / external logical structure；
- new connectives；
- standpoint-switching inference；
- immersive thought；
- target semantics。

所以 fragmentalism仍 coherent-looking，但其成本可以明确写成：

\[
\boxed{
PluralIrreducibleCenters
\Rightarrow
FragmentationMachinery\;or\;ManyWorlds.
}
\]

Opening Monism 若只保留 one irreducible absolute center，则可避免这部分 machinery，同时不删除其他 conscious minds。

---

## 9. Current project verdict

List 2025 对项目最重要的意义不是“fragmentalism wins/loses”，而是：

\[
\boxed{
OneWorld+NonFragmentation
\text{ can function as an at-most-one principle for irreducible FP actuality}.}
\]

因此 Two-Tier architecture 获得一个新的正方结构：

\[
\boxed{
OrdinaryConsciousPlurality
+
OneWorld
+
NonFragmentation
+
AtLeastOneAbsoluteFP
\Rightarrow
ExactlyOneAbsoluteFP.
}
\]

这是目前最强的 **singularity derivation** 候选之一。
