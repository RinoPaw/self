# Relativistic Collapse, Becoming, and Global-NOW Pressure

> 状态：2026-10-05 focused literature note。
>
> 目标：检验 objective collapse / flash ontology 能否从 local actualization 推出 one objective global NOW，以及 relativity 对这种推断施加什么 exact cost。
>
> 阅读层级：Tumulka 2006/2020 — arXiv/publisher metadata + abstract; Esfeld–Gisin 2014 — publisher/PhilPapers metadata + indexed full-text excerpt; Riggs 2024 — Springer full-text HTML relevant sections; Callender 2017 — abstract/metadata。

## 1. Tumulka rGRWf：collapse 不需要 preferred slicing

Tumulka 的 relativistic GRW flash theory把 primitive ontology写成 spacetime中的随机 flashes：

\[
F=\{f_1,f_2,\ldots\}.
\]

其重要目标是保持 relativistic covariance，同时：

- 不使用 preferred slicing；
- 不加入 spacelike-separated points 的额外 synchronization；
- 以 stochastic law给 flash distribution。

所以存在一个 serious collapse model满足：

\[
\boxed{
ObjectiveCollapseEvents
+\neg PreferredGlobalFoliation.
}
\]

这直接阻止：

\[
Collapse\Rightarrow GlobalNOW
\]

作为一般 theorem。

---

## 2. Esfeld–Gisin：若要求 genuine becoming，foliation pressure 回来

Esfeld 与 Gisin 对 rGRWf 的 philosophical reading提出关键压力。

如果只考虑整个 spacetime flash distribution：

\[
F_{4D},
\]

可以把理论理解成 Lorentz-compatible block-like ontology。

但如果还要求一个 genuine temporal-development fact：

\[
\text{initial flashes genuinely develop into one actual later distribution},
\]

那么 spacelike separated flashes之间的 nonlocal dependency 使“什么先成为实际、什么后成为实际”难以 Lorentz-invariant 地定义。

其 pressure 可抽象：

\[
\boxed{
GenuineOrderedBecoming
\Rightarrow
PreferredFoliationPressure.
}
\]

所以出现：

\[
\boxed{
LorentzCovariantWholeHistory
\quad|\quad
PrivilegedFoliationBecoming.
}
\]

---

## 3. This is a metaphysical fork, not a settled no-go

Tumulka 会强调 rGRWf 的 law / distributions本身可以 relativistic而无需 preferred slicing。

Esfeld–Gisin 的 claim更针对：

\[
\boxed{\text{becoming / temporal development interpretation}}
\]

而非否认 relativistic stochastic flash distribution存在。

所以项目不能写：

> relativistic collapse impossible.

更准确是：

\[
\boxed{
RelativisticCollapse
\not\Rightarrow
RelativisticGlobalBecoming.
}
\]

若把 global NOW 加进去，会引入额外 metaphysical structure。

---

## 4. Riggs 2024 gives an independent local/global pressure

Riggs 对 Ellis–Drossel EBU的批评从另一侧抵达同一边界：wave-function collapse即使可被理解成 events becoming actualized，也很容易只得到 local present / local becoming。

所以：

\[
\boxed{
ManyLocalActualizations
\not\Rightarrow
OneGlobalPresent.
}
\]

这与 relativistic flash fork独立汇合。

---

## 5. TSP — Temporal Synchronization Principle

项目现在可以明确写出缺失原则：

\[
\boxed{
TSP:\quad
LocalActualizationEvents(R)
\Rightarrow
\exists!T^*\;GlobalNOW(T^*).
}
\]

collapse literature没有免费提供 TSP。

至少三种路线：

### T0 — No global NOW

保留 relativistic/local/block-like actual history。

### T1 — Preferred foliation

加入：

\[
\mathcal F^*=\{\Sigma_t\}
\]

使 collapse/becoming按 privileged slices排序。

### T2 — Relational / local becoming

只定义 worldline / causal-local becoming，不产生 universe-wide NOW。

只有 T1 直接接近 UIWO 的 `Present(t*)`，但付出 preferred temporal structure cost。

---

## 6. Why cosmological time does not automatically solve it

FLRW-like cosmology可在高度对称背景中给 natural cosmic-time foliation。

但：

\[
\boxed{
NaturalPhysicalFoliation
\not\Rightarrow
MetaphysicallyPrivilegedNOW.
}
\]

即使有 preferred/canonical foliation，还需从：

\[
\text{foliation structure}
\]

到：

\[
\text{one slice is NOW simpliciter}
\]

的 privilege bridge。

这与项目一般的：

\[
Uniqueness/Structure\not\Rightarrow Privilege
\]

纪律完全一致。

---

## 7. Implication for UIWO

Collapse-Opening Synthesis希望：

\[
CollapseEvent
\Rightarrow
PhysicalActuality+ExperientialActuality+TemporalActuality.
\]

relativity audit说明第三项必须拆成：

\[
LocalTemporalActualization
\]

与：

\[
GlobalNOW
\]

两层。

所以最新准确 architecture：

\[
\boxed{
Collapse
\to
LocalBecoming
\not\Rightarrow
GlobalNOW.
}
\]

UIWO若要继续必须显式选择：

- 接受 preferred temporal structure；
- 提供新的 covariant TSP；
- 或放弃 objective global NOW，让 Opening退回 local/relational time。

---

## 8. Current verdict

TSP 不只是“还没找到文献”。relativistic collapse theory本身提供 clean counterpressure：

\[
\boxed{
ObjectiveStochasticActualization
\text{ can exist without one global synchronized present}.}
\]

因此：

\[
\boxed{Collapse\not\Rightarrow AbsoluteNOW.}
\]

若 Opening坚持：

\[
WorldActuality=NOW=AbsoluteI,
\]

它需要额外解释为何 reality具有 privileged temporal synchronization，而不能只诉诸 collapse。
