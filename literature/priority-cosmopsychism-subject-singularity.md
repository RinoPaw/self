# Priority Cosmopsychism and Subject Singularity

> 阅读状态：**publisher abstract/extract + full HTML secondary discussion**。重点核对 Schaffer priority monism、Goff constitutive cosmopsychism、Nagasawa/Wager priority cosmopsychism、Miller de-combination、Albahari aperspectival universal consciousness。未把任何未完整核对的章节标记为 fulltext-read。
>
> 项目用途：检验 `SAP`——从 subject-bearing actuality 到一个 global fundamental subject——有没有成熟 analytic route。

## 1. Target

当前：

\[
WAAP:\quad CompleteActuality(R)\Rightarrow SubjectiveArity(R)
\]

即使成立，也还需要：

\[
SAP:\quad SubjectiveArity(R)\Rightarrow\exists!s\;GlobalSubjectPole(R,s).
\]

priority cosmopsychism 是目前最成熟的 analytic singularity construction 之一。

---

## 2. Schaffer：Priority Monism 只给 one fundamental concrete object

Schaffer-style priority monism：

\[
\boxed{\exists!x\;BasicConcrete(x)\land x=Cosmos.}
\]

其核心是 whole prior to parts / cosmos grounds derivative concrete objects。

重要边界：该论题关于 **concrete-object dependence ordering**；它本身没有说：

\[
Conscious(Cosmos)
\]

更没有说：

\[
Subject(Cosmos).
\]

所以：

\[
\boxed{
OneFundamentalConcreteWhole
\not\Rightarrow
OneFundamentalSubject.
}
\]

这是 SAP 的第一条 gap。

---

## 3. Goff：最强 conditional SAP construction

Goff 的 cosmopsychism把 priority monism 与 consciousness-first thesis 结合。

粗略：

\[
PriorityMonism
+
ConsciousUltimates
\Rightarrow
ConsciousCosmos.
\]

进一步把 cosmos 理解为一个 conscious subject：

\[
\boxed{
CosmosSubject(C).
}
\]

其动机来自 Subject Irreducibility Problem：一个 conscious subject 的存在难以由完全不涉及该 subject 的更基本事实通过 analysis 得到。Goff 因而尝试用 `grounding by subsumption`：local subjects 是 conscious whole 的 aspects，而不是由 non-subjective microfacts 分析构造出来。

这使 cosmopsychism成为：

\[
\boxed{
PriorityMonism
+
SubjectIrreducibility/AntiEmergence
+
ConsciousWhole
\Rightarrow
OneFundamentalCosmicSubject.
}
\]

所以 SAP **可构造**。

但它不是从 WAAP 单独推出，因为：

- `PriorityMonism` 是额外 premise；
- `ConsciousUltimates` / conscious whole 是额外 premise；
- cosmos 是 one subject 而不是 one entity hosting plural subject-poles 仍含 subject-individuation commitment。

---

## 4. Nagasawa / Wager：priority cosmopsychism同样显式加 mental whole

priority cosmopsychism通常写成：

\[
PriorityMonism
+
CosmosPhenomenallyPropertied.
\]

这清楚说明：monism 本身不生成 mentality；需要再加 panpsychistic / phenomenal foundation。

因此不存在免费 inference：

\[
OneUltimateWhole\Rightarrow OneMind.
\]

更准确：

\[
OneUltimateWhole
+
MentalityOfWhole
\Rightarrow
CosmopsychistCandidate.
\]

---

## 5. Miller：de-combination 使 global subject 与 local subjects 的关系变成新问题

假设：

\[
CosmosSubject(C)
\]

且 ordinary humans：

\[
Subject(Alice),Subject(Bob),\ldots
\]

cosmopsychism必须解释：

\[
How\ do\ local\ subjects\ derive\ from\ /\ occur\ within\ C?
\]

Miller 把这叫 **de-combination problem**，与 panpsychist subject-summing problem 对称。

核心压力是 subject–subject proper parthood：

\[
Subject(a)\land ProperPart(a,C)\land Subject(C)
\]

并不容易获得 coherent metaphysical account。

这对 `self` 很重要：即使 SAP 成功，LOC 并没有因此变容易；反而 global subject 与 local subjects 的 relation 本身要新增一层 metaphysics。

---

## 6. Albahari：Fundamental consciousness 也不必等于 Fundamental subject

Albahari-style universal consciousness提供一个更强 countermodel：fundamental consciousness可以被理解成 **aperspectival consciousness**，不属于某一个 individual/cosmic subject。

所以即使有：

\[
FundamentalConsciousness(R),
\]

仍可能：

\[
\neg\exists s\;OwnsAsSubject(s,FundamentalConsciousness).
\]

因此还要记录：

\[
\boxed{
FundamentalConsciousness
\not\Rightarrow
FundamentalSubject.
}
\]

这使 SAP 不能偷渡“conscious = a subject's consciousness”。

---

## 7. Singularity ladder

文献现在迫使我们区分：

\[
\boxed{
OneFundamentalWhole
\to
FundamentalConsciousness
\to
FundamentalSubject
\to
OneGlobalSubject
\to
OneLocalAbsoluteLocus.
}
\]

每个箭头都需要独立 premise。

### S1 — Whole → consciousness

priority monism alone不给。

### S2 — consciousness → subject

Albahari-style aperspectival consciousness 阻止免费 inference。

### S3 — subjectivity → exactly one subject

需要 subject individuation / unity principle。

### S4 — global subject → local absolute locus

Miller de-combination 与项目 LOC gap 都说明仍然开放。

所以：

\[
\boxed{
One\ is\ not\ yet\ I.
}
\]

---

## 8. 对 SAP 的当前裁决

当前最强正方 conditional argument 可以写：

\[
PriorityMonism
+
SubjectIrreducibility
+
ConsciousWhole
+
OneSubjectPerFundamentalWhole
\Rightarrow
\exists!s_f\;FundamentalSubject(s_f).
\]

这个 argument 有成熟 literature support，但四个 premises 中至少后三个都超出 WAAP。

所以：

\[
\boxed{SAP\text{ is coherent and constructible, but not independently derived}.}
\]

并且：

\[
\boxed{
PriorityMonism\not\Rightarrow SAP.
}
\]

---

## 9. 对项目的直接意义

Whitehead route 如果未来击败 C0，只会把 default 推到：

\[
C1=PluralSubjectBearingActuality.
\]

要再进入：

\[
C2=SingularCenteredActuality,
\]

必须新增类似 cosmopsychist / absolute-idealist 的 whole-subject machinery。

因此 centered side 不可以把：

\[
RealityIsOne
\]

当作：

\[
ThereIsOneAbsoluteSubject
\]

的缩写。

新的 exact burden 是：

\[
\boxed{
Why\ is\ the\ fundamental\ whole\ itself\ one\ subject,
\ and\ why\ can\ it\ not\ contain\ irreducibly\ plural\ subject\ poles?
}
\]
