## 核心主张

Bader 的目标不是证明现实没有 asymmetry，而是区分：

\[
\text{fundamental non-symmetric relations}
\]

与

\[
\text{derivative asymmetry/order}.
\]

他主张 fundamental relations 可以全部是 symmetric，同时 derivative level 仍然拥有真实的 non-symmetric relations 与 order。

## 1. Asymmetric structure from symmetric ingredients

Bader 给出两类重要来源：

1. **asymmetric networks of symmetric relations**；
2. **asymmetric distributions of properties**。

也就是说，单个 relation 可以是 symmetric，但整个 relational pattern 仍然可以没有对应的交换对称。

形式上可以粗略表示为：

\[
R_i(x,y)\Leftrightarrow R_i(y,x)
\]

对每个 fundamental relation 都成立，但整体结构：

\[
\mathcal D=\langle X,R_1,\ldots,R_n,P_1,\ldots,P_m\rangle
\]

仍可以满足：

\[
Aut(\mathcal D)\neq Sym(X),
\]

甚至可能：

\[
Aut(\mathcal D)=\{id\}.
\]

因此“fundamental ingredients individually symmetric”不推出“whole configuration symmetric”。

## 2. Generative operations

Bader 随后指出 grounding / causation / composition 可以更适合理解为 **generative operations**，而非普通 relations。

普通 relation 预设两端 relata 已经存在；generative operation 只需要 inputs，随后产生 outputs：

\[
O:I\mapsto O(I).
\]

于是：

\[
Input\prec_O Output.
\]

这种 priority 不是因为先有两个对象再外加一根 directed arrow，而是因为 output 只有通过 operation 才出现。

Bader 用这一点解释为什么 generative operation 可以 **induce order**。

## 3. 对 self 的直接意义

`self` 的 Monism Selector Gap 要求 deeper reality `D` 内部存在一个非任意的 asymmetric organizing structure：

\[
A_D.
\]

Bader 提供两种成熟模板。

### 模板 A：configurational asymmetry

\[
D+\text{globally asymmetric pattern}\Rightarrow A_D.
\]

这条路线不需要 primitive directional relation。一个整体内部的 property distribution / symmetric-relation network 就可能唯一辨认某些位置。

这和项目原来的 automorphism criterion 完全兼容：真正重要的是完整结构的 `Aut(D)`，而非每个基本关系单独是否 symmetric。

### 模板 B：operational asymmetry

\[
D+O_{gen}\Rightarrow\text{input/output order}.
\]

这里 asymmetry 来自 generation 本身。

它与当前 fundamental-process / becoming 路线高度相邻，也给 grounding-as-priority 一个更具体的解释框架。

## 4. 不能过度推出

Bader 的理论并不会自动给本项目一个 absolute center。

即使：

\[
O(D)\Rightarrow E_1,E_2,\ldots,E_n,
\]

生成顺序是真实的，也仍可能有：

\[
E_1\sim_O E_2
\]

或者多个 conscious outputs 同等级出现。

因此：

\[
\boxed{\text{generated asymmetry}\not\Rightarrow\text{unique conscious center}}
\]

更不直接推出：

\[
LIVE(E^*).
\]

## 5. 对当前研究结构的推进

Bader 让 Stage 0B 可以从一个模糊要求：

> deeper reality 必须“有某种非对称”。

升级成两个可检验分支：

\[
\boxed{A_D^{config}}
\]

整体配置自身破坏候选中心交换对称；

以及：

\[
\boxed{A_D^{gen}}
\]

真实 generative operation 产生 input/output priority。

接下来需要逐一检查：

- 哪一种能唯一固定 conscious event；
- 哪一种只是提供一般方向；
- 哪一种能跨过 Privilege Bridge；
- 哪一种在相对论 / gauge / representation changes 下仍然不变。
