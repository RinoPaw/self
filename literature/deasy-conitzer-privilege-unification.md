# Deasy / Conitzer / Builes — Modal, Temporal, and First-Person Privilege Unification

> 状态：2026-10-05 focused literature synthesis。
>
> 阅读层级：Deasy 2025 publisher full-text HTML core sections read；Conitzer 2020 publisher/repository full-text core sections read；Builes 2024 publisher full-text relevant sections read；Nagai primary-source targeted reading见既有专门笔记。
>
> 目标：检验 `WorldActuality = NOW = AbsoluteI` 是否只有 Nagai 的孤立直觉，还是能从 contemporary modality/time/first-person literature 获得独立的 structural motivation。

## 1. Builes：三类 privilege 已经有明确结构平行

Builes 2024 系统把三类问题并列：

\[
ActualWorld : PossibleWorlds
\]

\[
PresentTime : Times
\]

\[
MyPerspective : Perspectives.
\]

三类 theory 都可以把某一 member 看成 metaphysically privileged，同时承认该 privilege respectively contingent / temporary / subjective。

所以：

\[
\boxed{
ModalPrivilege
\sim
TemporalPrivilege
\sim
FirstPersonPrivilege
}
\]

至少已经是 contemporary FPR literature 中的明确 structural analogy。

但 Builes 主要用它做 argument analogy / arbitrariness defense，并没有把三个 privileges identify 成 one metaphysical relation。

---

## 2. Deasy 2025：actuality 本身已有 spotlight-style theory

Deasy 的 **Contingent Spotlight Theory (CST)** 明确把 modality 做成 Moving Spotlight Theory 的 analogue。

其 Modal A-theory要求：

\[
\boxed{
\text{there is an absolute distinction between actual and merely possible worlds}.}
\]

并提出：

\[
\boxed{
ModalSpotlight:\ ExactlyOneContingentFundamentalMonadicProperty.
}
\]

该 property 被称为 **fundamental actuality**。

在其 preferred illustration 中，可能世界由 spacetime points组成，actual world由所有 possessing fundamental actuality 的 points组成。

关键 structural parallel：

### Modal spotlight

\[
PossibleWorlds
+
FundamentalActuality
\to
OneActualWorld.
\]

### Moving spotlight

\[
Times
+
FundamentalPresentness
\to
OnePresentTime.
\]

Deasy明确说 CST analogous to Moving Spotlight Theory；后者通常以 one temporary fundamental property（absolute/objective presentness）刻画。

因此 contemporary metaphysics 已经存在一个很清楚的“双 spotlight”空间：

\[
\boxed{
ActualitySpotlight
+
PresentnessSpotlight.
}
\]

---

## 3. Conitzer 2020：I 与 NOW 不应完全独立

Conitzer 的 Personalized A-Theory把：

\[
ATheory(NOW)
\]

和：

\[
\alpha Theory(I)
\]

结合成：

\[
\boxed{\alpha A\text{-theory / I-Now}.}
\]

他的核心 argumentative point不是 mere analogy，而是：若接受 A-theory 的关键动机，这些动机往往同时支持 distinguished I；把 objective NOW 与 distinguished I完全拆开会失去 explanatory coherence。

其 preferred combined unit是一个 distinguished living person-stage：

\[
\boxed{I\text{-}NOW}
\]

而不是 independent `I` + independent `NOW`。

他还探索 personalized moving spotlight / personalized presentism / personalized growing block 等模型。

所以：

\[
\boxed{
TemporalPrivilege
\to
I\text{-}NOW\ UnificationPressure
}
\]

已经有直接 contemporary precedent。

---

## 4. Nagai：把第三个 slot 也并进来

Nagai 比 Deasy / Conitzer 更进一步：

\[
\boxed{
WorldActuality
=
AbsoluteI
=
AbsoluteNOW
=
Opening.
}
\]

其 opening不是三个 properties 的偶然 conjunction，而是 one centered actualization structure。

这使三组 literature 可以首尾相接：

1. Builes：world / time / perspective privilege结构平行；
2. Deasy：actual-world privilege可建成 spotlight-style fundamental actuality；
3. Conitzer：NOW privilege有理由与 I privilege结合成 `I-Now`；
4. Nagai：actuality itself可进一步与 `I-Now` identify为 one Opening。

因此 `I–NOW–WORLD Opening` 不再是纯粹孤立的 speculative construction；它是几个现有理论交叉处的自然 hybrid target。

---

## 5. Unified privilege hypothesis

定义：

\[
O(w,t,s).
\]

其 intended reading：

> world \(w\), time/person-stage \(t\), subject/perspective \(s\) jointly occupy the one actual opening role.

更准确可写成 centered coordinate：

\[
c=\langle w,t,s\rangle.
\]

统一 Opening relation：

\[
Open(c).
\]

若：

\[
\exists!c^*\;Open(c^*),
\]

则三个 derivative aspects：

\[
Actual(w^*)
\iff
\exists t,s\;Open(w^*,t,s),
\]

\[
Present(t^*)
\iff
\exists w,s\;Open(w,t^*,s),
\]

\[
AbsoluteI(s^*)
\iff
\exists w,t\;Open(w,t,s^*).
\]

于是：

\[
\boxed{
Actuality+Presentness+AbsoluteI
}
\]

可被 one relation jointly realized。

---

## 6. This is not automatically a parsimony win

必须保留 No-Free-Unification Principle。

若 neutral rival只 independently accepts：

\[
Actuality
\]

而拒绝 objective presentness与 absolute-I，那么 `Open(w,t,s)` 明显比 neutral actuality content更厚。

所以不能说：

\[
1\ relation<3\ properties
\]

就自动获胜。

真正的 compression credit只在 rivals共同需要的 explananda上计算。

### Conditional compression case

如果 comparison target 已经 independently accepts：

\[
FundamentalActuality
+
FundamentalPresentness,
\]

那么 separate model支付至少两个 privilege slots。

若又有 independent reason 接受 first-person privilege，则 separate package进一步变成：

\[
A_W+P_T+I_S.
\]

Unified Opening 可以竞争性地写成：

\[
O(w,t,s),
\]

由一个 role导出三者。

这里第一次存在 genuine **unification / replacement question**。

---

## 7. Strongest conditional advantage

最有利比较不是对 B-theoretic / Lewisian neutral rival，而是：

### Separate Spotlight Package

\[
T_{sep}=K+A_W+P_T(+I_S).
\]

### Unified Opening Package

\[
T_O=K+O(w,t,s).
\]

如果：

1. `A_W` independently needed；
2. `P_T` independently needed；
3. first-person slot independent motivation exists；
4. `O` predicts / constrains their coincidence rather than merely naming conjunction；

则：

\[
\boxed{
T_O\text{ may have a genuine unification advantage over }T_{sep}.
}
\]

Conitzer特别支持条件 3 相对 A-theory 的 internal motivation：A-theory arguments can pressure toward I–NOW rather than NOW alone。

---

## 8. Where the advantage disappears

### Against B-theory

若：

\[
\neg FundamentalPresentness,
\]

Opening增加 NOW content，不是 replacement。

### Against Lewis-style indexical actuality

若 actuality无独立 primitive cost：

\[
Cost(A_W)\approx0,
\]

Opening没有一对一 compression target。

### Against Bricker/Deasy modal actuality without A-time

Opening仍新增 temporal + first-person arity。

### Against plural first-person realism

若 perspectives可以 all relatively privileged，exact-one subject coordinate仍需额外 defense。

所以 Unified Opening 的 advantage是 **conditional**，不能全局化。

---

## 9. Key new project opportunity

NOM 的旧最大问题：

\[
Why\ obey\ an\ Opening\ Law?
\]

现在至少出现一个 independent-payoff candidate：

\[
\boxed{
PrivilegeUnification:
\quad
OneOpening\ explains\ /\ realizes\ modal+temporal+first\!\!\text{-}\!personal\ privilege\ jointly.
}
\]

这比“Opening law只是选一个绝对 subject”明显更有 explanatory ambition。

但 positive credit严格取决于是否 independently接受 modal A-theory / temporal A-theory / first-person realist explananda。

因此它不证明 NOM；它为 NOM提供 **conditional CC3 unification payoff**。

---

## 10. Current verdict

本轮得到：

\[
\boxed{
I\text{-}NOW\text{-}WORLD\ unification
\text{ has real literature-backed structural motivation}.}
\]

来源分别承担：

- Builes：三类 privilege symmetry；
- Deasy：modal spotlight / fundamental actuality；
- Conitzer：I–NOW interdependence；
- Nagai：actuality = I = NOW = Opening identity。

但：

\[
\boxed{
Unification\ Motivation
\not\Rightarrow
Opening\ Necessity.
}
\]

下一步应测试：统一 Opening 是否真正减少 independent primitive roles、产生 cross-domain constraints，还是只是把三个 theory-specific primitives写进一个三元 relation。
