## 2. First-Person Symmetry Lemma

第一篇的核心 stress test：设两个 experiential events：

\[
E_1,E_2
\]

具有完全相同 phenomenal character。

Nimmo 的 lemma 是：

\[
\boxed{
PhenProfile(E_1)=PhenProfile(E_2)
\Rightarrow
\text{phenomenal character contains no internal selector privileging }E_1\text{ over }E_2.
}
\]

正文 indexed excerpt 将其写成：若 determinate self-location

\[
I=E_1\quad rather\ than\quad E_2
\]

完全由 phenomenal character grounding，则 phenomenal profile 中必须存在一个 symmetry-breaker；perfect duplication 按设定排除了这种差异。

因此：

\[
\boxed{
\text{determinate centered individuation requires an index not carried by shared phenomenal character}.}
\]

这个结论有意保持 modest：它只规定 phenomenal character **不能独自完成什么**。

它并不回答 external index 最终应被理解成：

- ordinary spatiotemporal / causal self-location；
- token-reflexive parameter；
- centered-world coordinate；
- primitive thisness；
- absolute orientation。

所以第一篇本身不是 absolute-realism 或 anti-absolute-realism 的结论。

## 3. strengthened duplication base

第一篇摘要还给一个 strengthened version：不仅 phenomenal character 相同，而且所有 relevant uncentered publicly specifiable correlates 也相同。

第二篇把 duplicated base 写得更明确。实际检索到的正文 section 3.2 表明 base 包含：

- total phenomenal character；
- internal phenomenal organization；
- genuinely phenomenal self-representational structure；
- subject-involving structure；
- ownership / mineness-like structure，如果理论认为它 phenomenally present。

而 base 明确不把下列外部参数当作 phenomenal difference：

- bare numerical distinctness；
- spatiotemporal coordinates as such；
- purely external causal histories；
- labels；
- token-reflexive parameters not themselves carried in phenomenal profile。

这个设计很重要，因为它阻止一种廉价反驳：

> “如果体验有 mineness，那么 duplicate 就不一样。”

Nimmo 的回答是：若 mineness 是 phenomenal profile 的真实部分，就把它一起复制。

于是：

\[
\boxed{
\text{duplicating phenomenal mineness still does not create a unique internal winner}.}
\]

## 4. 三种 individuation 必须分开

第二篇明确区分：

### Token multiplicity

可以存在两个 numerically distinct realizations：

\[
E_A\neq E_B.
\]

例如两个 brain events、computational realizations 或 branches。

### Presence-individuation

更强的问题：是否还存在一个 internal fact：

\[
Mine(E_A)\land\neg Mine(E_B)
\]

使一个 duplicate 成为 uniquely mine。

### External indexing

可以从外部用：

- spacetime location；
- causal history；
- label；
- token-reflexive relation

识别某个 token。

因此：

\[
\boxed{
\text{token distinctness}
\neq
\text{internal first-person privilege}
\neq
\text{external identifiability}.}
\]

这是 Nimmo 对本项目最有用的概念拆分之一。

## 5. Relational Individuation (RI)

第二篇加入的关键 premise 是 restricted anti-haecceitism：

\[
\boxed{
RI:\quad
\text{phenomenal presence has no primitive thisness over and above its phenomenal + structural profile}.}
\]

于是如果：

\[
Profile(E_A)=Profile(E_B),
\]

RI 排除额外的 internal primitive：

\[
FurtherInternalFPFact(E_A).
\]

所以：

\[
\boxed{
RI+PerfectDuplication
\Rightarrow
\neg FurtherInternalFPFact.
}
\]

这一结论是**条件性的**。

Nimmo 没有从 duplication alone 推导 anti-haecceitism；RI 本身就是 substantive metaphysical premise。

因此一个 further-fact theorist 可以拒绝 RI，并明确 postulate：

\[
PrimitiveAsymmetry(E_A,E_B).
\]

第二篇真正完成的是把争点暴露出来：

\[
\boxed{
\text{further-fact reading requires a primitive asymmetry-maker not contained in duplicated phenomenal/structural profile}.}
\]

## 6. centered worlds 的地位

Nimmo 的重要诊断是：centered-world formalism 可以展示 uncentered description 对 self-location 的欠定，但它本身不决定这种 residual openness 的 metaphysics。

也就是说：

\[
(W,c_A),\quad(W,c_B)
\]

可以同时表示两个 compatible centers，但形式主义自身没有告诉我们：

- 是否存在一个额外 internal first-person fact；
- 是否只是 ordinary self-location；
- 是否有 primitive center-selection；
- 是否所有 centers metaphysically equal。

所以：

\[
\boxed{
\text{centered-world representation is setup, not metaphysical solution}.}
\]

这和本项目长期区分：

\[
\text{center in content}
\neq
\text{mode of obtaining}
\neq
\text{absolute orientation}
\]

非常一致。

## 7. 对 `self` 的实际影响

### 7.1 强化 Phenomenology → AbsoluteOrientation gap

Nimmo 给出一个比一般 slogan 更干净的 duplication lemma：即使 phenomenal profile 包含 subject-involvement、ownership、mineness，并在两个 tokens 中完整复制，shared profile 仍不含 unique selector。

因此：

\[
\boxed{
\text{maximal local phenomenology}
\not\Rightarrow
\text{unique centered individuation}.}
\]

这直接支持仓库已有的 local-to-global / phenomenology-to-absolute gap。

### 7.2 不能直接推出 N-W

Nimmo 的结论只排除 duplicated profile **内部**的 symmetry-breaker。

external index 可以是完全 ordinary 的，也可以是 primitive absolute asymmetry。

所以不能写成：

\[
Nimmo\Rightarrow N\text{-}W.
\]

### 7.3 对 centered actuality 的真正压力

Role-First Centered Actuality 可以完整接受 Nimmo：

- exact phenomenal duplicates 不含 internal winner；
- centered actuality 的 orientation 不由 local phenomenal profile recover；
- absolute difference 属于 complete actuality structure。

因此 Nimmo 不 refute \(\Omega\)。

但它堵死一条潜在 reduction：

\[
\boxed{
\Omega\text{ cannot be derived merely from duplicated phenomenal / mineness structure}.}
\]

若 centered theory 仍坚持 duplicate case 中有 simpliciter winner，则需要把 asymmetry 放在 profile 之外。

这正好把争点推回当前 endgame：

\[
\text{Neutral Actuality}
\quad vs\quad
\text{intrinsically Centered Actuality}.
\]

## 8. 对 CC1 / CC2 / CC3 的审计

### CC1 — independent completion witness

**没有新增 surviving witness。**

Nimmo 主要是 negative constraint：local phenomenal completeness 不会产生 unique privilege。

所以：

\[
\boxed{CC1\text{ unchanged}.}
\]

### CC2 — neutral actuality incoherence

**没有给出 neutral actuality contradiction。**

相反，RI 与 ordinary external indexing 相容，甚至让 neutral completion 更容易理解。

但由于 RI 是 substantive premise，不能把它当作 neutral theory 的 theorem。

所以：

\[
\boxed{CC2\text{ unchanged}.}
\]

### CC3 — primitive replacement advantage

Nimmo 使 centered primitive 的内容更清楚：若它做 duplicate-breaking 工作，它不是 phenomenal profile 内已有结构的简单重述。

因此它强化：

\[
\boxed{
\text{primitive centeredness carries genuine asymmetry content}.}
\]

这对 `primitive count = 1 vs 1` 的粗粒度 parity 是额外提醒，但没有单独裁决哪一种 actuality primitive 更好。

所以：

\[
\boxed{CC3\text{ sharpened, not decided}.}
\]

### Derived route

这里影响最明确：

如果某个 derived selector 声称来自 phenomenal / mineness / self-model profile，则 perfect duplication 是直接 stress test。

任何成功 candidate 必须找到 profile 外的 independently motivated asymmetry source，并继续通过：

\[
NaturalPointing
\to
IndependentDefinability
\to
PrivilegeSemantics
\to
NonPluralizability.
\]

## 9. 与 Liang 2026 的交叉关系

Liang 的 distribution-model critique 后来明确引用 Nimmo，并把 Nimmo 定位成关闭一个重要 duplication route 的局部结果。

两者组合后可以写成：

\[
\boxed{
\text{phenomenal duplication gives no internal selector}
}
\]

加：

\[
\boxed{
\text{adding a private item / assignment still requires an independently motivated grounding bridge}.}
\]

因此从 local phenomenology 到 global absolute selection 的两步 shortcut 都受阻：

1. profile 本身不破对称；
2. 外加 item / assignment 也不能靠命名自动获得 privilege semantics。

这与仓库当前 Grounded Centering Ladder 高度一致。

## 10. 当前裁决

Nimmo 2026 现在值得进入正式 literature map，主要因为：

1. 第二篇已经同行评审发表，不再只是 candidate manuscript；
2. 它对 duplicate case 的 duplicated base 与 individuation distinctions 比仓库原先 candidate note 更精确；
3. 它给 `phenomenology/mineness cannot internally select a unique center` 一个可独立引用的 contemporary argument；
4. 它没有改变 Completion Underdetermination，也没有要求修改 `synthesis/current-position.md`。

项目应采用的最窄结论是：

\[
\boxed{
\text{Perfect duplicated phenomenal/structural presence contains no non-question-begging internal route to a unique first-person winner; under RI, no further internal first-person fact remains.}
}
\]

不要把它升级成：

\[
\neg AbsoluteOrientation.
\]
