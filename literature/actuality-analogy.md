# Actuality 类比：Lewis 与 Bricker

## 目的

这条文献线提供了一个和“绝对第一人称”高度同构的成熟争论：

- 一个候选地位可以被理解成纯 indexical；
- 也可以被理解成某种 absolute / simpliciter 的形而上特权。

## Lewis：indexical actuality

Lewis 的 modal realism 让所有可能世界在存在方式上处于同等地位。

“actual”没有表示某个世界独有的额外本体属性。它类似 “here / now / I”，其指称由所在世界决定。

粗略写成：

\[
Actual_w(x)\iff x\text{ belongs to }w.
\]

所以每个世界的居民都可以从自身世界正确地称自己的世界为 actual。

这和 standpoint pluralism 的结构非常接近：

\[
\forall S_i:\quad S_i\text{ 对 }S_i\text{ 而言是 factual / here / I}.
\]

## Bricker：absolute actuality

Bricker 保留多个真实可能世界，同时拒绝把 actuality 完全相对化。

其路线允许一个世界拥有特殊的 absolute actuality；该特权不能完全翻译成“相对于该世界 actual”。

这种理论给本项目提供了一个直接先例：

\[
\text{many real candidates}+\text{one privileged simpliciter}
\]

在逻辑上是成熟形而上学可以明确表达的结构。

## 对应关系

| 模态 | 第一人称研究 |
| --- | --- |
| possible worlds | standpoints / conscious perspectives |
| actual relative to a world | first-person special relative to a standpoint |
| Lewisian indexical actuality | standpoint pluralism |
| absolute actuality | absolute liveness / absolute first-personhood |

因此，当前核心争论可以视为：

\[
\text{indexical liveness}
\quad\text{vs.}\quad
\text{absolute liveness}.
\]

## 重要限制

Bricker 的 absolute actuality 主要通过 primitive actuality 来保存特权。

本项目目前不愿在这里停止。它更希望得到：

\[
D\Rightarrow L
\]

即由更深现实结构 \(D\) 解释绝对 liveness \(L\)，而不是直接把 \(L\) 放入基本事实清单。

所以 Bricker 提供的是“可构造性先例”，暂时没有提供本项目需要的来源解释。

## 认识论类比

absolute actuality / moving spotlight 一类理论长期面临认识论压力：如果大量处于相似证据位置的观察者只有一个真正处于绝对 actual / present 位置，主体凭什么知道自己处在那个位置。

这一压力在绝对第一人称模型中也会出现，需要单独处理。
