# John Alton Christmann 2026 — Global subject pressure in nontheistic idealism

> 阅读状态：**full text accessible; core argument sections read**。
>
> 发表：*Religious Studies*, First View, published online 2026-07-07。
>
> DOI: `10.1017/S0034412526101681`。
>
> 项目地位：目前最直接命中 `SubjectiveArity → GlobalSubject` 的 contemporary argument 之一；但其结论严格依赖 Yetter-Chappell-style phenomenal-tapestry idealism，不能直接升级成 actuality-general SAP。

## 1. Target theory

Christmann 针对 Helen Yetter-Chappell 的 *The View from Everywhere* (2025)。该 theory 把 physical reality理解成一个 **phenomenal tapestry**：

- 所有 possible sensory perspectives的 phenomenal threads；
- property-binding relations；
- spatial / temporal phenomenal relations；
- unity-of-consciousness / co-consciousness relations；
- 整体形成一个 global experiential structure。

Yetter-Chappell允许三种 bearer reading：

1. Robust Mind：有一个 cosmic subject；
2. Thin Mind：experiences本质上被体验，因此有 experiencer，但 experiencer不是额外 ontology；
3. No Mind：允许 free-floating experience。

她偏向 Thin Mind。

Christmann 的目标是证明：这个 global tapestry 的内部要求会产生 **global subject pressure**。

---

## 2. Argument I — Thin Mind Dilemma

Thin Mind 的目标是同时保留：

\[
Experience\Rightarrow Experiencer
\]

又拒绝：

\[
Experiencer=AdditionalRobustEntity.
\]

但在 global tapestry 尺度上，Thin Mind 必须是：

\[
Experiencer(AllPossiblePhenomenalPerspectives).
\]

而这些 perspectives 被统一成一个 overarching experience。

Christmann 的压力可以重构为：

### TM1

若所有 tapestry experiences genuine 被一个 experiencer experienced，则该 experiencer具有 determinate global experiential scope。

### TM2

具有该 scope 的 experiencer已经是一个 non-trivial globally unifying subject，而不只是 grammatical / logical placeholder。

### TM3

若拒绝这种 subjecthood，则 Thin Mind 不再能作为 genuine experiencer承担其角色。

因此：

\[
\boxed{
ThinMind
\Rightarrow
GlobalSubject
\;|\;
FailureToBeGenuineExperiencer.
}
\]

这是一个真正的 **collapse argument**：不是从 priority monism直接 stipulate cosmic subject，而是尝试从 theory 自己对 global experience bearer 的承诺推出 subjecthood。

---

## 3. Argument II — Synchronic Pattern Problem

第二个 argument更重要，因为它不只问“谁体验”，还问 global experiential unity 的具体 pattern 为什么是这个 pattern。

phenomenal tapestry不是 undifferentiated fusion。它包含极其具体的：

- 哪些 threads co-conscious；
- 哪些 properties bind成一个 object；
- 哪些 spatial relations形成一个 world；
- 哪些 contents simultaneously co-present。

因此存在一个 synchronic explanandum：

\[
Pattern_{co-conscious}(t).
\]

Christmann 认为 laws of temporal evolution最多解释：

\[
State_t\to State_{t+1},
\]

却没有自动解释：

\[
Why\ this\ synchronic\ phenomenal\ unity\ at\ t?
\]

可选 grounds：

1. brute co-consciousness pattern；
2. laws somehow fully determine synchronic phenomenal structure；
3. one unified experiential act whose intentional content contains the co-present items。

Christmann 认为第三项解释力最好：

\[
\boxed{
GlobalCoConsciousPattern
\Rightarrow_{abductive}
UnifiedGlobalExperientialAct
\Rightarrow
GlobalSubject.
}
\]

其核心直觉：contents之所以以这一整体 pattern共同出现，是因为它们共同作为一个 subject 的 unified act 的 intentional contents。

---

## 4. 为什么这比 priority cosmopsychism 更重要

priority cosmopsychism的结构通常是：

\[
PriorityMonism+CosmosConscious\Rightarrow CosmicSubject.
\]

这里 subjecthood在 premise package中已经很重。

Christmann 尝试从一个较弱的 global phenomenal structure 出发：

\[
GlobalPhenomenalUnity+CoConsciousPattern
\]

然后推出：

\[
GlobalSubjectPressure.
\]

所以它提供了当前最接近 **independent SAP bridge** 的论证：

\[
\boxed{
GlobalExperientialUnity
\Rightarrow
GlobalSubjectPressure.
}
\]

这不是 simple stipulation。

---

## 5. 但它不是 general SAP theorem

其 antecedent极厚：

\[
PhysicalReality
=
OneGlobalPhenomenalTapestry.
\]

Whitehead-style plural subjective actuality没有承诺：

- 所有 actual occasions属于一个 single overarching experience；
- all perspectives被 one co-consciousness relation全局统一；
- world structure本身就是一个 experiential tapestry。

所以 Christmann 不能直接建立：

\[
SubjectiveArity\Rightarrow OneGlobalSubject.
\]

更准确是：

\[
\boxed{
GloballyUnifiedExperientialReality
\Rightarrow
GlobalSubjectPressure.
}
\]

这比 SAP 弱，但比此前的 priority-cosmopsychist construction更具 derivational value。

---

## 6. 对 `self` 的新价值

### A. 找到真正的 singularity witness candidate

此前 SAP 的 `one` 几乎总来自 priority monism。

Christmann 给了另一个来源：

\[
\boxed{GlobalExperientialUnity.}
\]

如果项目能独立建立 complete actuality具有一个 **single global co-conscious structure**，那么 global subject不再完全是额外 posit。

### B. 新的 Global-Unity Route

现在有一条新候选链：

\[
Actuality
\to
SubjectiveArity
\to
GlobalExperientialUnity
\to
GlobalSubject
\to
LocalAbsoluteLocus.
\]

其中此前缺失的是中间两步。

Christmann主要支持：

\[
GlobalExperientialUnity\to GlobalSubjectPressure.
\]

### C. CC1 candidate

若 `GlobalExperientialUnity` 可独立建立，它可能成为一个新的 completion witness：

\[
X=OneGlobalCoConsciousStructure.
\]

但当前 neutral / Whitehead-style plural theory完全可以否认 X。

因此 X 还不是 common explanandum。

---

## 7. 压力测试

### P1 — Tapestry Conditionality

论证只在 reality已经被理解成一个 global phenomenal tapestry 时启动。

所以不能从：

\[
Actuality
\]

直接跳到：

\[
GlobalSubject.
\]

### P2 — Unity Primitive Option

Christmann 倾向认为 brute global co-consciousness不令人满意，但“不令人满意”不是 contradiction。

理论可以接受：

\[
PrimitiveGlobalUnityRelation
\]

而不接受 robust subject，除非进一步证明 experiencer / subject是该 relation 的唯一可接受 ground。

### P3 — Intentionality Inflation

第二个 argument进一步使用 intentional act 来 ground specific pattern。

这可能从：

\[
Unity
\]

升级成：

\[
IntentionalSubjectUnity
\]

需要额外论证为什么 non-intentional structural grounds不能承担 pattern-selection work。

### P4 — Global subject is still not local absolute I

即使 Christmann成功：

\[
\exists!s_G\;GlobalSubject(s_G),
\]

仍然没有：

\[
\exists!E^*\;LocalAbsoluteLocus(E^*,s_G).
\]

他的 subject反而更像 cosmic / divine perceiver。

所以 B4/LAP 完全保留。

---

## 8. Current verdict

Christmann 2026 是本轮真正值得升级的文献。

它没有证明 general SAP：

\[
SubjectiveArity\not\Rightarrow OneGlobalSubject
\]

仍然成立。

但它第一次给出一个 serious conditional bridge：

\[
\boxed{
GlobalExperientialUnity
\Rightarrow
GlobalSubjectPressure.
}
\]

因此 `self` 现在的 singularity research 不应只搜 priority monism，还应专门检验：

\[
\boxed{
Does complete actuality have one global co-conscious / experiential unity structure?
}
\]

如果答案是肯定的，SAP第一次获得一个 non-stipulative入口。

如果答案是否定的，Whitehead/Lipman-style plural subjectivity继续阻断 global singleton。
