# Single Reality 仍不等于 Single Experiential Center

## 背景

Rafael Sorkin 的 Quantum Measure Theory 曾提出一种 realist histories 图景：现实由单一实际 history 描述。后续 co-event formulation 进一步允许把 actual reality 表达成一个 co-event / coarse-grained history；Henry Wilkes 的 evolving co-event scheme 又把 reality 按阶段展开。

这些路线和本项目很相关，因为它们提供比“许多可能分支都同等实际”更强的 actuality structure。

## 1. Single-history actuality

可以粗略写成：

\[
\exists !H^*\;Actual(H^*).
\]

这解决一种 world/history-level actuality：全部可能 histories 中只有一个 actual history，或者只有一个 actual co-event reality。

## 2. History-to-Center Gap

但一条 actual history 可以包含：

\[
E_1,E_2,\dots,E_n
\]

等多个意识事件。

因此：

\[
\boxed{\exists !H^*\not\Rightarrow\exists !E^*\;LIVE(E^*)}
\]

这和 Process-to-Center Gap 同构：

\[
\exists !G\not\Rightarrow\exists !E^*\;LIVE(E^*).
\]

世界级、历史级、过程级的唯一 actuality 都不会自动传递成第一人称中心级的唯一 actuality。

## 3. 更一般的层级错配

设 \(D^*\) 是某个唯一 global actual structure，而它映射到一组意识事件：

\[
M(D^*)\subseteq\mathcal E_C.
\]

只要：

\[
|M(D^*)|>1,
\]

就仍需要额外结构把一个事件提升成 absolute center。

因此得到更一般的工作原则：

\[
\boxed{\text{global uniqueness}\not\Rightarrow\text{experiential-center uniqueness}}
\]

这可以覆盖：

- one universe；
- one actual world；
- one history；
- one co-event reality；
- one fundamental process；
- one causal-set growth law。

## 4. 对项目的意义

正方以后不能只寻找一个“唯一的更大对象”。

一个合格机制必须让唯一性真正落到意识事件层：

\[
D\Longrightarrow\exists !E^*\;LIVE(E^*).
\]

并且这一映射不能通过 primitive pointer、gauge total order 或 standpoint-relative rule 偷偷完成。
