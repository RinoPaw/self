本文件测试 `research/arguments/history-actualization-exhaustion.md` 与 `history-actualization-partition.md` 是否遗漏成熟路线。

当前状态：**candidate / targeted source check**。

---

## 1. Relational Quantum Mechanics：没有形成第七类

RQM 是对 `R = Relational / Perspectival Actualization` 的非常强物理实例。

SEP 对其核心结构的表述非常直接：

- contingent physical variables 都是 relational；
- 一个变量取值总是相对于第二个 physical system；
- event 的 actualisation 本身也 relative to a system；
- 不存在 absolute state / absolute value / absolute event；
- 没有 God’s-eye universal perspective，甚至可以说不存在以绝对意义给出的 universal quantum state。

所以 RQM 可以写成：

\[
Actual(e,S),
\]

而非：

\[
Actual(e).
\]

这不是第七种 actualization，而是 `R` 的清晰实例。

### 对 self

RQM 把 `standpoint pluralism` 的逻辑结构直接带入物理：

\[
\text{real event actualization}
\]

可以成立，同时：

\[
\neg\exists\text{ global absolute actualization fact}.
\]

因此正方需要说明 first-person `LIVE simpliciter` 为什么不能像 quantum event actualization 一样彻底 relationalize。

### 新压力：relativity iteration

Riedel 2024 指出 relationality 是否继续迭代是 RQM 的重要难题：

\[
A\text{ relative to }B
\]

本身是否又只相对于某个 perspective 成立？

这和 `self` 里“是否存在不可继续相对化层”高度同构，值得以后专门追踪。

## 2. Process ontology：挑战 history-level A1，但没有逃出 actualization-level taxonomy

Whitehead 式 process metaphysics 不把 enduring substance 或 complete history 当作最基本存在。

其基本单位是：

\[
\text{actual occasion},
\]

即一次 process of becoming / concrescence。

因此如果强制把：

\[
\Omega_D=\{\text{complete histories}\}
\]

当作所有理论都必须接受的基础对象，分类会过窄。

### 修正

把 schema 的输入一般化成：

\[
\Omega_D^{(L)}
\]

其中 `L` 是当前 actualization level：

- complete histories；
- branches；
- trajectories；
- events / actual occasions；
- first-person centers。

随后仍然问：

- 当前层是否存在 determinate global actuality？
- 是否 singleton？
- singleton 是否由 `D` 推出、由 extra seed 指定、或由 stochastic process realization？
- 若拒绝 global actuality，是 plural、relational 还是 indeterminate？

因此 process ontology 不构成第七类，而是要求：

\[
\boxed{\text{apply the partition at the right ontological level}}
\]

## 3. Modal interpretations：`Z/C` 边界案例

Modal interpretations of quantum mechanics 明确区分：

- dynamical state：给出 possibilities / probabilities；
- value state：表示 actually the case 的 definite-valued properties。

不同 modal interpretations 再提供 actualization rule / definite-value ascription rule。

这类理论正好说明 `Z` 与 `C` 为什么是解释架构分类，而非绝对 ontology natural kinds。

若 actual value state 是额外 actual state：

\[
Route\approx Z.
\]

若其演化由非平凡 probabilistic actualization dynamics 控制：

\[
Route\approx C.
\]

若 dynamical state + rule 已唯一推出 definite state：

\[
Route\approx S.
\]

所以同一个理论传统可以因 actualization dynamics 的不同落入不同路线。

## 4. Metaphysical indeterminacy：确认 `I` 必须保留

J. R. G. Williams 的 `Multiple Actualities` 以及 Barnes–Williams 的 metaphysical indeterminacy 理论说明：

\[
\text{there is an actual matter}
\]

不必推出：

\[
\text{there is one fully determinate actual configuration}.
\]

可以存在 primitive metaphysical indeterminacy，或以 multiple actualities 的 modal framework 表达 ontic vagueness。

因此 `I` 不是为了逻辑完整而虚构出来的空盒子；它有成熟形而上学实例。

### 对 self

absolute-first-person 正方除了证明 uniqueness，还隐含承担：

\[
\boxed{\text{Determinacy Requirement}}
\]

即为什么 absolute first-person status 必须完全 determinate。

这在此前没有被单独列为负担。

## 5. 当前没有找到的第七类

本轮重点找了：

1. actuality 有“程度”而非 binary / relational / indeterminate；
2. process ontology 完全逃离 actualization partition；
3. quantum-relational ontology 既非 `R` 也非 `I`；
4. modal actualization rule 构成独立 family。

目前没有找到足够成熟且真正不能映射到 `S/Z/C/P/R/I` 的路线。

特别是：

- RQM → `R`；
- modal interpretations → `S/Z/C` 的边界组合；
- metaphysical indeterminacy → `I`；
- Whitehead/process → 改变分类层级，不改变 partition form。

因此当前判断仍是：

\[
\boxed{S|Z|C|P|R|I}
\]

是一个有实际文献覆盖的 **near-exhaustive actualization architecture**。

---

## 6. schema 的重要修正

不再固定写：

\[
\Omega_D=\text{complete histories}.
\]

更一般地写：

\[
\Omega_D^{(L)}=\text{candidate actualia at ontological level }L.
\]

然后在每个 level 分别分类：

\[
Route_L\in\{S,Z,C,P,R,I\}.
\]

对 `self` 至少需要：

\[
Route_{universe},
\qquad
Route_{history/branch},
\qquad
Route_{first-person}.
\]

不能把其中任何两个自动合并。
