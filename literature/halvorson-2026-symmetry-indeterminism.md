# Halvorson–Manchak–Weatherall 2026 — symmetry, indeterminism, and non-haecceitistic extensions

> 阅读状态：**publisher full-text HTML excerpts / core formal sections read**；Princeton publication metadata cross-check。
>
> Hans Halvorson, J. B. Manchak, James Owen Weatherall, “Deterministic Theories”, *Philosophy and Phenomenological Research* 113(1), 2026, 134–152. DOI `10.1111/phpr.70122`。
>
> 项目用途：给 `Stochastic / Spontaneous Absolute-Orientation Law` 提供一个关键 formal precedent：**对称 initial structure 可以具有非对称 extensions，而无需先把差异解释成 primitive haecceities。**

## 1. Core distinction

Halvorson–Manchak–Weatherall区分多种 determinism notions，尤其强调 formal criterion `D3`：roughly，一个 initial segment 的 symmetries 是否都能延伸到完整 model 的 symmetries。

设 initial structure 为：

\[
I.
\]

完整 model 为：

\[
M\supset I.
\]

若存在：

\[
f\in Aut(I)
\]

但没有：

\[
\hat f\in Aut(M)
\]

使 \(\hat f|_I=f\)，那么 initial symmetry 没有延伸到 full model。

这就是一种严格 formal 的 indeterminism / underdetermination signal。

---

## 2. Toy structure：symmetric beginning, asymmetric completion

论文使用非常简单的 models 来说明：initial conditions 可完全对称，而 later/full structure加入一个 relation / predicate后降低 symmetry。

例如一个 two-element initial set：

\[
I=\{a,b\}
\]

允许 swap：

\[
a\leftrightarrow b.
\]

完整 structure加入 unary predicate \(P\)，并规定 exactly one object is \(P\)：

\[
\exists!x\;P(x).
\]

于是 full model 不再保留 initial swap symmetry。

重要的是，作者认为理解这种 indeterminism **不需要先诉诸 haecceitistic differences between worlds**。他们特别强调：即使相关 complete models up to isomorphism 看起来只有一个 qualitative type，仍然可以通过 initial symmetries是否具有 full-model extensions来刻画 indeterminism。

因此：

\[
\boxed{
SymmetricInitialState
+
AsymmetricCompletion
}
\]

不是自动等于：

\[
\boxed{PrimitiveHaecceitisticWorldDifference.}
\]

---

## 3. 对 absolute-orientation model 的直接映射

令 neutral / pre-orientation base：

\[
R.
\]

其中 local subjects：

\[
S(R)=\{E_1,\ldots,E_n\}.
\]

若 \(R\) 有 automorphism：

\[
\phi(E_i)=E_j,
\]

此前 deterministic structural PLP 要求从 \(R\) 自身 canonical 地挑一个 winner，因此失败于 symmetry。

Halvorson-style template允许另一种 architecture：

\[
R
\subset
\Omega,
\]

其中完整 structure新增一个 unary/relational role：

\[
Absolute(E).
\]

并满足：

\[
\exists!E^*\;Absolute(E^*).
\]

于是：

\[
Aut(R)
\not\subseteq
Aut(\Omega).
\]

即 complete actuality 本身是 symmetry-broken extension。

这给：

\[
\boxed{
BaseSymmetry
\not\Rightarrow
CompletedRealityMustRemainSymmetric.
}
\]

所以 perfect duplication只阻止 **canonical deterministic selection from the base**；它不阻止 law-governed asymmetric completion。

---

## 4. Why this matters for anti-haecceitism

此前 SAOL 有一个过粗 fork：

1. `A wins` 与 `B wins` 是 genuinely distinct token-worlds → haecceitistic pressure；
2. quotient automorphic outcomes → only one outcome type → token-level chance消失。

Halvorson-style formalism打开第三种描述：

### H3 — extension-relative symmetry breaking

不把 metaphysical content理解成两个带 primitive names 的 worlds，而看：

\[
\boxed{
\text{which symmetries of }R\text{ extend to the completed structure?}
}
\]

完整 model可以只有一个 isomorphism type，同时 initial-state symmetry仍无法唯一延伸。

因此：

\[
\boxed{
AntiHaecceitism
+
SymmetryBreakingCompletion
}
\]

至少在 formal level coherent。

这不直接证明 objective chance 已经定义完成；但它显著削弱：

> any asymmetric absolute-role outcome must be primitive token haecceitism.

---

## 5. Static world-counting is the wrong diagnostic

Halvorson等人的一个重要 methodology point：determinism不应只通过“有几个 possible worlds / model isomorphism classes”静态计数。

同一个 model up to isomorphism 仍可能体现：

\[
\boxed{
initial\ symmetry\ does\ not\ determine\ its\ later\ extension.
}
\]

对项目而言，这意味着不能只问：

> `Absolute(E_A)` 与 `Absolute(E_B)` 是不是两个 non-isomorphic worlds？

还应问：

> neutral base中的 subject permutation，是否能被唯一延伸到 complete centered actuality？

如果不能，则有真实的 symmetry-breaking / indeterministic structure，即使不存在 primitive cross-world labels。

## 6. What Halvorson does **not** give

这篇文章不是 first-person metaphysics，也没有：

\[
AbsoluteOrientation.
\]

它只给 formal lesson：

\[
\boxed{
SymmetryBreakingExtension
\text{ need not be analyzed in haecceitistic possible-world terms}.
}
\]

它没有回答：

1. 为什么 complete actuality必须新增一个 root；
2. 为什么 exactly-one；
3. 为什么该 root具有 first-person semantics；
4. 是否存在 objective chance distribution over extensions；
5. selected subject 是否能知道其 status。

所以它是 **architecture support**，不是 evidence for absolute first person。

## 7. Relation to spontaneous symmetry breaking

Liu 2003 对 classical spontaneous symmetry breaking + chance 提供邻近资源：symmetric laws / setup可以有 symmetry-related asymmetric realizations，并讨论何时可以把实际 breaking理解成 chance、何时不同 breakings可有 equal probability。

这提示项目必须分开：

\[
\boxed{
Symmetry
\neq
Probability.
}
\]

从 exact symmetry最多先得到：若存在 objective chance measure且 law尊重 symmetry，则 symmetry-related outcomes应受 covariance/equal-weight约束；**不能只凭 symmetry 自己就推出 uniform chance**。

因此 absolute-orientation law若使用 stochastic symmetry breaking，需要独立：

- outcome space；
- chance measure / dynamics；
- permutation covariance。

## 8. Project verdict

Halvorson 2026 给 SAOL 一个真正重要的新 opening：

\[
\boxed{
ExactBaseSymmetry
\not\Rightarrow
NoAntiHaecceitisticAsymmetricCompletion.
}
\]

于是原先：

\[
DeterministicSelector\text{ fails}
\Rightarrow
HaecceitisticLottery\text{ or quotient}
\]

的二叉不完备。

现在至少三叉：

\[
\boxed{
H1:\ TokenHaecceitisticChance
\;|\;
H2:\ QuotientOutcome
\;|\;
H3:\ StructuralSymmetryBreakingExtension.
}
\]

`H3` 是目前最值得继续开发的 anti-haecceitist nomological PLP architecture。

但最终核心 burden仍是：

\[
\boxed{
Why\ should\ the\ symmetry\!\!\text{-}\!broken\ role\ be\ AbsoluteI\ rather\ than\ a\ merely\ marked\ node?
}
\]
