## 1. Target: phenomenal / subject overlap

Mørch讨论的核心 overlap 是：一个 unified conscious subject 的部分或较小系统本身也构成 unified conscious subject，并且二者在 phenomenal constitution 上发生重叠。

必须区分：

\[
PhysicalOverlap
\neq
PhenomenalOverlap.
\]

material / spatial parts 可以 overlap，而 token experiences / phenomenal fields 未必共享。

---

## 2. Two subject ontologies

Mørch把 subject theories分成两类。

### 2.1 Substantive subject view

subject 是独立于 experiences 的 entity / substance / container。

于是同一个 token experience原则上可以同时 inhere in 两个不同 subjects：

\[
Experience(e)\land In(e,S_1)\land In(e,S_2).
\]

因此：

\[
\boxed{SubstantiveSubject\;\not\Rightarrow\;NoOverlap.}
\]

Mørch 的反对主要转成 parsimony：若没有独立理由，同时再 posit overlapping substantive subjects / extra ownership relations 会增加本体负担。

### 2.2 Deflationary bundle view

subject 不额外存在，而由一束 experiences / contents 及其 unity relation 构成。

Mørch认为最可信的定义不是 mere internal unity，而是：

\[
Subject(B)
\iff
Unified(B)
\land
ExclusivelyBounded(B).
\]

其中：

\[
ExclusivelyBounded(B)
\]

要求 B 内 experiences彼此 unified，同时不再与 B 外其他 experiences属于同一个相关 unity domain。

---

## 3. Core contradiction

设大 subject：

\[
S_1=ABC.
\]

较小 overlapping subject：

\[
S_2=AB.
\]

若 `ABC` 是一个 subject，则 A/B 必须与 C unified：

\[
U(AB,C).
\]

若 `AB` 同时是一个 independently bounded subject，则 A/B 又必须不与 C unified：

\[
\neg U(AB,C).
\]

于是：

\[
\boxed{U(AB,C)\land\neg U(AB,C)}.
\]

因此在 **single-unity-relation + exclusive-boundary bundle view** 下：

\[
\boxed{PhenomenalSubjectOverlap\Rightarrow\bot.}
\]

这是真正的 contradiction，而不是单纯直觉不适。

---

## 4. Why the result is conditional

Mørch 自己讨论两条 escape。

### Escape A — multiple unity relations

令大 subject由 \(U_1\) unified，小 subject由不同的 \(U_2\) unified。

逻辑矛盾消失：

\[
U_1(AB,C)
\land
\neg U_2(AB,C).
\]

Mørch 的反对是我们没有独立 phenomenological reason posit 多种 qualitatively different unity relations；因此该 escape 被判为不经济，而不是逻辑不可能。

### Escape B — drop exclusive boundedness

只定义：

\[
Subject(B)\iff Unified(B).
\]

则 overlap 也不再矛盾。

代价是：一个大 unified field 的大量 proper subsets 都可能成为 subjects，产生大量 nested / overlapping subjects。

Mørch认为 unified + exclusively bounded bundle更接近 minimally sufficient subject criterion，但这里仍有 substantive metaphysical disagreement。

所以最准确结果是：

\[
\boxed{
DeflationaryBundle
+
ExclusiveBoundedness
+
SingleUnityType
\Rightarrow
NoPhenomenalOverlap.
}
\]

而不是无条件：

\[
\boxed{Consciousness\Rightarrow NoOverlap.}
\]

---

## 5. Goff / Roelofs counter-position

Goff & Roelofs 明确 defend **Weak Sharing**：

\[
\boxed{
OneTokenExperience(e)
\text{ may belong to }
S_1\neq S_2
}
\]

当两个 subjects mereologically overlap / one contains the other 时，single token phenomenal state原则上可 shared。

他们的目标主要是 coherence defense：有 independent reason posit sharing 时，不应因 privacy / exclusivity intuitions 就先验排除。

这说明 Mørch 与 Goff/Roelofs 的真正分歧深入到 subject individuation：

\[
\boxed{
ExclusiveBoundarySubjecthood
\quad vs\quad
OverlapTolerantSubjecthood.
}
\]

而不是关于一个已共同承认的 subject ontology 得出不同结论。

---

## 6. Recent distinction: phenomenal vs physical overlap

近期讨论进一步强调：Mørch 即使成功禁止 **phenomenal token overlap**，也不能自动禁止 physical / spatial overlapping subjects。

一个较小 subject可以拥有自己的 token stream，同时其 contents以 copy / transfer / grounding 方式贡献给较大的 subject，而不共享 numerically same token experiences。

因此：

\[
\boxed{
NoPhenomenalOverlap
\not\Rightarrow
NoNestedPhysicalSubjects.
}
\]

这对 cosmopsychism / monadic models很重要。

---

## 7. Impact on Roelofs continuism

Continuism最危险的 reading 是：

\[
LocalSubjectField
\subset
GlobalPhenomenalField
\]

且 local/global literally share token experiences。

在 Mørch package 下这会受到直接压力。

但 continuism仍至少有两种回应：

1. **field-first / non-exclusive subject ontology**：接受 local subject不是 exclusively bounded bundle；
2. **one field, informational agents**：把 ordinary persons主要看作 informationally bounded regions / agents，而不把每个 region都定义成独立 phenomenally exclusive subject。

所以：

\[
\boxed{Morch\;pressures\;Continuism,\;but\;does\;not\;refute\;GEU.}
\]

甚至在强 anti-overlap reading 下，也仍可能有：

\[
OneGlobalPhenomenalField
\]

而 ordinary local subjects以 non-overlapping derivative streams / informational structures实现。

---

## 8. Impact on Osborn / Subject Universalism

Strict Subject Universalism：

\[
\forall\Gamma\subseteq Subjects,
\quad Subject(\bigoplus\Gamma)
\]

天然产生大量 overlapping subjects。

因此如果接受 Mørch 的 preferred deflationary-exclusive subject ontology：

\[
\boxed{SubjectUniversalism\text{ is strongly incompatible}.}
\]

但 universalist可以改采 substantive / non-exclusive subject ontology，承认 overlap并支付 parsimony / many-subjects cost。

所以真正结果是一个 **Subject-Ontology Fork**：

\[
\boxed{
ExclusiveBundle
\Rightarrow
NoOverlap
}
\]

versus

\[
\boxed{
Universalism/Sharing
\Rightarrow
RejectExclusiveBoundary\;or\;adoptSubstantiveSubjects.
}
\]

---

## 9. Consequence for Global Closure Package

旧 GCP：

\[
GCP=SU+MF+FC+EIP.
\]

Mørch表明还必须显式加入一个 subject-ontology choice：

\[
SO\in\{ExclusiveBundle,OverlapTolerant\}.
\]

若：

\[
SO=ExclusiveBundle,
\]

则 SU/EIP 的 literal overlap reading失败。

若：

\[
SO=OverlapTolerant,
\]

GCP保持 coherent，但承担 many-subject / parsimony / phenomenology burden。

因此 GCP 不是被击倒，而是多了一项真实成本：

\[
\boxed{GlobalClosure\;requires\;an\;explicit\;theory\;of\;subject\;boundaries.}
\]

---

## 10. Project verdict

Mørch 是 high-value counterpressure，但没有关闭 GEUP。

她最强的贡献是把 overlap debate 从 vague intuition 升级成一个条件性定理：

\[
\boxed{
DeflationaryBundle
+
ExclusiveBoundedness
+
OneUnityRelation
\Rightarrow
NoOverlap.
}
\]

因此：

- Osborn universalism不能再把 overlap当作无成本；
- Roelofs continuism必须明确 local subject ontology；
- Goff/Roelofs Weak Sharing成为直接竞争理论；
- `GEU` 本身仍未被排除；
- `GlobalSubject` 与 `local subject boundaries` 必须分开记账。

当前不改变：

\[
\boxed{GEUP\text{ serious but unproven}.}
\]
