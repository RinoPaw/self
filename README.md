# self

关于**第一人称、绝对第一人称、意识、时间与现实结构**的个人哲学研究仓库。

这里暂时把一个核心直觉当作待研究假说，而不是已经证明的结论：

> 普通第一人称性可能属于所有意识；但完整现实中是否还存在一个不可复制、不可进一步相对化的“绝对第一人称”或“绝对当前经验中心”，仍需要论证。

当前研究重点：

- 严格区分普通第一人称与“绝对第一人称”。
- 研究第一人称不对称究竟只是现象学结构，还是对应客观的本体论不对称。
- 同时处理“为什么是这个主体”与“为什么是这个时刻”的 I–NOW 不对称。
- 检查相对论、多元宇宙、完全复制、对称性等情形下理论是否仍然自洽。
- 探索完整现实结构是否可能唯一决定一条绝对经验轨迹，而不把绝对第一人称当作可任意切换的额外标签。

详细研究笔记见 [`docs/absolute-first-person.md`](docs/absolute-first-person.md)。
