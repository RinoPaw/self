# self

关于**第一人称、绝对第一人称、I–NOW 与现实结构**的个人哲学研究仓库。

最初的问题是：

> 为什么偏偏是这个人、这个时代、这个当前经验？

经过 self-location、symmetry、fragmentalism、actuality、subject unity、Universal-I、presence 与 completion 等路线的压力测试，当前问题已经收缩为：

\[
\boxed{\text{Does actuality itself have irreducible first-person arity?}}
\]

## 当前结论

项目没有证明 absolute first-person 存在，也没有证明它不存在。

目前最公平的竞争是：

\[
\boxed{\text{Neutral Actuality}\quad|\quad\text{Intrinsically Centered Actuality}}
\]

- **Neutral Actuality**：现实完整地成立，但 actuality 本身没有唯一第一人称方向；多个主体仍可 genuinely conscious，并拥有真实的 local first-person organization。
- **Centered Actuality**：现实的实际成立方式本身就带有一个 irreducible first-person opening；这不是事后给某个主体贴标签，而是 complete actuality 的 constitutive structure。

当前普通 phenomenology、presence、semantics、structural dominance、self-manifestation、causal unity 与 ordinary evidence 都没有迫使我们选择 Centered Actuality。因此当前仍是 **Completion Underdetermination**，且 Neutral Actuality 作为较弱 completion principle 保留 provisional abductive lead。

这不是对 centered view 的 refutation。

## 依赖关系

若先接受 Centered Actuality：

\[
\text{Centered Actuality}
\Rightarrow
\text{At Least One Opening}
\]

再加上 `OneWorld + NonFragmentation + First-Person Non-Compossibility`：

\[
\Rightarrow \text{Exactly One Irreducible Opening}
\]

再加入 subject-ontology premises，才进入：

\[
\text{Selective Local Opening}\quad|\quad\text{Universal-I}
\]

最后才是 diachronic opening path / continuation dynamics。

所以当前真正最上游的问题只有一个：**为什么 reality 的 actuality 必须是 centered，而不能是 neutral？**

## 当前四个理论位置

- **M0 — Neutral Actuality / Neutral Relationalism**：无 irreducible simpliciter first-person actuality。
- **M1 — Fragmented Pluralism**：多个 irreducible centers，通过 fragmentation / many-centred metaphysics 保留 plurality。
- **M2 — Universal-I**：一个 irreducible subject/center 覆盖全部或广泛 experiences。
- **M3 — Selective Centered Opening**：一个 local person-stage/path 承担 absolute opening，其他 subjects 仍 genuinely conscious。

在 `OneWorld + NonFragmentation + CenteredActuality` 条件下，主要内部竞争缩成 M2 vs M3；但在最上游，M0 仍完全 live。

## 已关闭路线

除非新文献提供比现有结果更强的资源，以下路线默认不再重复：structural dominance / causal centrality / informational maximum → privilege；ordinary phenomenology/mineness → global absolute orientation；bare actuality thickness → first-person arity；ordinary temporal phenomenology → `PresenceSimpliciter`；self-manifestation bottleneck → one absolute local locus；global subject → unique local absolute locus；primitive Universal-I ownership without assignment principle；exact-one 作为 unitary reality 下的独立 brute selector。

重新打开 absolute axis，需要至少一种真正的新资源：independent completion witness、neutral incoherence theorem、privilege-sensitive evidence channel、genuine primitive-replacement theorem、进入 common core 的新 global physics/metaphysics structure，或能实质改变 locality 的 subject-identity theorem。
