# self

关于**第一人称、绝对第一人称、I–NOW 与现实结构**的个人哲学研究仓库。

最初的问题是：

> 为什么偏偏是这个人、这个时代、这个当前经验？

当前研究没有证明 absolute first-person 存在，也没有证明它不存在。

## 当前 theory space

最新结果要求至少区分三种 completion architecture：

\[
\boxed{
\text{Subject-Neutral Actuality}
\quad|\quad
\text{Plural First-Person Actuality}
\quad|\quad
\text{Singular Centered Actuality}.
}
\]

- **C0 — Subject-Neutral Actuality**：现实 genuinely actual，但 actuality 本身没有 irreducible first-person obtaining mode。
- **C1 — Plural First-Person Actuality**：现实包含多个 irreducible first-person obtaining modes，但没有一个 globally privileged singleton。
- **C2 — Singular Centered Actuality**：complete actuality 本身具有一个 unique global first-person opening / orientation。

项目原始 absolute-first-person target 是 C2。

## 最新突破：plural-opening countermodel survives

已经构造：

\[
\boxed{
OneActuality
+PluralIrreducibleFirstPersonModes
+ModePreservingGlobalCoherence.
}
\]

这个模型当前没有被迫：

- 降格成 third-person meta-facts；
- 分裂成 many actual worlds；
- 产生 ordinary formal contradiction。

它明确拒绝 Christian List-style **Single-Perspective Closure**：多个 genuine first-person facts 若 globally compossible，必须能从同一个 perspective jointly obtain。

因此它在 List/Fine/Lipman taxonomy 中属于 one-world fragmentalist / standpoint-pluralist horn，而不是 List quadrilemma 的反例。

这使 singularity 的真正问题收缩为：

\[
\boxed{
Why\ must\ one\ actuality\ satisfy\ Single\!\!\text{-}\!Perspective\ Closure?
}
\]

## 当前 exact-one 状态

保留条件式：

\[
ALO+LE+SPC+NF_{SPC}
\Rightarrow
ExactlyOneOpening.
\]

其中：

- `ALO`：至少一个 irreducible opening；
- `LE`：一个 perspective 不能同时完整处于 mutually exclusive states；
- `SPC`：globally compossible first-person facts 必须 one-perspective-co-obtainable；
- `NF_SPC`：actuality 满足这种 compossibility standard。

所以不能再说：

> one world / unitary reality 本身解决 uniqueness。

exact-one 现在依赖独立 defend `SPC`。

## Evidence 标准也升级了

一个支持 C2 的新 datum `X`，仅满足：

\[
C2\models X,
\qquad C0\not\models X
\]

远远不够。

必须继续检查 C1 能否解释它。

当前要求：

\[
\boxed{
Independent(X)
\land NaturalFit(C2,X)
\land \neg CheapNonSingularAccommodation(X).
}
\]

也就是：subject-neutral 与 plural-first-person 两类 non-singular rivals 都不能低成本吸收 `X`，它才真正支持 unique absolute center。

## 当前结论

目前 ordinary phenomenology、presence、de se、actuality thickness、structural/causal centrality、self-manifestation 等都没有做到这一点。

所以：

\[
\boxed{UniqueAbsoluteFirstPerson\text{ remains unestablished}.}
\]

而当前 live competitor space 是：

\[
\boxed{C0\quad|\quad C1\quad|\quad C2.}
\]
