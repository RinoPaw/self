# self

关于**第一人称、绝对第一人称、意识、I–NOW 与现实结构**的个人哲学研究仓库。

核心假说保持开放：多个主体都可以 genuinely conscious，并拥有 ordinary first-person phenomenology；完整现实中是否还存在一个不可继续相对化、全局唯一的 **absolute first-person / absolute I–NOW orientation**，仍未证明。

最新 frontier：[`synthesis/frontier-2026-10-05-presence-route-closure.md`](synthesis/frontier-2026-10-05-presence-route-closure.md)。

## 当前研究已经走到哪里

最初问题：

> 为什么偏偏是这个人、这个时代、这个当前经验？

经过 self-location、symmetry、duplication、process、grounding、fragmentalism、actuality、presence、subject unity、Universal-I 与 completion 压力测试后，问题已经收缩成：

\[
\boxed{
\text{Does actuality itself have irreducible first-person arity?}
}
\]

ordinary first-person axis 与 absolute axis 现在严格分开：

\[
\boxed{
Consciousness
\neq
LocalFirstPersonOrganization
\neq
PhenomenalMineness
\neq
StrongIrreducibleFPFact
\neq
AbsolutePrivilege.
}
\]

因此：

\[
FirstPersonalGivenness
\not\Rightarrow
AbsoluteOrientation.
\]

## 当前两个 strongest actuality packages

### Neutral Actuality

\[
\boxed{N\text{-}ACT=K+A_N}
\]

`K` 可以已经包含 one coherent actual world、多个 genuine conscious subjects、local first-person organization、phenomenal mineness、de se cognition，以及 independently motivated temporal/perspectival structure。

actuality 本身保持 first-person-neutral。

见：[`research/models/neutral-actuality-core.md`](research/models/neutral-actuality-core.md)。

### Constitutive Role-First Centered Actuality

\[
\boxed{C\text{-}ACT=K+\Omega[R;E^*]}
\]

这里 `E*` 不是先独立存在、再被贴上 absolute 标签的 token；orientation 与 locus 共同 individuate complete centered totality。`WorldActuality = AbsoluteI = AbsoluteNOW = Ω` 被理解成一个 centered actuality kind 的不同 aspects。

见：[`research/models/role-first-absolute-opening.md`](research/models/role-first-absolute-opening.md)。

所以当前真正 endgame 是：

\[
\boxed{
NeutralCompletion
\quad vs\quad
CenteredCompletion.
}
\]

## Completion Fork

Neutral side：

\[
\boxed{C_N:\quad K\text{ can constitute complete actual reality}.}
\]

Centered side：

\[
\boxed{C_C:\quad K\text{ is incomplete unless actuality is intrinsically centered}.}
\]

centered side要取得独立优势，至少需要一项：

1. **CC1 — Independent completion witness**；
2. **CC2 — Neutral actuality incoherence**；
3. **CC3 — Genuine primitive replacement advantage**。

截至目前：

\[
\boxed{CC1\text{ 未找到 surviving witness}}
\]

\[
\boxed{CC2\text{ 未找到 contradiction}}
\]

\[
\boxed{CC3\text{ 未形成 decisive replacement win}}.
\]

因此当前触发：

\[
\boxed{CompletionUnderdetermination.}
\]

\boxed{

## 当前 verdict

现在最公平的竞争仍是：

\[
\boxed{
\text{actuality is intrinsically neutral}
\quad vs\quad
\text{actuality is intrinsically first-personally oriented}.}
\]

现有 evidence / common explananda 尚未裁决这个 primitive-kind difference。

Centered Completion 已经拥有一个干净、非 pointer 式的 ontology；但它是更强结构承诺，而目前没有 independent payoff。因此当前 provisional ranking 是：

\[
\boxed{N\text{-}ACT/N\text{-}W^+\text{ retains a prima facie abductive lead}.}
\]

这个结论不是：

\[
\neg AbsoluteOrientation.
\]

当前 strongest positive result 是：

\[
\boxed{
\text{if actuality is intrinsically centered, unitary reality can derive exactly one irreducible opening}.}
\]

当前 strongest negative/comparative result 是：

\[
\boxed{
\text{ordinary phenomenology, presence, semantics, structure, and current evidence do not force that centered actuality premise}.}
\]

## Research stop condition

absolute axis 现在处于真实 stop condition。只有出现以下新资源时值得重开：

- **new independent completion witness**；
- **neutral incoherence theorem**；
- **privilege-sensitive evidence channel**；
- **genuine primitive replacement theorem**；
- **new global physics/metaphysics structure**，独立进入 common core 并推出 first-person arity；
- **新的 subject-identity theorem**，实质改变 Locality / Universal-I 的比较。

重复 ordinary presence、selector、structural maxima、self-manifestation、generic causal centrality、death transfer、bare duplicate identity、generic tense semantics 不再算 frontier progress。

详见：[`synthesis/handoff-2026-10-05-terminal-frontier.md`](synthesis/handoff-2026-10-05-terminal-frontier.md)。
