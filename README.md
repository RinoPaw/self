# self

关于**第一人称、绝对第一人称、I–NOW 与现实结构**的个人哲学研究仓库。

最初的问题是：

> 为什么偏偏是这个人、这个时代、这个当前经验？

当前最上游问题已经收缩为：

\[
\boxed{\text{Does actuality itself have irreducible first-person arity?}}
\]

## 当前结论

项目没有证明 absolute first-person 存在，也没有证明它不存在。

目前最公平的竞争仍是：

\[
\boxed{\text{Neutral Actuality}\quad|\quad\text{Intrinsically Centered Actuality}}
\]

- **Neutral Actuality**：现实完整成立，多个主体 genuinely conscious，并拥有真实 local first-person structure；actuality 本身不含唯一 global first-person direction。
- **Centered Actuality**：现实的实际成立方式本身具有 irreducible first-person opening；它是 complete actuality 的 constitutive structure。

普通 phenomenology、presence、semantics、structural dominance、self-manifestation、causal unity 与 ordinary evidence 均未迫使我们选择 Centered Actuality。因此当前仍是 **Completion Underdetermination**，Neutral 保留 provisional abductive lead。

### 2026-10-05 最新修正

此前 `Unitary Singularity Lemma` 被写成 centered horn 内最强正面结果。重新审计后：

\[
ALO+OneWorld+NF+FPNC\Rightarrow ExactlyOneOpening
\]

的条件式仍有效，但 `FPNC`（不同 irreducible first-person openings 不能共同成立）不是免费前提。它依赖一个 substantive first-person compossibility 标准，目前需要独立论证。

所以：

\[
\boxed{Singularity\text{ is reopened at FPNC/LFPC}.}
\]

同时，旧 completion witness 标准也被加强。以后：

\[
N\not\models X
\]

不够；必须进一步问 Neutral 能否在**仍保持 genuinely neutral** 的情况下低成本解释 `X`。新的核心测试是：

\[
\boxed{
Independent(X)
\land NaturalFit(C,X)
\land \neg CheapNeutralAccommodation(N,X).
}
\]

## 当前依赖关系

若先接受 Centered Actuality：

\[
CenteredActuality\Rightarrow AtLeastOneOpening.
\]

要进一步得到 exactly-one，目前还需要：

\[
FPNC/LFPC+\text{an independently defended unity/compossibility criterion}.
\]

只有 singularity 真正建立后，才进入：

\[
SelectiveLocalOpening\quad|\quad UniversalI
\]

与 diachronic opening path。

## 当前理论空间

至少区分：

- **M0 — Neutral Actuality**：actuality 无 irreducible global first-person arity。
- **M1 — Plural Subject/Perspective-Bearing Actuality**：perspectival/subjective obtaining 可以 fundamental，但不形成唯一 privileged singleton。
- **M2 — Universal-I**：一个 irreducible subject/center 覆盖全部或广泛 experiences。
- **M3 — Selective Centered Opening**：一个 local stage/path 承担 absolute opening，其他 subjects 仍 genuinely conscious。

这意味着即使未来证明 actuality intrinsically perspectival，也仍不能跳过 singularity 与 absoluteness。

## 默认关闭路线

除非产生新类型结果，默认不再重复：structural/causal/informational winner → privilege；ordinary phenomenology/mineness → absolute status；ordinary temporal phenomenology → `PresenceSimpliciter`；bare actuality thickness → first-person arity；self-manifestation bottleneck → one locus；generic global subject；primitive assignment；death-transfer speculation。

当前真正高价值的两刀是：

1. 独立建立或击穿 `FPNC/LFPC`；
2. 找到一个通过 **Neutral Accommodation Test** 的 completion discriminator。
